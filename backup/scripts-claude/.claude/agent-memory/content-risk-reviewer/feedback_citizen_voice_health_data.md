市民の声（📝市民意見リスト／`03_themes/_citizen_voice/*.md`）を対外発信に引用するときの2つのハードルール。

**ルール1: 病歴・受診歴は原則そのまま載せない。**
「乳がん検診で要精密検査になった」「◯◯で通院している」等は個人情報保護法の**要配慮個人情報（病歴）**にあたる。氏名・地区・年代を伏せても、本人は確実に自分だと分かり、家族・職場・かかりつけ医など周囲も識別しうる。プライバシー侵害の成否は「一般大衆が特定できるか」ではなく「特定の者との結びつきを認識できる者がいるか」で見るのが安全側。政策の論点（例：市外のかかりつけ病院で市の検診を受けられるようにしてほしい）は病歴なしで成立するので、病歴は落として「市外の医療機関にかかっている方からの声」程度に丸める。

**ルール2: 原典にない属性を足さない。**
「平日に働いていて集団検診に行けない」等を説明として付け足すと、実在の個人にありもしない属性を付与することになる（[[feedback-no-fabricated-stories]] の対象でもある）。一般論として書くなら、引用者の描写と明確に切り離した独立段落にする。

**Why:** 2026-08-18 朝便SNS（がん撲滅キャンペーン／大腸がん検診）のレビューで両方を検出。ご意見箱フォームの利用目的に「公表可」が明記されているか未確認のまま、病歴を含む声を引用しようとしていた。

**How to apply:** Axis 1（個人情報）で市民の声引用を見たら、必ず `03_themes/_citizen_voice/` の原文と突合する。①病歴・受診歴の有無 ②原典にない属性の追加 ③「今年5月」等の時期の絞り込み、の3点をチェック。同意の有無が不明なら草川に ASK_USER。
