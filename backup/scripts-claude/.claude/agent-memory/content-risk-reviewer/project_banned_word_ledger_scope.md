`drafts/<案件>_banned.txt` の禁止語台帳は、**そのパッケージ限定**で運用する。台帳ファイル自体が冒頭コメントで案件名を宣言し、行によっては `allow:v5_FINAL|v7_FINAL` と版限定の例外を持つ構造になっているため、他案件へ自動的に波及させない。

具体例：`2026-08-04_体育館空調0パーセント_banned.txt` に「熊本」が登録されている（理由＝被災自治体の実名は当該パッケージの全媒体で禁止、長文ブログ v5/v7_FINAL のみ許可）。一方で「熊本」は 2026-08-07 朝便・2026-08-17 夕便で実際に公開発信済み。

**Why:** 台帳を全案件横断の恒久禁止語として扱うと、既に公開済みの語で誤って REJECT を出す。逆にスコープを緩く見すぎると 2026-08-06 の草川判断（被災自治体の実名を軽々に出さない）が空文化する。恒久的な扱いは草川に照会中で未回答（2026-08-18 時点）。

**How to apply:** 別案件のレビューで台帳の語に当たったら、①台帳冒頭の案件宣言を読み、②当該パッケージ外なら自動 REJECT にせず LOW 記録にとどめ、③草川未回答である旨を1行添える。照会に回答が来たら本メモを更新する。関連＝[[feedback-citizen-voice-health-data]]
