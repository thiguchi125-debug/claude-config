内部DB（📝市民意見リスト・📮投げ込み台帳）でも、実名の伏せ字に**本名由来のイニシャル**（三谷→「Mさん」）を使わせない。`相談者ID: 2026-08-13-A` のような**名前と無関係な連番ID**に置き換え、実名との対応表は Drive `日常資料アーカイブ/00_名簿・個人情報/` 側だけに置く。

**Why:** イニシャルは本名の部分開示そのもの。亀山の小字（道野・阿野田・川合・三寺など）は世帯数が少なく、「小地名＋姓の頭文字＋案件内容」の3点で実質的に個人が特定できる。Notionは閲覧者が限られるとはいえ、エクスポート・引用・対外発信への転用経路があり、伏せ字が仕事をしていない状態で保存されると後段で気づけない。

**How to apply:** Axis 1（個人情報）で内部運用レコードを見るときも、伏せ字の有無ではなく**粒度**を見る。イニシャル＋小地名の同居を検出したら MEDIUM（REVISE）。あわせて「所有区分・責任の所在が未確認の物件（民地の枯れ木など）」は、対外発信に転用されると所有者への名誉毀損になりうるので、レコード本文に転用禁止の1行を入れさせる。関連: [[feedback-kizai-teikyo-kifu-check]]
