「自治会行事に◯◯を持っていく」「機材を貸す」「手伝いに人を出す」型のタスク・メモを見たら、Axis 3-A（寄附行為禁止・公選法199条の2）を必ず起こす。金銭だけでなく**物品の無償提供・機材の無償貸与・無償の役務提供**が寄附に当たりうる。

**Why:** 草川は亀山市eスポーツ協会・まちのミライ亀山・青年会議所など複数団体の役員を兼ね、団体名義の活動と議員個人の行為が混ざりやすい。主体が「草川個人」なら選挙区内の自治会への寄附になり、「団体の備品を団体として持参」なら寄附ではない。**主体を書かないまま内部台帳に残すと、記録そのものが後から不利な証跡になる**（曖昧な記録が一番危ない）。

**How to apply:** 主体が本文から確定できない時点で ASK_USER 相当。headless実行で本人確認が取れない場合は、そのレコードだけ保存を保留して「📥未分類インテーク」へ回すか、本文に「主体未確認・公選法確認待ち」と明記させる。確定後は「◯◯協会の備品を協会として持参」のように**所有主体と負担主体**を1行で書き切らせる。関連: [[feedback-masking-initials-from-real-name]]
