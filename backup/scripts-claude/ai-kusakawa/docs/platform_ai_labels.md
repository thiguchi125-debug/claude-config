# AIくさかわ動画 投稿時のAI生成ラベルON手順（PF別）

> AIくさかわ動画を投稿するとき、**必ず**各プラットフォームのAI生成コンテンツ表示を有効にする。
> 動画自体に冒頭カード＋常時ラベルが焼き込まれているが、PF側のラベルは別途本人操作が必要。
> UI文言はアップデートで変わることがある。見つからない場合は投稿設定内の
> 「AI」「生成」「改変コンテンツ」に類する項目を探すこと。

## 動画ホスト3PF（必須操作あり）

### TikTok
1. 動画をアップロード→投稿画面へ
2. 「その他のオプション」（または「詳細設定」）を開く
3. **「AI生成コンテンツ」トグルをON**
4. キャプション文頭に「※この動画はAIが生成しています」を確認して投稿

### Instagram Reels
1. リール作成→キャプション入力画面へ
2. 「詳細設定」を開く
3. **「AIラベルを追加」（AI情報の表示）をON**
4. キャプション文頭の明記文を確認して投稿

### YouTube Shorts
1. YouTube Studio（アプリ可）でアップロード
2. 「詳細設定」→「改変コンテンツ」の質問
3. **「はい（リアルに見えるAI生成・改変コンテンツを含む）」を選択**
4. 概要欄文頭の明記文を確認して投稿

## クロスポスト4PF（PF機能なし→キャプションで代替）

### X / Threads / Facebook / LINE
- AIラベル機能なし（2026-07時点）
- **投稿文の文頭に「※この動画はAIが生成しています」を必ず残す**（sns-content-creatorが自動挿入。削らない）
- Facebookは投稿画面にAIラベル項目が出た場合はONにする（段階導入中）

## 禁止事項（全PF共通）

- 明記文をキャプションから削って投稿しない
- 動画冒頭のAI明記カード（1.5秒）をトリミングして再アップしない
- 実写の本人動画と混在させる編集（実写と誤認させる見せ方）をしない
