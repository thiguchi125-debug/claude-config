drafts/ のSNS原稿ファイルは「公開本文（【X】【Threads】【Facebook】等）」と「内部注記（テーマ/由来/納品msg_id/予備見出し/検証済み数値/アーカイブ接地/安全ゲート/不使用にした素材）」の二層構造になっている。リスクレビュー時は**内部注記に第三者の個別相談由来の情報が混ざっていないか**を必ず確認し、混ざっていれば「⚠️Notion等へ保存・共有する際はこの行以下を除外」注記が入っているかを検査する。片方のファイルにだけ注記があり、もう片方の同じ素材に注記がない、という取りこぼしが起きる（2026-08-09 朝便=人事院勧告／夕便=生活保護費 の両ファイルで、同じ育休退園の市民提供情報が夕便にだけ除外注記付きだった）。

**Why:** 内部注記は「発信しない」前提で書かれるため警戒が緩むが、Notion保存の対象は原稿ファイル全体になりがちで、そのまま転記されると第三者の個別相談が保存物として残る。育休退園のように対象世帯が狭いテーマは、内容だけで情報提供者が園・市側から推定されうる（＝匿名化されていても特定リスクが残る）。

**How to apply:** ①レビュー出力に「Notionへ転記してよいのは公開本文ブロックのみ」を毎回明記する ②第三者由来の未確定情報は、正本を📝市民意見リスト(c2c34bd8-)側にマスク保存し、原稿ファイル側は参照にとどめる ③発信素材化は「本人同意・属性の丸め・市の公表」の3条件を満たしてから改めてリスクレビューを通す。関連: [[feedback-safety-gates-before-notion-save]]
