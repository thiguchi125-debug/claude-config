市民から個人チャネル（Discord DM・SNS DM・LINE・メール）で届いた声を、原稿の書き出しに「市内の方から〜という声をいただきました」の形で使う案件は、**Axis 1 を第三者への特定可能性だけで採点しない**。属性（年代・地区・家族構成）を全部落としても、**送信者本人は自分の声だと必ず分かる**。したがって「もっと丸めれば安全」という書き換え提案は問題を解いていない。判定軸は「投稿前に本人へ一報が入っているか」の一点に置き、HIGH / ASK_USER に上げて草川に選ばせる。

**Why:** 2026-08-10 夕便（イベントカレンダーが2つある）で確立。13:08 に届いたDMを同日19:30便に転用する構成で、原稿側は属性（転入2年・子どもが生まれた・草川のストーリーで知る）を全部落として「市内の方から」だけにしており、第三者からの特定可能性は実質ゼロだった。それでも残るリスクは法的なものではなく**チャネルの信頼**＝「この人に相談すると数時間後に勝手に投稿される」という印象が、草川が最も声を集めたい層（転入・子育て世代）に伝わること。器が私的DM→公開投稿に変わった以上、[[feedback_consent_scope_org_to_personal_blog]]（器が変われば同意を取り直す）の射程に入る。修正コストはDM1通・2分で、失うものと釣り合わない。

**How to apply:**
- 由来が個人チャネルなら、匿名化の可否を論じる前に「本人に一報したか」を最初に問う。
- 提示する選択肢は「投稿前に一報（推奨）／投稿直後に一報／声への言及を外す／今夜は見送る」の4択。**「もっと匿名化する」は選択肢に混ぜない**（解決策に見えて解決していないため、草川の判断を誤らせる）。
- ご意見箱フォーム由来は既存ルール（属性を付けず本文のみ・[[feedback_goikenbako_quote_no_attributes]]）で足りるが、DM由来は「送信者と草川が1対1で既知」である点が違う。ここを同一視しない。
- 声の正本は原稿ファイルではなく📝市民意見リスト(c2c34bd8-)側にマスク保存し、原稿の「由来」行はNotion転記から外す（[[draft-internal-notes-transcription-scope]]）。
