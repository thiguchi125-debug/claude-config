夜間ジョブが書く内部運用ログ（例: 📮発信候補パックの「## 本日の候補」節、📮SNS便ステータス、📥未分類インテーク）は、市民向け発信本文と同じ基準で減点しない。読者は草川本人と朝夕便ルーティンのみで公開経路がない。

具体的な扱い:
- 絵文字（💡📣📮📥等）は違反にしない。Notion DB名の一部＝固有名詞であり、剥がすと識別子が壊れる。「発信物で絵文字を使わない」は市民向け本文のルール
- 未公開の発信ネタ名（例:「紀勢本線のICカード決済 — 出屋ほか地区の市政報告会ネタ」）を在庫として書くのは Axis 2 違反にしない。事前公表になるのは公開経路がある場合だけ
- ツール名・スクリプト名の deny 記録（content_safety_gate.py 等）は Axis 4 の対象外（人ではない）
- ただし **他議員名・市民の実名・特定可能な相談内容だけは内部ログでも同基準で弾く**。内部ログはコピペで対外文書へ流用されやすく、混入すると流用時に事故る

**Why:** 2026-08-12 の候補0件パックのレビューで、内部ログに公開発信物の基準を機械適用すると絵文字・未公開ネタ名で無意味な REVISE が量産されると判明した。夜間ジョブは毎晩走るので同じ判定が毎日発生する。

**How to apply:** 依頼文で「公開経路なし／内部運用ログ」と明示された対象は、8軸のうち Axis 1（実名・特定可能な相談内容）を主軸に見て、Axis 5〜8 と絵文字・詩的表現の禁止表現群は実質スキップしてよい。公開経路の有無が不明なときは確認するまで公開発信物として扱う。
