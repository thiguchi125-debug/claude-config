対外発信で「市が手を打ってきた場所の外側」「答弁があっただけ」「支援はない」といった**市の不作為を前提にした批判**が出てきたら、リスクレビューで必ず一次確認する。確認先は議会の**現況報告書**（`01_council/*現況報告*.txt`）と**主要施策の成果報告書**（`05_resources/*主要施策の成果報告書*.txt`）。事業化済みだった場合は HIGH 扱いで ASK_USER に上げる。

**Why:** 2026-08-09 夕便（亀山市内の特殊詐欺2件）で実際に発生。原稿は防犯カメラ支援を「令和4年12月に求めた→市は仕組みづくりを進めたいと答弁があった」で止め、「市がこれまで手を打ってきた場所の外側で進む」と続けていた。しかし一次資料では**地域防犯カメラ設置支援事業は令和6年度に開始済み**（R6年度成果報告書＝5自治会8台に補助交付／R7年9月現況報告＝3自治会6基申請・4基設置／R7年12月現況報告＝申請6基すべて設置）。この誤りは三重の損失を同時に生む——①執行部から事実誤認と反論される ②草川自身の「求めた→実現した」実績を自分で消す ③批判が空振りして「調べていない議員」と見られる。選挙が近いほど②③の damage が大きい。原稿の自己ゲート欄には「制度化・事業化済みは一次確認できず」と書かれていたが、実際にはローカルアーカイブに一次資料があった＝「確認できなかった」ではなく「探し先を間違えた」。

**How to apply:**
- 批判の前提が「市の不作為」なら、grep 対象に `01_council` の現況報告書と `05_resources` の成果報告書を**必ず**含める（議事録だけを見て「答弁止まり」と判断しない）。
- 差し替えの型は「批判の削除」ではなく「実績の回収＋批判の対象を絞り込む」。事業が動いている事実を書いたうえで、指標設計や届き方に注文をつける形にすると、事実誤認リスクが消え、実績アピールと政策批判が両立する。
- 亀山市の特殊詐欺対策の確定事実（2026-08-09 時点・一次確認済）：
  - 地域防犯カメラ設置支援事業＝令和6年度開始。R6=5自治会8台、R7=申請6基すべて設置。
  - 市内の特殊詐欺被害＝令和5年 19件/約1,120万円、令和6年 12件/約5,690万円、令和7年1〜10月 14件/約8,290万円（令和7年12月定例会 危機管理監答弁）。
  - 市は同答弁で、国際電話の利用休止手続の周知・**自動通話録音機の普及促進**など「犯人と物理的に接触させない環境づくり」に注力する方針を表明済み。＝「啓発回数しかやっていない」という前提は成立しない。
  - ⚠️ 上記の被害統計と自動通話録音機の答弁は**他議員（古田議員）の質問に対する市答弁**。対外発信では他議員名を出さず「市が議会で示した数字」「市が議会で答弁している」と帰属する。「私が引き出した」とは書かない（[[feedback_no_other_council_members_names]] / 誤帰属ガード）。
