次期ごみ処理施設（亀山市）を扱う対外発信では、以下を対外発信に載せない。2026-08-31の午前レビューで草川が了承し、同日夕便SNSでも維持された確定運用。

- パブコメ意見38の「他の地区への移転」要望
- 地区名「道野」
- 意見38に登場する特定民間事業者名
- ごみ袋有料化をめぐる令和7年6月答弁と今回パブコメ回答の並置

**Why:** 建設地は未定で、市はパブコメ回答に「建設地を特定したものではございません」と明記している。この段階で移転論・地区名を出すと地区間対立を誘発する。パブコメ提出者は9人しかおらず、地区名＋要望内容の組み合わせで提出者が絞られる。有料化の並置は、未確定の政策転換（市が有料化に舵を切った）を示唆し、負担直結テーマで不安を招く。

**How to apply:** 同テーマのSNS・ブログ・印刷物・報告会スライドで上記4点をそもそも書かない。安全性・交通など地区中立な論点だけを切り出す。あわせて「現敷地内に整備する場合は」「施設の搬入口前の交差点」といった**現行施設（総合環境センター）を同定させる表現**を使うときは、必ず「建設地は未定」の一文を併記する。市の条件付き回答を条件節ごと引いていても、一文がないと現地建て替えが既定路線と読まれ、市の公式見解と食い違う印象を議員発信が与えることになる。
