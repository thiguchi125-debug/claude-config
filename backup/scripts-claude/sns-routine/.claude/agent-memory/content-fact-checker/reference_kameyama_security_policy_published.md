亀山市の情報セキュリティ関連を発信でファクトチェックするときの一次情報。

## 公開されているもの
- ページ: https://www.city.kameyama.mie.jp/docs/2026032300015/ 「サイバーセキュリティを確保するための方針について」（掲載日 2026-04-01）
- PDF: https://www.city.kameyama.mie.jp/docs/2026032300015/file_contents/cyber_security_policy.pdf （277KB）
- 正式名称: **亀山市電子行政情報セキュリティポリシー（電子行政情報セキュリティ基本方針）**
- 冒頭に「本基本方針は、地方自治法第244条の6に基づく『サイバーセキュリティを確保するための方針』として取り扱います」と明記
- 発出名義は連名（亀山市長／教育委員会／選挙管理委員会／監査委員／公平委員会／農業委員会／固定資産評価審査委員会／水道事業／工業用水道事業／病院事業管理者）
- 適用範囲＝内部部局・行政委員会・議会事務局・消防本部署・地方公営企業・小中学校

## 公開されていないもの（ここが発信で効く）
基本方針を `pdftotext -layout` で全文抽出しても **USB／私物／台帳 の語は0件**。「電磁的記録媒体」が適用範囲に入るだけ。具体の遵守事項は下位文書に委任されている：
- §10 電子行政情報セキュリティ**対策基準** — 策定するとあるが公開所在は未確認
- §11 電子行政情報セキュリティ**実施手順** — 条文に「公にすることにより本市の行政運営に重大な支障を及ぼすおそれがあることから**非公開とする**」と明記

→ 「亀山市の私物USB可否・台帳の有無は公表資料では分からない」は**事実として正しい**。ただし根拠は「概要書に載っていないから」ではなく「基本方針は公開だが実施手順が§11で非公開だから」。後者で書くこと。

## 例規集には載っていない
亀山市例規集（Reiki-Base https://www1.g-reiki.net/kameyama/ 第4編行政通則 第4章情報管理）にセキュリティポリシーは**不掲載**。同章にあるのは情報公開条例・個人情報保護法施行条例・個人番号条例・防犯カメラ要綱・ドライブレコーダー要綱など。例規集を引いて「無い」と結論しないこと。
