一次情報: https://www.city.kameyama.mie.jp/docs/2026082100047/ ／添付 `file_contents/kaitou.pdf`（10p・`pdftotext -layout` で全文可）

突合済みの確定値（2026-08-31 検証）:
- 募集期間 令和8年7月1日（水）〜30日（木）／提出者数9人／提出件数42件／反映件数0件（PDFの「修正等」欄は42件すべて「修正なし」）
- 公表場所4か所＝産業環境部環境課廃棄物対策グループ（総合環境センター4階）／市情報公開センター（市役所本庁舎2階）／関支所窓口／あいあい（南側ロビー）。閲覧は9月25日（金）まで・各施設の開庁時間内に限る
- 42件中23件（約55%）の回答が「施設整備基本計画」または「一般廃棄物処理基本計画」を名指しして次段階送りにしている
- 市の定型句は「本構想は、次期施設整備の方向性を示す段階として、処理システム・事業方式…」＝**事業方式**（「事業手法」ではない）
- 意見38（道野地区・搬入口前交差点）への回答に「ご意見のとおり、現施設における、搬入口前交差点の視認性、通学路としての安全性（歩道未整備）、大型車と一般車の混雑について等の課題を認識しております」＋「現敷地内に整備を計画する場合には…周辺道路について、一体的に検討してまいります」

落とし穴:
- パブコメ側の表記は「ごみの有料化」。**「ごみ袋の有料化」は原文にない**（指定袋制を前提にしてしまう）。「ごみ袋の有料化・指定袋」は草川の令和7年6月質問側の語で、市は同答弁で「現時点では導入する考えはない」と答えている。両者を混ぜない
- 意見38には特定民間事業者名と「道野」地区名が出る。対外発信では地区間対立・私企業名指しを避ける
- 「基本計画に委ねるのではなく基本構想の段階で整理を」という趣旨の指摘は複数（少なくとも4件）ある
