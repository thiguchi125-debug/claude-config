亀山市の下水道・浄化槽ネタを検証するときの一次情報と既知の落とし穴。

## 公共下水道事業計画の見直し（公開日 2026-08-03）
https://www.city.kameyama.mie.jp/docs/2026072800575/

原文で確認済みの数値・固有名詞（そのまま引用可）:
- 正式計画名は「流域関連亀山市公共下水道事業計画」。完了目標は**令和17年度**
- 「令和7年度末時点での下水道普及率は65.1％にとどまっています」← **このページに載っている**
- 「公共下水道計画区域を約1,739haから約1,687haへ変更します」
- 「関町古厩、関町萩原、関ヶ丘等の計52.6haについて、公共下水道計画区域から浄化槽処理区域へと移行します」
- 「開発行為等により増加する計0.4haについて、公共下水道計画区域に編入します」（差引 1,739−52.6+0.4＝1,686.8≒1,687 で整合）
- 意見受付はLOGOフォーム https://logoform.jp/form/Ymi6/1716460 。**締切日・縦覧期間の記載は一切なし**
- 区域図PDF `file_contents/file_gesuiarea.pdf` あり。ただし**テキストレイヤーなしの画像PDF**（pdftotextで抽出不可）
- 担当: 上下水道部 下水道課 下水道工務グループ TEL 0595-97-0627

## 浄化槽整備事業補助金制度（公開2025-04-01 / 更新2026-04-16）
https://www.city.kameyama.mie.jp/docs/2018090400127/

**⚠️ 最重要の落とし穴**: 補助金額の表は rowspan で3区分にまたがっており、素朴にHTMLをテキスト化すると金額が誤対応する。実際の対応は:
- 区分(1)「浄化槽によってのみし尿および生活雑排水を処理することが可能な区域」の**転換**のみ → 5人槽332,000円 / 6〜7人槽414,000円 / 8〜50人槽548,000円
- 区分(1)の新築、**区分(2)「(1)以外の区域」の転換**、区分(3)災害 → いずれも 5人槽168,000円 / 6〜7人槽207,000円 / 8〜50人槽276,000円
- つまり **33万2,000円を無条件に「転換なら」と書くと誤り**。区分(2)なら16万8,000円で半額以下

その他の原文:
- 対象地域＝下水道法第4条第1項又は第25条の23第1項の事業計画区域を除く＋農業集落排水事業計画区域を除く＋大型合併処理浄化槽の住宅団地等を除く（3つ目を落としがち）
- 交付対象者に「ただし、設置することにより汚水処理未普及解消につながる人に限る」の条件あり
- 「※ 単独処理浄化槽を撤去したときは9万円を、配管工事を行ったときは6万円を別途補助します」←「**宅内の**配管工事」とは書いていない
- 「下水道事業の計画区域の変更等により補助対象地域を変更する場合があります」← 区域変更→補助対象化の論理を裏づける原文
- 「設置した浄化槽については、適正な維持管理（法定検査、保守点検、清掃）が必要となります」
- 補助金交付決定前の着工は対象外
- 担当は**下水道管理グループ TEL 0595-97-0628**（見直しの0627とは別番号。混同注意）
