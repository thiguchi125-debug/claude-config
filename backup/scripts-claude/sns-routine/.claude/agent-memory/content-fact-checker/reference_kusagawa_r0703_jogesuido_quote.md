草川本人（○４番 草川卓也君登壇）の発言、原文:
> 令和７年度、先ほどお示しした資料でも、上下水道部の予算は前年度比マイナス７.２６％ということでしたけれども、こういった上水道も含めたインフラ整備というのはやっぱり亀山市はまだまだ弱いんじゃないかということを今回のこの代表質問を通じてぜひ認識していただきたいですし、それに対する対策を早急にお願いしたいと思っております。

**引用時の注意:**
1. 帰属は草川本人で確定（他議員ではない）。「代表質問」という呼称も本人が同じ発言中で使っている
2. 7.26%の出所は**草川が議場で示した資料**。市の公表資料で独立に裏取りしたものではないので、「上下水道部予算は7.26%減だった」と断定せず「〜という数字を挙げて申し上げました」の伝聞・自己言及の形にとどめる
3. **文脈が真逆になりうる**: この発言は「上水道施設の整備方針」の項で、直前に「この計画性のなさをちょっと何とか改善をしなければいけない」と述べた上での、**投資が足りない＝もっとやれ**という趣旨。下水道の計画区域**縮小を是とする**文脈に引用すると「前と言ってることが違う」と読まれる。使うなら「だからこそ限られた予算の配分を厳しく見る必要がある」と橋渡しの一文を必ず挟む
4. 同じ質問で使った水道カルテ（国交省・令和6年12月公表）: 基幹管路の耐震適合率 亀山22%（全国42%）／浄水施設0%（全国43%）／配水池0%（全国63%）。料金回収率は100%超（草川は再質問で「回収率110％」と言及）。数値は杉本上下水道部長の答弁でも同じ値が確認できる
