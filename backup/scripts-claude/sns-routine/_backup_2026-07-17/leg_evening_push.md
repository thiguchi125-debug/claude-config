# 返信処理ロジック（未処理返信があれば必ず最初に実行）

1. ステータスページの「現在のメニュー」からメニュー送信msg_idと候補一覧（番号→候補全文・接地・🎬）を取得。「処理済み返信msg_id」一覧も取得。
2. Discord受信（after=メニュー送信msg_id）→ USER_ID本人のメッセージのみ→処理済みmsg_idを除外。
3. 各返信を解釈:
   - 「Nで」「N」「Nお願い」→ 候補NのPFセット生成（下記生成規則）
   - 「N、〇〇だけ直して」「N 〇〇風に」→ 指示を反映して候補Nを生成
   - 「1と3両方」→ 各テーマを順に生成（それぞれ別ページ・別DM）
   - 「Nを動画で」→ 動画モード（下記）
   - 「出し直して」「別の切り口で」「他のは？」→ **候補の出し直し**: 前メニューの候補は角度を変え（同テーマでも切り口一新）、未提示のニュースSNS向き・💡ストックから新顔を混ぜて、新しいメニューを再送（メニュー形式・ステータスページ「現在のメニュー」更新・履歴に「出し直し」1行）。この返信は処理済みに含める
   - 「パス」「今日はパス」→ ステータス履歴に「パス」記録のみ。DM返信不要
   - 解釈不能 → 短く聞き返すDMを1通（「N でとご返信ください」）し、処理済みに含めない
4. **PFセット生成規則**: 📮候補パックの「生成ガイド」節（voice-dnaコア・禁止表現・PF別体裁）に厳密準拠。候補の接地情報（過去発言・数字・出典）を必ず使う。事実の創作禁止（パックとニュースダイジェストに無い数字・固有名詞を新たに作らない）。絵文字なし。他議員名なし。X(140字目安)／Threads(300〜500字)／Instagram(600〜1000字・ハッシュタグ3〜5個)／Facebook(500〜800字)。
   **ブログ（必須・アンカー記事）**: 800〜1500字・1行目は必ず「こんにちは、亀山市議会議員の草川たくやです。」・タイトル50字以内（例:【草川たくや 亀山市】〜）・小見出し2〜3個・末尾に定型フッター（`~/.claude/agents/blog-writer-normal.md` の「（必須）定型フッター」節をReadして**一字一句コピー**。改行・空行も維持・省略禁止）。「Nをブログ深掘りで」指定時は1500〜2500字（現場の声→全国データ→国の制度→亀山でできること→議会アクション宣言の5段構成）。SNS4本はブログの派生として要点を圧縮する。
5. **リスク自己チェック（生成後・送信前に必ず）**: 生成ガイドのリスク8軸要点（公選法・個人情報・名誉毀損・差別・利益相反・品位・物議・機密）と禁止表現リストで全文を検査。
   - HIGH該当 → 本文をDMに出さず「⚠️この候補は〈理由〉のリスクがあります。出してよければ『N 承知で』と返信を」と確認。
   - CRITICAL該当 → 生成中止「🚨候補Nは〈理由〉のため生成を中止しました」
6. 問題なければ: DMに5点連投: まず【ブログ】をタイトル込みで分割送信（1通1900字以内・2通目以降は「【ブログ 2/3】」形式）→続けてPF別4通（各通の冒頭に【X】【Threads】【Instagram】【Facebook】。コピペしやすいよう本文のみ・余計な前置きなし）→ 📣投稿管理DBに1ページ作成（投稿タイトル=テーマ見出し・ステータス=未着手・プラットフォーム=[ブログ,X,Threads,Instagram,Facebook]・ネタ元=候補の種別に応じて 日次活動orSNS/新聞・本文=先頭にブログ全文節＋PF別セクション）→ ブログ全文を `~/.claude/projects/-Users-kusakawatakuya/drafts/YYYY-MM-DD_〈テーマ短名〉_v1.md` にWriteで保存（D1完全保管・フッター省略禁止）→ 最後に「保存済み: <NotionページURL>」を1通。
7. **動画モード（「Nを動画で」）**: 35〜45秒のショート動画台本（冒頭「亀山市議会議員の草川たくやです」名乗り→課題→事実1つ→決意型結び。一文30字以内・テロップ想定）＋撮影メモ（ロケ候補・カット割り3〜4・服装/小道具ヒント）をDMに1通で返信 → ステータスページ「動画リクエスト」節に `- [ ] YYYY-MM-DD 便名 候補N 〈テーマ見出し〉` を追記（今夜Macがフル制作する）→「今夜、挿入画像と投稿文一式を自動制作します」と添える。
8. 処理した返信のmsg_idを「処理済み返信msg_id」節に追記（7日超の行は削除）。「履歴（直近7日）」節に結果1行を追記。

# 候補選定とメニュー送信

1. 📮候補パック・📰ニュースダイジェスト・📮ステータス（履歴＝既に選択/パス/送信済みの候補は除外）を読む。
2. 優先順位で候補2〜3本を選ぶ: **①草川の投げ込み由来（パックの種別=投げ込み）＞②当日ニュースのSNS向き（ダイジェストの[SNS]マーク行・活用:SNS行）＞③💡ストック由来（パックの種別=ストック）**。
   - ニュース由来候補は「亀山→」接地行をそのまま切り口に使う。
   - 🎬動画適性のある候補にはマークを付ける。
3. メニューをDMに1通で送信。形式:
   「📨【夕便】発信候補:
   1. 〈見出し〉（切り口1行）🎬
   2. 〈見出し〉（切り口1行）
   3. 〈見出し〉（切り口1行）
   → 『1で』『1を動画で』『2、〇〇だけ直して』『パス』で返信」
   - ローカルガード用: 送信msg_idを使い、Bashで `~/.claude/scripts/sns-routine/_menu_state.json` に `{"leg":"evening","date":"YYYY-MM-DD","menu_msg_id":"<送信msg_id>"}` を書く（正本はステータスページ「現在のメニュー」節=次項6で全置換。これは返信便がclaudeを起動すべきか軽量判定するための補助ファイル）。
4. 昨夜の動画フル制作完了（ステータスページ動画リクエスト節に本日日付近くの `[x]` 行）があれば、メニューに「🎬昨夜の動画素材できています（Drive📱動画素材＋📣DB）」を1行追加。
5. 候補が1本も無い日は「今日は候補がありません。『発信: 〇〇』で種を投げてください」を送信。
6. ステータスページ「現在のメニュー」節を全置換: 便名・送信時刻・**送信メッセージid**・番号→候補全文（接地・🎬含む）。「履歴」節に「夕便送信 N本」を1行追記。

- 当日投げ込みの読み方: ステータスページの朝便メニューmsg_id以降を受信し、「発信:」「ひらめき:」で始まる本人メッセージを候補化（見出しと切り口はその場で整える。接地はニュースダイジェスト・パック生成ガイドの範囲で。数字の創作禁止）。
