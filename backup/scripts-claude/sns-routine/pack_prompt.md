## Step 1: 生成ガイド節の鮮度チェック＆更新

   - 節の中身が初期プレースホルダー（「（初回夜間ジョブが書き込む...）」等）のまま、または空
   - 節内に `<!-- guide_updated: YYYY-MM-DD -->` マーカーがあるが、その日付が今日から30日以上前
3. 書き換える場合、以下の内容で「## 生成ガイド」節全体を構成する（`mcp__claude_ai_Notion__notion-update-page` の `update_content` コマンド。`old_str` は fetch で取得した「## 生成ガイド」見出し行から次の「## 」見出し直前までの現在の全文、`new_str` は下記）。voice-dnaは `~/.claude/agents/knowledge/kusagawa_archive/04_compass/voice-dna.md` を読み、コア要点を30行以内に圧縮すること（全文コピー禁止・要約）。

## Step 2: 候補収集（最大8本）
1. `mcp__claude_ai_Notion__notion-search` で 📣SNS投稿管理DB（`data_source_url: collection://1bd98deb-624f-402c-aeb3-bdaa4782b389`）内を検索。query は `💡`。`filters.created_date_range` は開始日=今日から7日前・終了日=今日、`page_size` は12程度。
2. 検索結果のうち、タイトルが `💡` で始まるページを候補にする。各ページを `notion-fetch` して「ステータス」プロパティが「未着手」のものだけ残す（進行中・完了は除外）。
3. 上位8件までに絞る（優先順位: 今夜のtriageで新規登録されたもの＝作成日時が最も新しいもの優先）。
4. 候補が0件でも異常ではない。Step 4 で「本日は候補なし」を明記して進む。
5. ニュース系の候補（📰ニュースDB由来・タイトルに新聞記事っぽい引用のみで草川の視点が無いもの）はパックに入れない（朝便が📰ダイジェストから直接使うため二重化しない）。

## Step 3: 各候補の接地・動画適性・切り口
候補ごとに以下を行う（1候補あたりの探索は最小限に絞りトークンを節約すること）:
1. 候補の本文・テーマから検索キーワードを1〜3語抽出する。
2. `grep -rn -C2 "<キーワード>" ~/.claude/agents/knowledge/kusagawa_archive/{01_council,02_publications,03_themes,05_resources,06_election}` （まず `grep -rl` でファイル特定→該当ファイルのみ `-C2` で周辺行取得。PDF等grep不可のバイナリは無視）で草川の過去発言を探す。
   - 見つかった場合: 出典パス＋行番号（例 `03_themes/子育て.md:L120`）と発言要旨を1件だけ「接地」として記録。
   - 見つからない場合: 「未発言=新規論点」と明記。
3. 関連する数字があれば出典（一次資料名・年月）とセットで1点だけ添える。数字が無ければ省略可。
4. 🎬動画適性を判定する:
   - 有: ビジュアル変化・現場のストーリー性・60秒で語れる具体的シーンがある（例: 施設訪問・工事現場・イベント・実演）
   - 無: 抽象的な制度論・数字だけの話で画にならない
   - 判定＋理由1行を記録。
5. 切り口（発信の角度）を1行で記録する（例:「他自治体比較で危機感を出す」「市民の声から入る」等）。

## Step 4: 「## 本日の候補」節を全置換
1. 📮発信候補パックページを再度 `notion-fetch`（Step1で更新した場合は最新化のため）。
2. 「## 本日の候補」見出しから文末（または次の「## 」見出し直前）までの現在の全文を `old_str` に、以下フォーマットで組んだ新内容を `new_str` にして `mcp__claude_ai_Notion__notion-update-page` の `update_content` を実行する。

候補がある場合のフォーマット（候補ごとに繰り返し）:
```
## 本日の候補
### 候補: 〈仮見出し〉
- 種別: 投げ込み／ストック
- 🎬動画適性: 有／無 ＋ 理由1行
- 接地: 〈archiveパス:L行＋発言要旨〉または「未発言=新規論点」／関連数字（あれば・出典付き）
- 切り口: 〈1行〉

（候補ごとに上記ブロックを繰り返す。最大8本）
```

候補が0件の場合:
```
## 本日の候補
本日は候補なし（💡ストック・当日投げ込みともに未検出）。生成ガイドは維持。
```

## Step 5: 動画リクエストキューの書き出し（Task 3連携）
1. 📮SNS便ステータスページ（page_id `39dcf503-a68f-811b-bdd3-cce4e418187a`）を `notion-fetch` し、「## 動画リクエスト」節を読む（**このページは書き換えない・読むだけ**）。
2. 未処理行（`- [ ] YYYY-MM-DD 便名 候補N テーマ見出し` 形式で、`- [x]` になっていないもの）をすべて抽出する。
3. `~/.claude/scripts/sns-routine/_video_queue.txt` に書き出す。**毎回必ず上書きする（追記しない）**。未処理行が1件もない場合は空文字列で上書きする（`Write` ツールで空文字列を書き込み、ファイルを空にする）。これによりシェル側が `test -s` でファイルが空かどうかを見て第3ステージ（動画フル制作）の起動要否を判定する。
4. 書き出し形式は1行1件、Notion上の行をそのまま転記する（余計な加工をしない）。
