## 🔌 MCPツールの扱い（最優先・スキップ禁止）

このジョブは launchd の headless 実行のため、`mcp__claude_ai_Notion__*` と `mcp__claude_ai_Gmail__*` は **deferred（スキーマ未ロード）の状態で起動する**。
**deferred は「未接続」ではない。** スキーマが見えないだけで、ロードすれば通常どおり使える。

最初に必ず1回だけ ToolSearch を呼んでスキーマをロードすること:

```
ToolSearch query="select:mcp__claude_ai_Notion__notion-fetch,mcp__claude_ai_Notion__notion-search,mcp__claude_ai_Notion__notion-update-page,mcp__claude_ai_Notion__notion-create-pages,mcp__claude_ai_Notion__notion-query-database-view,mcp__claude_ai_Gmail__search_threads,mcp__claude_ai_Gmail__get_thread"
```

**ToolSearch を試す前に「未接続」「MCP不在」と判定して処理を中止することを禁止する。**

# 処理手順

1. `_delivery_state.json` から今朝の納品msg_idを取得。ステータスページ「本日の納品」（テーマ・由来・予備見出し・接地）と「処理済み返信msg_id」を読む。
2. Discord受信（after=納品msg_id）→ 本人メッセージのみ→処理済みを除外。
3. 各返信を**返信文法**で解釈して処理:
   - 「Bで」「Cで」→ 予備見出しのテーマで一次調査（一次記事WebFetch・アーカイブgrep接地・数字の裏取り）→短文セット（X/Threads/FB・写真があればInsta）を再生成→安全ゲート→DM納品→📣DBに新ページ→drafts保存→テーマ履歴追記→ステータスページ「本日の納品」更新
   - 「〇〇直して」「〇〇風に」→ 指示を反映して該当PF（指定が無ければ全PF）を修正→安全ゲート→修正版をDM納品→📣DBの当日ページを更新→draftsにv2として保存
   - 「ブログ化」→ 当日テーマのブログを生成: 800〜1500字・1行目「こんにちは、亀山市議会議員の草川たくやです。」・タイトル50字以内（【草川たくや 亀山市】〜）・小見出し2〜3個・末尾定型フッター（`~/.claude/agents/blog-writer-normal.md` の「（必須）定型フッター」節をReadして**一字一句コピー**・省略禁止）。「ブログ深掘りで」なら1500〜2500字5段構成（現場の声→全国データ→国の制度→亀山でできること→議会アクション宣言）。分割DM納品（1通1900字以内・「【ブログ 2/3】」形式）→📣DB当日ページ先頭にブログ節追加＋プラットフォームに「ブログ」追加→drafts保存（D1・フッター省略禁止）
   - 「動画で」→ 35〜50秒・目標45〜50秒台本（冒頭「亀山市議会議員の草川たくやです」名乗り→課題→事実1つ→決意型結び・一文30字以内・テロップ想定）＋撮影メモ（ロケ候補・カット割り3〜4・服装/小道具）をDM1通→ステータスページ「動画リクエスト」節に `- [ ] YYYY-MM-DD 朝便 テーマ` を追記→「今夜、挿入画像と投稿文一式を自動制作します」と添える
   - 「パス」→ 履歴に「パス」記録のみ。DM返信不要
   - 「承知で」→ HIGH保留中の原稿をDMへ納品（ステータスページの保留記録を解除）
   - 「別テーマ: 〇〇」→ そのテーマで一次調査→生成→安全ゲート→納品→保存のフル実行
   - 修正でも差し替えでもない投げ込み（活動メモ・写真・市民の声等）→ **触らない**（夜間intakeの管轄。リアクション・カーソル操作禁止）。処理済みにも含めない
   - 解釈不能 → 短く聞き返すDM1通（「『〇〇直して』『Bで』などでご返信ください」）。処理済みに含めない
4. **生成規則**: 📮候補パック「生成ガイド」節に厳密準拠。事実の創作禁止・絵文字なし・他議員名なし。X(140字)／Threads(300〜500字)／Instagram(600〜1000字・ハッシュタグ3〜5)／Facebook(500〜800字)。
5. **安全ゲート（生成後・送信前に必ず）**: fact自己チェック（全数字・固有名詞の出典照合）＋リスク8軸＋禁止表現。HIGH→「⚠️〈理由〉。出してよければ『承知で』」／CRITICAL→生成中止通知。
6. 処理した返信のmsg_idを「処理済み返信msg_id」節に追記（7日超の行は削除）。「履歴（直近7日）」節に結果1行を追記。
