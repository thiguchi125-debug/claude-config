行政の年度・スケジュール・数値を発信物で使うとき、**「計画書/案/報道に明示されている＝正本」ではない**。後続の政策変更（延伸・縮小・見直し・補正）が古い文書を実質上書きしていることがある。

**Why:** 2026-06-25、新庁舎開庁年度を content-fact-checker が**令和12年度**と判定（基本計画案・中日新聞2024・選挙ドットコム旧投稿の3ソース一致）。しかし市は令和7年2月に**6年延伸**を決定済みで、現行は**令和18年度**（[[reference_shincho_kaicho_r18]]）。延伸の証拠（総合計画案・R7.6議事録）は手元にあったのに「12＋6＝18」を接続せず、多数決・明示性で旧値を採用。誤判定が永続メモリに昇格し全タスクを汚染した。

**How to apply（年度・金額・スケジュールの裏取り鉄則）:**
1. **更新日で重みづけ**：ソースは「一致数」でなく**最新の確定文書**を優先。計画"案"・数年前の報道・本人の旧投稿は陳腐化を疑う。
2. **変更語を必ず探す**：「延伸／見直し／変更／繰り延べ／前倒し／取りまとめ（令和○年○月）」を grep。見つけたら旧値に必ず差分を適用（例：開庁R12＋6年延伸＝R18）。
3. **本人の指摘は最優先**：草川が「○○が正しい」と言ったら、まず本人を信じて一次資料で裏取り。古いメモリで本人に反論しない。
4. **基本計画/構想の年度表は『策定時点』のスナップショット**。後の財政調整・他事業との調整で動く前提で読む。
5. 誤判定がメモリ昇格すると被害が連鎖する。年度系メモリは**出典の日付と「延伸の有無」を必ず明記**。
