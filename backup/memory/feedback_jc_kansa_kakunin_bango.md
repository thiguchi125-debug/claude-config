JC（三重ブロック協議会）財政審査会議の議案を監査役として指摘出しするとき、コンプライアンス確認番号・公益確認番号が「確認中」「申請中」のままでも指摘項目に入れない。

**Why:** 2026-10-08 第6回財政審査会議の指摘出しで、草川が「これはもう指摘しなくていい」と明示した。
**How to apply:** 議案アジェンダシステム（ag.jaycee.or.jp）の議案監査では、この2番号を指摘から外す。決算の予算列上書き・日程不一致・空欄など、他の指摘はこれまでどおり行う。按分率など委員会独自の処理も指摘しない（同日追加）。指摘には「参照箇所」と「なぜ直す必要があるか」を必ず書く（簡潔すぎて意味が通じないと言われた）。指摘メモはvault `00_Inbox/` に保存した前例がある。
