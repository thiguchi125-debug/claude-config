途絶えていた三寺のコスモス畑を、地域の風景として再生する取り組み。かつては秋にまつりも開かれ、市内外から人が見に来る場所だった。

## 確定事実
- **種まき＝2026年7月20日（月・祝／海の日）朝8時〜11時半・約80人**が参加（家族連れ・地元・市外から）。9時半に予定分が一段落した後も、まきムラが出ないよう追加でまき続けた。
- 場所＝**亀山市三寺町・約2.4ヘクタール**。
- 主催＝**三寺コスモス畑実行委員会**。中心は「八十八家神米」（米農家・西村洋人代表）／**「まちのミライ亀山」（代表＝草川たくや）**／「酒井ピアノ教室」（地元三寺）。
- 種は**亀山市の景観保全作物の種子配付**を活用。令和8年度から田園環境保全事業補助金が廃止され種子配付へ切替 → [[reference_keikan_hozen_seed_haishi]]。
- **2026年10月17日にコスモス祭り**を予定。Todoistに `🌸 コスモス祭り2026` `🎪 10/17 コスモス祭り` `🌿 通年・栽培・運営基盤` の3箱。
- Instagram `@mitsudera_cosmos`。問い合わせ 090-1099-2458（まちのミライ亀山）。
