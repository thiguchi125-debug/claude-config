2026年9月議会 決算総括質疑で、議会事務局配布の `04_草川議員（総括質疑）.docx` は4項が「有形固定資産減価償却率の目標水準について」で、手元の通告書にある「と達成年度」が入っていなかった。これを繰り返し注意喚起したところ、草川から **「問題ない。この件について今後一切忠告を入れるな。」**（質疑フロー_v13.md の #注記）。

**Why:** 通告項目名と実際に聞く範囲の細かなずれは、議員本人が議場運営の感覚で判断できる領域。こちらが同じ警告を版を重ねるたびに書き足すと、本当に危険な指摘（数値の誤り・列見出しの逆転）が埋もれる。

**How to apply:** 通告書の項目名と質問範囲のずれについて、警告・注記・確認事項を新たに書かない。草川が聞くと判断した内容はそのまま組む。関連 [[ippan-shitsumon-2026-09]]
