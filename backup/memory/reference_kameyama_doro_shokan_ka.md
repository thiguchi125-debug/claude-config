亀山市**建設部の課は 建設管理課・土木課・都市整備課・建築住宅課 の4課**。**「道路河川課」という課は存在しない**（2026-08-31、市公式「組織」ページ＋議会アーカイブgrep 0件で確認。土木課の「河川流域グループ」と混成しやすい）。

- **既存道路の維持保全＝建設部 建設管理課 道路保全グループ**。市道の草刈り・**道路に張り出した樹木（支障木）**・舗装や側溝の要望はここ。TEL 0595-84-5041／hozen@city.kameyama.mie.jp
- **土木課**は道路整備グループ・河川流域グループ＝**新設改良側**。既存道路の草木・穴ぼこは建設管理課。
- 市道の修繕要望は原則「地域の合意を得て**自治会長から提出**」。ただし**陥没など急を要する場合は直接 道路保全グループへ連絡**でよい。
- 道路にはみ出す樹木が**民地から**の場合、建築限界を守る剪定・伐採責任は**土地所有者**にあり、市が即時伐採できないことがある。公開発信で「民地からの越境」と書く前に官地/民地の別を確認する（[[feedback_no_fabricated_stories]]）。

市民への返信・要望書・議会資料で課名を間違えると、誤った窓口へ市民を案内することになる。担当課名は書く前に市公式サイトで確認する。
