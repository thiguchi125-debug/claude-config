2026-09-10、LINE文面の整形依頼で草川の入力にあった「下カブトの盛りテラス」を、固有名詞は変更しない方針でそのまま残した。正しくは **「かぶとの森テラス」**（亀山市・昼生地区）。スマホ音声入力の誤変換で、草川が自分で直した。

**Why:**
- 草川はスマホから音声入力で文面を投げてくることがある。**固有名詞は「入力どおり＝正」ではない**
- ひらがな＋カタカナ混じりの施設名（かぶとの森テラス／みずきが丘 等）は特に化けやすく、漢字の誤字と違って一見して不自然に見えないため素通りする
- 誤った施設名のまま送れば、相手には伝わらないか、地元の施設名を間違える議員になる。私信でも実害がある
- 「かぶとの森テラス」は既に [[project_jichikai_all_routes]] に載っていた＝**手元をgrepしていれば1回で捕まえられた**

**How to apply:**
- 発信物・私信・内部文書を問わず、原稿に亀山市内の**地名・施設名・自治会名・団体名**が出てきたら、書き始める前に1回だけ突合する：
  `grep -ril "<KW>" ~/.claude/projects/-Users-kusakawatakuya/memory/ ~/.claude/agents/knowledge/kusagawa_archive/03_themes/`
- ヒットした表記が入力と違えば、黙って直さず「入力は〇〇ですが、正しくは△△でしょうか」と確認質問に混ぜる（表記確認は AskUserQuestion 1問に束ねてよい）
- ヒットしない固有名詞は、勝手に補正も温存もせず**未確認として草川に投げる**
- 「固有名詞は入力どおり残す」は**表記ゆれ（送り仮名・中黒）に対する原則**であって、誤変換の温存を正当化しない
- 関連：[[feedback_kameyama_kanji_typo_guard]]（こちらは生成側の文字化け。本件は入力側の誤変換で、原因も検出方法も別）
