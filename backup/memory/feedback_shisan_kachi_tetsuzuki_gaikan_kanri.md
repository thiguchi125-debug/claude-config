農振除外・農地転用・開発許可など**資産価値に直結する手続**の市民相談は、通常の市民相談より外観管理の要求水準が高い。2026-08-12 NS-2026-0812-01（農振除外）で確立。

**Why**: 議員が特定個人の資産価値に関わる手続を市に照会した事実は、**市側の相談記録・復命メモとして公文書になり得る**。情報公開請求で「議員から特定地の農振除外について照会があった」が出てくる可能性は現実にある。Notion・draftsは開示対象外なので、防御になるのは**市側の記録に残る照会の中身が一般的な制度要件の確認で完結していること**だけ。行為が適法かつ模範的でも、記録側に性格が書かれていないと後から立証できない。

**How to apply**:
1. **二層分離**（[[feedback_safety_gates_before_notion_save]]の個人情報版）。識別情報＝氏名・連絡先・地番はDrive `日常資料アーカイブ/00_名簿・個人情報/<分野>相談/<相談ID>` の1か所のみ。Notion📝市民意見リストは非識別版（相談ID・論点・市の回答・次アクション）。**Todoist件名・カレンダー枠の説明・drafts/のファイル名も相談IDに寄せる**（スマホ通知やスクショで最も人目に触れる面）。相談IDは `NS-YYYY-MMDD-NN` 形式（NS＝農振）。
2. **記録に3点を書く**。①照会の性格＝「制度の一般要件と公表区域の状況のみを照会し、当該地番の該当性・個別の可否は照会していない」②本人が窓口に行く筋道＝「用途が定まった段階でご本人から所管課へ。議員が可否を左右できない」③勧誘禁止＝「伺った連絡先は本件の折り返しにのみ使用。入会・支持のお願いはしない」。
3. **締切がある手続は、心構え1行でなく行動制約3点＋制度上の帰結で書く**。「間に合わせることを目的化しない」は草川の話し方を縛るだけで、外形で問われる「何をしたか」の反証にならない。(a)締切に間に合わせる目的で所管課へ重ねて働きかけない (b)申請書類の作成・提出・日程調整に関与しない (c)どの回の受付に乗せるかを勧めない、を明記し、そのうえで**制度上そもそも直近の受付に乗らない**なら事実としてそう書く（自制の宣言より防御力が高い）。
4. **利害関係の非該当を1行**。草川本人・親族に当該地および周辺の利害関係がないこと。**未確認なら「未確認」と書く**（確認していないことを「確認済み」と書かない）。
5. **未確認属性が確定したらDrive識別版側へ書く**。区域・交付金エリア・受益地などの属性が非識別版で重なると、そこから土地が特定可能になる。
6. 選挙P2直前期（2026-09-18〜）以降に案件が動く場合は、その時点で再レビュー。
