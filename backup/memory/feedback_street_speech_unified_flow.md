街頭演説の talking points は **3パターン（重め／親しみ／攻め）に分割せず、1本の統一されたフロー**で出す。

**Why:**
- 話し手（草川本人）が街頭で20分ループする際、3パターンを使い分けると場面切替で集中が切れて話しにくい
- 3パターンは「企画提案資料」としては良いが「現場で使う台本」としては機能しない
- ループしているうちにテーマがブレる原因にもなる
- 2026-05-06「今日の街頭演説は」で3パターン出力に対し「一貫性がなくて話しにくい」とフィードバック

**How to apply:**
- daily-street-speech を起動する際は、デフォルトで **1本の統一フロー** を出す
- 貫くテーマ1つ（例：「届かない最後の100m」「条件が整うのを待つのか、自ら整えにいくのか」等のvoice-dna中核フレーズ）を冒頭で固定
- その1テーマから3軸（伝える／繋ぐ／希望）と今日の素材を自然に展開
- 20分のうち core-loop（30秒掴み → 3軸ローテ → 1分結び）を3〜4周できる構造
- 「客層別差し替え」が必要なら、本文1本＋差し替えバンク方式（本論は同じ、掴みやエピソードだけ差し替え）
- 3パターン提示が欲しいときは草川から明示的に「3パターンで」と依頼があった場合のみ
