# 市政報告レポート印刷物（A4両面）制作チェックリスト

## ルール本体

草川版 市政報告レポート（地区別印刷物）を制作する際、**以下のチェックリスト全項目をクリアしてから印刷工程に進む**。木下版・御幸版・太岡寺版v19を踏襲規範とする。

## Why（この feedback の根拠）
2026-05-14〜15 に太岡寺版 v1→v19 を19回イテレーションして印刷準備した際、局所修正の累積で**全体バランス破綻**を繰り返した。「ヘッダ氏名小さい」「数字セル拡大→空欄発生」「章2タイトル2行折り返し」「章本文フォントバラバラ」「プロローグ神辺向けコピペ残存」など、**事前にチェックリスト化していれば各3回呼び出しは1回で済んだ問題**を蓄積。

## How to apply

### 📐 レイアウト規範（木下版v22踏襲・実測値）
- A4両面2ページ構成厳守（3ページ目溢れ禁止）
- ページpadding上下: **約10mm/12mm**（木下版14mm前後／太岡寺版v18で確定）
- 左右マージン: **約11mm**
- ヘッダ顔写真: **36mm円形**
- 「草川たくや」氏名: **42pt級ゴシック太字**（v8〜v9で22ptは小さすぎ草川指摘）
- 連絡先ボックスの電話/メール/ご意見箱ラベルは**金枠角丸装飾**
- カラースキーム: 緑#1f7a3a・金#c89211・濃緑#0e4d27 統一

### 🔤 タイポグラフィ階層
- 氏名: 42pt
- 章タイトル: 16pt（章2が長文で1行収まらない場合のみ14pt+letter-spacing -0.01em+nowrap）
- プロローグh2: 12pt級
- 数字セル value: 22pt（v13で草川指示・縮小不可）
- 数字セル unit: 11pt
- 数字セル label: 9pt
- **章本文（全章）: 9.5pt統一**（章ごとにフォントサイズを変えない・v18で草川指摘「ここだけ大きくない？統一して」）
- 行間: 1.6（章2のみ1.45で詰めることも可）

### 🖼️ 写真・イラスト規範
- **章2主役写真は横長80×54mm**（縦長48×64mmは脇役見え・草川指摘で却下済）
- **章1バス写真は横長64×42mm**
- **章3地図・工事写真は横長75×50mm**
- **数字グリッドは flex:1 で残り幅フル展開**（width固定だと右側に空欄・草川指摘済）
- **キャプション形式**: 「▲タイトル」改行「※聞き取り内容をもとに草川が作成したイメージ図です」（イメージ図の場合は注記必須・木下版踏襲）
- iPhone写真はPIL exif_transpose で正規化後にEXIF strip（[[feedback-image-exif-processing]] 参照）

### 📝 文章内容チェック
- **プロローグh2が太岡寺/木下/御幸等の地区主語になっているか**（神辺地区共通プロローグを使うときも、太岡寺独自要素を1段落追加推奨。v9で「神辺地区は『選ばれる地域』」コピペ残存が致命的事故）
- **章タイトル・本文・キャプションに他地区名の残存がないか**（grep "神辺" "木下" "御幸" 等で確認）
- **特定案件への直接想起表現を避ける**（「無秩序な設置リスク」は特定事業者名誉毀損リスク・草川指摘）
- **「常に」「全て」等の最上級修飾は根拠1件しかない場合避ける**（「いち早く」「○○の動きが続いてきた」等にぼかす）
- **自治会員個人名は配布物本文に載せない**（要望書PDFでは正式に記載されている会長名でも、配布物では「自治会から」と団体名のみ）

### 🏗️ 章順構成
- 表面: ヘッダ → プロローグ → 章1 → 章2（地区主役テーマ）
- 裏面: 章3 → 連絡先
- **主役テーマは表面に配置**（太岡寺版は太陽光条例が主役→章2に格上げ、和賀白川線→章3に降格）

### 🛡️ 安全ゲート（必須）
- **content-fact-checker** で数値・固有名詞・法令・統計の一次情報遡及
- **content-risk-reviewer** で公選法・個人情報・名誉毀損・差別・利益相反・品位・物議・機密の8軸スキャン
- **大幅な内容変更（プロローグ書き換え等）後は安全ゲートを再通過させる**（v14でプロローグ書き換え後にゲート再通過せずv19まで進めて草川指摘で逆戻り）

### 🔍 全体俯瞰レビュー
- **natural-design-reviewer** を制作中に複数回呼ぶ（局所修正の累積で全体バランス破綻するため）
- 草川版 design-director エージェントは現状未登録のため natural-design-reviewer のみ運用（[[feedback-design-director-not-registered]] 参照※未作成）

### 📦 保管・配布
- アーカイブ: `~/.claude/agents/knowledge/kusagawa_archive/02_publications/reports/<YYYY-MM>_<地区名>版_市政報告/`
- 配布前確認: Desktop に最終版PDFをコピー、当該地区自治会長への事前一報推奨
- 配布タイミング: 市議選告示日（推定2026-10-18）前180日以上は通常期、それ以降は事前運動疑義の精査必要
