ohayo v2.5 D5でNotionダッシュボードへの書き込みを3セクション（スケジュール／フォーカス／選挙進捗）に限定したことで、副作用として「以前は書き込んでいたが今は止まったセクション」に古い表示が残り続ける問題が発生する。2026-05-13朝、5/13ohayoでニュースDBには最新3件入っているのに、ダッシュボードは5/12時点の4件が表示されたままで草川から指摘を受けた。

**Why:** 「書き込み停止」と「表示削除」は別物。停止しただけでは古い表示が残り、日中にダッシュボードを開いた草川が古いニュース・古いタスク・古い「次にやること」を最新と誤認するリスクがある。ニュースDBやタスクDBは別途最新化されているので、ダッシュボードに古いコピーがあると二重情報源で矛盾が起きる。

**How to apply:**
1. ohayo起動時、Step 4のNotion書き込み開始前に、書き込まないセクション（ニュース／iJAMP／過去発言連動／Drive新規／市民意見／会議自動整理／自動抽出レビュー／タスク詳細／積み残し／進行中PJの「次にやること」サブ箇条書き）を**ダッシュボード本文から検出**し、存在すれば**即座にcontent_updatesで削除**する（new_str=""で空置換）。
2. 削除対象セクションのリスト（恒久的に書き込まない）：
   - `## 🗞️ 今朝のニュース`
   - `## 🌐 iJAMP他自治体の好事例`
   - `## 🔍 過去発言連動`
   - `## 📂 昨日のDrive新規資料`
   - `## 📋 昨夜届いた市民意見`
   - `## 🤝 昨夜の会議自動整理レビュー`
   - `## 🤖 昨夜の自動抽出レビュー`
   - `## 📋 積み残し確認`
   - 進行中プロジェクト各PJ下の `\t- **次にやること：** ...` 行

   ⚠️ **2026-05-13 v2.5-c更新**：`## ✅ 今日のタスク` は削除対象から除外。「タスク詳細は毎日変わる動く情報」と草川判断、毎朝ohayoが3ブロック構造で全置換更新する。
3. ダッシュボードに残すのは「**毎朝書き換える＆日中も参照価値のある3セクション**」のみ：
   - `## 📅 今日のスケジュール`
   - `## 🎯 今日のフォーカス`
   - `## 🗳️ 選挙進捗`
   - 加えて：`## 📔 昨夜のまとめ`（朝1回・概要） / `## 📬 重要メール・要対応`（朝1回・概要） / `## 🔗 進行中プロジェクト`（PJ名+リンクのみ・次にやることは削除） / `## ✅ 毎日のルーティン`（1行案内）
4. 草川が「ダッシュボードに〇〇を表示したい」と明示的に追加依頼するまでは、Step 4の書き込み停止＝表示も削除を徹底。
5. 削除はohayoの**毎朝の通常処理**として組み込む（再発するため）。タイムアウトしてもfeedback_notion_update_content_pitfalls_v2.md に従い1回verifyで反映確認。

**草川承認**: 2026-05-13朝ohayo時 — 「ダッシュボードに表示はいらないので過去の表示は削除して」「ohayo起動時に古い表示検出→自動削除」と明示指示。
