亀山市の通学路交通安全プログラムは、所管事務事業概要書（R6・R8とも一字一句同一）で**「市内全ての小中学校の通学路を対象」**。所管＝教育委員会事務局 教育総務課。道路管理者＋亀山警察署が同席して年1回回る合同点検はこの枠だけ。

通学路・園児の安全ネタを扱うとき、事故りやすい3点：

1. **「幼稚園 vs 保育園」の二分法は成立しない**。亀山市は幼保連携型認定こども園を基本形態に据え（就学前教育・保育施設の再編方針）、井田川幼稚園＋みずほ台幼稚園は令和8年度から園児募集停止→井田川認定こども園、第一愛護園＋亀山幼稚園→亀山認定こども園。公立幼稚園は令和7年度で4園。議場で「区分での整理はしていない」と返されて土台が抜ける。論点は園種でなく**点検の網を張る単位**。
2. **「市は見ていない」は取れない**。令和4年6月の草川質問（川崎南保育園）に対し、当時の健康福祉部次長が「長明寺町の集落内の狭隘な道路が登降園経路となっており、安全面で非常に危険であると認識している」と答弁済み。問うべきは認識の有無でなく、認識が対策に変わる回路。
3. **「地元要望」制度が別ルートで実在する**が、**ＬｏＧｏフォームと結びつけるのは誤り**（2026-08-22 一次資料で確認・訂正）。R6所管事務事業概要書（市民文化部・地域サービス室）の記載は「市道、側溝、河川、照明灯、交通安全施設等の地元要望については、**現地確認を行い、Fix My Street Japan（スマートフォンアプリ）を活用して**迅速に関係部局へ連絡する」＝**職員が現地確認したうえで関係部局へつなぐ**経路。ＬｏＧｏフォームがアーカイブに出るのは①**職員の道路パトロール**での異常箇所共有（令和5年7月〜／第2次総計検証・施策評価資料）②文化年事業・イベントの参加申込みとアンケート の3件のみで、**住民が随時 危険箇所を申し出る窓口としての根拠はない**。対外発信で「ＬｏＧｏフォームで要望できます」と書かない。
   使える確定事実（出典＝令和7年3月 本会議 建設部長答弁。他議員質問への答弁のため対外発信では「市が議会で示した」と表記）：令和5年度の市道の地元要望155件／令和6年度は令和7年2月末で103件／令和元年度〜令和7年2月末の要望1,124件のうち未着手102件・約91％対応済／**緊急性の高くないものは要望書の提出順**（＝早く出す意味がある）。定期点検との違い（随時 vs 年1回必ず・警察同席の有無）で切る。

未就学児側の国の枠組み＝キッズ・ゾーン（令和元年11月12日通知・保育所等の**周囲半径500mを原則**・市町村等が道路管理者/都道府県警察等と協議のうえ設定。「おおむね半径500m」はスクールゾーン側の語）と、令和6年6月14日事務連絡「未就学児が日常的に集団で移動する経路の交通安全の確保について」（**点検主体は「施設等」＝各園**）。亀山市での設定・実施状況はアーカイブに記録なし＝未確認。
