# 昼生コミバスお花見企画 — 主催表記ガード

**事実**: 2026-06-08のコミバスお花見企画（住民36名・菖蒲園）の主催は **昼生地区まちづくり協議会（国分等会長）／市地域社会振興会との協働連携事業**。草川は議員として参加・制度につなぐ立場であり、企画主催者ではない。

**Why:** [[親子で米づくり事業の正しい主催表記]] と同型の主催誤帰属リスク。地域の住民活動を議員個人の手柄のように発信すると(1)協議会・地域社会振興会との摩擦、(2)選挙前の「手柄横取り」印象=票への悪影響、(3)事実誤認。検討部会の座長は草川の父である点も利益相反の影が出やすく、主体を住民側に正しく置くことが防波堤になる。

**How to apply:**
- 主語は必ず「昼生地区まちづくり協議会が企画した／住民が動いた」。草川は「参加し、制度につなぐ役割」と書く
- 「住民が動き、議員が制度につなぐ」という役割分担フレームは適切（草川を主催者にしない構造）
- 国分等会長など市民の実名は対外SNSでは原則伏せる。「協議会の会長」「地域の方」等の役職・汎用表記。引用は氏名なしで可
- 検討部会座長＝草川の父である事実は、SNSで身内推しに読める文脈でなければ伏せて問題なし（[[利益相反リスク判定]]）。ただしブログ本文では既記載のため整合は取れている
