私立園の関係者から直接「亀山市の私立保育園支援は他市より少ない」と指摘があり、2026-09-16に亀山側の実態と県内8市を調査。**差の本質は金額ではなく階層**＝他市が持つ2階（保育士個人への給付／国基準超の配置への人件費補助）が亀山に無く、民間保育所補助費は1階（事業別運営費補助）だけ。

**押さえた事実**: 私立は4園でなく**8施設**（認可3・こども園3・小規模2／R6概要書の「私立4園」は区分が古い）。3歳未満の45.3%を私立が受ける。民間保育所補助費R8=36,973千円・R7比△1.9%。**R6決算の執行率72.5%**、障がい児保育は当初1,300千円に対し実績774,720円（市の説明「申請件数が見込みより少ない」）。市単独要綱は13本中4本のみ。宿舎借上・就職支援金等は国の保育対策総合支援事業メニューで県は受給済＝**財源でなく受け皿要綱が無い**。民間向け要綱11本は令和12年3月末で一斉失効。

**次の一手**: 未照会4件（①保育促進事業補助金10,000千円の根拠要綱が例規集に無い ②障がい児保育の申請が少ない理由 ③紙おむつ支援の検討状況＝R5.3答弁が3年半未実行 ④私立8施設の定員・在籍数）を子ども政策課 保育サポートGへ照会してから通告文へ。
