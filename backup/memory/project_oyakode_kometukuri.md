# 親子で米づくり事業 — 正しい主催表記

**事実（伊勢新聞2025-06-03による確定情報）**:
- 第1回（2025-06-01・太岡寺町・親子32組約100人）= **亀山青年会議所主催／草川卓也理事長が企画**
- 第2回（2026-05-10・親子約80名）= **亀山青年会議所主催／JC継続事業として正式位置づけ**
- 利益相反: なし（亀山JC独自事業、市からの補助金・後援名義・施設提供なし）

**Why**: 2026-05-10のSNS下書き初稿で「私が個人で立ち上げた」と表現したところ、伊勢新聞2025-06-03付記事「小中学生親子100人、横一列 亀山の田んぼで田植え、青年会議所が企画」(https://www.isenp.co.jp/2025/06/03/130245)で第1回もJC主催・草川は理事長として企画していたことが判明。「個人主催」表記は事実誤認＋JC内反発リスク＋議員の市政報告レポート57「主催中！」記述との解釈ズレを招く。

**How to apply**:
- 本事業の発信は必ず「亀山青年会議所主催／草川がJC理事長時代に企画した取組」と表記
- 「自分が個人で立ち上げた」「個人主催」は使わない
- 第2回以降は「JC継続事業として正式位置づけ」が事実ベースの記述
- 草川市政報告レポート57の「親子で米づくり体験 主催中！」は「JC理事長として主催中」の意味であった
- 関連発信物の事前事実確認は **伊勢新聞検索 + アーカイブ grep "親子で米"** から始める
