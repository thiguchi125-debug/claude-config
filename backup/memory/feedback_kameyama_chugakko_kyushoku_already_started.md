亀山市の中学校給食は、**2026年5月19日時点ですでに実施開始済み**。

**Why**: 2026-05-19 政策研究エージェント（policy-expert-childcare-education）が亀山市公式サイトから「令和8年度2学期から全員喫食制給食開始」というファクトを引き、加筆版B返信案に「過渡期の補食ルール整理」として書いた。草川本人から即訂正：「中学校給食はもう始まっています。二学期は古い情報」。計画上の予定時期と実際の開始時期が一致していない可能性、または計画が前倒しされた可能性がある。公式サイトの古い計画ページが残っているとAIが拾ってしまう典型例。

**How to apply**:
- 中学校給食について発信・議会発言する際は**「すでに実施中」を前提**に書く
- 「令和8年度2学期から開始予定」「過渡期」「これから始まる」というフレーミングは**全面禁止**
- 補食問題・空腹問題（トイレでの隠れ喫食含む）は「**給食実施前提でも発生する問題**」として論じる
- 横浜市の補食ルール事例は「給食を実施していても補食を認めている」点で**亀山に直接当てはまる**
- policy-expert系エージェント／kameyama-researcher呼び出し時は「中学校給食は既に実施開始済み（R8.2学期予定は古い情報）」を前提条件として明示する
- 公式サイトの古い計画ページ（2025-11-28付け「中学校給食について（令和8年度開始）」等）が検索でヒットしても採用しない
