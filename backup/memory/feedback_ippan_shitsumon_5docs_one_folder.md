2026-09-07 草川「そんな設計だったか？聞き取りが必要な情報も別カードにまとめるのではなかったか？設計カードも常に参照できる内容がいい。細分化しただけ？作成資料もどこにあるのかわからない」。

**正本＝会期フォルダの README.md**（`~/Documents/ObsidianVault/20_議会活動/<会期>/README.md`）。要点：
- 00_通告書（事実・不変）→10_設計カード（1件名1ページ・なぜ／取りたい答弁／逃げ3型と返し／根拠3本／射程／時間。想定答弁もここ）→20_聞き取りカード（執行部から聞いた値・裏取り・出所・議場での扱い＝市に答えさせる／自分から言う／言わない）→30_議場カード（表紙＋1件名1枚。読み上げ・返し1行・言わないこと、だけ）→40_資料（番号は議場カードと一致）。
- 調整は1往復：草川が該当カードに `#注記` → AIが1件1行の対応一覧 → まとめて承認 → 該当カードだけ新版・そのPDFと結合PDFだけ再生成・字数再計算。消込は `_変更ログ.md` に1行、本文に「✅注記反映」を残さない。
- 伝播は一方向（聞き取り→設計→議場）。時間は音読実測が正。前夜に凍結。

**Why:** 9月会期で設計書v1〜v7全文改版（4万字×7回）→凍結→議場カード1ファイル85KBに全部を詰め込み→草川が「見にくい・資料がどこか分からない」。資料はoutputs、設計はdrafts、カードはvault、通告書はMailと4か所に散った。general-question-prepの8節骨子とDrive ZZ_一般質問制作の構成は決めてあったのに従わなかった。
