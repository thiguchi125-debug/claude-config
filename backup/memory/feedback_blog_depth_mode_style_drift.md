深掘りモードの blog-writer 出力が「いつもの草川ブログらしくない」と指摘された（2026-07-04 草津線直通ブログ）。AI臭ドリフトの典型＝①📌等の絵文字見出し（[[feedback_no_emoji_ai_smell]]違反）②「まちの価値を塗り替える」「地図に刻む」「その一歩を問いかけ続ける」等の詩的・抽象表現（[[feedback_no_abstract_poetic_phrases]]違反）③情報密度が薄く情緒で埋める④5段テンプレを機械的になぞる。

**Why:** 実物（`02_publications/blog/` 直近＝防災気象2026-05-04・シャープ2026-02-11等）はまったく違う型。絵文字なしのプレーン地の文見出し（「何が、どう変わるのか」「草川たくやの視点」）／数字・法令公布日・策定率・URL・出典を括弧で都度差し込む圧倒的な具体密度／署名的な実務セクション「草川たくやの視点」で市の現状評価＋番号付き具体アクションを列挙／締めは詩でなく実務的行動宣言。

**How to apply:** 深掘りブログを書く/レビューする前に必ず `02_publications/blog/` の直近実物を1〜2本読んで型を合わせる。blog-writer出力をそのまま信じず、(a)絵文字見出しを外す(b)詩的抽象を具体に置換(c)URL・出典・日付・数値の密度を実物並みに(d)「草川たくやの視点」型の番号付き実務セクションを必ず入れる、を検品。テンプレ機械適用は陳腐化サイン（[[feedback_blog_depth_mode_latest_cases_required]]と同根）。
