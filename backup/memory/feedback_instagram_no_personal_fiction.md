# Instagram（および全SNS）の中途半端に私的な作り話演出は禁止

## ルール

Instagram等のSNS投稿で、以下の演出パターンは**全面禁止**：

1. **第一人称体験風の演出**
   - NG: 「その一言が、耳から離れない」
   - NG: 「あの日、〇〇さんが言った言葉が」
   - NG: 「私はそのとき、ハッとしました」
   - → 草川が直接その場で聞いたかのような匂わせは、AIインタビュー由来の声と相性最悪。**第三者から届いた声は「届きました」「ありました」の事実描写で書く**。

2. **抽象化された架空シーン描写**
   - NG: 「中学進学を楽しみにしていた子が、『つまらない』と言い始める」
   - NG: 「私立を探し始める家庭。クラブチームを検討する家庭。そして、用意できない家庭」（誰のことか曖昧な詩的列挙）
   - → 元データに「私立進学検討・クラブチーム検討」と書いてあっても、それを擬人化・劇場化して書くのは作り話。事実は事実として「私立進学やクラブチーム移籍を検討する家庭が出始めている」と書く。

3. **詩的umbrellaで複数論点を傘がけ**
   - NG: 冒頭3行で詩的フレーズ→読み手に「何の話？」と思わせて引っ張る型
   - → AIインタビュー由来は事実引用力こそが武器。詩性で水増ししない。

## 推奨フォーマット（AIインタビュー由来Instagram）

```
【〇〇に届いた声】

AIインタビューに、亀山市在住の〇〇（属性）からこんな声が届きました。

「〜（生の引用）〜」

このメッセージから見えてくる構造的な課題は3つあります。
1. 〜
2. 〜
3. 〜

参考になる先進事例は〜。

亀山では「〜」という方針が示されていますが、〜については、まだ見えていません。

6月議会の〇〇委員会で、〜の早期公表を継続的に求めていきます。
```

つまり：**引用→構造化→比較→提案 の事実ベース4段構成**。詩的演出は最小、誇張なし。

## Why

2026-05-23 中学部活地域移行AIインタビュー#37のSNS化で、Instagram原稿が「"子どもたちの1年を、無駄にしたくない" その一言が、耳から離れない」「中学進学を楽しみにしていた子が、『つまらない』と言い始める」等の私的体験風＋抽象架空シーン演出になっていて、草川から「中途半端に私的な作り話くさい展開は不愉快」と直接フィードバック。

AIインタビューは**草川が直接聞いていない第三者の声**。それを「耳から離れない」と書くと、嘘ではないがミスリードで、AIインタビュー基盤の中立性も損なう。

memory既存ルール `feedback_no_fabricated_stories.md`（架空エピソード禁止）の境界線を、SNS詩性枠でも明示化する必要があった。`feedback_sns_citizen_lifescene_first.md`（Before/Afterシーン先行）はキープだが、「誰のシーンか」を曖昧にせず**事実引用ベース**で書くのが正解。

## How to apply

- Instagram/Facebook/note等の中長文SNSで、AIインタビュー・市民相談・SNS DM由来の声を扱うとき、必ず**「届きました」「いただきました」「お聞きしました」**の事実描写で書き始める
- 「耳から離れない」「ハッとした」「忘れられない」等の感情演出フレーズは**全面禁止**
- 「あの子は」「ある家庭では」型の擬人化・抽象シーン描写は**全面禁止**（一次情報として確認できる具体例は固有名を伏せた事実として書くのはOK）
- Before/Afterシーン先行は引き続きOKだが、それは**生活者全般の一般的シーン**として書く（例:「中学進学後にスポーツを続けたいと願うご家庭で、選択肢が見えないことがある」）であり、特定の誰かの私的シーンを擬人化することではない
- AIインタビュー由来コンテンツでは、**冒頭で「AIインタビューに〇〇からこんな声が届きました」と明示**してから引用に入る
