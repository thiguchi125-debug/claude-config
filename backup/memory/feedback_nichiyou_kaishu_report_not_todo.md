AIが平日に積む「@日曜改修」タスク（仕組みの修理メモ）は、Inboxや🏛議員活動に置かず **🗂 構想バックログ** に集め、期限は付けない（草川のTodayに出さない）。日曜の改修セッション後に、全件について「済／未／やめた」を1行ずつ草川へ報告する。

**Why:** 2026-09-14のInbox棚卸しで草川が「この手のタスクは自動で入ってきているが何の意味があるのかわからない。日曜は昨日だが達成されたのか？確認しようがない」と指摘。実際9/13は週の利用上限で改修0件・13件が未処理のまま散らばっていた。

**How to apply:** 新たに積むときは `td.py add ... "🗂 構想バックログ"`＋@日曜改修。ohayoのInbox棚卸しで見つけたら構想バックログへ移すだけで期限の突合は不要。日曜の改修後は報告を省略しない。[[feedback_maintenance_weekly_window]] [[feedback_inbox_sweep_must_set_deadline]]
