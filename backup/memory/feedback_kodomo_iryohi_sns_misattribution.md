`outputs/daily-content/2026-05-27/kodomo-iryouhi-18-musho/` 一式（blog/instagram/threads/x/short_video等）と `drafts/2026-05-27_子ども医療費18歳拡大_v1.md`、`drafts/2026-06-03_子ども医療費18歳まで_v1.md` は、**2026年3月議会（令和8年3月4日 代表質問）の子ども医療費18歳拡大の質疑を草川の発言として誤帰属している**。

**事実（一次情報＝議事録 mydrive_亀山市定例会第２号（送付用）令和８年３月４日.docx_20DhGx.txt で確認）**:
- 当該医療費質疑をしたのは草川（4番）ではなく **福沢美由紀議員（11番）**。草川は3月4日代表質問・3月5日議案質疑では**総合計画（コストコ誘致・都市拠点・環状道路・公共交通「乗って残す」）**を質しており、医療費は質していない。
- 誤帰属された逐語＝福沢氏の言葉：「子どもを大事にしてくれるまち」「中学生議会で15歳が16歳以降の医療費を質問→響いた」「OTC類似薬・慢性疾患」「なぜ来年度しないのか分からない」「教育費と医療費は次元の違う問題」。これらを**草川発言として使うのは禁止**。
- 全国90.5%（通院1,576/1,741）・入院1,600/1,741・県内22/29市町(10市12町)・毎年約4,000万円・市の第3次総合計画優先順位は、いずれも福沢氏質疑への市答弁。**「市の調査」「市の方針」として中立に書けば引用可**、ただし「草川が引き出した／追及した」とは書かない。

**草川本人の本物の医療費発言（これを軸に書く）**: 2022年9月議会「県内でもいち早く所得制限なしで15歳まで踏み切った」＋窓口無料化拡充を質問／2023年3月議会「子ども医療費の無償化及び窓口無料化の18歳年度末まで実施」を要求（桑名市など県内格差を指摘）／2022公約で18歳まで医療費無料を筆頭／教育民生委員会の委員。

**Why**: [[qa-pair-misattribution-across-questioners]] の具体実例。SNS素材を土台にブログ化すると汚染を引き継ぎ「他議員発言の誤帰属事故」になる（CLAUDE.md違反）。

**How to apply**: 子ども医療費テーマを再発信する時は、上記SNS/draftの v1系を**そのまま土台にしない**。正しい確定版は `drafts/2026-06-03_子ども医療費18歳まで_v3.md`（両ゲートAPPROVE済）。要本人最終確認＝「令和6年9月に窓口無料化中学生拡大」の時期、「国保ペナルティ令和6年4月全廃（こども未来戦略R5.12.22閣議決定）」の年月日（いずれも議事録外）。
