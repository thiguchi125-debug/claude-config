## 1. 自治会別訪問管理DB nichijo自動転記 検証手順（5/22戸別訪問で実施）

### 前提：nichijo SKILL.md には Step 2.6 が**既に実装済み**
- 2026-05-04 全面リライト
- 45自治会名検出辞書／22地区名／施設→自治会推定／関係性温度／市政報告会フィールド更新

### 検証手順

**Step V1**：5/22戸別訪問完了後、草川がnichijoで以下のように記録入力
```
記録：5/22 太岡寺町 戸別訪問 在宅対面15軒・在宅拒否3軒・不在投函42軒
```

**Step V2**：nichijoが Step 2.6 を起動し、以下を実行することを確認
1. 「太岡寺」自治会名を検出（45自治会名辞書）
2. 自治会別訪問DB（collection://996b1d15-）から「太岡寺」レコードを検索
3. 該当レコードの数値フィールド加算：
   - 在宅対面 += 15
   - 在宅拒否 += 3
   - 不在投函 += 42
   - 訪問済軒数 += 60
4. 訪問完了日 = 2026-05-22
5. 訪問ステータス = 「進行中」（既存）or 「完了」（軒数 >= 世帯数）

**Step V3**：nichijoサマリ出力に「🏘️ 自治会別訪問管理DB追記: 太岡寺 - [URL] - 訪問ログ」が表示されることを確認

**Step V4**：草川がブラウザで自治会別訪問DB「太岡寺」レコードを開き、4の数値が正しく加算されているか確認

**Step V5**：もし加算されていない場合 → skill-creator で nichijo SKILL.md Step 2.6 を修復
- 失敗パターン1：自治会名検出ロジックが「太岡寺町」を「太岡寺」自治会にマップできていない
- 失敗パターン2：レコード検索でヒットしない（多分プロパティ名違い）
- 失敗パターン3：数値加算でNotion API失敗（型不一致）

### 検証完了基準
- 入力1回で 4 つの数値フィールド全てに正しく加算
- サマリ出力に1行追記表示
- 草川目視確認OK

## 2. 市政報告会DB「開催決定→自動レコード作成」仕組み設計

### 現状：nichijo Step 2.6 は市政報告会**フィールド更新のみ**
- 自治会別訪問DB「市政報告会開催済」=true 化／「市政報告会日」入力／「市政報告会メモ」追記
- **市政報告会DB（collection://df08b5ea-）への新規レコード作成は未実装**

### 拡張仕様：nichijo Step 2.6-G「市政報告会DBレコード自動作成」

**トリガー**：草川入力に以下のキーワード全てが含まれる
- 「市政報告会」
- 「開催確定」or「日程確定」or「決まった」
- 日付（M/D or YYYY-MM-DD）
- 時刻（HH:MM）
- 地区名 or 自治会名

**入力例**：
```
記録：城東地区市政報告会 開催確定 7/4(土) 14:00〜15:00 会場 城東コミセン
記録：御幸 市政報告会 日程決まった 5/30(土) 10:30 御幸町集会所
記録：木下市政報告会 6/13(土) 19:00 木下集会所 開催確定
```

**実行内容**：
1. 開催地区を 22 地区から判定（select 値）
2. 開催自治会を 45 自治会から検索（relation・複数自治会合同なら全て紐付け）
3. 形態を判定（自治会単位／複数自治会合同／地区全体）：単一自治会=自治会単位、複数=複数自治会合同、地区名のみ=地区全体
4. 市政報告会DB（collection://df08b5ea-）に新規レコード作成：
   - タイトル：「{地区名}市政報告会 2026 第N回」（既存 N をカウントして+1）
   - 開催日：YYYY-MM-DD
   - 開催地区：select
   - 開催自治会：relation（自治会別訪問DBへ）
   - 形態：select
   - 会場：text
   - 進捗ステータス：「未着手」
   - メモ：「【YYYY-MM-DD nichijo自動作成】開催確定報告（原文）」
   - 報告会ID：auto_increment（自動）

5. 自治会別訪問DB側も連動更新：
   - 市政報告会日：YYYY-MM-DD
   - 市政報告会開催済：false（実施前なので）
   - 市政報告会メモ：「{開催日} 開催予定（市政報告会DB レコードID:SHK-N）」

6. nichijoサマリ出力末尾：
   ```
   🎤 市政報告会DB レコード作成: {タイトル} ({SHK-N}) - {URL}
   ```

### テンプレート計画レポート（オプション拡張・event-prepスキル化候補）
