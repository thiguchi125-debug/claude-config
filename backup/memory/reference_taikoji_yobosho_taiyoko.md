# 太岡寺自治会要望書（太陽光発電施設規制条例の早期策定）

## 一次情報メタデータ

| 項目 | 内容 |
|---|---|
| **提出日** | 令和5年（2023年）12月12日 |
| **宛先** | 亀山市長 櫻井 義之 様 |
| **提出主体** | 太岡寺自治会 |
| **会長** | 村山 竹則 |
| **正式名称** | **要望書**（嘆願書ではない） |
| **対象事案** | 太岡寺町地内に計画された大型太陽光発電設備設置事業 |

## 要望事項
1. 太陽光発電等の計画に対して地域住民とともに亀山市として関与し、規制できる条例やガイドライン等の仕組みを早急に策定
2. 地元自治体が太陽光発電等の計画の構想段階から関与し、規制できる仕組みづくりを国と県に働きかけ

## 経緯（要望書→条例制定）
- 令和5年12月12日: 太岡寺自治会要望書提出
- 令和7年度: 草川委員長下の産業建設委員会が「太陽光発電施設とまちづくり」所管事務調査テーマ選定
- 令和7年5月21-22日: 山梨県北杜市・長野県上田市視察
- 令和7年9月: 5本柱の提言書を市長へ提出
- 令和7年12月議会: 市長答弁「3月議会での提案に向け検討」
- 令和8年2月2日: 産業建設委員会協議会で「3月議会→6月議会」変更（単独条例化）
- 令和8年4月17日: 条例案本文（全26条）公表
- 令和8年6月議会: 議案提出予定
