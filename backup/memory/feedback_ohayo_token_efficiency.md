ohayo スキルは Notion DB全件取得（ニュース70件・タスク100件・プロジェクト18件）+ ローカルフィルタが燃費悪化の主因。2026-05-06 草川指示で以下を ohayo SKILL.md 冒頭に追加。

- ダッシュボード本文置換は省略、見出し日付セットのみでOK
- 最新情報はチャット出力に集約（草川はチャットで読む）
- DB filter付きview を作って軽量化（次回 ohayo前に notion-create-view で作成提案）
- API タイムアウトはサーバ処理済みのケース多数のため、即リトライせず fetch で状態確認してから差分送信
- 「📌 運用クイックリンク」「📌 クイックリンク」セクションの重複検出時は触らずチャット警告のみ

**Why:** 草川「内容変えなくていいけどトークン消費しすぎる」(2026-05-06朝)。朝のオートメーションが100K+消費は持続不可能。

**How to apply:** ohayo起動時、SKILL.md冒頭の「⚡ トークン効率化原則」セクションを参照。次回 ohayo 前に「軽量view 3個（タスク=期限<=今日∧未完了／ニュース=本日付／プロジェクト=進行中）作るか」を草川に提案。承認時は notion-create-view で作成、SKILL.md の view_url を新URLに差し替えて恒久化。
