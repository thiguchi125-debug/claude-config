# ブログ深掘りモードは最先端事例スキャンを書く前に必須

**ルール**: blog-writer 深掘りモードで AI/DX／医療／防災／公共交通／教育 等のドメイン専門領域のブログを書くときは、書き始める前に必ず「2025〜2026 の最先端事例」を最低5本スキャンしてから書く。「亀山現状＋三重県＋全国導入率」で止めない。海外事例も最低1本入れる。

**Why**: 2026-05-11、内部AI活用ブログを「24時間チャットボット段階導入／KPI見える化／人材確保／三重県相乗り」で書いた結果、草川から「2023年水準・つまらない・トークン浪費」と却下。policy-researcher を広く浅く回しただけで最先端事例スキャンを省略していた。fact-checker / risk-reviewer は「事実の正しさ・公選法/個人情報リスク」を見るので「面白さ・新規性」はそのまま通過してしまう。事後に WebSearch 3 本で「政府ガバメントAI源内（500業務）」「エストニア99.99%自動給付」「安野貴博デジタル民主主義2030」「取手・福島・浜田の議員業務AI」「音声AI窓口」が一気に出てきたため、最初から組み込んでいれば書き直し不要だった。

**How to apply**:
- blog-writer 深掘りモード起動の **前** に、policy-expert-<domain> または WebSearch で「2025-2026 最先端事例 / 国外含む / 横並び」を最低5本スキャン
- 検索クエリには「2026」「最新」「最先端」「自律型／エージェンティック」「プロアクティブ」「ゼロタッチ」「先行実装」等の前線ワードを混ぜる
- 国内事例だけで止めない。エストニア・オーストリア・フィンランド・英GDS・台湾・シンガポール等から最低1本
- 「これは去年の話題か、今年の話題か」を著者（Claude）が言語化してからブログ提案を組み立てる
- 「①〇〇の段階導入 ②KPI見える化 ③人材確保 ④県相乗り」型のテンプレ4本柱が出てきたら、それは陳腐化のサイン。最先端材料を再投入して書き直す
- 純粋にローカル固有の事案（お知らせ・実績報告・地区別市政報告等）は適用外
