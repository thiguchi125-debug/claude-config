# イベント運営段取り表は「スマホ縦スクロールPDF」で作る

草川のイベント（例：温泉で、産後ケア。）の**当日運営段取り表（行動表）**を作るときの確定フォーマット。2026-06-22に確立、本人が「この形式は今後も活用」と承認。

**構成（5〜6ブロック）**: ①ヘッダー（イベント名・日時・会場・緊急連絡）→ ②概要カード（日時/会場・温泉/参加者/スタッフ）→ ③参加者情報 → ④タイムテーブル → ⑤役割分担 → ⑥持ち物・ご用意するもの → ⑦緊急時・配慮 → ⑧当日の流れ（口頭説明メモ）。タイムテーブルは**横長の表でなく時間ブロックのカード型**（スマホで折り返さず読める）。

**デザイン**: ブランド色＝紙#faf6ef／椿の朱#c46b4a・濃朱#a8512f／藍#2a3b4a。**絵文字禁止**（CSS装飾で見出し）[[feedback-no-emoji-ai-smell]]。レイアウトは `max-width:560px` のモバイルファースト1カラム。

**Why（NGになった形式）**:
- **A4 PDF** → 横長で「スクロールできない・読みにくい」と却下。
- **長尺PNG画像** → 文書全体を1枚に縮小しスマホ幅に合わせるため**文字が極小→拡大必須**で「最悪」と却下。画像である限り直らない。
- 正解＝**スマホ幅の1ページ縦長PDF**。フィット表示で文字が読めるサイズ＋縦スクロールのみ＋ベクター文字でくっきり＋LINE添付でそのまま開ける（ホスティング不要）。HTMLが読みやすさ最上だがDrive/LINEはHTMLをページ表示しない（公開URL必要・個人情報あり不可）ためPDFが無難。

**How to apply（PDF化の手順とハマりどころ）**:
1. HTMLは `width=device-width` のレスポンシブで作る（普段はブラウザ確認用に `open` で表示）。
2. PDF化＝print用 `<style>` を注入したコピーを Chrome headless `--print-to-pdf`：
   `@page{size:390px <H>px;margin:0;}` `@media print{html,body{background:#faf6ef;}.wrap{max-width:none;}}`
3. **<H>は実測必須**。スクショ実測値より**print描画は約200px高い**。さらに **+40〜60pxの余裕**を足さないと中身が1px超過して**真っ白な2ページ目（＝長い空欄）**が発生する。
4. **ハマりどころ①**: `body{background:色}` はページ全体を塗るので、ページが中身より高いと**色付きの長い余白**になる。→ ページ高さを中身ぴったりに。
5. **ハマりどころ②**: 余白ページ判定で背景色をbgとして誤検出する。実測時は `@media print{html,body{background:#fff}}` にして**白い余白を pdftoppm→PIL で下から検出**し中身末尾pxを得る。
6. 単ページ確定の検証＝PDFの `/Count` が `1` になる高さを下から探す（例：3500pxで確定したことあり）。
7. 個人情報（氏名・電話）入りの段取りは**参加者情報の見出しに「※個人情報注意」**＋**ファイル名にも「※個人情報注意」**を付け、スタッフ限定運用。
8. 保存＝案件フォルダ（`02_publications/leaflets/<YYYY-MM>_<案件>/`）＋スマホ閲覧用にDriveミラー `_drive/_INBOX_daily/` へコピー。
