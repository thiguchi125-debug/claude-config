小中学校体育館へのエアコン設置を求めるアクション。設計書の正本は `~/publications/2026-08_体育館エアコン署名/design.md`、Todoist PJ は `🌡 体育館エアコン`（🏛議員活動配下・id 6hFwfC7c48xMRFfV）。

**3フェーズ**: ①8月＝市民参加型の分散WBGT測定（測定器を地区へ貸与し保護者・部活動団体が測る／参加者がそのまま署名の呼びかけ人母体になる）②9月議会＝一般質問の柱1本に格上げ、空き地条例は12月へ後ろ倒し ③10/18公示〜10/25は完全停止、11月以降に署名本格化→12月議会へ請願。

**議場で確定済みの数字**（再取得不要）: R6.12.11＝体育館空調の設置率・確保率・断熱室数すべて0%／指定避難所としている小中学校体育館は**12ヶ所**。R7.3.6＝体育館は1校6,000〜9,000万円（電気改修除く）＋断熱工事、市は「体育館は特別教室の整備後」と明言。R8当初予算＝特別教室59室を10年リース、債務負担R9〜R19・765,611千円、**R9夏季使用開始**。

**質問の核心（誤りやすい）**: 「リース期間R9〜R19だから2033年の交付金期限に間に合わない」は**誤り**。R9〜R19は債務負担＝支払い期間であって工事期間ではなく、整備自体はR9で完了する。正しくは「**整備はR9で終わる。市が自ら置いた『特別教室の整備後』という条件はR9で充たされる。ならばR10以降の工程表をいま示せ**」と迫る。

**公選法ガード**: WBGT計は必ず**貸与**（贈与は199条の2の寄附禁止に抵触するおそれ・貸出記録を残す）。署名は呼びかけ人複数名義で草川はその一人。署名者名簿は後援会名簿へ転用しない。利用目的は「市長**および市議会**への提出」と書く（請願再提出を自分で塞がないため）。悉皆訪問の場で署名簿は出さない。
