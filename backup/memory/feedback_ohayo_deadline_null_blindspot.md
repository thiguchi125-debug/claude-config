# ohayo は期限なしinboxタスクを構造的に拾えない穴

**Why**：2026-05-11、草川指摘「eスポーツサークル作りがタスクから抜けていた」。原因調査の結果、該当タスク [eスポーツサークルの結成](https://www.notion.so/298cf503a68f80bb8e36c8cde54cf9fe) は inbox 状態で存在していたが、**期限が未設定**だったため ohayo §3-1b の包含基準（期限<=今日／本日 inbox／今週中）から外れていた。同様のパターンが [eスポーツ資金調達](https://www.notion.so/298cf503a68f800caff2fb3f637905e3) など複数存在。最終更新2026-02-11と3ヶ月放置されていた。

期限を切らずに「いずれやる中期目標」として inbox に置くと、朝の視界から構造的に消える＝草川の頭の中だけに残り、忘れる。

**How to apply**：
1. **タスク登録時の期限必須化**（CLAUDE.md ルール候補）：inbox にタスクを置く場合は仮期限（最長3ヶ月先）を必ず設定。期限なし inbox は禁止。
2. **月次棚卸しスキル**（仮称 task-audit-monthly）：毎月1日の oyasumi で「期限なし inbox」「最終更新60日超 inbox」を全件リストアップして草川に提示。
3. **当面の暫定運用**：草川が「タスクから抜けていた」と気づいたとき、必ず期限を設定してから対応再開する。今回のように「期限 = 月末」「期限 = 来月15日」など中期目標として仮設定でOK。
4. **ohayo §3-1b 例外ルール拡張案**（要検討）：プロジェクト紐付き＋優先度=高 の期限なし inbox は週次レビュー対象として「📌 期限なし戦略タスク」セクションに表示する。実装コストはあるので、まず月次棚卸し優先。
