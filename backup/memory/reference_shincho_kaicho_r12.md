# 亀山市 新庁舎整備の確定事実

| 項目 | 内容 |
|---|---|
| **開庁目標** | **令和12年度（2030年度）** |
| **建設予定地** | 亀山駅周辺 |
| **総事業費** | 約95億円（中日新聞報道） |
| スケジュール | 用地交渉=令和6年度〜／着工=令和10年度／開庁=令和12年度 |

## 重要な注意
- **「令和18年度開庁」は誤り**。木下市政報告会スライド(2026-06-13)のPLAN.mdに「新庁舎 R18開庁」と書かれていたが、これは事実誤認。2026-06-25 太岡寺スライドの content-fact-checker が複数ソース一致で確定（亀山市新庁舎整備基本計画案・中日新聞・草川本人の選挙ドットコム投稿「令和12年開庁」）。
- 草川本人が過去に「亀山駅周辺に令和12年開庁」と発信済み。R18等と書くと自己矛盾・信頼失墜になる。
- 発信物で新庁舎の開庁年度に言及するときは必ず**令和12年度（2030年度）**を使う。

## 関連
- 次期ごみ処理施設も同時期の大型事業（[[reference_jiki_gomi_shori_shisetsu]]）：現施設R12.3稼働終了→次期R15年度稼働開始目標
- 市の大型事業（新庁舎R12開庁・ごみ処理施設R15稼働）が2030年代前半に重なる＝財政点検の論点
