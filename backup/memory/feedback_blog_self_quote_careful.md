ブログでの過去発言の自己引用は**禁止ではない**。但し、**多くの場面で気持ち悪く見える**ので慎重に検討すること。

**気持ち悪く見えがちなパターン（2026-05-11 AI×亀山市政ブログv1で発生した実例）**:
- 冒頭からいきなり議事録引用ブロック＋「これは私自身が発した言葉です」
- 「2019年の初当選以来〜一貫して問い続けてきました」型の自己史開示
- 議事録の長い逐語引用ブロック（>2行）を論理の起点に置く
- 「5年経った今もこの見立てを変える必要はありません」型の独善的回顧
- 自分が命名したフレーム（亀山版Society5.0／3層フレーム等）を出典と共に再アピール

**自己引用が活きる場面（例外）**:
- 議会討論原稿・後援会向け実績まとめ等、自分史開示が記事の趣旨
- 「6月議会で私はこう問いました」型の事実報告（短く、必要最小限で）
- 公約と実績の連続性を示す節目記事（任期総括等）

**Why:**
- 議員ブログは「自分史」ではなく「市民にとって有益な事実と提案」の場
- 自己引用ブロックを論理の起点にすると、自己中心構造に読める
- 過去フレーズの逐語再利用は voice-dna 保持には不要（文体・語彙レベルで自然に出る）
- ただし政治家として「私はこう考えてきた」を示す必要がある場面はある

**How to apply:**
- ブログ草案を書く前に「自分史的記事か／提案型記事か」を判定
- 提案型記事のデフォルトは「事実→現状→事例→提案」構造。自己引用ブロックは原則挿入しない
- 過去のフレーム（3層／3本柱等）を使う場合、「私が2020年に提案した」と名乗らず、地の文で自然に活用する選択肢を優先検討
- どうしても議事録引用が必要な場合は1〜2行に短く、引用ブロックではなくインライン
- blog-writer agent への指示文に「自己引用は文脈で慎重判断。原則は事実と提案から書く」を明記
