原稿の修正版を渡すとき、**変更箇所を蛍光マーカーで塗ったHTML（差分マーキング版）を作らない**。2026-08-31 育休退園ブログで作って却下された。草川の言葉＝「蛍光ペン無理ですね、**箇所にセンスがない**、なしで」。

**Why**: 文字単位diff（difflib）は日本語だと「で」を残して「きない場合があ」を消す、といった無意味な断片で塗り分かれる。人間が「ここを直した」と認識する単位と機械の一致単位がずれるため、塗られた箇所そのものが読み手の納得と噛み合わない。色を足すほど原稿が読みにくくなり、レビューの役に立たない。

**How to apply**: 変更点は**散文で数点に絞って説明する**（「年長の限定を復活」「変更申請を2か所復活」のように、何をなぜ戻したかを言葉で）。差分を見せる必要があるときも色分けHTMLではなく、修正版テキスト1本を `drafts/` に置いて `open -e` で渡す（[[feedback_copypaste_draft_delivery]]）。なお同じ轍で、HTML化のときフッターを比較対象外にしたまま表示からも落とし、草川に「フッターはどこいった？」と言わせた。原稿の一部だけを描画するビューを作らない。
