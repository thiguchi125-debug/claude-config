## 改修困難ポイント（次回再利用時に注意）
- linear-gradient の hard-edge は PDF レンダリングで暗化 → タイトル下線は box-shadow inset で実装
- Chrome PDF出力は大画像を非圧縮埋め込みする → 元画像を300dpi印刷向け（短辺1000-1500px JPEG88-90）に必ず最適化
- columns:2 段組は指示外で勝手にやらない（プロフィール intro は1段フラットが正解）
- 「目視確認を怠るな」= natural-design-reviewer agent でPNGを客観検証
