2026-08-10、草川から「今日はもう達成不可能なものや削除すべきものが混在している、どう理解すればいいのか」。
実際に見ると本日期限9件のうち**今日やる想定のものは0件**だった。

**混ざっていた4種類**

| 種類 | 件数 | 中身 |
|---|---|---|
| A 相手のボール（催促日が今日） | 3 | @結果待ちの期限は「催促日」であって作業日ではない |
| B 前提が未達 | 2 | 「（教委確認後）」「（経路確定後）」＝前提が済むまで着手できない |
| C 動詞も完了条件もない | 3 | 「国1バイパス側道の段差 連絡待ち」「AIインタビューの有効活用を」＝記録であってタスクでない |
| D 要確認 | 1 | 期限の根拠が読めない |

**Why:** Todoistの期限は1種類しかない。@結果待ちに「催促日」という別の意味を持たせても、
「今日」ビューは実作業と同じ列に並べる。毎朝「今日やれないこと」を見せられると一覧そのものが
信用されなくなり、棚卸しで期限超過を0件にしても朝の画面は改善しない。

**How to apply**
- `td.py today` / `morning` は **📍今日やる（自分の手番）／⏰今日は窓が閉じた／📮催促する／⏸保留** に分けて出す（実装済）。
  窓の閉じ時刻は 役所17:00・現地18:00・夜電話20:00・机上21:00（task_windows.py の Kind と揃える）。
- 前提つきタスク（「〜後）」）は前提が済むまで @結果待ち に寄せる。済んだ時点で実作業として立て直す。
- 動詞なし・完了条件なしは書き換えるか記録へ逃がす。[[feedback_todoist_inbox_verbless_memo_rot]] の再発。
- 記録へ逃がす前に**正本DBに既にあるか確認する**。木下報告会の防災の件は
  🎤市政報告会DBの「主な意見・要望」に記録済で、Todoist側は二重持ちだった。
- 「今週中」ビューにも同じ混ざりがあるが、先読み用なので未対応。

**やらかし:** 二重持ちを消すときタスクIDを取り違え、隣の「防犯カメラ設置の希望」を誤削除した。
TodoistのDELETEは復元できない（同内容で作り直した）。**削除前に必ず id と件名を突き合わせる。**
