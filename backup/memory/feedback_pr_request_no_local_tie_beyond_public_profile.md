亀山ゆかりの民間人（選手・アーティスト・事業者等）本人から「テレビ出演が決まったので拡散してほしい」型のPR依頼が来たとき、**本人の公表プロフィールより細かい粒度で地域を書かない**。公表が「三重県出身」なら投稿も「三重県出身」まで。「亀山出身」「亀山にゆかりのある」へ絞るなら本人に一言確認してから。

**Why:** 拡散依頼の同意範囲は告知の拡散であって、本人が公表していない居住地・出身地を公表することへの同意ではない。地元で最も発信力のある議員が一段絞って書くと、本人が管理していない個人情報を議員が公表した形になる。2026-09-04のゴルフサバイバル（BS日テレ）告知で発生。依頼文の「亀山市ということもわかると思います」は**撮影に使われた店舗が亀山だと分かる**という意味で、本人が亀山ゆかりだと公表する同意ではなかった（読み違えるところだった）。

**How to apply:**
- 第一手＝本人の公式プロフィール（所属ツアー・団体の選手ページ等）で公表表記を確認する。読み仮名も原文metaをcurlで直取り（[[feedback_webfetch_summary_invents_furigana]]）。
- 絞りたいときは本人へ確認DM。文面の型＝`drafts/2026-09-04_golfsurvival_nakano_本人確認DM.txt`
- 依頼文に出てくる**店舗・事業所には触れない**。店名不明でも、議員が特定の民間店舗を宣伝する形になる。
- 「ぜひ応援してください」は主語を必ず付ける（「〇〇選手をぜひ応援してください」）。主語なしだと1枚だけ切り取られたとき議員アカウントの応援呼びかけに読める。選挙が近いほど効く。
- 収録会場・撮影地を亀山と決めつけない。2026-09-04はスリーレイクスCCを亀山と思い込みかけたが実際は**いなべ市**（公式サイトで確認）。
- 継続放送番組の続編告知は毎回判断する。2026-09-04は草川判断で**今夜の1本のみ**とした。
