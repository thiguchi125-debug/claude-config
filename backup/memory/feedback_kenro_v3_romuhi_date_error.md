けんろう版市政報告v3（`kusagawa_archive/02_publications/reports/亀山建設労働組合_市政報告_v3.txt`・2026年5月発行）に含まれる「2026年4月、国が大工労務費基準値（100㎡＝84.7万円）を告示」は**事実誤り**（2026-07-24のけんろう版チラシ制作時にcontent-fact-checkerが検出）。

**正しい事実**:
- 中央建設業審議会が大工の労務費基準を**勧告したのは2025年（令和7年）12月2日**、改正建設業法の全面施行は同12月12日。13職種99基準値。
- 「告示」ではなく**「策定」「定めた」**が正確（官報告示の設計労務単価とは制度が異なる）。
- **84.7万円（100㎡あたり）は東京都の値**（84万7856円）。都道府県別に設定されており全国一律ではない。三重県の値は別。

**Why:** v3は発行済みのためアーカイブ上に誤表記が残り続ける。grepで引いた文言をそのまま流用すると誤りが再生産される。

**How to apply:** 労務費基準値に言及する発信物・チラシ・議会原稿では「2025年12月、国が策定（100㎡あたり84.7万円・東京都の例）」の形で書く。v3由来の文言を流用する際は必ずこの点を修正。修正済みの正文例は `~/publications/2026-07_けんろう版市政報告チラシ/kenro_ura.html` の建労カード。関連: [[project_shisei_report_kawaicho_complete_form]]
