ブログ・SNS・ショート動画・印刷物を書き始める前に、**担当agent（`~/.claude/agents/*.md`）と該当SKILL（`~/.claude/skills/*/SKILL.md`）の定義ファイルを必ずReadする**。Agentツールを起動できない設定のセッションでも、**定義ファイルを読むことに制約はない**。読んでその通りに書く。

**Why:** 2026-08-05、体育館空調の発信物一式で二重の事故が起きた。
- **形式逸脱**：ショート動画原稿で `short-video-virality-architect.md` の憲法5構成（コールドオープン／撮っている理由／結びの決意）を3つとも外した。これらは「8軸満点でも出荷拒否」と明記されていた。尺35〜45秒・カット15以上・A/B/C 3バリアント・8軸採点も全て未実施。ブログは1,500〜2,500字規定に対し5,893字、Facebookは500〜800字に対し1,621字だった。
- **制約の捏造**：さらに悪いことに、`sns-content-creator.md` に存在しない「X ≤140字」という制限を自分で作り、原稿ヘッダに書き、自作チェッカーにまで埋め込んだ。実際の仕様は「長文可・字数上限なし・ハッシュタグ最大4つ」で、草川の認識（X Premium課金済み）と最初から一致していた。**仕様を読まないと、守れないだけでなく、ありもしないルールで自分と草川を縛る。**

**How to apply:**
- 制作の第一手は「対象agent/SKILLをRead」。voice-dna・playbook・anti_patterns など「必読」と書かれた参照先も開く。
- **規定と内容がぶつかったら、内容を削る前に必ず草川に判断を仰ぐ。** 2026-08-05草川指示「ブログは超過していい、詳しく説明すべきブログであるべき」。字数上限を理由に中身を落とすのは本末転倒で、直すべきは規定のほう（blog-writerに徹底解説モード4,500〜8,000字を新設した）。
- **テンプレの定型句を、事実でないのに入れない。** 憲法の「最近この声が本当に多いんです」を、市民の声起点でない案件（文科省の調査公表が起点）に当てようとした。フォーマット遵守が捏造になるなら、フォーマットを外して理由を書く。
- 承認済みの逸脱は原稿に `<!-- FORMAT-EXCEPTION: 尺=55秒 / 草川承認 2026-08-05 / 理由 -->` を書く。
- 機械判定は `python3 ~/.claude/scripts/check_content_limits.py <draft.md>`（ブログ字数モード／SNS PF別字数・ハッシュタグ上限／動画の憲法5構成・尺・カット数・一文30字超）。[[feedback_safety_gates_before_notion_save]] と併せて保存前に必ず通す。
