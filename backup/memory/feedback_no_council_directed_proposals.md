# 議会・他議員に対する提言は対外発信物で避ける

**ルール**: 草川がブログ／SNS／印刷物／演説等の対外発信物で示す政策提案は、**亀山市執行部（市長・部長級・所管課）に向けた論点**として書く。議会全体や同僚議員の業務改革を求める色（「議会も変わる必要がある」「議員側もAIを使うべき」「議会改革を提言する」等）は対外発信から外す。他自治体の事例紹介は中立的事実報告として残してOK。

**Why**: 2026-05-12、AI活用ブログ v3 で「議員業務のAI支援を、議会全体の議論として」「執行部だけでなく、議会も同じ歩幅で前へ進む必要があります」と書いたところ、草川から「議会に対する提言は避けたい」と差し戻し。risk-reviewer の HIGH 7-A「議員品位（自己アピール／他議員巻き込み）」指摘とも整合する。亀山市議会18名の同僚議員との関係性、CLAUDE.md恒久ガード「他議員の名前は対外発信物に載せない」の精神とも整合させると、議会全体や同僚議員に方向性を求める書きぶり自体を避けるのが安全。

**How to apply**:
- 政策提案の宛先は「亀山市執行部（市長・部長級・所管課）」に限定する
- NG表現例: 「議会全体の議論として」「議会も同じ歩幅で」「議員側がAIを使い倒す」「議会改革」「同僚議員と一緒に」「議会を動かす」
- OK表現例: 「執行部に提案します」「市に求めます」「次期計画で明文化すべき」「議会で問い続けます」（自分が問う行為は OK）
- 他自治体の議会事例（取手・福島・浜田等）は中立的事実報告として §現状認識セクション に残してOK
- 議員業務 AI 化のような議会改革テーマは、対外発信ではなく内部メモ／議会会派内資料に留める
- スピーチ・印刷物・SNS でも同様。「議会も変わるべき」型の言い回しを検知したら自動で「市政（執行部）が変わるべき」へリフレーミング
