2026-10-08、3本柱シリーズ第5回（看板1-1「工場が来る前に、備える町へ：水・人・通勤の3点セット」）のブログ・台本を草川が却下。「半導体やAI産業など企業誘致を柱にするのは変わらないが、事前準備を全面に出すのは市民に響かない」。
