市政報告会スライド（および草川の対外プレゼン資料全般）に**絵文字を一切使わない**。🚌🚖🤝☎️🎯📅 等すべて禁止。チープに見えるため（2026-06-13 草川直接指示「絵文字はチープに見えるので今後金輪際使わないで」）。

**How to apply:**
- アイコンが欲しい場面は、絵文字ではなく **CSS図形（丸・四角・矢印）／番号バッジ／ライン画／実写真／figure画像** で表現する。
- 電話・メール等は絵文字（☎️📧）でなくテキストラベル（「電話」「メール」「直通」）＋色で。
- 既存テンプレート（小下/御幸 slides.html）に絵文字が残っている場合も、流用時に除去する。
- ブランド色 #c7ff4a / #1f5a3a / #0f3d27 / #f3efe4 のCSS装飾で代替。
