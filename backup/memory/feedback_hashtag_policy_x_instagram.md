**X向けの投稿には必ずハッシュタグを付ける。Instagramには5つ付ける。**（2026-07-30 草川指示）

標準タグは voice-dna §5.4 の `#亀山市 #草川たくや`。Instagramは5つ埋めるため、テーマタグ（`#子育て` `#防災` `#市政報告` 等）や地区名タグを足して構成する。

**Why:**
ハッシュタグ無しの投稿は検索・発見の導線がゼロになり、届く相手が既存フォロワーだけに閉じる。「声を、チカラに。」の前提である「届く」を、投稿の形式段階で自分から狭めてしまう。

**How to apply:**
- X：本文末尾に最低1つ。標準は `#亀山市 #草川たくや`。
- Instagram：5つ。ブランドタグ2つ＋テーマ・地区タグ3つが基本形。
- Threads / Facebook：本ルールの対象外（従来どおり）。

**例外（重要）— 他地域の災害・事故に触れる投稿では地元ブランドタグを使わない:**
`#亀山市` `#草川たくや` はリーチ拡大の装置であり、他県の被災に関する投稿に付けると「地元有権者向けの露出目的」と読まれる。この場合は**出来事のタグだけ**にする。
2026-07-28 熊本地震の哀悼投稿での実例：X＝`#熊本地震 #令和8年熊本地震`／Instagram＝`#熊本地震 #令和8年熊本地震 #熊本 #お見舞い申し上げます #被災地に心を寄せて`。
判断基準は「そのタグは、被災地に届けるためか、自分に届かせるためか」。後者ならその投稿では外す。

**Instagramの追加注意:**
Instagramは画像が要る媒体。哀悼・お悔やみ系の投稿では**現地の被災写真を使わない**（他人の被災の画像を自分の投稿の素材にしない）。無地のテキストカードにするか、Instagramへの投稿自体を見送る判断も取る。
