# 亀山市 次期ごみ処理施設 確定事実

| 項目 | 内容 |
|---|---|
| **現施設の稼働終了** | **令和12年3月**（現行長寿命化計画に基づく） |
| **次期施設の稼働開始目標** | **令和15年度** |
| 現施設の処理能力 | 80t／日（40t／24h×2炉・溶融処理方式＝シャフト炉式ガス化溶融炉） |
| 基本構想 | 「次期ごみ処理施設整備基本構想」を在り方検討委員会で審議。R7.12時点で骨子案取りまとめ、R8.6時点で最終案を取りまとめ。本年度内策定をめざす |
| 並行事業 | ごみ溶融施設・し尿処理施設の大規模整備（長寿命化）も進行 |
| 旬の話題 | 能登半島地震の災害廃棄物を令和6年10月から受け入れ、**令和7年9月末で受入れ終了**（前年に終了済み・時制注意） |

出典: 令和7年12月/令和8年6月 亀山市議会定例会 現況報告書、R8.3月 産業建設委員会提出資料（溶融施設長寿命化計画書）、令和8年度施政及び予算編成方針。
