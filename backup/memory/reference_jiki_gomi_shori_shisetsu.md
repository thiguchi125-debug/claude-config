# 亀山市 次期ごみ処理施設 確定事実（R8.6 基本構想（案）ベース・2026-07-25更新）

| 項目 | 内容 |
|---|---|
| **現施設の稼働終了** | **令和14年度末**（旧長寿命化計画はR11年度末が延命化目標年次→次期R15年度稼働に合わせ**さらに3年延命**。「令和12年3月終了」は旧計画の値＝発信で使わない） |
| **次期施設の稼働開始目標** | **令和15年度** |
| 現施設の処理能力 | 80t／日（40t／24h×2炉・シャフト炉式ガス化溶融炉／平成12年4月稼働開始） |
| **次期施設の規模** | 焼却 **48t／日**（人口減で縮小）／粗大ごみ破砕 13.4t／日 |
| **必要敷地面積** | 約 **16,000㎡** |
| **建設地** | **未定。「今後別途検討する」と構想（案）に明記**。現・総合環境センター（布気町）も候補に含み、参考として現敷地内の概略配置図を掲載。断定発言は禁止 |
| **総事業費（建設＋20年運営）** | 案1 ストーカ式306.64億／案3 シャフト式280.94億／**案4 既存建屋活用リニューアル271.33億（総合評価◎）** |
| 工事費のみ | 案1 148.2億／案3 133.1億／案4 122.26億／参考(基幹的設備改良) 116.95億 |
| 事業方式 | **DBO方式が優位**と評価（PFI導入可能性調査は処理方式・建設地決定後） |
| 広域化・集約化 | **今回は見送り**。三重県「ごみ処理長期広域化・集約化計画（仮称）」R9年度末策定を踏まえ中長期で近隣市町と再検討 |
| ごみ処理経費 | R4年度 27,732円／人で**県内4番目に高い**（R6年度26,659円／人）。近隣同規模都市は11,000〜17,000円台 |
| 亀山の強み | 溶融飛灰の山元還元による全量再資源化で**最終処分量ゼロ**達成／かめやまタベスケ／埋立プラの掘り起こし溶融（全国初） |
| 構想（案）の議会提示 | **令和8年6月17日 産業建設委員会協議会**（骨子案はR7.12）。在り方検討委員会に自治会連合会長・地域まちづくり協議会長が参画 |
| 旬の話題 | 能登半島地震の災害廃棄物を令和6年10月から受け入れ、**令和7年9月末で受入れ終了**（時制注意） |

## 草川の議場での立ち位置（R7.6一般質問）
「市民サービスを後退させない」4点＝①分別のしやすさを守る ②ごみ袋有料化・指定袋を導入しない（市答弁＝現時点で導入の考えなし） ③自己搬入350kg以下無料を工事中も途切れさせない（市答弁＝敷地内レイアウトを検討） ④**搬入口前交差点の見通しと歩道のない通学路を施設更新と一体で改良**（市答弁＝関係部署を交えて検討）。④の論拠は布気町**道野**方面からの車両・自転車の危険＝道野自治会向けの主戦場。
