YouTube「【脱・AIデザイン】AI生成でもプロ級のデザインを上手く作るには？」（ケト氏・約30パターン検証）を
起点に、design-studio の弱点を潰す改修を 2026-08-25 に実施した。

**動画の結論＝7アプローチ**: ①デザインシステム移植 ②スキルで判断力を与える ③順番と参照先を変える
④技術の流儀に乗る ⑤様式と質感を指定 ⑥動きで見せる ⑦写真と動画で実在感（動画内「最も再現性が高く楽」）。

**この環境に当てた診断**: ③は Step 4-B 模写採点として実装済みで既に強い。①④⑥は印刷物中心のため優先度低。
効いていなかったのは **②と⑤（＝様式を選ぶ判断が無い）** と **⑦（写真がハードゲートでない）**。
