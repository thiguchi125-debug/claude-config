三寺コスモス畑（[[project-mitsudera-cosmos]]）の発信で毎回引っかかる制度事実。

- **田園環境保全事業は「令和7年度で廃止」**。「令和8年度に廃止」は誤り。一次資料＝2026.3議会 資料5「令和7年度で廃止する事業及び令和8年度から内容等が変更となる事業一覧」（産業環境部 農林振興課／廃止理由＝補助金の活用実績が減少傾向）。後継が景観保全作物の種子配付で、令和8年度標準予算 4,433千円（新規事業一覧・農業振興事業）。
- **種子配付の対象者は農業者要件**。「景観保全に取り組む団体なら申請できる」は誤り。正＝①市内に住所を有し市内に農地を所有する者 ②市内に住所を有する農業者 ③**市内に住所を有する農業者を主たる構成員とする団体**、かつ**下限面積300㎡**。配布作物はひまわり・コスモス・菜の花・れんげ。出典 https://www.city.kameyama.mie.jp/docs/2026040800033
  - 三寺の実行委が申請できたのは米農家「八十八家神米」が入って③に当たるため。要件を「景観保全に取り組む団体」と書くと、草川が代表の「まちのミライ亀山」単独で申請できたかのように読め、**利益相反の説明（誰でも使える一般制度を同じ手続きで使った）が逆に崩れる**。
- **昼生地区は7自治会**＝神向谷／下庄／弘法寺／出屋／日焼／中庄町／三寺町。**表記は「神向谷」が正**（2026-08-05 草川確認済み）。亀山市社協の地区カルテPDFは「神向屋」表記だが、地名・コミバス停は神向谷。社協資料を引くときに引きずられない。
- 種まき当日（2026-07-20）の実数＝約2.4ヘクタール・約80人・朝8時〜11時半。農地区分は**休耕田**（伊勢新聞 2026-07-21 既報）。
- 「またここで咲くのを見られるのがうれしい」は**草川が現場で直接聞いた言葉**（2026-08-05 本人確認）。伊勢新聞にも77歳の栽培関係者の発言として載っているが、直接聞いているので「話してくださいました」と書いてよい。
