亀山マタニティサポート119（妊婦の緊急搬送支援制度）の一次情報で裏取り済みの事実。発信物で繰り返し使われるため、毎回grepし直さずここを起点にしてよい（ただし新しい進捗は要再確認）。

**確定事実**
- 2025-09-11（令和7年9月）本会議一般質問で、草川が「妊婦事前登録型の救急搬送支援システム（通称ママ・サポート119）」の導入を提案。先行例として名張市・岡山県高梁市を挙げている。出典＝`~/.claude/agents/knowledge/kusagawa_archive/01_council/kaigirokur0709_kusagawa_only.txt` 1169行付近
- 市の答弁は子ども未来部長（高宮綾子部長）。2026-03-04の代表質問答弁で「ご提案いただきました」と草川提案であることを認めている
- 制度の正式名称は **亀山マタニティサポート119**。「ママ・サポート119」は草川が議会で使った通称であり、市の制度名ではない
- 運用開始＝2026年4月。二次元コードで事前登録したかかりつけ産科医療機関等の情報を消防本部と共有し、急な破水・陣痛で家族の協力が得られない場合の救急搬送に使う
- 同じ2026年4月から産後ケア事業も拡充し、新たに通所型・宿泊型を追加
- 「市内に分娩可能な産科医療機関がない」は子ども未来部長が本会議で明言した**市の公式認識**。この表現をそのまま使う限り、特定医療機関への不利益な言及にはならない
- 2026-03-04 代表質問で草川は「ぜひ積極的な利用促進もお願いしたい」と述べている。要望は一言のみで、掲示・広報手段の具体提案まではしていない。出典＝同ディレクトリ `mydrive_亀山市定例会第2号_令和8年3月4日_tcuP0.txt`

**発信で誤りやすい3点**
1. 制度名を「ママ・サポート119」と書く → 正式名は亀山マタニティサポート119
2. 2026-03の利用促進を「求めた／提案した」と強く書く → 実際は答弁後の一言要望。「利用促進をお願いした」が実態に合う
3. 実施主体を草川側に寄せる → 実施は市（子ども未来部＋消防本部）。草川は提案者。[[feedback-election-eve-achievement-attribution]] 参照
