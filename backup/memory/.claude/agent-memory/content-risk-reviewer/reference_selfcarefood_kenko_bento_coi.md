「かめやま健康弁当」（監修＝一般社団法人セルフケアフード協議会・島津製作所と農研機構が2022-04-01設立）を草川名義の発信で扱うときは、**Axis 6 利益相反を必ず立てる**。

**事実（一次資料）**:
- 草川は**教育民生委員会の委員**（[[feedback-kusagawa-role-committee-master]]）。
- 同委員会は **2026-04-24 に同協議会と意見交換会を実施**。説明資料＝`~/.claude/agents/knowledge/kusagawa_archive/01_council/説明資料_亀山市議会教育民生委員会意見交換会_260424_セルフケアフード協議会.txt`
- **その資料の表紙に "Confidential" 表記がある** → 資料由来の内容（正会員10社・特別会員7機関・G-Plus食品認証・江別認知症コホート等）を対外発信へ引くのは Axis 2 機密違反。報道・市公式で取り直すこと。

**Why:** 所管委員会の委員が、委員会で接触した団体の監修商品を推奨する形になると、便宜供与の外形が立つ。2026-10-25市議選が近づくほど「特定事業者への肩入れ」と読まれやすい。なお草川が財産上の利益を供与するわけではないので**公選法199条の2（寄附）には当たらない** — ここを混同して過剰にREJECTしない。

**How to apply:**
- 販売店名（例：スーパーサンシ亀山エコー店）と価格を書くなら、**報道由来と明示**し、商品推奨ではなく市の健康施策の評価として組む。
- 委員会での意見交換に触れる／触れないの判断は草川に確認する（不開示のまま推奨するのが最も外形が悪い）。
- 監修団体名を出す場合は、意見交換会の経緯を1行注記するか、団体名自体を落とす。
