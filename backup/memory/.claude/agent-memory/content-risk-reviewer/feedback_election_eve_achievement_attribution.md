選挙が近い時期の発信・返信では、公選法の明文違反（寄附・投票依頼）だけでなく、以下2つの「合法だが読まれ方が危ない」表現を必ず拾う。

**(1) 実績の因果独占**：「◯◯は私が導入を求めた制度で、この4月から始まりました」型。提案が事実でも、実施主体（市・所管課）が消え、制度が草川の成果物のように読める。
→ 書き換えの型：「◯月の市議会で私が提案し、市が◯月から始めた制度です」。提案者と実施主体を1文の中で分離する。

**(2) 任期を超えた約束**：「議会で継続して追いかけます」「議会で継続して問い続けます」型。任期は2026年10月までで、その先は選挙結果次第。選挙2か月前だと「次も議会にいる」前提＝当選を織り込んだ表現と読まれうる。
→ 書き換えの型：「引き続き向き合っていきたい課題です」「私が取り組み続けたいテーマです」。議会という場と将来の任期を約束から外す。

**Why:** どちらも単体では公選法違反にならないため素通りしやすい。ただし選挙前は「実績アピールの場に相談を使った」「当選前提で語った」という物議・信頼失墜の経路になり、訴訟でなく票で失う。2026-09-02の妊婦健診コメント返信レビューで3案すべてに出た定番パターン。

**How to apply:** Axis 3（公選法）とAxis 7（品位・約束）で機械的にキーワード検出する。検出語＝「私が導入を求めた」「私が実現した」「私が求めた制度」「議会で継続して」「議会で追いかけ」「問い続けます」。P1通常期はMEDIUM（REVISE）、P2直前期（2026-09-18〜）以降は1段格上げでHIGH（ASK_USER）。

関連：[[reference-maternity-support-119-facts]]／公開コメント欄の返信は削除しない限り告示日以降も表示され続けるため、告示後に同スレッドへ追記・編集しない運用をセットで提案する。
