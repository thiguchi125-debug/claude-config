防災・ハザード系の発信で、市が公表している注記（浸水想定区域内・土砂災害警戒区域内）を根拠に**避難所となる学校名を実名で挙げる**場合は、以下の枠組みで判定する。削除まで求めない一方、必ず草川にASK_USERで問う。

**Why**: 市の公表情報の忠実な引用であり公益性は高い（自分の避難先の条件を市民が確認できる）が、選挙前は「不安を煽って票を得ようとしている」と読む余地が残る。特にSNSで校名だけ切り取られると、避難所としての立地条件の話が「あの学校は危ない」という学校評判の話にすり替わる。保護者の不安と学校への問い合わせ集中という副作用は、記事本文の緩衝が落ちた瞬間に発生する。

**How to apply**:
- ブログ本文は校名を残してよいが、直後に「これは学校の安全性の問題ではなく、避難所としての立地条件の話。市の一覧の備考欄にそのまま書かれている」旨の緩衝一文を必ず添える。
- **SNS展開では校名を出さない**（「4つの小学校に注記がついている」＋市の一覧URL）。ブログとSNSでここは同一原稿にしない。
- 「防災工事の区分」「要注意」等の行政用語は、「いますぐ決壊する意味ではない」等の一行注記なしで数字だけ出さない（21池／27池のような比率は不安喚起に直結する）。
- **運用開始前の実績数字で評価しない**（例：令和8年4月本格運用のアプリを、2026年2月時点のDL数で「目標に遠く届かない」と評価すると、市側から「本格運用前の数字」と正当に反論され論拠が崩れる）。時点関係を明示し、最新値は議会で確かめる形にする。

**選挙フェーズ別の追加ルール（投票日2026-10-25）**:
- P1（〜2026-09-17）：「議会で確かめます」型のCTA・一人称の委員会言及（「今年3月の予算決算委員会で確認したところ」）は活動報告の範囲でOK。
- P2（2026-09-18〜10-17）：同じ文言でも1段階格上げ。①「議会で問い続けます」等の**任期を含意する恒久宣言**は「9月議会で確かめます」のような**特定会期に限定した表現**へ。②一人称の実績言及は「市の答弁によれば」と主体を市へ移す。③既公開記事もP2期間中の再投稿・再拡散は要判断。

**関連**: [[feedback-phrase-todokanai-owaraseru]]（「届く／届かない」を抽象タグライン化しない）／被災地に言及した哀悼投稿と亀山の政策記事は接続しない（前振り読みを防ぐ）
