亀山市コミュニティバスの利用者数を検証するときの定番トラップ。

**事実:**
- 草川がR4.9月定例会で述べた「コミュニティバスに関しては、利用状況、令和3年度は6万8,619人、目標として10万7,200人」は、**乗合タクシーを含む合計値**。草川自身が同じ発言中で「これ乗合タクシーも含むんでちょっとややこしいんですけれども」と断っている。
- コミバス単体（6路線集計）の令和3年度実績は **63,931人**（R6.9所管事務報告〈総務委員会資料抜粋〉の路線別推移表）。
- 63,931 + 乗合タクシーR3実績 4,688 = 68,619 で完全に一致する。
- 同じR4.9答弁で草川は別に「地域公共交通計画では令和8年度のコミバス目標は10万2,000人以上」とも述べている。目標値が2系統あるので「目標10万7千人」を単独で断定しない。

**Why:** 内部メモや発信物で「コミバス利用者 約6万8千人」と単体扱いで書くと、収支率4.8%（コミバス単体）の議論軸と混ざって数字が崩れる。`reference_kameyama_combus_revenue.md` にも単体扱いで載っているため再発しやすい。

**How to apply:** コミバス利用者数の検証依頼が来たら、まず「その数字は乗合タクシー込みか」を必ず問う。単体を出すならR6.9所管事務報告の路線別表（さわやか号/野登・白川/東部/南部/西部/加太地区福祉バス）を出典にする。
