**確定していること:**
- 路線維持基準＝評価指標「1便当たりの平均乗車人員」／評価基準 **3.0人/便・日**（R6.9所管事務報告〈案〉・総務委員会資料抜粋）。見直し(改善)基準は「平日1日当たりの停留所別乗降者数 5.0人/日以上」。
- コミバスは **7路線**（さわやか号・野登ルート・白川ルート・東部ルート・南部ルート・西部ルート・加太地区福祉バス）。市公式ページでは野登・白川は「野登・白川地区自主運行バス」として1行にまとまることがあり、6路線に見えるので注意。
- R6.12 笠井政策部長答弁（草川質問）：「市内7路線のうち…路線維持基準を下回っております…現在、**南部ルートなど3路線**が該当」→ 3路線であることは確定、路線名は南部のみ明示。
- 南部ルートの実績：令和5年度 2.2人（草川「昼生ニュース」）／令和6年度 **1.9人**（R8.3.4 櫻井市長答弁）。※R8.3.4は**福沢美由紀議員の質問**への答弁。引用時は「他議員が引き出した数字」と明示。

**確定していないこと:**
- 基準割れ3路線を「西部・南部・加太」と名指しする一次情報は archive・市公式ともに未確認。`reference_kameyama_combus_revenue.md` は「R3アンケート」を出典としているが該当資料は見つからない。
- R8.3.4部長答弁の「南部ルートや亀山椋本線沿線の亀山南部地区と西部ルート加太地区福祉バス沿線の亀山西部地区」は**低調エリアの列挙**であって基準割れ路線名の確定ではない。

**How to apply:** 路線名を出すなら「南部ルートなど3路線（R6.12答弁）」に留める。「加太」は正式には**加太地区福祉バス**。
