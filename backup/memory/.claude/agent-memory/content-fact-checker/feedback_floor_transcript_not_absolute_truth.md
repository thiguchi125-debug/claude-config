議場の一般質問 transcript（kusagawa_only.txt 等）は「草川が実際に何を言ったか」の一次情報ではあるが、**発言内容の事実正確性の一次情報ではない**。草川本人が議場で言い間違えることがある。

**Why:** 2026-06-15 R8.6.15 中項目6（シャープ第2工場・次世代産業）で、議場 transcript line79 に草川の言い間違いが2点あった：
- 「国は2024年経済対策で半導体・AIに**210兆円超**の公的支援」→ 正しくは**10兆円超**（2024-11-22閣議決定「AI・半導体産業基盤強化フレーム」・経産省/NRI）。桁が一桁違う。
- 「2023年に**三重半導体ネットワーク**を立ち上げ」→ 正しくは**みえ半導体ネットワーク**（2023-03-02設立・三重県公式）。
- SNS原稿（v1）はいずれも正しい値に修正済みで、誤りの伝播は起きていなかった。もし「transcript＝正」と前提していたら、正しいSNSを誤判定して差し戻していた。

**How to apply:** 発信物を「議場 transcript と整合するか」だけで判定しない。transcript に出てくる数値・金額・固有名詞・年も、桁・名称・年度が常識的に怪しければ外部一次情報（省庁公式・県公式）で再突合する。SNS/ブログが transcript と食い違っていても、外部一次情報に照らして発信物の方が正しければ VERIFIED とし、「議場でこう言ったが発信物は正しい値に直してある」と明記する。逆に transcript の数字をそのまま発信物に転記しただけのケースこそ桁ミスを疑う。
