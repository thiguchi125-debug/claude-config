草川たくやは実践倫理宏正会系の「朝起会」（朝5:00〜6:00）に参加し、会員の前で「感話」を話す機会がある。政治集会ではないため、政策・実績・議員としての押し出しは一切入れない。聴衆は地域の実践者・経営者。結びを「今日一日の実践」に落とすと刺さる場。

**個人史素材（裏取り状況）**
- 早稲田大学 応援部**主将** — 市政報告レポート16/17/22/23/27号ほか複数リーフレットで裏取り済み（`02_publications/leaflets/`）。確定事実として書いてよい。
- 2011年 東日本大震災後、応援部の一員として**岩手県陸前高田市**へ被災地支援。①復興支援チャリティーライブ ②仮設住宅の慰問活動。現地は「何もない」状態で、戦後の焼け野原の写真そのものだった。
- ここから導かれる草川の持論：**「応援というのは、誰かを応援しているようで、実は自分も応援されている」**。陸前高田で実証された。
- **重要**：陸前高田での具体的なセリフ・誰が何と言ったかはアーカイブに一切記録がない（grep済み）。本人記憶が未確認なので創作禁止。原稿では【要確認】枠にして本人に埋めてもらう。

「私は、あなたの応援団」（policy_compass Theme A'）と同根の思想だが、朝起会など非政治の場ではスローガン形では出さず、体験談として語らせる。
