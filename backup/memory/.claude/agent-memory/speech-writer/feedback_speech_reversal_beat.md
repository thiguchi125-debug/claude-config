草川のスピーチ原稿は、出来事を時系列に並べただけでは不合格。以下4点を必ず設計する。

1. **山場の反転を一撃で立てる**。「応援しに行った → 応援されて帰ってきた」のような転換は、淡々と書かず短文の連打＋対句＋間で叩く。
2. **冒頭を説明から始めない**。「今日は8月6日です」型の日付説明はフックにならない。情景・体感から入って事実は後ろに置く。
3. **修辞を意図配置する**（対句・首句反復・三連・漸層）。偶然に頼らない。
4. **デリバリーキューを必ず付ける**（間／長い間／ゆっくり／強く／静かに／視線）。原稿埋め込み＋別記サマリの両方。

**Why:** 2026-08-06 朝起会の感話で、本人下書きが「時系列に並べただけで平凡」だったと明示的に指摘があった。特に「反転が山場なのに淡々としている」「掴みが説明」「修辞設計ゼロ」「結びが一般的な訓話に落ちている」の4点が名指しの不満。

**How to apply:** speech-writer で原稿を出す前に、(a) 山場の反転が短文で立っているか (b) 冒頭1文が説明でないか (c) 結びが「誰かに声をかけてみてください」レベルの一般訓話に落ちていないか を自己チェックする。結びは聴衆の当日の実践に固有名で刺さる形（朝起会なら「朝、起きること自体が互いへの応援になっている」等）まで具体化する。
