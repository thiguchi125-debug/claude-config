**公式LINEの配信文は500文字以内、ハッシュタグは付けない。ただしLINEスタンプ（絵文字コード）は使う**（2026-07-28 草川指示）。

**Why:** LINEは長文だとトークルームで折りたたまれて読まれない。ハッシュタグはLINEでは検索・回遊の機能を持たないので文字数を食うだけ。一方でLINEは親しい距離感の媒体で、スタンプが入るほうが読まれる。

**How to apply:**

**1. 字数** — 500字は **URL を含む全体**で数える。ブログURL（go2senkyo）≒50字、AIインタビューURL≒76字で**リンク2本＝126字**。本文に使えるのは実質370字前後。

**2. 削る優先順位（重要・直感と逆）** — 超過時に削るのは**中盤のデータ細部**であって、提案の中身や導線の丁寧な言い回しではない。
- **最優先で残す**＝「何を求めたか」。議会で何を提案したのかが伝わらない要約は、短くても失敗（2026-07-28に「まず測る」だけに縮めて『端折りすぎて誤解を与えそう』と草川から差し戻し）。
- **先に削る**＝台数・稼働率・逐語答弁などの数字ディテール。これらは**ブログに逃がす**のがLINEの正しい役割分担。LINEは「何を求めたか＋ブログへの導線」。
- **削らない**＝「よろしければご一読ください」「伺った内容は私のもとに届き、市政に活かしていきます」等の丁寧な導線説明。LINEの距離感を作っている部分。

**3. スタンプ・絵文字** — LINE公式アカウントの絵文字コード（`(happy)` `(shiny)` `(sedan)` `(lightbulb)` 等）とUnicode絵文字（🤖等）を使う。**[[feedback_no_emoji_ai_smell]]（発信物で絵文字を使わない）の例外が公式LINE**。挨拶の後、情景の後、CTAの後に1〜2個ずつ置く程度。

**4. 定型** — 冒頭 `こんにちは、草川たくやです` ＋スタンプ。終止は **`皆様のお声、これからもお聞かせください。`**（「皆さんの声」ではない）。

**5. 導線2本** — ブログURL（[[feedback_sns_blog_link_required]]）とAIインタビューURL（[[feedback_line_ai_interview_over_form]]）。URLは前後に空行を入れて独立させる。

**実例（2026-07-28 草川確定・471字）**: `drafts/2026-07-27_亀山駅前送迎環境_SNS7PF_v2.md` の公式LINE節。
