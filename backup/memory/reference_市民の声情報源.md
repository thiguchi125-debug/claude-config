## Why（参照する理由）

- 草川独自施策発掘の最重要素材。**過去発言＋市民の声＋国政動向**が揃って初めて「他議員と何が違う草川独自施策」が立ち上がる
- 2021〜2026の5年分の生データなので、**草川の支持者層の関心の経年変化**が読み取れる
- 個別意見には「給食白衣個人持ち化」「体育の着替え男女分離」「教育委員会LINE分離」「災害弱者の給水アクセス」等の **草川独自軸の種** が多数含まれる

## How to apply（使い方）

### A. 施策発掘・政策検討時
- 担当ドメインのファイルを読み、市民の声から施策候補を吸い上げる
- 各施策提案に「市民の声裏付け」（シート行・年代・地区＋抜粋）を必ず添える
- expert agent に渡す際は **担当ドメインファイル1本だけ** で十分（直接3シート読みは tool_uses 浪費）

### B. ブログ／SNS／街頭演説／市政報告会
- 「市民から実際こう届いている」根拠として頻出ワード件数を引用
  - 例：「保育園関連105件」「給食関連53件」「リニア22件」「コストコ16件」
- 個別意見の生引用（年代・地区メタ付き、本人特定不可）

### C. 議会一般質問の根拠
- 「Googleフォームで○件届いている」と議場で根拠化（市民意見受付BOX 354432ec- とは別ルート）
- 重複や類似要望を集約して「複数市民から○件の声」と数量化

## 増分取込運用

新規回答が3シートに追加された場合：

1. `mcp__claude_ai_Google_Drive__read_file_content` で増分行を抽出（既存件数との差分）
2. 6ドメインのいずれかに分類
3. 該当ドメインファイルに追記（時系列順を維持）
4. _index.md の件数を更新

**実装候補**：
- **oyasumi** 週次バッチで自動 ETL更新（3シートをポーリング）
- **iken** スキルから手動更新（受付BOX管理と並行）
- **policy-update** 月次棚卸しで施策候補との紐付け確認

ETL parser スクリプトは subagent 一時保管（`/tmp/citizen_voice_etl/parser.py`）。永続化したい場合は `~/.claude/skills/citizen_voice_etl/` に移管予定。
