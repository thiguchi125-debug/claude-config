ショート動画は、ゲート2段を通った台本をまずObsidian（50_発信/）で開いて草川の `#注記` を待ち、確定してから挿入画像とSNS7種を作る。

**Why:** 2026-09-22 個別避難計画×拠点避難所で、台本未確認のまま画像16枚＋SNS7種を並列で作り、草川の修正（結び・拠点の意義の一文）で作り直しになった。草川「先に内容確認しなくていいのか？台本だけでもobsidianで」「今回の進め方には問題がある」。

**How to apply:** short-video-create の Step 4.5（台本確認ゲート）で必ず止まる。画像やSNSを「待ち時間に並行で」進めない。発信物全般で、下流の制作物（画像・派生文）は本文確定後。関連 [[feedback_okiba_4tsu_tsukaiwake]]

**2026-10-01改定（草川提案）:** 草川が `#注記` を入れるのは**ブログ（深掘り）1本だけ**。台本・SNS7種はブログ確定後にそこから派生して作り直す（ブログに無い事実を作らない）。台本は注記対象にせず、画像着手前に「この台本で撮れるか」を一読でOKだけもらう（9/22の作り直し事故を防ぐ最小の止め）。SNSはゲート通過後にまとめて見せる。
**Why:** 3本柱シリーズ第02回で、ブログ・台本・SNSを並行に作った後に草川が「ブログの内容が薄すぎる」と止めた。3本に注記させると手間が3倍になり、ブログを直せば台本・SNSも変わるので先行分は無駄になる。
