団体・協会名義（例: 亀山市eスポーツ協会公式アカウント）で「実名掲載OK」の同意を得た素材を、**草川たくや個人の政治ブログ（議員肩書・ご意見箱・公式LINE・Threads導線つき）へ移植する**とき、その同意は自動的には有効にならない。同意の"射程（器）"が「協会の投稿」から「議員個人の政治発信」に変わるため。

**Why:** 特に不登校の子・要配慮層が絡む素材は、団体名義SNSではあえて「草川の名前・顔・肩書を入れない／協会会計／主語=私たち協会」という防御設計で作られていることがある（例: 2026-07-03 でんでん交流会別稿）。それを政治ブログに載せると、子どもの声が草川個人のブランド物語の裏付けになり「子どもの政治利用」と読まれる物議リスク（HIGH）が構造的に発生し、同意者も「協会はOKでも議員ブログは別」と後から言い得る。

**How to apply:**
- 器が「団体名義SNS→個人政治ブログ」へ変わる素材は、同意を「**議員個人の政治ブログ（ご意見箱・LINE付き）に、実名で載せる**」と明示して取り直してから公開。取れるまで投稿しない。
- 中和策: 当該段落末尾に「これは私の実績づくりのためではなく、協会のみんなで積み重ねている活動の一つ」等の humble な一文を足し、自己PR感を薄める。理事等の立場は本文で明示（[[guard_esports_dual_role_conflict]]）。
- 判断が要る場面は content-risk-reviewer が Axis7品位・配慮＋Axis1個人情報でHIGH→ASK_USERを出す。草川本人判断を仰ぐ。
