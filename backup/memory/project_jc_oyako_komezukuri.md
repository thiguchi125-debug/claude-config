（一社）亀山青年会議所「親子で米づくり体験」＝2025年に草川が第64代理事長として立ち上げた新規事業。2026年は2年目、草川は**監事**として会場進行をサポート。田植え5/10 → 稲刈り8/30（日）9:00-12:00・太岡寺町の水田 約25アール・園児と小学生と保護者60人／関係者含め総勢80人・こしひかり・のこぎり鎌・参加費無料。2025年は田植え6/1・稲刈り9/14・約100名・収穫米は精米1家族10kg贈呈。協力＝亀山市山下町の米農家「八十八家・神米（かんべえ）」（屋号掲載は本人了承済み）。

**発信時の恒久ガード5点（2026-08-31 安全ゲートで確定）:**
1. **収穫米の配布に一切触れない**。JCが9月中旬以降に1袋10kgを参加者へ無料配布するが、草川名義の発信で書くと公選法**199条の3**（候補者等が役職員である団体が、候補者の氏名を表示した方法で寄附をすることの禁止）に触れる。主語をJCに固定しても不可 — 氏名冠タイトル＋一人称＋「私が理事長のときに立ち上げた」が同一記事にあると、**記事自体が「氏名表示」の実行手段**になる。参加費無料のため米に対価性がなく防御線が無い。配布現場で手渡し役に立たない・写真に入らないことも要。
2. **協力農家の代表者名を書かない**。伊勢新聞2026/08/31は「西村洋一」だが、三重県安心食材表示制度DB・食べチョク・同紙2025/09/15はすべて「**西村洋人**」。表記が割れるので屋号のみ。
3. **JC理事長名を書かない**。2026年度理事長と同名の市職員が亀山市R6所管事務事業概要書（産業建設委員会・環境課／生物多様性・獣害対策室主査）に記載あり。同一人物の可能性。
4. **参加児童の発言を引用しない**。新聞に載った発言は記者に向けられたもの。氏名を伏せても草川への発言に付け替えることになる。
5. **未確認の情景を書かない**。「足元がぬかるむ／泥だらけ」は本人確認で**否定**（稲刈り前は落水して地面を固めるのが通常）。「できた！」の声は本人が実際に聞いたが「歓声」は盛りすぎ。
