市民からのSNS DM相談への返信（iken経路=SNS DM）を確定する際の作法。2026-06-18、亀山中保護者からの部活動地域移行（ソフトテニス部）DM返信で、A案（共感型）を草川が手直しした確定版から抽出。

**Why:** AI生成の初稿は「議員が現場を把握できていなかった」ことを露呈する表現や、不要な署名を付けがちで、政治家の返信として不自然になる。

**How to apply:**
- **議員の無知を露呈する表現は禁止**。「これは私も初めて知った大事な事実です」型はNG。市民が持ち込んだ具体的な現場情報は「とても大事な現場の課題です」と受ける（事実として価値を認めるが、知らなかったとは言わない）。[[feedback_no_parroting_in_replies]]
- **返信が遅れた場合は冒頭で素直にお詫び**。「申し訳ございません、リクエスト欄に埋もれていて返信が遅れました」型を挨拶直後に差し込む。
- **SNS DMは末尾に署名を付けない**。「草川たくや」のサインオフは不要（DMは誰からか自明）。メール返信のみ署名フル。[[feedback_citizen_reply_progress_report_style]]
- **議会名を明示**：「本会議で」より「亀山市議会の本会議で」と書く。
- **継続フォローは「議会で継続して追いかけます」**（「委員会の場で」より本人は「議会で」を好む）。[[feedback_no_aggressive_pursuit_phrases]]
- 一人称は「私」、共感→現状認識→約束（持ち帰り確認＋継続フォロー）→未来、の流れ。約束はL2相応に留め個別即解決を約束しない。
