草川のタスクを Todoist 等に登録する前に、**保存先と期限の両方を毎回本人に尋ね、回答を得てから登録する**。「今日+3日」等の既定値で勝手に確定登録しない。提案として既定/推奨を示すのは可だが、**本人の回答を待ってから保存**する。

**Why:** 勝手な既定期限・既定保存先での登録は、後から本人が直す手間と朝の視界汚染を生む。本人が「期限を整理したい」と能動的に期限設計したいケースがある（2026-06-15 リマインダー棚卸しで直接指示）。

**How to apply:** スマートインテーク／タスク登録時、(1)保存先候補と(2)期限候補をセットで提示 → 本人の回答を取得 → 一括保存。複数タスクならまとめて期限を尋ねる。これは [[feedback_task_deadline_3days]]（未指定なら+3日デフォルト）を上書きし、「黙って+3日」ではなく「+3日を推奨として提示し回答を待つ」へ更新。関連: [[project_todoist_task_migration]]
