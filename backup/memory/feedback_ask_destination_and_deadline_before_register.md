草川のタスクを Todoist 等に登録する前に、**保存先と期限の両方を毎回本人に尋ね、回答を得てから登録する**。「今日+3日」等の既定値で勝手に確定登録しない。提案として既定/推奨を示すのは可だが、**本人の回答を待ってから保存**する。

**さらに重要（2026-06-15 追加指示）：タスクは登録前に必ず本人確認すること。無用なタスクが増える傾向がある。** スマートインテークで「次アクション候補」を洗い出しても、それを**全部タスク化してはいけない**。多くは**記録（市民意見リスト／PJ経緯ログ／ネタDB）に残せば足りる**。タスク化すべきは「期限を切って自分が能動的に追う必要がある具体行動」だけ。

**記録 vs タスクの判定例（木下空き家・2026-06-15）：** タスク化が必要だったのは「後日現地再確認（写真記録）」**1件のみ**。「バリケード＝近日中に実施」「所有者＝確認していく」「管理不全空き家＝指定を目指す」は**方針・状況であって、記録に残せば十分**＝タスクにしない。AIは4件タスク化して3件が無用と指摘された。

**Why:** 勝手な既定期限・既定保存先での登録は、後から本人が直す手間と朝の視界汚染を生む。本人が「期限を整理したい」と能動的に期限設計したいケースがある。無用タスクの量産は朝のタスクビューを汚し、本当に追うべき1件を埋もれさせる（2026-06-15 リマインダー棚卸し＋木下空き家相談で直接指示）。

**How to apply:** スマートインテーク／タスク登録時、(1)「これは記録だけで足りるか、タスク化が要るか」を各項目で先に振り分け → (2)タスク化候補のみを保存先候補＋期限候補とセットで提示 → (3)本人の回答を取得 → (4)一括保存。迷ったら記録寄せ＋「これもタスクにしますか？」と尋ねる。これは [[feedback_task_deadline_3days]]（未指定なら+3日デフォルト）を上書きし、「黙って+3日」ではなく「+3日を推奨として提示し回答を待つ」へ更新。関連: [[project_todoist_task_migration]]
