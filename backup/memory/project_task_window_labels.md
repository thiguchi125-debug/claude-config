## バッチ枠が要る理由

`bulk_plan.py` は**1タスク＝1ブロック**なので、15分の電話1本に30〜60分を割り当ててしまう。
役所照会46件を渡すと39件しか置けず3割が溢れた。
**1枠に何件詰めるかから設計**すると（60分空きなら4件・30分なら2件）69件中67件が収まる。
枠サイズを固定せず長短両方持たせるのが肝（60分固定＝8日分しか使えず14件溢れ／30分固定＝日数は増えるが総数が減る）。
作業用スクリプトは `scratchpad/batch_blocks.py`（要なら再作成）。

## 1日上限を必ず持たせる（2026-08-10 の失敗）

バッチ配置は「その日に空きがあるか」だけで置いたため、1日上限が効かず
8/13に6.5時間・8/14に5.0時間を積んだ。`bulk_plan.py` は `CAP_WEEKDAY=4 / CAP_WEEKEND=2` を
持っているのに、自作のバッチ配置スクリプトには無かった。**枠を置くときは必ず日別合計を数える。**
目安は1日3.5時間まで（それ以上は実際には回らない）。

さらに、置いた枠どうしの衝突検査もしていなかった：
- 9/4 5:00-6:30 に繰り返しの大物枠と個別枠を二重に作成
- 8/13 13:00-14:00（別セッションの枠）と 13:15-14:15（自分の枠）が重複

**枠を作る前に、その時間帯が本当に空いているかを既存の【作業】枠も含めて確認する。**

## 4週間の容量は満杯（2026-08-10 実測）

8/19-9/6の日中9:00-15:00に60分以上の連続空きがある日は**ほぼゼロ**。
夜18:45-21:00の空きも8/21・8/26・8/28と8/29以降だけ。
「日別の【作業】時間が少ない日」＝空いている日ではない（サロン・地域行事等が入っている）。
新しい枠を足すときは、何かを外すか、9月以降に送るかの二択になる。

## 運用

- カレンダーの【作業】枠の本文に、その回かける先・用件を箇条書きで入れる
- Todoistの期限は枠の日付に揃える（時間の正本はカレンダー側）
- 複数ラベルのタスクは**主窓ひとつに寄せる**（役所＞現地＞夜電話＞机上）。
  両方の枠に入れると同じ用件が2回出てきて枠が信用されなくなる
