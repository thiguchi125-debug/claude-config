## バッチ枠が要る理由

`bulk_plan.py` は**1タスク＝1ブロック**なので、15分の電話1本に30〜60分を割り当ててしまう。
役所照会46件を渡すと39件しか置けず3割が溢れた。
**1枠に何件詰めるかから設計**すると（60分空きなら4件・30分なら2件）69件中67件が収まる。
枠サイズを固定せず長短両方持たせるのが肝（60分固定＝8日分しか使えず14件溢れ／30分固定＝日数は増えるが総数が減る）。
作業用スクリプトは `scratchpad/batch_blocks.py`（要なら再作成）。

## 運用

- カレンダーの【作業】枠の本文に、その回かける先・用件を箇条書きで入れる
- Todoistの期限は枠の日付に揃える（時間の正本はカレンダー側）
- 複数ラベルのタスクは**主窓ひとつに寄せる**（役所＞現地＞夜電話＞机上）。
  両方の枠に入れると同じ用件が2回出てきて枠が信用されなくなる
