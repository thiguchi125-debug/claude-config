画像・PDF・動画素材・印刷物など**ファイルとして成果物を作ったら、指示されなくてもその場で `open <保存先ディレクトリ>` してFinderに表示する**。チャットに画像を貼るのとは別に、必ずフォルダも開く。

**Why:** 2026-08-06 草川指摘「作成した画像があるならフォルダを表示して。指示されなくてもやるべき」。草川は生成物を**自分の目で・実ファイルとして**確認してからでないと次に進めない（スマホ転送・編集アプリへの読み込み・印刷など、次の操作が必ずファイル単位で発生する）。チャットに貼るだけだと、毎回「フォルダ表示して」と言わせることになる。こちらから出すのが前提。

**How to apply:**
- 生成・更新・差し替えのいずれでも、**その回で触ったファイルがあるディレクトリを開く**。複数箇所に出力したなら全部開く（例：`~/outputs/short-video/<案件>/infographics/` と `~/outputs/<案件>/`）。
- Driveミラーへコピーした場合は、ミラー先のフォルダURLも併せて文中に出す（CloudStorage実体は開かずURLで足りる）。
- チャットへの画像貼付（Read）とフォルダを開く操作は**両方やる**。どちらかで代替しない。
- 差し替え・作り直しのときは、旧版を `_v1_backup/` に退避してから開く（どれが最新か迷わせない）。
- 保存先は [[reference_storage_map]] の正規置き場に従う。Desktop/Downloadsに置いて開くのは禁止。
