ショート動画＋SNS投稿文の納品物は、Drive `📱動画素材/<YYYY-MM>_<案件>/` に**全部まとめる**（完成mp4・cover・`SNS投稿文_7PF_vN.md`・`台本_vN.md`・`README.md`）。2026-09-15 あそぼうさい薪割りで、草川「全て一つのフォルダにまとめて」→「今後の管理を考えるとどれが一番いい？」→Drive一本化を推奨し承認。

**Why:** 投稿はスマホから行うので、投稿する場所から全部取れることが最優先。Obsidian vaultはiCloud同期で動画（約100MB）が重く、vault全体より大きい。`~/outputs/` は素材・作業ファイルで500MB超かつスマホから見えない。同じ投稿文を2か所に置くと版がずれる。

**How to apply:**
- READMEには中身の表・今の状態（ゲート結果・NotionのURL）・投稿手順・注意（直前期の再審査日・告示後の運用）・作り直し先（outputsの制作フォルダ）を書く。
- 投稿文をObsidianに一時的に置いた場合は、Driveへまとめた時点で `~/Archive/_trash_pending_<日付>/` へ移す（草川の `#注記` が無いか確認してから）。
- 修正版はDrive上で上書きせず別名（v3…）で置く＝[[feedback_never_overwrite_delivered_drive_file]]。関連 [[feedback_copypaste_draft_delivery]]
