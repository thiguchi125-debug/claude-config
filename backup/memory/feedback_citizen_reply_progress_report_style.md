市民意見への返信を「これまでの取り組みの経過についてご報告」体裁で作るとき、草川が確定させたスタイル（2026-06-16 山添真理菜様への返信で確定）。

**Why:** 草川は受け取った意見への返信を、対決調や空疎な共感でなく「事実に基づく経過報告」として丁寧かつ端的に返したい。意見受領から時間が経っているケースが多いため「この度は」は使わない。

**How to apply:**
- 出力は必ず**プレーンテキスト**で、デスクトップに `.txt` 書き出し→`open -e` で開く（CLIはコピーボタンが出ず、チャット枠コピペは行頭に全角スペースが混入するため）。Markdownの `**` 太字・`#` 見出しは使わない。見出しは `【…】`。
- **構成**：①宛名（冒頭にフルネーム＋様、姓名間は全角スペース 例「山添　真理菜　様」）②「平素より市政にお心を寄せていただき、ありがとうございます。」③「以前お寄せいただいた、〜についてのご意見について、これまでの取り組みの経過をご報告いたします。」④【テーマ別見出し】で経過報告⑤「いただいたお声は、今後の…政策を考える大切な材料として活かしてまいります。お気づきの点があれば、いつでもお寄せください。」で結ぶ。
- **件名行と末尾の署名（亀山市議会議員 草川たくや）は付けない**（草川側で対応）。
- **ニュアンス**：文はぶつ切りにせず「運営されていますが、私は〜」とつなぐ。「一方で、」は避けて直接展開。市民の指摘を否定せず受ける＝課題に触れる前に「おっしゃる通り、」を添える。報告と共感をなめらかに一文化。
- 長さは端的に。事実は議会質問アーカイブと突合し、過去の草川の取り組み（質問時期・実績）を最低1件は織り込む。確認できない数字は断定を避ける。
- 各意見は処理後、📝市民意見リスト（ds c2c34bd8）＋必要に応じ📝一般質問ネタDB（ds 42716725）に登録。[[feedback_no_aggressive_pursuit_phrases]] 準拠で「次の議会で追及」型は使わず「執行部との対話を重ねながら求める」。
- **同一人物からの複数意見は1通にまとめる**（草川指示）。
- 受け手の言い回し（2026-06-16 給食×医療費まとめ返信の確定で追加）：①受け手が既に知っている事実は「**ご案内の通り**」で受ける ②長く待たれてようやく実現したことは「**ようやく始まりました**」 ③固有名詞は正確に（亀山中学校給食は「**外部給食センター方式**」）④冗長な「すでに〜しており」より「実現し」と簡潔に。
- **中学校給食は中部中学校でも実施開始済み**（草川確認・2026-06）。「準備中」「これから」表現は誤り、GUARDRAILS【8】「中学校給食は実施中前提」準拠。
