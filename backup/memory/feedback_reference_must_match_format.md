制作物の造形を借りるとき、**参照は必ず同じ判型の実物**を使う。手元にある別判型の参照で代用しない。代用すると「構図」ではなく「部品」だけを抜き出すことになり、意味を持たない図形が並ぶ。

**Why:** 2026-08-31 育休退園サムネで実際に起きた。サムネ(16:9 OGP)の参照が1枚も無い状態で、印刷物の参照 brand01(Warren 2020＝**Tシャツ・缶バッジ・ヤードサインのムードボード**)と rep10(A4縦の企業インフォグラフィック)を代用。そこから円・縦ストライプ・斜め面という部品だけを抜いて16:9に貼り、草川に「クズデザイン」と却下された。**模写採点表は5軸中5軸「可」で通っている** — 参照が間違っていれば採点表は間違ったものへの忠実度を測るだけで、質を担保しない。

さらに、参照が無いまま机上でひねり出した選び方ルール「写真がテーマと意味的に繋がらないなら写真を使わない」が誤りだった。政治サムネの実物12点を収集して調べると、**人物とテーマが繋がっている面は2点のみ、残り9点は「ただ喋っている人」を端25〜35%に置いて成立**。写真を外して幾何図形で代替したのが失敗の直接原因。ルールは撤回済み。

**How to apply:**
- 判型フォルダに参照が無いなら、**代用せずに先に集める**。集めるまで実装に入らない
- 参照が無いまま「型の選び方」ルールを机上で作らない。実物を見てから書く
- 借り先の質ゲートは判型ごとに違う。「議員の自作紙面は不可」は**紙のチラシの規則**で、サムネには適用しない（サムネは政治発信で最も競争が激しく、実際に上手い運用がある）
- 実装者には「参照画像と自分の出力を並べて採寸比較し、差を数値で報告する」ことまで指示する。「参照から借りた」の自己申告だけでは部品貼りを検出できない
