**正式名称**：小中高生限定！コミバス無料乗車キャンペーン2026
出典：亀山市公式 https://www.city.kameyama.mie.jp/docs/2026062500027

| 項目 | 内容 |
|---|---|
| 実施主体 | **亀山市**（政策部 政策推進課 交通政策グループ） |
| 実施期間 | 2026年7月21日（火）〜9月30日（水） |
| 対象者 | 市内コミバス路線を利用する小学生・中学生・高校生（**住所要件なし**） |
| 対象路線 | 全7路線（さわやか号・野登・白川・東部・南部・西部・加太地区福祉バス） |
| 利用方法 | 高校生は降車時に学生証を提示 |

**利用実績（未確認）**：2026-08-26時点で**900名弱**。出所＝自治会連合会からの情報提供（伝聞）。市の公表資料・所管課への裏取り未実施。**9/30まで継続中のため期間途中の累計**であり最終実績ではない。

**使うときの注意**：
- 未確認のまま対外発信・議場・訪問先で口に出さない。残る未確認は「延べか実人数か」「路線別・学齢別の内訳」「市の負担額」「市が公表済みの数字か」の4点。
- 主体は**市**。「私が無料にした」と書かない（[[feedback_sns_no_action_promise_assertions]]）。
- 恒常化を論じるときの論拠数字は [[reference_kameyama_combus_revenue]]（収支率4.8%）と [[reference_kameyama_combus_fare]]（運賃4区分）。
