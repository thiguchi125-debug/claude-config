亀山市の育休退園は **令和8年4月（利用案内改定）と令和8年8月1日（事務連絡）の2段階**で変わっている。

**【B】令和8年8月1日〜**（子ども未来部子ども政策課長 事務連絡 令和8年8月3日・保護者各位「両親ともに育児休業を取得した場合のきょうだい児の保育要件の取扱いについて」）
両親ともに育休のとき、きょうだい児（上の子）が **3歳以上児クラスなら、育児休業対象子どもが1歳になった翌日の属する年度の3月31日まで**在園可。変更前は「5歳児クラスのみ取り消さない」で、それ以外は取得日から認定取消。**3歳未満児クラスは適用外**。

**⚠️ 令和8年度版利用案内 Q34「両親ともに育児休業を取得される場合は…原則翌月から退園」は、この事務連絡で上書きされている。** 8/1以降にQ34だけを引くと誤り。利用案内PDFだけをファクトチェックしても検出できない。

**言ってよい／いけない（2026-08-26 FACTBASE改訂で更新）**: 「これまでは**原則**、下の子が1歳になるまで」は**言ってよい**（根拠＝R7年度版p.16⑥「産後12か月を超える育児休業中は、原則として保育所等の利用継続はできません」＋令和7年6月定例会 高宮子ども未来部長答弁）。旧版の「延びた＝一律誤り」は撤回済み。ただし①3歳未満児クラスには「延びた」と言わない（R7の例外に既に「満1歳に達する日以後の最初の3月31日まで」がある）②年長（5歳児クラス）はR7から無条件（事由9(1)・p.16⑥「認めます」）でBefore/Afterが無い③期間が明記されて延びたのは3歳以上児クラスの年少・年中の層のみ。「（最長）」の2文字を落とさない。
**【A】4月改定でも3歳未満児クラスは「新たに対象に入った」ではない**（2026-08-27 ブログv2検証で確認）: R7事由9(3)とR8事由8(3)は要件（4か月前から在園／当該児童の発達上、環境の変化が好ましくないと思料される／引き続き利用することが適当と認められる）が同一。変わったのは事由番号・判断単位（3歳未満の児童→3歳未満児クラス）・保育必要量（R7は「その他」事由で福祉事務所長裁量→R8は短時間原則、福祉事務所長が認めれば標準時間）。
