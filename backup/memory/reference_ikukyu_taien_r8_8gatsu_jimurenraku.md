亀山市の育休退園は **令和8年4月（利用案内改定）と令和8年8月1日（事務連絡）の2段階**で変わっている。

**【B】令和8年8月1日〜**（子ども未来部子ども政策課長 事務連絡 令和8年8月3日・保護者各位「両親ともに育児休業を取得した場合のきょうだい児の保育要件の取扱いについて」）
両親ともに育休のとき、きょうだい児（上の子）が **3歳以上児クラスなら、育児休業対象子どもが1歳になった翌日の属する年度の3月31日まで**在園可。変更前は「5歳児クラスのみ取り消さない」で、それ以外は取得日から認定取消。**3歳未満児クラスは適用外**。

**⚠️ 令和8年度版利用案内 Q34「両親ともに育児休業を取得される場合は…原則翌月から退園」は、この事務連絡で上書きされている。** 8/1以降にQ34だけを引くと誤り。利用案内PDFだけをファクトチェックしても検出できない。

**言ってはいけない**: 「期限が『1歳になるまで』→『年度の3月末まで』に延びた」は誤り（令和7年度版にも3歳未満児について「満1歳に達する日以後の最初の3月31日まで」があり、令和7年度版の認定期間表に育児休業の行自体が無い）。年度末までの期限は【B】の話として語る。
