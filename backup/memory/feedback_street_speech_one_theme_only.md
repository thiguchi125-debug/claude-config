街頭演説の「1本の統一フロー」は、**1テーマを深く掘る** という意味。複数の話題を「水と緑と足」のような詩的フレームで束ねるのは禁止。

**Why:**
- 2026-05-06 v3で「鈴鹿山系の麓で水と緑と足を次の世代に手渡す」という詩的umbrellaフレームを使い、ネイチャーポジティブ協定＋水路＋配水池耐震＋コミバスを無理矢理束ねたところ、「テーマ設定も流れもわかりにくい、無理矢理感が大きい」と差戻し
- 詩的umbrellaは政治家らしい虚飾になり、voice-dna（具体・現場・数字）から外れる
- 軸1→軸2→軸3 の繋ぎが「ところで」「最後に」のような無理な接続詞になる
- 聴衆は「結局この人は何の話をしてるの？」となる
- 「1本」とは「テーマ1つで深く」、「3軸」は1テーマの中での視点切替（背景/現状/将来）として使う、という解釈に再定義

**How to apply:**
- daily-street-speech 起動時、**今日の鮮度素材から1テーマだけ選ぶ**（複数候補があるなら草川に「今日はこのテーマで」と確認）
- そのテーマの30秒掴み → 背景・なぜ重要か → 草川の継続取り組み（archive引用） → 今後の論点 → CTA、というシンプルな**1テーマ縦堀り構造**
- 3軸（伝える/繋ぐ/希望）は使ってもいいが「3軸全部入れる」を目的化しない。**そのテーマが自然にどの軸に属するか**で1〜2軸に集中
- 詩的フレーム・スローガン的umbrellaは禁止。「○○と○○と○○」「○○のまち」「○○を次の世代に」などのlyrical束ねワードは使わない
- 別テーマで話したくなったら**翌日の街頭演説に回す**。同じ20分に詰め込まない
- 1テーマ縦堀りで20分が持たない場合は、**同じテーマを別エピソード・別数字・別市民の声で言い直す螺旋**で回す（テーマを変えるのではなく深掘りで回す）
- 政策分散ルール（feedback_street_speech_topic_diversity.md）は「**1日では1テーマ／週単位で5ドメイン分散**」と再解釈する
