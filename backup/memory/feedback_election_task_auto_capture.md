# 選挙関連タスクの自動拾い上げ — 3スキル連携設計

**Why**: 2026-05-21 草川指示「後援会の幹事（サポーター）やウグイスの募集は急務だが、タスクに上がってこないのが問題。選挙関係で生まれているタスクがタスクDBに反映されていないのが問題」

**根本原因**：選挙活動の意思決定（「サポーター募集を始めたい」「ウグイス候補をリストアップしたい」等）が**頭の中で完結**して、タスクDBに自然に流れる仕組みが無い。

**How to apply**: nichijo・ohayo・task-audit の3スキルで連携して、選挙関連タスクの自動拾い上げを実現する。

## 1. nichijo スキル拡張：選挙キーワード→タスク自動提案

### 仕組み
「記録」トリガー時、内容に **選挙関連キーワード** が含まれていたら関連タスクをDone候補orタスク追加候補として提示。

### 選挙関連キーワード辞書
```yaml
人材確保:
  - 後援会幹事, サポーター, ウグイス, 選挙運動員, 出納責任者
  - 選挙事務所スタッフ, ポスター掲示, 選挙カー運転手
  - SNS応援部隊, 街頭サポーター, 印刷物配布
  - 立会演説スタッフ, 開票立会人

戸別訪問:
  - 訪問完了, 〇〇軒, 在宅, 投函, 配布
  - 自治会, 地区, 訪問ルート

市政報告会:
  - 市政報告会, 報告会開催, 案内チラシ, 開催日程
  - 会場確保, 集客

公約・発信:
  - 3本柱, 公約, リーフレット, 市政報告レポート
  - ポスター撮影, 政策発信

法定届出・手続き:
  - 立候補届, 選挙運動費用, 収支報告書
  - 公費負担, 公報原稿, 選挙はがき
```

### 動作例
- 草川入力：「記録：後援会幹部会で太郎さんに幹事を打診した」
- nichijo検出：「幹事」キーワード → 関連タスク提案
  - 「選挙運営人材確保2026 PJの『後援会幹事候補リスト作成』タスクに太郎さんを追加？」（Y/N）
- 草川承認 → タスク本文に進捗追記＋PJ次の一手判定

## 2. ohayo シグナル拡張：選挙人材不足検出

### シグナル追加
```
🗳️ 選挙運営人材シグナル
  ├ 未確保カテゴリ: N/9（後援会幹事 / ウグイス / 事務所スタッフ / 出納責任者 / 掲示責任者 / 運転手 / SNS応援 / 街頭サポーター / 印刷物配布 / 立会演説）
  ├ 期限まで30日切ったカテゴリ: M件
  └ 0%着手のカテゴリ: K件
```

### 閾値
- 未確保3カテゴリ超 → ⚠️
- 期限30日切迫 → 🚨
- 0%着手 5カテゴリ超 → 🚨

### 誘導文
「選挙運営人材確保2026 PJを見直す」「task-audit pj-focus モードで詳細確認」

## 3. task-audit pj-focus モード拡張：選挙PJ「足りないタスク」テンプレ照合

### 仕組み
★選挙PJ・選挙運営人材確保2026PJ・選挙ポスター費用PJ等の選挙関連PJに対して、**期待されるタスクのテンプレート**と現状を照合。

### 必須タスクテンプレ（選挙運営人材確保2026 PJの場合）
```yaml
- 後援会幹事・サポーター候補リスト作成（5/31期限・後援会員DBから抽出）
- 後援会幹事・サポーター打診（6月中）
- ウグイス嬢候補リスト作成（7/15期限）
- ウグイス嬢打診・確定（7/31期限）
- 選挙事務所スタッフ募集開始（7/15期限）
- 出納責任者選任（8/31期限・法定届出PJと連動）
- 選挙ポスター掲示責任者募集（9/15期限）
- 選挙カー運転手手配（9/15期限）
- SNS応援部隊募集チラシ作成（7/31期限）
- 街頭演説サポーター打診開始（8/31期限）
- 印刷物配布スタッフ募集（9/15期限）
- 立会演説スタッフ確定（10/10期限）
- 開票立会人選定（10/17期限）
```

### 動作
1. PJ現有タスクと必須テンプレを照合
2. 不足タスクを「自動提案候補」として表示
3. 草川承認で一括タスク登録

## 4. 同様の構造改善が必要な他PJ

| PJ | 必須タスクテンプレ要 |
|---|---|
| 法定届出・選挙手続き | 各届出書類15件以上の標準テンプレ |
| 選挙ポスター・費用書類 | 撮影/デザイン/印刷/掲示の標準フロー10件 |
| 後援会員DB流入運用 | 月末ゲート集計タスク（5/31、6/30...）の自動繰返し |
| 9地区悉皆訪問 | 各地区の月別目標・実績集計タスク自動生成 |
