**制度の正式表記は「かめやまマタニティ・サポート119」**（ひらがな＋中黒）。議事録の答弁表記「亀山マタニティサポート１１９」を対外発信にそのまま使うと、市民が検索して辿り着けない。正本＝ https://www.city.kameyama.mie.jp/docs/2026030500011/ （2026-04-03公開）。担当は**子ども未来部 子ども総合支援課 母子保健グループ**（TEL 0595-98-5003）。

**草川の提案→実現の時系列（議事録で裏取り済み・草川発言＋市答弁ペア）**
- 2025年9月定例会 一般質問：草川が「市内唯一の分娩取扱医療機関が分娩休止」を示し、妊婦事前登録型の救急搬送支援システム（通称ママ・サポート119）の導入を提案。先行例に名張市・岡山県高梁市・新見市。高宮綾子 子ども未来部長「制度導入の可能性について調査・研究を進めてまいりたい」
- 2026年3月5日 本会議 質疑：同部長「消防本部と連携し、本年4月から運用を新たに開始します」「事前に二次元コードから登録していただいたかかりつけ産科医療機関等の情報を消防本部と共有」「本年4月からは産後ケア事業も拡充し、新たに通所型と宿泊型にも取り組んでまいります」。草川「ぜひ積極的な利用促進もお願いしたい」
- 2026-03-04 代表質問で部長が「ご提案いただきました」と草川提案であることを答弁で認めている。ただし「草川の提案が導入の原因」と市が明言した記録はないので、対外発信では「私が導入を提案し、市が今年4月から始めた制度」と提案者と実施主体を分けて書く。

**混同しやすい事実：市内に分娩可能な産科医療機関はないが、妊婦健診は市内でも受けられる。** 市は「妊婦一般健康診査票（14回分の補助券）で県内医療機関で受診」と案内（https://www.city.kameyama.mie.jp/docs/2016033100332/boshi.html ）。「産む場所が市内にない→だから健診も市外」と書くと誤解を生む。市外通院が発生するのは主に分娩先で健診も受けるケース。

**登録導線の現在形**：議事録は「二次元コード」だが、市公式ページの現在の案内は「申請フォームから登録」。対象も「一人のとき」ではなく「本人または家族等の車で参加医療機関に移動できないとき、または主治医等が緊急に搬送する必要があると判断したとき」。
