シャープ亀山工場の現状（報道ベース・2026年6月時点）。**「シャープが亀山から去った/撤退した/世界の亀山が終わる」は事実誤認＝禁止。**

## 3施設の正確な状況
- **第1工場（K1）**＝**稼働継続・むしろ強化**。iPhone用カメラモジュールは2024年に終了 → **2026年度から欧米自動車メーカー向け車載パネルの量産を立ち上げ**、Nano LED等次世代技術へ投資継続。シャープは**「生産を第1工場に集約」**する方針＝亀山で事業を再構築している（投資している側）。
- **第2工場（K2）**＝スマホ向け中小型液晶の生産を**2026年12月で終了**（当初8月→顧客需要で延期・2026-05-12発表・河村哲治社長）。**鴻海への売却は不成立**でシャープが保有のまま宙に浮く。**希望退職1,170人**・27年3月期に約**90億円の営業損失**見込み。「世界の亀山」を象徴したのはこのK2の液晶。
- **亀山北工場**（別棟・スマホ向けセンサー部品・2021年3月期以降 稼働停止）＝**トピアに12億円で売却**（2025年8月・売却益4.8億円）。K1/K2の液晶生産とは別施設。混同注意。

## 発信での扱い
- 正しいフレーム＝「シャープ後の代替産業」ではなく「**シャープが第1工場で再構築するこの局面で、市はシャープと共に亀山の産業基盤（電力・工業用水・集積技術）を次世代産業へどう広げるか**」。
- 議場・原稿・SNS・ブログとも**報道事実には「報道によれば」を冠す**。
- 6月議会一般質問③-2はこの正確な前提で構築（[[project_ippan_shitsumon_2026-06_resume]]）。
