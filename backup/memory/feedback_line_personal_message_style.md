2026-09-10、LINE私信（後援会幹事の相談＋イベント協力の依頼）の整形で、草川が確定版に入れた手直し＝①お礼と直近の依頼を**1ブロックにまとめた**（空行で切らない）②結びの「お知らせいただけると**助かります**」→「**幸いです**」。

**Why:**
- LINEは1行ごとに空行を入れると縦に伸びてスクロールが増える。話題が変わるところだけ空行で切るのが草川の体感に合う
- 「助かります」は目上・世話になっている相手にはややくだけている。私信の結びは「幸いです」

**How to apply:**
- 段落は**話題単位**で切る。お礼＋直近の1件は同じブロック、別件（相談ごと）で1回空ける、結びで1回空ける
- 相手に可否を委ねる結びは「〜いただけると**幸いです**」
- 依頼は**所要時間＋こちらから伺う**を書く（「30分ほどお時間を頂戴できないでしょうか。ご都合のよい場所へこちらから伺います。」）＝相手が可否を判断しやすく、断りやすい
- 絵文字は使わない（[[feedback_no_emoji_ai_smell]] は私信でも同じ）
- 1:1の私信でも、後援会・寄附・飲食が絡む文面は content-gate-lite に通す（公選法199条の2の外形チェックが効く）
