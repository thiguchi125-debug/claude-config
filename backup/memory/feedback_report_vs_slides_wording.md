草川が「**出屋のレポート**」のように言うとき、地区版市政報告レポート（紙）ではなく **市政報告会スライド** を指している場合がある。指示の中身と実物のページ数で判別してから作業に入る。

**Why:** 2026-08-23、「出屋のレポートの話です　写真1枚だけのページを外して」という指示を受けた。地区版レポートは A4両面＝**必ず2ページ**で、写真だけのページは構造上あり得ない。一方その日の報告会スライドは40ページあり、写真1枚だけのスライドが1枚だけ存在した。指示の対象は明らかにスライドだった。逆に安知本のときは「レポートを表示して」で紙のレポートが正解だったので、語だけでは決まらない。

**How to apply:**
- 判別は実物で行う。`pdfinfo` でページ数を見て、**2ページ＝紙のレポート**（`02_report/`）、**数十ページ＝スライド**（`03_slides/`）。「3ページ目」「〇〇のスライドを足して」など2ページに収まらない指示は、その時点でスライド確定。
- 片方の読みが物理的に成立しないなら、聞き返さずに成立する側で進めてよい。ただし**どちらと判断したかを納品時に1行で明示**し、違えばすぐ戻せるようにする。
- 地区名の取り違えは即座に巻き戻す。同じ日に安知本と出屋の両方を触ったとき、こちらが安知本を編集して「違う、戻して」と言われた。バックアップと `_old_*.pdf` を必ず残しておけば1コマンドで復元できる（[[feedback-houkokukai-slide-edit-via-source]]）。
