# タスクの期限は基本3日以内

✅タスクDBへ新規登録するタスクの**期限（date:期限:start）**は、草川から特に明示指定がない限り**今日から3日以内**に設定する。

## Why:
2026-05-11、「中庄橋まわり 中ノ川河川堤防の対応進捗確認」タスクを 2026-05-25（2週間後）で登録したところ、草川から「期限は3日以内に、今後もそのように」と直接指示。理由は明示されていないが、運用上の推察:
- 期限が遠いタスクは ohayo の本日／超過ブロックに乗らず視界外に流れる
- 2週間先設定だと「今日やらなくていい」と先送りされ inbox 滞留の温床
- 3日以内なら毎朝のブリーフィングで連続して目に入り、自然に処理される
- 期限超過しても3日刻みなら再設定の体感コストが低い

## How to apply:
- **デフォルト**: 期限を聞かれない／指定されない単発タスクは `今日+3日` を入れる（例: 今日2026-05-11なら 2026-05-14）
- **例外（明示指示で延ばす）**: 「6月議会に間に合えば」「来週中で」「期限なし」等、草川が長めの期限を明示したときのみそれに従う
- **例外（短くする）**: 「今日中」「明日まで」等の急ぎ指示は当然それに従う
- **既存タスクの再設定**: 期限超過タスクを再スケジュールするときも基本3日以内で刻む（遠い未来へ送らない）
- **市民相談の単発返信**: 元々48〜72時間以内に返す運用なので自然に合致
- **議会・選挙の特定日に紐付くタスク**: 議会開会日／街宣日／選挙公示日等の固定日付があるものはその日付を期限に（3日ルールより固定日付が優先）
