リスクレビューで引用・記述を削除させて再執筆させると、**執筆エージェントは空いた分量を「もっともらしい当日の情景」で埋めてくる**。2026-08-31のJC稲刈りブログで実証：児童の発言引用を削らせたら「足元は乾ききっておらず、靴もズボンも泥だらけ」「途中でやめてしまう子はほとんどいませんでした」「保護者の方が横で束をまとめ」という段落が新規に出現した。本人に確認したら**ぬかるんでいなかった**。SNS横展開でも同型で「歓声が田んぼのあちこちから」と格上げが起きた。

**Why:** もっともらしいからこそ危ない。この種の記事を最も丁寧に読むのは当日その場にいた参加者と関係者で、一般読者が気づかない細部を一目で判定する。選挙前に「見てもいないことを書く議員」という評価が付くコストは、情感的効果とまったく釣り合わない。

**How to apply:** ①修正版のレビューは全体再点検ではなく**差分**で洗い、増えた文の出所を一つずつ問う ②「一般に成り立つ所作・手順の説明」（例：腰をかがめて鎌をあてる＝稲刈りとはそういうもの）は書けるが、「その日その場で起きた特定の出来事」（田の状態・誰が何をしたか・程度の主張）は本人確認なしには書けない、と線引きを執筆側に明示して渡す ③削除指示を出すときは同時に「穴は情景描写で埋めず、既確認の事実の範囲で埋めよ」と書く ④修正のたびに「声」→「歓声」のように語が盛られていないか語彙レベルで比較する。
