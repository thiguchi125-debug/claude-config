# 亀山市 新庁舎整備の確定事実（2026-06-25 一次資料で再確定）

| 項目 | 内容 |
|---|---|
| **開庁目標** | **令和18年度（2036年度）** ← 当初R12から約6年延伸後の現行値 |
| **建設予定地** | JR亀山駅周辺エリア（選定済み） |
| **現庁舎** | 築65年超。災害時の防災拠点として建て替え |
| **延伸の経緯** | 市は令和7年2月に大規模施設整備の基本的考え方を取りまとめ、新ごみ処理施設との整備時期調整＋財政負担軽減のため**約6年延伸**を決定 |
| **財源** | 国・県の交付金/補助＋庁舎建設基金を計画的に積立。事業手法は引き続き検討 |
| 総事業費 | 約95億円（中日新聞2024報道・旧計画ベース。延伸で変動余地あり、断定回避） |

## 一次情報
- **第3次亀山市総合計画（案）p.144**：「新ごみ処理施設の整備時期との調整により、整備時期を**6年程度延伸**することとしました」（市は令和7年2月に取りまとめ）＝**正本（延伸後）**
- **R7.6本会議 原田総務財政部長答弁**：「整備時期を6年程度延伸することといたした」
- 木下版市政報告会PLAN（2026-06-13）：「新庁舎 R18開庁」＝市「大規模施設等整備事業主要スケジュール」由来で正しかった
- **亀山市新庁舎整備基本計画（案）の整備スケジュール表＝旧計画**：R5基本計画→R7用地交渉→R8基本設計→R9実施設計→R10-11工事→**R12開庁**。これは平成30基本構想・令和元基本計画ベースで、令和7年2月の延伸決定前。**この表を現行と誤読しないこと**

## 重大注意（二度と間違えない）
- **「令和12年度開庁」は旧計画。現行はR18（2036年度）**。逆ではない。
