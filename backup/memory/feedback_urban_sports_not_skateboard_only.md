アーバンスポーツ署名（鈴鹿川かわまち版／安楽橋の下版）の発信物は、**スケートボード特化にしない**。主題は「多様なアーバンスポーツ（スケートボード／3人制バスケ／BMX／パルクール）による**子どもの居場所づくり**」。

論理の背骨は草川自身の議場ロジック（R8.3.10 本会議一般質問）：
**「音を出せる（人家から距離）」×「歩いて通える（アクセス）」＝相反する2条件を同時に満たす場所が河川敷・橋の下**。
市（建設部長）答弁は「地域活性化に資する可能性の一つとして受け止める」「整備内容は未確定、協議会・ワークショップで意見を伺う」まで＝**約束ではない**。

**Why:** 2026-07-18確定のv2は動画・SNSだけがスケボーに寄っていた。Change.org本文は最初から「スケートボード**など多様なアーバンスポーツ**の拠点（子どもの居場所）」で、①本文には「ストリートバスケ」も明記。発信側だけが狭かった（2026-07-22 草川指摘でv3に改稿）。

**How to apply:**
- 種目を挙げるときは草川が議場で挙げた4種目に限る。**フットサル・ボール遊び等の球技は署名要望文に無く、アーバンスポーツの範疇外**＝期待形成になるので書かない（fact-checker/risk-reviewer 双方指摘・2026-07-22 草川了承）。使い方の広がりは「使う子どもたちと一緒に決める」で含みを残す。
- 冒頭フックで「子どもが遊べる場所がない」と広く言わない。市の公園・児童センター等を否定したと読まれる。「アーバンスポーツを楽しめる場所」と限定する。
- 「決めるのは子どもたち自身」は行政の決定権否定に読まれる。「**使い方を決める場に、子どもたちを**」にする。
- 議会実績（議場質問＋市答弁）を署名告知に載せるときは、署名ブロック直前に「ここから先は、議員としての報告ではなく、市民の一人としての活動のお知らせです」で主体分離する。団体は「有志で立ち上げ、私はその一員として」。
- 名阪工業団地第三公園は「市内初の常設」と書かない。正＝「市が2024年8月にアーバンスポーツ利用のために開放した、市内で唯一の場所」（2023年8月に試験開放が先行・市公式に「常設」の語なし）。
- **P2（2026-09-18〜）以降**、この原稿の再投稿・切り抜き・固定表示は公選法軸が1段階格上げ（全件ASK_USER）。9/17までに掲示継続かコメント誘導を外した版に差し替えるかを判断する。

**2026-07-27 v5.1で主題をさらに転換（この行が最新）**：草川指示「アーバンスポーツといってもよくわからない」「子どもの居場所や遊び場に特化」により、**総称「アーバンスポーツ」を音声から全廃**し種目名（スケボー／3人制バスケ（3x3）／BMX）で言う。総称は署名要望文・ハッシュタグ・長文PFの注釈付き言及にのみ残す。冒頭は「亀山の子どもに、**もうひとつ**、もっと自由に遊べる場所をつくりたい」＝「もうひとつ」が既存施設（公園・児童センター）否定の緩衝を兼ねるので**この語を落とさない**。

**校区の数字は誤用しやすい（2026-07-27 fact-checkで発覚）**：中部中学校区は市内の小学生の44.6%（1,184人・R8.5.1）だが**最多ではない**。亀山中学校区が1,209人=45.6%で最多（中学生も亀山中602>中部中593）。「いちばん子どもが多い学区」は**誤り**＝使用禁止。「これだけ子どもが多いのに」で書く。校区別人口102.5%（亀山市こども計画(案) p.5）は**総人口・H28→R7の10年比で+2.5%**であり、「子どもが増えている」「急激に増えている」と言い換えるのは誤り。他2校区との比較（「あとの2つは減っています」）は資源配分の選別ロジックに読まれる＋署名①の鈴鹿川が減少側の亀山中学校区にあり自己矛盾するため**書かない**。

**署名①の提出先は2者（2026-07-28 草川確認・発信物で落ちやすい）**：署名①（鈴鹿川かわまちづくり版）＝**亀山市長 ＋ 亀山市かわまちづくり協議会 会長**。署名②（安楽橋の下版）＝三重県知事＋亀山市長（安楽川が一級河川＝県管理）。**印刷物（署名簿・趣意書）は当初から2者で正しく、動画・SNS・Change.org掲載文だけが市長単独**になっていた＝紙が正・発信が誤という逆パターンなので、宛先を書くときは必ず `publications/2026-06_かわまちアーバンスポーツ署名/署名簿.html` の「提出先：」行を正本として照合する。個人情報の利用目的文も「市・県に提出する目的」だと協議会が漏れるため「市・県・協議会」または「要望書の提出のみ」と書く。2026-07-28に v5.1台本15箇所・告知SNS.txt 2ファイル各7箇所・change_org掲載文・m2_atesaki.png を修正済（Change.org実ページは草川手番）。
