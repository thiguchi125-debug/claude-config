# ルール

相手が書いてきた事実情報を返信文の中で**そのまま繰り返さない**。

**典型NG例**（草川2026-05-10指摘の実例）:
- 「5月6日から8日、東京の実の娘さんと再会され、しっかりとお応えになった――」
- 「92年の長いご人生を歩まれたお姑様」
- 「シャープの脳トレを楽しみ、LINEを使いこなしておられた」
- 「医療センターを退院されてから安全の里に入所され、看取りのご決断をされたなかで」

これらは元の文面の事実をなぞって「読みました」とアピールする構文。AI生成物の典型的悪パターン。

# Why

草川直接フィードバック（2026-05-10 市民意見返信生成セッション中）。

人間が自然に書く返信は、相手が書いた事実を反復するのではなく、それを読んで自分が何を感じ・何を考え・何を決意したか、で構成される。事実の反復は「ちゃんと読んだよ」というアピールにしか見えず、わざとらしく、不誠実にすら映る。

# How to apply

**全ての返信・応答系の生成で適用**：
- 市民意見への返信案（iken スキル全パターンA/B/C）
- 市民相談メール下書き
- SNSコメント返信・引用RT・お礼DM
- LINE個別返信
- 会話の応答全般

**作り方の指針**：
1. **読んだ自分の心情/身体反応から書き始める**（「しばらくスマホを置きました」「胸が熱くなりました」「少し手が止まりました」「そのお時間に――」）
2. **その状況に対する自分の見解・決意・約束**を組み立てる
3. **固有名詞・数字を入れるなら自然な脈で1〜2点に絞る**（4要素以上は反復臭）
4. **短くする方が安全**（長文ほどおうむ返しが混入しやすい）
5. **間接参照を使う**（「あの停留所の話」「そのお時間に」「文面を読みながら」等で、具体の反復を回避）

**OK例**：
- 「『看取り』の二文字を読んで、しばらくスマホを置きました」（自分の反応）
- 「文面を読みながら、安全の里に向かうあの道を思い浮かべていました」（自分の脳内・場所言及は最小）
- 「あの停留所の話を覚えていてくださって。私の方こそ、ありがとうございます」（間接参照＋感情）

**NG例**：
- 「5月6日から8日、東京の娘さんと再会され、しっかりとお応えになった」（日付・固有名詞・行為の反復）
- 「92年のご人生を歩まれた」（年齢の反復）
