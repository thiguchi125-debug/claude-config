亀山中学校の下校とコミバス南部ルートがかみ合わないのは**水曜日だけ**（授業終了14:20、13:22の便のあと16:37ごろまでバスが無い）。月・火・木・金は間に合っている（草川の現地認識・2026-10-10）。

**Why:** 神向谷懇談会スライドv16 p.46は「完全下校16:45⇔16:35/18:15・1時間30分のすき間・文化部でも厳しい」と全曜日の問題のように書いており、そこから作った第3回台本v4を草川が「違う　水曜日が問題　他は間に合う」と訂正した。

**How to apply:** この話題で発信・台本・質問を作るときは水曜に限定する。16:45/18:15のすき間を問題として使わない。協議中の案2（水曜8便13:22発の繰り下げ・検討中）が本筋。
