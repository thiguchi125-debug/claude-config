学校体育館（避難所となる屋内運動場）の空調をめぐる国の期日は**2つあり、ずれている**。混同すると議場でも発信でも誤る。

- **設置率100%の目標＝令和13年度中**。令和17年度中から前倒しされた。決定は**2026年8月27日**の内閣府「令和８年熊本地震非常災害対策本部会議（第13回）」での総理発言。文科省HPでも明記。
  - **2026年7月31日は「前倒しできるよう取組を加速せよ」の指示までで、年度は示されていない。**「7月31日に令和13年度へ前倒し」は誤り。議場・発信では「7/31に指示、8/27に決定」と2段で言う。
- **交付金（屋内運動場の空調設備整備事業／学校施設環境改善交付金）の対象期間＝令和15年度まで。変更されていない。** 前倒し決定後に出た文科省資料「学校体育館への空調整備の早期実施に向けて」**令和8年9月2日版**にもQ&A付きで残っている。→「目標は令和13年度、しかし補助の窓は令和15年度まで」が使える。
- 算定割合1/2。対象工事費の上限は**EHP 1.1億円／GHP 1.4億円、単年度ごと・建物区分ごと**。「上限1棟1.1億円」は不正確。起債充当率100%・元利償還金の50%に交付税措置で、国の試算では実質地方負担25%。
- 全国設置率31.7%（令和8年5月1日時点）。亀山市は14棟中0棟。
- 熊本地震（2026-07-28発生）では文科省が**発災翌日7/29**に「体育館や武道場には空調設備が設置されていないところも多い」として普通教室の避難所活用を通知（８文科施第３５１号）。最大506か所9,931人が避難、クーラー等1,075台を空輸。
