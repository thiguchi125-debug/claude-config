2026-08-10のタスク棚卸しで実測して確定した。「毎週火水木10:00-11:00を役所連絡タイムにする」型の
固定枠は**作ってはいけない**。地域行事・サロン・議会公務が不規則に入るため2週間で崩れ、
崩れた枠は信用されなくなって、いま起きているのと同じ「棚卸しが機能しない」状態に戻る。

**実測値（2026-08-10〜09-06の4週間）**

| 枠案 | 空いた回数 |
|---|---|
| 平日 10:00-11:00 | 12回中 **2回** |
| 火木 14:00-15:00 | 8回中 6回 |
| 土 9:00-12:00 | 4回中 **1回** |
| 日 9:00-12:00 | 4回中 **0回**（稲刈りJC・ポンプ点検・風祭） |
| 月木金 5:00-6:30 | 12回中 **12回** ✅ |
| 日 5:00-6:00 | 4回中 **4回** ✅ |

**結論**
- 週末午前は地域行事で埋まっている。作業枠を置く場所ではない。
- 月・金の6:30に街頭活動が毎週あるので、早朝枠は**6:30まで**で切る（7:00までにすると毎週ぶつかる）。
- 日中・夜の枠は固定せず、`skills/task-add/sessions.py` で毎週その週の空きを測って置き直す。

**Why:** 総空き時間は4週間で197時間あり「時間が足りない」ように見えないが、
`plan_blocks` が挨拶回り優先枠(15:00-18:30)・昼・予定間バッファ15分を除くと、
実際に置ける量は1日あたり約2ブロックまで落ちる。粗の空き時間で判断すると必ず楽観側に外れる。

**How to apply:** 作業枠を提案するときは必ず4週間ぶん実日付で衝突検査してから出す。
「毎週◯曜◯時」と言い切らない。早朝枠だけは繰り返し予定にしてよい。
