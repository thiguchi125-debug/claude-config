# ohayo タスクは「超過＋本日＋今週中」の3ブロック表示が標準

**Why**：2026-05-11 朝、5/7前後に登録した今週中期限タスク20件超が朝のブリーフィングから消えていた。スキル設計上は「本日期限＋期限超過」のみ取得だったが、これだと「昨日登録した／中期で動かしている」タスクが朝の視界から完全に外れる。週前半に集中する〜日曜期限のタスクを朝に俯瞰できないと、電話一発系の前倒し処理を逃す。

**How to apply**：
- ohayo §3-1b の取得後処理を以下3ブロックに拡張：
  1. **⚠️ 期限超過**（期限 < 今日、Done/Archive 除外）
  2. **⭐ 本日期限**（期限 = 今日）
  3. **📅 今週中**（期限 > 今日 かつ 期限 <= 今週日曜 = 今日+(6-曜日番号) 日。月曜起算）
- 各ブロックでタスク名・期限・優先度を表で並べる。件数の絞り込みは禁止（has_more=true のとき2ページ目まで取得）。
- 今週中ブロックは「登録時期」マーカー（要約欄の「【YYYY-MM-DD 登録】」）が読める場合は最右列に出すと新規タスクの取りこぼし検知に役立つ。
- このルールは ohayo SKILL.md §3-1b に正式反映予定（次回スキル改修）。それまでは ohayo 起動時に手動で3ブロック展開する。
