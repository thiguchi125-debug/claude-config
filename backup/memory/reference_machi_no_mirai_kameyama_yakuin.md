草川は市民団体**「まちのミライ亀山」の役員**（2026-09-17 草川回答で確定）。旧称「まちづくり亀山」— 2026年4月時点のブログは旧表記で書かれており、4月の活動に団体名を出すと表記が割れる。

**なぜ効くか**: 候補者等が役職員である団体は、当該選挙に関し**候補者の氏名を表示した方法で寄附をしてはならない**（公選法199条の3）。「【草川たくや 亀山市】」のような氏名冠タイトル＋一人称の記事は、この「氏名表示」の実行手段になり得る。無償の物品提供・無料体験があると構成要件に近づく。

**どう適用するか**: 団体活動を氏名冠で発信するときは3点を確認する。
1. 立場を**「役員を務める市民団体」と明示**する（「所属する」では不十分。後から役員と判明すると隠していたと読まれる）
2. 参加者への**持ち帰り物品の無償提供**があるか
3. **参加費・入場料などの対価**があるか

物品なし＋対価ありなら、立場明示だけで通せる（2026-09 あそぼうさい薪割りブログの実例）。物品ありなら団体名を落とすか発信を見送る。加えて、団体が市事業に関わる可能性があるため、**市・行政への要望や提言は書かない**（利益相反）。
