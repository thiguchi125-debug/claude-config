- 城北杯＝城北地区まちづくり協議会の主催。2026-10-04（日）、あいあいで開催。親子約50名。太鼓の達人eスポーツ公認大会。協会は謝礼・実費ありで関わった
- 選挙公報で決めた「役員の団体に触れない」は、個人SNSには当てはめない（草川回答）
