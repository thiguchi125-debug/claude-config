# 「次の議会で追及」型の表現を軽々に使わない

ブログ・SNS・スピーチ・印刷物等の発信物で、**特定の次回議会名 × 対決的動詞** を組み合わせた表現を使わない。

**Why**:
- 草川は「対立より対話」「繋ぐ・繋ぐ・繋ぐ」を政策コンパス軸とする政治家。voice-dna軸2「繋ぐ思いを、形にする」「繋いできた声が、形になる」と整合しない。
- 「6月議会で追及する」「次の議会で詰める」のような表現は、(a) 市当局との関係を不必要に対立的に見せる、(b) 約束した時期に成果が出ない場合のリスク、(c) 草川の継続的・丁寧な政治スタイルと乖離、の3点で不利益。
- ただし「継続的に取り組む」こと自体は重要で、これは積極的に表現すべき。

**How to apply**:

## ❌ 避ける表現パターン

| パターン | 具体例 |
|---|---|
| 特定議会×対決動詞 | 「6月議会で追及」「次の定例会で詰める」「9月議会で正す」「12月議会で問い詰める」 |
| 強い対決動詞単体 | 「追及する」「糾弾する」「詰める」「切り込む」「徹底的に問う」「許さない」 |
| 特定議会×強コミット | 「6月議会で必ず取り上げます」「次の議会で結論を出させます」 |

## ✅ 推奨する表現パターン

| 意図 | 推奨表現 |
|---|---|
| 継続的フォロー | 「継続的にフォローしてまいります」「丁寧に確認を続けます」「引き続き取り組みます」 |
| 議会での対話継続 | 「議会の場で対話を重ねていきます」「議会を通じて確認していきます」 |
| 注視 | 「注視していきます」「経過を見守りながら必要な発言を続けます」 |
| 約束ある場合 | 「然るべき機会に取り上げます」「適切なタイミングで論点として提起します」 |

## 例外（明示的な対立軸が必要な場合のみ）

- 議会答弁で明らかに不誠実な対応があった場合：事実関係を踏まえた上で「再質問で確認する」程度の言い方は許容
- 公約として「○○条例制定を求める」等、政策パッケージの一部として位置づけられている場合
- いずれの例外も発信前に草川本人の承認を得る

## 関連ルール

- voice-dna §6（軸2「繋ぐ思いを、形にする」）
- 政策コンパス：対立より対話の原則
- 公選法的にも、特定議会日程を絡めた強い表現は controversial になりやすい

## 適用範囲

ブログ・SNS（X/Threads/Facebook/Instagram/LINE/YouTube/TikTok）・スピーチ・印刷物・市政報告会原稿・市民相談返信案 等、草川名義で外部に出る**全発信物**。
