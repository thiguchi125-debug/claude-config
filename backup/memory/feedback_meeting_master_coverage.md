oyasumi Step 4.5 で AIミーティング → 会議体マスタの自動マッチが「確度<0.8」で未紐付になる事象（2026-05-09に「国際情勢と日本の未来に関する講演」で発生）の根本原因と対処。

## 根本原因
- 🏛 会議体マスタ DB（`46414643-9717-404f-9572-2908c2c0a7f3`）に登録されている会議体は4件のみ：
  - 三重大学応援団 / 亀山JC / コスモス三寺 / 亀山市eスポーツ協会
- 草川の活動は実際にはもっと多くの会議体・勉強会・講演会に参加している（志事塾／自治会総会／後援会／各種市政報告会／視察団等）
- マスタに登録がないと、自動マッチアルゴリズムが確度0.8を超えられず未紐付（要朝レビュー）になる

## 対処（2026-05-10 草川指示）

### A. 未紐付発生時の即時対応（ohayo セッション内）
1. `ai-interview-config-designer` ではなく**この feedback を引いて**会議体マスタに新規追加する
2. 会議種別: `議会公務` / `地域・団体` / `市民相談` / `その他` の4択
3. 開催頻度: `月次`/`隔月`/`四半期`/`半期`/`年次`/`不定期`/`単発` の7択
4. 単発講演・勉強会は **`不定期` か `単発`** を使う
5. 草川の役割: 該当者は `会員` / `顧問` / `オブザーバー` / `議員として` / `委員` / `その他`
6. 追加後、未紐付ミーティングページに「会議体」relation で手動リンク（Notion UI で1クリック）

### B. 既知の未登録会議体（2026-05-10時点・要追加候補）
- **志事塾** … 朝比奈さん主催の地域勉強会・講演会（2026-05-10 追加済 `35ccf503-a68f-81ce-bdd8-d3333b5cc31b`）
- **後援会**（活動再開時に追加）
- **市政報告会（自治会単位）**：楠平尾／御幸／小下／木下／安知本／城東 等は📣市政報告会DB側で管理しているため、会議体マスタには「市政報告会（草川主催）」を1件登録して個別開催を ミーティングノート側で扱うのが運用しやすい
- **自治会総会**：訪問先の自治会総会は単発扱い、その都度マスタ追加
- **JC田植え／納涼大会等のJC公式行事**：亀山JC（既登録）の関連ミーティングとして処理

### C. ohayo SKILL.md への反映（次回更新時）
セクション X（昨夜の会議自動整理レビュー）に注記：
> ⚠️ 未紐付ミーティングが検出されたら、まず会議体マスタに該当レコードがあるか確認。なければ「単発」or「不定期」で新規追加し、ミーティング側に手動リンク。oyasumi cron は会議体マスタを毎晩読み直すので、登録した次の夜から自動マッチするようになる。

## 教訓
- 「未紐付ゼロ」目指すには会議体マスタを継続的に育てる
- 単発の講演会・勉強会も登録対象（マスタ＝「継続会議体だけ」ではない）
