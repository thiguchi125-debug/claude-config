# フォーム回答の属性帰属を推定しない

**ルール**: Googleフォームや申込フォームの自由記述欄（特に「アレルギー・授乳・体調等で配慮が必要な事項」のような複数主体が混在し得る設問）に書かれた情報は、**主語が明示されていない限り「お母さま／お子さま／同伴者の誰のものか」を勝手に決めつけない**。返信メール・運営内資料・次タスクへの転記時には「どなたの分か要確認」として未確定扱いにし、本人への返信メール本文で1行確認するか、別途問合せる。

**Why**:
2026-05-19 「温泉で、産後ケア。」初回申込（なかむらあいり様）対応で、フォーム回答「えびかに」を私が独断で**お子さまのアレルギー**と決めつけてメール下書きとプロジェクトページ・タスク要約まで反映してしまい、草川から即指摘を受けた。
- 設問文は「アレルギー・授乳・体調等で配慮が必要な事項（任意）」であり主体は不明
- お弁当（500円）の発注対象は基本お母さま → むしろお母さまのアレルギーの可能性のほうが運用上の妥当性が高い
- 託児中の食材接触リスクなら子の分、お弁当発注なら母の分、両方の場合もあり得る
- 推定で進めると、誤発注（食材残存）／誤情報共有（保健師申し送り）が起き、信頼を損なう

**How to apply**:
1. **返信メールでは「どなたの分か」を1行確認する**: 「『えびかに』について、お母さまご自身・お子さま、どちらの分かをお弁当発注と託児スタッフ間の情報共有のために確認させてください」型を必ず差し込む
2. **運営内資料・タスク要約には「○○（どなたの分か要確認）」と明示**: 「お子さまのアレルギー」「お母さまのアレルギー」と断定書きしない
3. **次タスクへの転記時に主語を継承しない**: 推定属性が他工程（弁当発注／保健師申し送り／案内メール）に伝播するのを止める
4. **対象設問例（要警戒）**: 「アレルギー」「体調」「配慮事項」「持病」「家族構成」「同伴者の特徴」「アクセシビリティ要求」など、母子・複数同伴者を抱える申込で主語が省略されがちな項目全般
5. **citizen-inquiry-responder / iken スキル等の市民対応系全般に適用**: フォーム回答だけでなくメール・DM・LINE等でも、主語省略の文章をそのまま「誰の」と断定しない
