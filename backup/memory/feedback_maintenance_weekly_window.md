2026-09-06 棚卸しで決定。仕組みの改修は**日曜の1セッション**にまとめ、平日は議員業務だけに使う。壊れたら手動で凌ぎ、修理タスクは `td.py add` に「@日曜改修」ラベルで積む。例外は草川が「今直して」と明示した時だけ。CLAUDE.md トークン節約節に同文あり。

**Why:** 8/23〜9/6の実測5.1Gのうち、改修に費やした9/2〜9/4の3日だけで2.1G（41%）。道具の手入れが本業より重くなっていた。改修を思いついた時に始めると、1回150〜300Mの重いセッションになる（[[project_token_efficiency_overhaul_2026-09-05]]）。

**How to apply:** 平日に「〇〇が壊れている」「〇〇を改善したい」が出たら、原因の特定と手動回避まではやってよいが、コード修正は提案に留めて `td.py add "<件名>" --label 日曜改修` を勧める。日曜セッションでは積んだ分を上から片付ける。関連: [[project_dormant_skills]]
