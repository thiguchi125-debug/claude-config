農業振興地域の整備に関する法律 13条2項の除外要件は **6号**（5要件は改正前）。令和4年法律第56号・**令和5年4月1日施行**で「当該変更により、農用地区域内における地域計画の達成に支障を及ぼすおそれがないと認められること」が**第2号に新設**され、以降の号が1つずつ後ろにずれた。e-Gov原文で確認済（2026-08-12）。

| 号 | 要件 |
|---|---|
| 第1号 | 農用地区域以外の土地をもって代えることが困難 |
| 第2号 | **地域計画の達成に支障を及ぼすおそれがない**（新設） |
| 第3号 | 農業上の効率的かつ総合的な利用に支障を及ぼすおそれがない |
| 第4号 | 担い手への農用地の利用集積に支障を及ぼすおそれがない |
| 第5号 | 土地改良施設の機能に支障を及ぼすおそれがない |
| 第6号 | 土地改良事業の完了後8年経過（起算＝工事完了公告の工事完了日の属する年度の翌年度の初日／施行令9条） |

**「8年ルール＝第5号」と書いてある資料は改正前**。検索上位に旧資料が多く残るので毎回疑う。

**目標地図に位置づけられた農地は第2号に直結**（第3号ではない）。国「農業振興地域制度に関するガイドライン」第16の2(3)②イが、目標地図で農業を担う者が特定されている土地を農用地等以外に供する場合は第2号を満たさないと考えられる、と明記。第4号の判断も第2号イの結果を踏まえて行える。

亀山市の運用（[見直しページ](https://www.city.kameyama.mie.jp/docs/2023021300025/)）:
- 市も**6要件**で公表
- **農振除外の受付は例年2月末と8月末が期限**
- **令和7年4月から、目標地図に位置づけされた農地の除外は地域計画の変更告示後**に行う必要があり、通常より時間を要する
- 所管＝産業環境部 農林振興課 農林政策グループ **TEL 0595-84-5068**（0595-82-9669はFAX）
- 目標地図は毎年変更公告が出る。引用前に[掲載ページ](https://www.city.kameyama.mie.jp/docs/2014112305210/hito-nouchi.html)で最新の公告日を確認（初版=令和7年3月31日／変更版=令和8年3月25日）
