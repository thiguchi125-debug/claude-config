草川が自分でX原稿を刈り込んだ実例（2026-06-28「温泉で産後ケア」）。AI生成版は制度説明・数字を本文に全部詰め込んでいたが、草川は大幅に削り、フック→共感→現場→**1つの核メッセージ**だけに絞った。

**草川が削った／変えたもの（研究結果）:**
- 数字・制度詳細を全削除（「4月から通所/宿泊型」「産後1年以内・7回」「残る壁2つ」「加算17万4,200円」）→ Xに制度解説を載せない。
- 副論点（上の子の壁をなくし）をXから外す → 主メッセージ（選べる受け皿）を薄めないため。
- 情緒描写「湯から上がった表情が、本当に柔らかかった」を削除 → Xでは演出を削ぎ落とす。
- 政策主体を明示：「選べる担い手を育てる」→「**市が支援をして**選べる担い手を育てる」。市民有志任せにせず市の支援を引き出す筋に。
- ブログ全文URLは本文から外し**リプライ欄（最初の返信）へ**。

**How to apply:** sns-content-creator等でX生成時は、
1. 本文は短く**1ツイート1メッセージ**。数字・制度詳細・副論点はブログへ逃がす。
2. **リンクは本文に入れずリプライ用に分離**して提示（本文リンクはXのリーチを下げる）。
3. 情緒描写・演出は最小限。政策の主体（市が何をするか）を明示。
これはX特化。Facebook/Instagramは詳細OK、Threadsは中間。
