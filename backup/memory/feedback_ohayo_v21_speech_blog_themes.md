ohayo v2.1（2026-05-06追加）で「🎤 今日の街頭演説おすすめテーマ（3案）」「📝 今日のブログ・SNS発信おすすめテーマ」セクションを朝のブリーフィングに追加した。

**Why:**
- 草川指示「今日おすすめの街頭演説テーマ・ブログSNS更新テーマを朝のブリーフィングに追加」（2026-05-06）。朝のブリーフィングは「予定確認」だけでなく「今日何を語るか／発信するか」のメニュー機能を持たせる方が議員業務に効く。

**How to apply:**
- 朝のおはよう出力の「🎯 今日のフォーカス」直後に2セクション必須表示
- 街頭演説は3案（A=深掘り／B=共感現場／C=攻め）。daily-street-speechのA/B/Cパターンに対応
- ブログ・SNSはレーン別（深掘り／ノーマル／SNS即時）
- **テーマ提案のみ**（本文生成しない）。本文化は「街頭演説の要旨 A案で」「ブログ書いて：X」等で下流エージェント起動
- 追加fetchゼロ：§3-0〜§3-5で既取得のニュース／タスク／プロジェクト／選挙進捗／市民意見直近／SNS下書き直近3件を再利用
- ローカル `policy_compass.md` のみ追加読込（小サイズ・3軸整合性確保）
- voice_examples.md / policy_compass_evidence.md は読まない（重い）
- **Notionダッシュボード本文書込なし**（チャット限定）。理由：テーマは毎朝変わるため update_content コストに見合わない。v2の燃費方針継承
- 公選法ガード：選挙日まで残り日数で表現調整（30日以内は政策論型優先、7日以内は実績報告型）。「投票してください」直接表現は提案でも禁止
- 重複除外：§3-3 SNS下書き直近3件と重複するテーマは出さない
