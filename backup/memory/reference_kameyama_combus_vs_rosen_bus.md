亀山みずほ台線（亀山駅前⇔平田町駅・鈴鹿市と共同・イオンモール鈴鹿の停留所あり）と亀山椋本線（亀山駅⇔椋本・津市と負担）は**コミュニティバスではない**（廃止代替などの路線バス）。

**Why:** 2026-10-10、第3回台本の調査報告で両線を「コミュニティ系バスの市外乗り入れ」と書き、草川が訂正。

**How to apply:** 「コミバスは市外へ行ける／行けない」を書くとき、この2線を根拠にしない。コミバスの市外停留所の有無は未確認。夕方の南部接続例は、阿野田方面が椋本線で帰れるため三寺・神向谷・二本松・昼生方面に限定する（research_ledger/2026-10-10_コミバスとJR接続_時刻突合.md）。[[reference_kameyama_combus_fare]]
