草川の実写ショート動画・写真投稿の撮影想定に **市の公共施設の館内・敷地** が含まれる場合、台本テキストが無害でも Axis 1（個人情報・肖像）と Axis 8（公の施設の政治的中立性）で 🔴 HIGH を立て、以下3点を必ず本人に確認する。

1. 施設管理者（図書館長・所管課・教育委員会等）への撮影許可を取ったか。市の施設で議員が政治的発信物を撮ること自体が苦情の起点になる。
2. 他の利用者が映り込まない時間帯・アングルか。**図書館は特に重い**——「誰が何を読んでいたか」は図書館の自由に関する宣言が守るべき利用者の秘密で、後ろ姿・書架＋人影でも配慮対象。
3. 市の公式サイト画面・市の掲示物・ロゴを映す場合、画面内に出典（「亀山市公式サイトより」等）を表示し、市の公認・共同制作と誤認される構図を避ける。

**Why:** 台本の言葉だけを見て APPROVE を出すと、リスクの本体（撮影行為そのもの）を素通しする。公共施設での政治撮影は「投稿しなければ起きない問題」の典型で、事後の謝罪コストが高い。

**How to apply:** 入力に「撮影想定」「ロケ地」「実写」の記載があるとき、テキスト8軸のスキャンとは別に撮影固有チェックを1ブロック立てる。屋外の公道・自分の事務所・私有地は対象外（LOW）。
