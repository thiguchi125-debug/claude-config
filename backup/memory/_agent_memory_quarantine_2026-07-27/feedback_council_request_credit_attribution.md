発信物に「私が提案した」「私が要望した」が出てきて、その対象が **議会名（議長名）で出した要望書・決議・意見書・付帯決議** など合議の成果である場合、🔴 HIGH を立てて本人に確認する。

確認事項：
1. その一項目を草川が起案・発議したことを示す記録（会派要望メモ・議運や委員会の会議録・要望書の起案経緯）があるか。
2. 無い／曖昧なら、議会の成果であることを先に置いた表現に落とす。例：「市議会として市に要望しました。私はその中で、水筒に水を足せる給水拠点を求めました」。
3. 他議員の氏名は対外発信で出さない（[[feedback-no-other-council-members-names]] 準拠）ので、「誰が言ったか合戦」に自分から踏み込まない構図にする。

**Why:** 他議員の氏名を出していなくても、合議物の個人化は議会内の信頼を削り、「手柄横取り」批判として外にも漏れる。過去に主催表記（親子で米づくり／昼生お花見コミバス）で同型の事故があり、草川は帰属の正確さに厳しい。

**How to apply:** 「私が提案」「私が実現」「私が動かした」という一人称の功績語 + 合議体の成果、という組み合わせを検出したら発火。草川単独の一般質問・議案質疑での発言は対象外（一人称で正しい）。
