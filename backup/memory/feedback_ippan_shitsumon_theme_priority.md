草川が6月議会テーマ絞り込みで示した**優先順位の序列**（2026-05-29 会派協議ログ＋10点フィードバックから学習）。一般質問テーマ提案は必ずこの順で並べ、上から拾える形にする。

**優先順位（高→低）:**
1. **地域・市民と約束したテーマ（コミット済み）= 最優先**。例: 井田川駅前の浸水問題（地域と約束）。約束は市民の声の量や鮮度より上。
2. **会派で協議・調整中のテーマ**。例: 部活動の地域展開／中学校給食。会派の動きと必ず連動させる（草川は会派で一般質問を調整する）。
3. **市民の声が起点（ネタ元=市民相談/現場気づき）のものが最も有効**。データだけ・鮮度だけのネタより、特定の市民の訴えが起点のものを上位に。
4. **本人が当事者のテーマは足場が強い**。例: 消防団（草川=第3分団員）。
5. **6月議案・現況報告で市が既に扱うテーマは除外**（議案質疑・委員会と棲み分け）。→ **テーマ選定前に必ず6月議会の現況報告書＋教育行政現況報告＋議案書（Drive `_index/議会資料アーカイブ/R08/06_定例会/`）を先に読む**。「やってます」で終わるテーマを外す。
6. **3月議会で既出のテーマは、強力な新ネタがなければ見送り**（例: 子ども医療費18歳・水道管路更新は3月で扱済）。あえて6月で再提起するなら新しい強い切り口が必須。

**やらないこと/嫌う型:**
- 「インクルーシブ」等のきれいなフレーム先行は刺さらない。**危険・老朽・放置・矛盾など市民の切実な訴え**を軸にする（例: 公園遊具はインクル横展開でなく「東野公園の老朽・危険遊具の放置」が正しい起点）。
- **祝い金（出生祝金）の話題は今後も不要**（草川直接指示 2026-05-29）。
- 鮮度・インパクトだけで市民発端でないネタ（例: 新防災気象情報の市報告追認）は下位。

**見せ方:** 詰め込んだ大テーブルは「見にくい」と嫌う。おすすめ順のランク形式で、各候補に「誰の声か／なぜ今／議案でないか」を明記。詳細は [[feedback-content-generation-default-flow]] と同様に簡潔に。
