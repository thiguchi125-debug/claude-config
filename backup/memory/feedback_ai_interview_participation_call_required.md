# AIインタビュー由来コンテンツには参加呼びかけを必ず入れる

## ルール

AIインタビュー（depth-interview-kusagawa.vercel.app）の結果を素材として作成する**全種類のコンテンツ**に、以下を必ず含める：

1. **AIインタビューへの参加呼びかけ**（次の声を集めるための導線）
2. **具体的URL**: `https://depth-interview-kusagawa.vercel.app/`
3. **既存の定型クレジット**（`feedback_ai_interview_disclaimer.md` 準拠：安野貴博氏のdepth interview基盤／有賀啓介氏支援／個人情報伏せて再構成）

対象は **SNS 4PF（Instagram/Facebook/Threads/X）／ブログ深掘り／ブログノーマル／ショート動画台本／長尺動画台本／スピーチ（街頭演説・市政報告会・自治会挨拶）／印刷物（チラシ・市政報告レポート）／LINE配信** など、AIインタビュー素材を1mmでも使ったコンテンツすべて。

## 推奨フォーマット

### ブログ・長文SNS（IG/FB/note）
本文末尾の主張クロージングの後、フッター（◆ご意見箱／◆公式LINE等）の前に挿入：

```
🎙️ あなたの声も、AIインタビューで聴かせてください
中学生の保護者の方、現役顧問の先生、地域の指導者、卒業生の保護者——
どの立場からの声も、議会の議論の土台になります。匿名で参加可能、20〜30分の対話形式です。

▶ https://depth-interview-kusagawa.vercel.app/

（安野貴博氏のdepth interview基盤／有賀啓介氏支援）
```

呼びかけ対象（「どの立場からの声も」の後の例示）は**テーマごとに最適化**する。部活なら保護者・顧問・指導者、医療なら患者・医療従事者・家族、防災なら自治会役員・要配慮者支援者、等。

### Threads（短中文）
```
よかったらAIインタビューで聴かせてください。
（匿名OK・20〜30分の対話形式）
▶ https://depth-interview-kusagawa.vercel.app/
```

### X（140字制限・最後の余白で）
```
▶あなたの声もAIインタビューで
https://depth-interview-kusagawa.vercel.app/
```

### 街頭演説・市政報告会・自治会挨拶（口頭）
原稿に呼びかけパラグラフを必ず差し込む：

```
皆さんの声も、AIインタビューでお聴かせください。
スマートフォンで20分ほど、匿名でAIと対話するだけで、皆さんの本音が議会の議論の土台になります。
QRコードはこのチラシの裏面に。あるいは『草川たくや AIインタビュー』で検索してください。
```

### ショート動画台本
動画末尾のCTA枠 or キャプション末尾に挿入：
```
🎙️ あなたの声もAIインタビューで聴かせてください
▶プロフィール欄のリンクから（depth-interview-kusagawa.vercel.app）
```

### 印刷物（チラシ・市政報告レポート）
QRコード+URL+「AIインタビュー実施中・匿名OK」のコーナーを必ず確保。

## Why

2026-05-25 AIインタビュー#37（中学部活地域移行）のブログ作成時、草川から「AIインタビューを促す内容を入れるべき。今後もAIインタビューに関するテーマなら全て入れるように」と直接指示。

AIインタビューは1回ごとに完結する素材ではなく、**継続的に声を集めて議会論点の土台を厚くしていく装置**。出来上がったコンテンツに参加呼びかけが入っていないと、その装置の循環が止まる（=次の声が集まらない）。

SNSフッターは既に `feedback_ai_interview_disclaimer.md` で必須化されていたが、**ブログ本文・スピーチ原稿・動画台本では呼びかけが抜けるケース**があった（今回の部活ブログ初稿でも本文中にURLが明示されておらず「皆さんの声を議会のテーブルに載せます」という抽象的呼びかけのみだった）。これを全コンテンツ種で明示URL付きの呼びかけ必須に格上げ。

## How to apply

- AIインタビュー由来素材で何か1つでもコンテンツを作るとき、出力前に「参加呼びかけ＋URL は入っているか？」を最終チェック
- 既存のSNSフッター定型（feedback_ai_interview_disclaimer.md）に**「呼びかけパラグラフ」を必須追加要素として組み合わせる**
- ブログでは「本文末尾の主張クロージング → 🎙️呼びかけ → 標準フッター（◆ご意見箱／◆公式LINE等）」の3層構造を守る
- 呼びかけ対象（「どの立場からの声も」例示）はテーマごとにカスタマイズ
- 印刷物は QRコード＋URLの物理導線を必ず確保
