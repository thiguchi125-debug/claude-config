PF UI遮蔽ゾーン（[[pf-ui-occlusion-zones]]）を避けると、挿入画で使える縦は **y236-1236 の1000pxだけ**。
ここに「ラベル＋見出し＋リード＋カード2枚＋出典」の6要素を入れると、実測でこうなる：

- 見出し 76-84px（可読性フロア72pxは満たすが、推奨88-120pxには届かない）
- 支え文字 44-48px（フロア44pxぎりぎり）
- 出典 26-28px（注釈の下限26pxぎりぎり）
- 要素間の余白 15-23px

**7要素以上（例：カード2枚＋例示ボックス＋出典）は、フォント縮小だけでは入らない。**
構造圧縮が要る：①タグと本文を同じ行に畳む（`display:flex` の1行カード）
②独立行の矢印グリフ（▼）をカードのタグ内に取り込む（縦を丸ごと1行ぶん節約）
③見出しの改行位置を変えて行数を減らす。

**Why:** 2026-08-31 の育休退園 a2（要素7つ）は、フォントを floor まで落としても
必要量1079px > 使える1000px で入らず、上記①②で初めて収まった。

**How to apply:** 「位置の修正では収まらない」と分かったら、**情報を勝手に削らない**。
文言・数字・固有名詞は1文字も触らず、改行位置と要素構造だけで詰める。
それでも入らなければ「情報量そのものを削る必要がある」と草川に報告して判断を仰ぐ。
修正後は旧版と可視テキストのdiffを取り、文言差分ゼロを証明してから出荷する。
