草川が役員（事務局長）を務める**亀山市eスポーツ協会**名義でイベント告知を出すときの公選法上の担保は、
2026-07-22 のリニア杯第4回レビューで確立した**2点セット**：

1. **主体を協会（会長名義）とする** — 例「主催 亀山市eスポーツ協会（会長 山本真司）」
2. **運営費および賞品を協会が負担している事実を本文に明記する**

**Why:** 公選法199条の5は、候補者等が役職員である団体が、その候補者等の**氏名を表示し又は氏名が類推される方法で**
選挙区内の者へ寄附することを（選挙に関わりなく）禁じる。上記2点は
「これは協会の催しで、草川個人の持ち出しではない」ことを文面上で立証し、
寄附の主体と資金の出所の両方を草川から切り離す役割を持つ。
草川の氏名を伏せるだけでは足りない（[[reference-kusagawa-phone-number-identity]] の通り番号から類推され得るため）。

**How to apply:** 協会名義の案内・チラシ・メールを審査するときは、この2点が本文にあるかを必ず確認する。
2026-08-19 の建築コンテスト参加者案内 v4 は**両方とも欠落**していた（会長名なし・負担者の記載なし）ため差し戻し対象。
あわせて、**賞品の出所が未確定のまま「賞品をお渡しします」と断定しない**こと。
未確定のまま告知すると直前に草川が自腹で補填する経路が生まれ、それは199条の2の明確な違反になる。
賞状・参加賞は Drive `日常資料アーカイブ/03_後援会・組織/亀山eスポーツ協会/05_賞状・メダル素材/` に在庫があり安全。
