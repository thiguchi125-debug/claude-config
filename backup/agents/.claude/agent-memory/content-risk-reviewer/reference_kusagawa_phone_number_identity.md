電話番号 **090-1099-2458 は草川たくや個人／草川たくや事務所（中庄町858）の番号**であり、
議員名・肩書と並べて長年にわたり選挙区内へ配布済み。確認できた掲載先（一部）:

- 市政報告レポート 38 / 39 / 48 / 49 / 50 / 53 / 54 / 61 / 62（`t.higuchi125@gmail.com` と併記）
- けんろう版市政報告・昼生ニュース・南部ニュース・菅内ニュース・御幸
- `kusagawa_archive/06_election/` の選挙印刷物・飲食業組合アンケート
- 情報公開請求書、PTA連絡網

**Why:** 亀山市内の多数の世帯がこの番号を「草川たくや議員の番号」として現に保有している。
したがって協会名義の案内で表記だけ「事務局 090-1099-2458」に替えても、
公選法199条の5がいう「**氏名が類推されるような方法**」を解消したことにはならない。
氏名を消す＝匿名化、という判定は誤り。

**How to apply:** 議員名を出さない建て付けの団体発信（eスポーツ協会等）でこの番号が出てきたら、
「氏名を消したから解決」で通さない。緩和策は番号の差し替えではなく、
①協会の別役員（会長）を責任者として明示 ②メールを一次窓口にし電話は当日緊急のみに限定
③協会が費用・賞品を負担している事実を明記、の組み合わせ。
なお草川は同協会の**事務局長**なので「事務局」ラベル自体は虚偽ではない（2026-08-03 リニア杯延期案内で使用実績あり）。
