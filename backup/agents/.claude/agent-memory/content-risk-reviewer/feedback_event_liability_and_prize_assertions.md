イベント案内で**責任・負担・配布物を断定する文**は、書いた瞬間に義務を生む。3種類あり、扱いが違う。

**1. 「本イベントの運営責任は、◯◯が負います」→ 書かない。**
主体を明示したいだけなら「本イベントは、◯◯が主催・運営します。」で足りる。
「責任を負う」は、会場でのけが・事故に対する**責任の引受け表明**として読まれ得る。
イベント保険の有無を確認しないまま書くのは危険。
※ 2026-08-19 建築コンテスト v4 レビューで当職が LOW-2 として「運営責任の明示」を求めた結果、
v5 にこの一文が入った。**当職の指摘自体が新リスクを生んだ実例**。主体明示と責任引受けを混同しない。

**2. 「運営費・賞品は、すべて◯◯協会が負担しています」→ 書く（公選法上必須）が、同時に4条件を課す。**
[[project-esports-event-koshenho-two-part-basis]] の2点セットとして必須の記載だが、断定した以上、
以下のどれか1つでも崩れると**本文が虚偽になり、かつ公選法199条の2の寄附に転落する**：
- 草川が自腹で補填しない（手順書に明記済み）
- 草川が**立て替えない**。やむを得ず立て替えたら当日中に協会から精算し領収書を残す（精算されない立替＝寄附）
- **会場を協会名義で予約し、協会会計から支払う**（草川個人名義の予約・支払いは矛盾）
- 賞品を**スポンサー企業からの現物提供で調達しない**（提供元が企業になり「協会が負担」が崩れる）

**3. 「参加した全員に参加賞と賞状をお渡しします」→ 現物が確定するまで断定しない。**
賞状素材はあるが「参加賞」の現物は別。渡せなければ約束不履行。
確定しないなら「参加した全員に賞状をお渡しします」に絞る。
申込フォーム側の記載（「参加者全員に賞状」）と数え方が食い違っていないかも突き合わせる。

**How to apply:** 議員関与団体のイベント案内を審査するときは、断定文を1つずつ拾い、
「これが履行されなかったら何が起きるか」を書き出す。公選法の担保として必要な断定（2）は残し、
不要な責任引受け（1）は削り、履行未確定の断定（3）は現物確認まで保留させる。
