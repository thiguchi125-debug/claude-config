任天堂の「コミュニティ大会ガイドライン」（https://www.nintendo.co.jp/tournament_guideline/index.html）の適用範囲は
**「任天堂が著作権を有するゲーム」**かつ「日本国内で開催されるコミュニティ大会または日本国内に居住する方が主催するコミュニティ大会」（原文）。

**Why:** 亀山市eスポーツ協会は任天堂タイトル企画（かめやまゲーム交流会9/19）と
Mojang/Microsoftタイトル企画（かめやま建築コンテスト2026＝Minecraft）を並行して持っている。
memory の [[project_nintendo_tournament_license]]（団体主催は個別許諾申請必須／大会名に「eスポーツ」不可／
スポンサー不可／出場料を取ると会計公開義務）は**任天堂タイトルの催しにしか効かない**。
Minecraftの著作権者は Mojang / Microsoft であって任天堂ではないため、建築コンテストには一切及ばない。
2026-08-19のファクトチェックで、この2件を混同して「スポンサー帯を消すべき」「協会名を変えるべき」と
判定しかけた（一次情報で否定）。

**How to apply:** 協会名義の催しをチェックするときは、まず**使用タイトルの著作権者**を確定する。
- 任天堂タイトル（スマブラ・マリオカート等）→ [[project_nintendo_tournament_license]] の6制約が全部かかる
- Minecraft → Minecraft Usage Guidelines のみ（主名称にMinecraft不可／公式ロゴ・ゲーム内アセット不可／
  免責表記 `NOT AN OFFICIAL MINECRAFT EVENT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT` を
  目立つ位置に／主催者と連絡先と連絡方法の明示が必須。チャット・フォーラムのリンクは連絡方法として認められない）
- ハード名「Nintendo Switch」を書く場合の商標帰属表示は、どちらの企画でも付けてよい（任天堂ガイドラインとは別問題）

Minecraft Usage Guidelines の「Target audience」節には
「The allowances we give in these guidelines do not authorize commercial companies, corporate brands,
advertising agencies, **non-profits, politicians**, political action committees, governments to use or exploit
Minecraft for promoting products, services, or agendas unrelated to Minecraft.」とある。
議員名・肩書を載せない運用は、公選法対策であると同時に**Mojang側の要件**でもある（任天堂側と同じ構図）。
