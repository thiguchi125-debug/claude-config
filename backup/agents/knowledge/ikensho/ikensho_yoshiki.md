# 意見書・要望書 様式知識（ikensho-drafter 用）

## A. 議会意見書（地方自治法第99条）

市議会が国会・関係行政庁（国の省庁・県）に対し、議会の意思として提出する文書。議員が「案」を作り、議会運営委員会協議→本会議で議決されて初めて「亀山市議会」名義になる。

### 構成（標準形）

```
発議第◯号（議会事務局が付番・ドラフト段階では空欄）

◯◯◯◯を求める意見書（案）

【本文＝現状認識と必要性】
　◯◯については、…（現状・課題を2〜3段落。全国状況→本市の実情の順）。
　よって、国におかれては、下記事項について特段の措置を講じられるよう強く要望する。

記

1　◯◯◯◯すること。
2　◯◯◯◯すること。
（項目は名詞止めでなく「〜すること。」で統一・3〜5項目が通例）

　以上、地方自治法第99条の規定により意見書を提出する。

　令和◯年◯月◯日
　　　　　　　　　　　　　　　　　　　三重県亀山市議会

（提出先）
衆議院議長／参議院議長／内閣総理大臣／◯◯大臣（所管大臣）
※県宛の場合は 三重県知事（必要に応じ三重県議会議長）
```

### 起案時の実務注意

- **全会一致慣例**: 意見書は全会一致で可決されるのが通例。特定政党・特定議員への批判、イデオロギー色の強い文言は通らない。事実と制度要望に徹する。
- **提出先と所管の一致**: 要望項目ごとに所管省庁を確認し、提出先大臣を過不足なく列挙する。
- **時機**: 国の法改正・予算編成・計画改定のタイミングに合わせると採択されやすい。
- **先例準拠**: 直近の亀山市議会採択意見書（市議会HP・議決結果）の文体・字下げに合わせる。全角スペース1字下げ・「記」書き・「〜すること。」調が基本。
- **数字・法令名は一次情報から**: content-fact-checker 通過必須。

## B. 要望書（市長・所管課宛）

議員個人・自治会・団体が市に施策を求める文書。議決不要で自由度が高いが、誰の名義かで書き方が変わる。

### 構成（標準形）

```
令和◯年◯月◯日

亀山市長　◯◯　◯◯　様
（課題が明確なら「亀山市◯◯部◯◯課」を併記）

　　　　　　　　　　　　　　　◯◯自治会　会長　◯◯◯◯
　　　　　　　　　　　　　　　（連名の場合は列記・議員は「紹介議員」として末尾）

◯◯◯◯に関する要望書

【趣旨】
　日頃より…（1段落の挨拶）。◯◯地区では…（現状・困りごとを具体的に。日付・場所・件数など事実ベース）。
　つきましては、下記のとおり要望いたしますので、特段のご配慮を賜りますようお願い申し上げます。

記

1　◯◯◯◯（現場写真・位置図を別紙添付する旨があれば明記）
2　◯◯◯◯

以上
```

### 起案時の実務注意

- **名義の整理が最初**: 自治会名義か・団体名義か・議員個人か。自治会名義の場合、草川は「つなぎ役・紹介」であり主催者面をしない（[[feedback_ohanami_hanyu_shusai_attribution]]と同型の帰属注意）。
- **個人情報**: 要望者の実名・住所は本人了解の範囲でのみ記載。対外派生物では伏せる。
- **現場事実の具体性**: 「危険」ではなく「◯月◯日夕、通学児童が◯◯交差点で…」。ただし架空エピソード禁止（[[feedback_no_fabricated_stories]]）。
- **過去要望の重複確認**: アーカイブと📝市民意見リストを先にgrepし、既提出・既回答があれば「再要望（前回◯年◯月・回答◯◯）」として書く方が強い。
- **回答期限は求めすぎない**: 「ご回答を賜りたく」程度に留め、期日指定は関係が既にあるときのみ。

## 納品

- 完成品は txt で書き出し `open -e`（TextEdit・コピペ時に余白が入らない [[feedback_copypaste_draft_delivery]]）。
- 意見書は fact-checker＋risk-reviewer 必須（政治的物議軸を特に）。要望書も対外文書のため同様。
