# 議会だより 一般質問ページ フォーマット規定（編集要領・固定）

> 亀山市議会だより編集要領に基づく議員別一般質問ページの規定。**毎定例会で固定**（2026-07-02 草川確認済）。
> ゴールドスタンダード実例: `gold_standard_R7.6.md`

## 原稿の構成要素（順序固定）

| # | 要素 | 規定 |
|---|---|---|
| 1 | 氏名行 | `草川 卓也（会派：結）` |
| 2 | 吹き出し（大見出し） | キャッチコピー1行。**字数カウント外** |
| 3 | ■小見出し＋問＋答 | テーマ1〜2本。問=草川質問の要約、答=執行部答弁の要約 |
| 4 | 【その他の質問】 | 掲載しなかった質問件名の箇条書き。**字数カウント外** |

## 字数規定

- **タイトル＋見出し＋Q&A本文で650字**（吹き出し・その他の質問はカウント外）
- 圧縮は段階方式: v1忠実版（会議録文言そのまま）→ v2（~690字）→ v3（650字確定）

## 文言ルール

- 問・答とも**会議録の文言ベースの要約**。語尾整理・冗長削除のみ可、**意味の改変・創作は禁止**
- 答弁の数字・固有名詞（SATAS・キオクシア・USJC等）は会議録からコピペ（手打ち禁止）
- 見出しに編集上の造語を使う場合は原稿内で会議録引用と区別できるようにする
- 他議員の氏名・質疑内容は一切含めない（誤帰属ガード）

## 提出用docx 書式（build_docx.py が自動適用）

- フォント: **Yu Gothic・全段落bold**
- 氏名行: 11pt 黒
- 吹き出し: 15pt 緑 `#1F5A3A`
- ■小見出し: 11.5pt 緑
- 問: 10.5pt 緑 ／ 答: 10.5pt えんじ `#B03A2E`
- 【その他の質問】: 緑ラベル＋黒箇条書き（List Bullet）

## 引用参照マークdocx（mark_quotes.py が自動生成）

- 会議録原本に、原稿の引用元箇所を色付けして編集委員会の照合に供する
- 赤 `#C00000` = 草川発言由来 ／ 青 `#0033CC` = 執行部答弁由来
- **提出用docxの問・答の文言と、マーク用のred_quotes/blue_quotesは同一テキスト**を使う（1ソース2出力）

## 提出物（毎回2点セット）

2. `【会議録】一般質問◯月◯日_引用参照マーク.docx`
