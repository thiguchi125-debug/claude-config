## 差し替えポイント
| 箇所 | 内容 |
|---|---|
| `__H1__`(表)/`__A1__`(裏) | 写真。PILで事前クロップ推奨（object-position任せにしない）。**背景の第三者はぼかす**（PIL GaussianBlur+フェザーマスク） |
| `__QR_IKEN__` / `__QR_LINE__` | QR PNG（qrcode 誤り訂正H・深緑）。**レンダ後に必ずcv2デコード検証（高解像度側で）** |
| 号数・発行月 | 「20XX年 ◯号／◯月議会報告」「【20XX年◯月 発行】」 |
| 数字ラック | 4点まで。大数字=金・出典注記必須 |
| カードバッジ | 前進（ベタ）/提言/質疑/継続（枠）— 実現したら「実現」ベタ |

## 制作手順
1. base64埋込の最終版を生成: placeholder→data URIをpythonで置換（試作フォルダの手順参照）
2. レンダ: Chrome headless `--window-size=794,1123 --hide-scrollbars`（PNG検品用）／`--print-to-pdf --no-pdf-header-footer`
3. 結合: `pypdf`で表裏マージ
4. QR検証は `--force-device-scale-factor=3` の高解像度スクショで（74dpi相当だと長URL側が読めないことがある＝正常）
