草川の市政報告レポート（A4両面・印刷会社品質狙い）は、**「広報かめおか文法」翻訳**で組むと草川本人の水準を満たす。均等箱グリッド＋ベタ緑帯＋単一ゴシックの版は「素人以下のAI臭さ」として却下された（2026-07-07）。

**Why:** かめおか公式広報誌のような編集紙面が草川の理想。AI臭の正体は①全要素の角丸ボックス囲み ②反復するベタ塗り見出し帯 ③単一ゴシック ④裏面の均等4分割 ⑤純白背景＋中央寄せ。これらを一つずつ潰すと素人が見分けにくいプロ紙面になる。

**How to apply:** 実装契約＝`drafts/2026-07-07_市政報告レポート試作/design_spec_kameoka.md` を正本に。背骨は「罫線囲みゼロ・ベタ帯ゼロ」。分節は①余白 ②淡色ウォッシュ(緑/金10%以下・border無し) ③ヘアライン1本 ④明朝見出し、の4手段のみ。核心：
- warm paper `#fbfaf6`（純白禁止）＋左揃え基調＋フラット（影・グラデ禁止）
- **明朝×ゴシック2書体混植**（Hiragino Mincho ProN W6 大見出し／Hiragino Sans 本文）。ジャンプ率≥4.2倍（マストヘッド39pt÷本文9pt）
- 表面＝金タブ旗(clip-pathで旗尾V切欠き)＋緑デート＋明朝大氏名＋緑下線＋英字サブ＋声チカラpill／ヒーロー写真左＋明朝号タイトル右／手書きキャッチは明朝＋SVG二重ストローク(faux筆記体禁止・白文字は写真の暗部=スーツに置く)／数字レールはウォッシュ地＋ヘアライン行＋金Helvetica数字(囲み無し)
- 裏面＝明朝セクション扉＋金下線＋写真クラスタ2点／**非対称カード**(主役1=広col+wash+円形ヌメラル / 脇役3=狭col・ハイライン区切り)／円形ヌメラル1点のみ(緑正円42pt白数字+外に金対比)／縦組み編集後記1点のみ(左下)／淡金特大エコー
- 各意匠を増殖させない＝手書き表紙1・縦組み後記1・円ヌメラル裏1
- badge=塗りpill(前進緑/提言金/質疑緑アウトライン/継続グレー)。赤不使用。討議資料を表裏フッター必須・他議員氏名ゼロ・絵文字ゼロ
- ファクトチェック済み文言はそのまま流用（例「三重県内の自治体で初」「太陽光は成立・施行と書かない=質疑時点の報告」）

**制作パイプ:** placeholder HTML→base64埋込→Chrome headless(816×1145px=216×303mm塗り足し込み)→PNG自Read→§7の14項AI臭チェック→修正ループ(最低2周)。QRは`--force-device-scale-factor=4`で撮って個別crop+2x upscaleするとcv2で確実に2個デコード(全ページmulti-decodeは落ちる)。単ページ厳守はmediabox=215.9×303.0mmで確認、pypdfで結合。密度が高いので数字レール/本文の級数・行送りを削って1ページに収める(本文9pt/lh1.6まで許容)。成果物一式=`drafts/2026-07-07_市政報告レポート試作/kameoka_*`。
