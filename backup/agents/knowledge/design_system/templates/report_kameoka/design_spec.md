# 市政報告レポート デザイン仕様書 v1 ―「広報かめおか文法」翻訳版
**対象**: 草川たくや 市政報告レポート A4両面（2026年 夏号・6月議会報告）
**性格**: print-designer への実装バトン。実装はしない。この仕様に沿ってHTML/CSS→PDFを組む。
**ベンチマーク（正）**: `references_pro/pro1_kameoka_cover.png`（表紙）＋ `references_pro/pro2_kameoka_spread.png`（見開き＝草川本人選定）
**反面教師**: `omote-1.png`/`ura-1.png`（却下初版）

---

## 0. 却下初版が「AI臭い」理由（絶対に繰り返さない5点）
1. **全要素が角丸ボックスで囲まれている** → 紙面が「箱の集合」に見える。プロ紙面は箱を使わず余白と淡ウォッシュで分節する。
2. **同一のベタ塗り緑帯見出しが反復** → 単調・テンプレ感。かめおかにベタ帯は一切ない。
3. **単一ゴシックで全部組んでいる** → 声の抑揚がない。かめおかは明朝の大タイトル×ゴシック本文でジャンプ率を作る。
4. **裏面が均等4分割の同サイズ箱** → 情報の軽重が消える。かめおかは非対称グリッドで主役と脇役を作る。
5. **純白背景＋中央寄せ多用** → 硬く事務的。かめおかは温かみのある紙色＋左揃え基調＋大胆な余白。

> **本仕様の背骨＝「罫線囲みゼロ・ベタ帯ゼロ」。区切りは①余白 ②淡色ウォッシュ ③細いヘアライン1本 ④明朝見出し、の4手段のみで作る。**

## 1. ページアーキテクチャ（かめおか文法のA4両面翻訳）

### 表面（pro1＝表紙型を「編集扉」に翻訳）
かめおか表紙はほぼ写真＋マストヘッドのみ。市政報告は情報量が要るため、**上40%＝表紙の呼吸、下60%＝編集面**のハイブリッドにする。上から5ゾーン：

| ゾーン | 高さ目安 | 中身 | かめおか対応 |
|---|---|---|---|
| **A マストヘッド** | 上端〜30mm | 金タブ旗「市政報告」＋緑デートブロック「2026 夏／6月議会報告」＋明朝大の「草川たくや」＋ゴシック英字下線サブ（下線はかめおかの"Kameoka City Monthly Newsletter"下線の翻訳）＋「声を、チカラに。」ピル | 3層マストヘッド＋タブ旗 |
| **B ヒーロー扉** | 〜115mm | 草川ポートレート（左寄せ）＋明朝の号タイトル＋リード1文＋**手書きブラシ体キャッチ1点** | フルブリード写真＋明朝タイトル＋手書きスクリプト |
| **C トップ記事（部活動）** | 〜185mm | 明朝大見出し＋ゴシック2段本文＋金マーカー2語 | 特集本文 |
| **D 記事2（給食）＋数字レール** | 〜265mm | 左8col＝給食本文／右4col＝「数字で見る6月議会」レール（ウォッシュ地・囲みなし・ヘアライン区切り） | 本文＋データ |
| **E フッター** | 下端 | ヘアライン1本の上に「討議資料」タブ＋発行者＋QR2種 | 誌面フッター |

**表面に円形ヌメラルは置かない**（かめおか表紙も置いていない）。数字レールは大級数の金ヌメラルをヘアラインで区切るのみ。

### 裏面（pro2＝見開き型を単ページに凝縮）
草川本人が選んだベンチマーク。**非対称写真・記事グリッド＋水彩分節＋円形ヌメラル1点**を単ページに翻訳。上から：

| ゾーン | 中身 | かめおか対応 |
|---|---|---|
| **A セクション扉** | 明朝見出し「市政の現場から――6月議会、4つのご報告」＋金アンダーライン＋淡ウォッシュ地＋リード＋環境ポートレート小（A1里山） | 見開き扉の明朝タイトル＋水彩スプラッシュ |
| **B 非対称カードグリッド ×4** | Q→A→ひとことの4トピック。**均等4分割にしない**。1本を主役（広col＋写真＋円形ヌメラル）、3本を脇役（狭col・写真なし・バッジのみ）。分節は水彩ウォッシュ＋余白＋ヘアライン | 非対称写真グリッド＋円形ヌメラル1点 |
| **C 編集後記** | 縦組み2〜3行の締め（縦組みはここ1点のみ＝pro2の縦組みへの敬意） | 縦組み本文 |
| **D フッター** | 表面と共通（討議資料＋発行＋QR2種） | ― |
| **E 淡色エコー** | 下端に「声を、チカラに。」を淡金8%で特大エコー（英字ではなく日本語＝下記6-4） | ページ下端の淡色特大英字エコー |

**円形ヌメラルは裏面に1点だけ**（pro2の「15」に相当）。採用数字＝**978人/日**（関西本線輸送密度2024・交通カード）を第一推奨、代替＝**140件**（野立て太陽光）。円内に大数字＋小単位、円の外に対比「1987年 4,294人/日→」を添える。

## 2. グリッド／余白（mm）

- **判型**: A4 210×297mm。**塗り足し3mm**込みで **216×303mm キャンバス**で制作（`@page{size:216mm 303mm;margin:0}`、trim枠は内側3mmのガイドとしてCSS変数で持つ）。
- **外マージン（trimから）**: 天地左右とも **15mm**（かめおか級の呼吸）。数字レール側だけ右15mmを死守し内側ガター4mm。
- **本文領域**: 210−15−15＝**180mm幅**。
- **12カラムグリッド**: ガター4mm → 1col＝(180−44)/12＝**11.33mm**。
  - ヒーロー：ポートレート **5col** ＋ タイトル/リード **7col**。
  - トップ記事：本文 **8col**（内2段：3.66col×2＋段間4mm）＋ 数字レール **4col**。
  - 裏面カード：主役カード **7col**、脇役カード **5col**（2列組みで主+脇、脇+脇の非対称を作る）。
- **ベースライングリッド**: **4mm**刻み。本文行送りをこれに乗せる（下記タイポ参照）。見出し・写真天地も4mm整数倍にスナップ。
- **写真サイズ比（大：中：小 ＝ 2：1.4：1）**:
  - 表面ヒーロー（大）＝ 横 **58mm** 前後。
  - 裏面 環境ポートレート／主役カード写真（中）＝ 横 **42mm**。
  - 裏面 補助写真（小）＝ 横 **30mm**。
  - トリミングは全て天地も4mmグリッドにスナップ。角丸は**付けない**（写真は直角＝箱感回避のため囲み罫も付けない）。

## 3. タイポグラフィ（明朝×ゴシック混植・ジャンプ率1:5級）

### フォントスタック
```css
--font-mincho: "Hiragino Mincho ProN","Yu Mincho","YuMincho",serif;   /* 号タイトル・大見出し・扉・縦組み */
--font-gothic: "Hiragino Sans","Hiragino Kaku Gothic ProN","Yu Gothic",sans-serif; /* 本文・小見出し・ラベル */
--font-num:    "Helvetica Neue","Arial",var(--font-gothic),sans-serif;  /* 大数字・円形ヌメラル・% kcal */
```
- 混植は**2書体まで**（明朝＋ゴシック）。数字はHelvetica系を数字部のみに限定適用（`font-feature-settings:"tnum"`／和文単位「人/日」「回」は和文側で組む）。
- **装飾・丸ゴシック・ポップ体は禁止**。ブラシ体は §6-3 の1点のみ（画像アセット化）。

### 級数スケール（pt主／px参考 1pt≒1.333px）／用途・字間・行送り
| 用途 | 書体 | サイズ | 行送り | 字間 |
|---|---|---|---|---|
| マストヘッド「草川たくや」 | 明朝 W6 | **40pt**（53px） | 1.0 | +0.04em |
| 号タイトル（表ヒーロー明朝大） | 明朝 W6 | **26pt**（35px） | 1.15 | +0.02em |
| トップ記事 大見出し | 明朝 W6 | **21pt**（28px） | 1.25 | +0.01em |
| 裏面セクション扉 | 明朝 W6 | **22pt**（29px） | 1.2 | +0.02em |
| 小見出し（記事内・カード見出し） | ゴシック W6 | **13pt**（17px） | 1.4 | 0 |
| リード文 | ゴシック W3 | **11pt**（15px） | **1.8** | 0 |
| 本文 | ゴシック W3 | **9.5pt**（13px） | **1.75** | 0 |
| キャプション／出典 | ゴシック W3 | **8pt**（11px） | 1.5 | 0 |
| バッジ・ラベル | ゴシック W6 | **9pt**（12px） | 1.0 | +0.08em |
| 数字レール ヌメラル | Helvetica Bold | **32pt**（43px） | 1.0 | 0 |
| 円形ヌメラル（裏1点） | Helvetica Bold | **48pt**（64px） | 0.95 | 0 |

- **ジャンプ率**: マストヘッド40pt ÷ 本文9.5pt ＝ **約4.2倍**、円形ヌメラル48pt÷本文＝**5.1倍**。参照（かめおか）並みを担保。物足りなければ号タイトルを28ptへ、本文を9ptへ振って比を上げてよい。
- **約物は半角詰め**（`「」（）、。`のベタ空き回避）。**行頭の句読点・閉じ括弧のぶら下げ**処理。数字の**全角半角混在禁止**（半角に統一、単位も統一）。
- **金マーカー**は蛍光塗りではなく、**該当語のみゴシックW6＋金#c89211文字色＋語尾に細い金アンダーライン**で。囲み・ハイライト帯にしない。対象＝「12月末をめど」「全庁挙げて対応」。

## 4. カラートークン（白地＋緑＋金＋淡ウォッシュ・インク節約）

```css
:root{
  --paper:      #fbfaf6;  /* 温かみのある紙色。純白#fffは使わない（硬すぎ・AI臭の一因） */
  --ink:        #1a1a1a;  /* 本文。純黒#000は使わない */
  --ink-sub:    #4a4a4a;  /* キャプション・補助 */

  --green-900:  #14432b;  /* 明朝大タイトル・扉見出し */
  --green-700:  #1f5a3a;  /* 草川ブランド主色。小見出し・タブ・バッジ */
  --green-500:  #2f7a50;  /* アクセント線 */
  --green-100:  #e7efe9;  /* 面のごく淡い緑 */

  --gold-700:   #a8790a;  /* 金の濃色（数字・下線） */
  --gold-500:   #c89211;  /* 金アクセント。マーカー語・タブ旗・円ヌメラル縁 */
  --gold-100:   #f1e6c8;

  --wash-green: rgba(31,90,58,.08);   /* 分節ウォッシュ（緑） */
  --wash-gold:  rgba(200,146,17,.10); /* 分節ウォッシュ（金） */
  --hair:       rgba(31,90,58,.35);   /* ヘアライン1本用 */
}
```
- **かめおか→草川ブランド翻訳**: かめおかのティール#0d8b8b→**緑#1f5a3a**、かめおかのオレンジ日付ブロック→**金#c89211タブ**。かめおかの多色（桃・青・紫）水彩は**採らない**＝草川は緑・金の2色ウォッシュに絞る（節度＋インク節約）。
- **60-30-10**: 紙・余白（ニュートラル）60／緑30／金10。**金は線・小数字・マーカー・タブ・円縁に限定**（面で使わない）。
- **赤は一切不使用**（緑・金・ニュートラルのみ）。
- **バッジ配色**（囲み箱でなく塗りピル or 袋文字ピル）: 前進＝緑ベタ白文字／提言＝金ベタ白文字／質疑＝緑アウトライン緑文字／継続＝ニュートラル濃グレー。**赤・多色化しない**。
- コントラスト: 本文#1a1a1a on #fbfaf6 は十分。金#c89211を白地の**本文級**には使わない（薄い）＝金は見出し級・数字級のみ。

## 5. 写真ディレクション

### 表面ヒーロー（大・横58mm）
- **第一候補 H2**（のぼり前スーツ・屋外）＝かめおか的「環境ポートレート」で現場感が出る。第二候補 H1（スーツ室内・正面）は**顔＋上半身で左寄せトリミング必須**（右下の皿を必ず外す）。品質・視線で最終判断。
- **要件**: ①視線が紙面内側（右）へ流れる向き ②頭上に号タイトルを置く余白（headroom） ③背景がタイトル可読を妨げないこと ④**300dpi以上**（実寸58mm＝約685px以上）。
- 直角トリミング・囲み罫なし。人物の肩ラインを4mmグリッドに合わせる。

### 裏面グリッド
- **全カードに写真を入れない**（均等＝AI臭の元）。**環境写真は2点まで**：セクション扉に **A1里山**（横42mm・ぼかし背景で扉の水彩地と馴染む）、主役カード（浸水 or 交通）に現場写真1点。
- 手元素材：A1里山（扉）／A2米づくり（脇の季節アクセント・横30mm）。**追加収集中**の井田川駅前・亀山駅前の現場写真が入れば主役カードへ優先配置。無ければ主役カードは円形ヌメラル＋ウォッシュで視覚重心を作り、写真は増やさない。
- トリミング方針：横位置・情報の核（人の顔・現場の主対象）を各写真の左1/3に寄せ、右側に本文が食い込む余地を残す（pro2の写真→本文の視線連結を再現）。

## 6. かめおか固有意匠の翻訳指定

### 6-1 タブ旗（マストヘッド）
- かめおかの「No.060」ティールタブ＋オレンジ日付を、**金タブ旗「市政報告」＋緑デートブロック「2026 夏／6月議会報告」**に翻訳。タブは紙面左上角から下垂する小旗形（下辺を旗尾に切り欠き＝pro1のタブ形状）。角丸なし・幅18mm程度。

### 6-2 円形ヌメラル（裏面1点のみ）
- 緑#1f5a3a塗りの正円（径28mm）内に **978**（Helvetica Bold 48pt・白）＋下に小さく「人/日（2024）」、円の外・左上に金で「1987年 4,294人/日 →」の対比。**円は1個だけ**。円に影は付けない（フラット）。代替数字＝140件（太陽光）。

### 6-3 手書きブラシ体キャッチ（表紙1点のみ）
- **日本語ブラシ体を推奨**（英語スクリプトは議員報告物では広告臭・不自然になるため**不採用**）。文言＝トップ記事の約束を短く象徴する **「家庭へ、前もって。」** もしくはタグライン **「声を、チカラに。」**（本人選択）。
- **実装**: 信頼できるブラシ用webフォントがChrome headlessに常駐しない前提で、**手書き文字は SVG/PNG画像アセットとして1点作成**しヒーロー写真の余白に重ねる（外部フォント依存を避ける＝CSP安全）。アセットが用意できない場合の**フォールバック**＝明朝W6を斜体風にせず素直に置き、かめおか同様の**手描き二重ストローク装飾（≒のような跳ね）を2〜3本 SVGで添える**（faux筆記体は禁止）。
- 位置は写真上の**1箇所のみ**。裏面には手書きを持ち込まない。

### 6-4 ページ下端の淡色特大エコー
- かめおかの淡英字「Hello, New World!!」に相当。**英字は不採用**（広告・AI臭リスク）。代わりに裏面下端へ **「声を、チカラに。」を淡金 rgba(200,146,17,.10) の特大（60pt級）** で敷く。フッターQRと干渉しない高さに置き、**採用は任意**（誌面が詰まるなら省略可）。

### 6-5 水彩スプラッシュ（分節）
- かめおかの多色水彩→**緑・金の単色・低不透明度ウォッシュ2〜3点**に節制。有機的なにじみ縁のPNG（単色・軟エッジ）を扉背後とカード境界に敷く。**幾何学的な角丸ブロブ・シャープな図形は禁止**（それはボックスの再来）。--wash-green/--wash-goldのトークンで色を統一。

### 6-6 縦組み（1点のみ）
- pro2の縦組み本文への敬意として、**裏面「編集後記」2〜3行だけ縦組み明朝**。数字・英字・単位を含む本文（Q&A・数字レール）は横組みのまま（可読性・混植事故回避）。

## 7. AI臭チェックリスト（実装後 print-designer 自己検品）
- [ ] 角丸ボックスで囲まれた要素が**ゼロ**（写真・記事・数字・カードいずれも囲み罫なし）

- [ ] 中央寄せの多用がなく**左揃え基調**
- [ ] 影・グラデーション不使用（フラット）
- [ ] **絵文字ゼロ**・装飾フォントゼロ

## 9. print-designer への実装ブリーフ（着手順）
1. 216×303mmキャンバス・15mm外マージン・12col/4mmガター・4mmベースラインのグリッドCSSを先に敷く。
2. §4カラートークンと§3フォントスタックを`:root`に定義。
3. 表面5ゾーンを上から積む（マストヘッド→ヒーロー→部活動→給食＋数字レール→フッター）。**箱を一切描かず**、分節はウォッシュ／ヘアライン／余白で。
