# Illustrator受け渡し

`starter.svg`はA4仕上がり210×297mmに四方3mmの塗り足しを加えた216×303mmです。

レイヤーは次の5つに分離しています。

1. `background`
2. `photo`
3. `decoration`
4. `text`
5. `trim-marks`

IllustratorでSVGを開き、写真枠を実画像へ置換してから書体と改行を確認します。最終入稿時は印刷会社の指定に従い、文字のアウトライン化、リンク画像の埋め込み、CMYK変換、オーバープリントプレビューを人間が確認してください。HTML/PDF版とIllustrator版を並行編集せず、どちらを最終正本にするか案件フォルダのREADMEへ記載します。
