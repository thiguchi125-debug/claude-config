# イラスト素材庫（自前生成・政治利用セーフ）

## ⚠️ 用途の切り分け（2026-08-12追加・ここを間違えると⑤軸が埋まらない）

模写採点の**⑤イラスト・アイコン軸**を埋める手段は判型で分かれる。**この素材庫だけでは市政報告は埋まらない。**

| 何を作るか | 使うもの | 誰の手番 |
|---|---|---|
| **市政報告レポート・三つ折り・後援会リーフレット** | `components/icons_policy.html`（政策アイコン8種）＋`components/diagram_parts.html`（図解4種）。**HTML/CSS/SVGで即使える** | Claude（生成不要） |
| **子育て・地域イベントのチラシ／ポスター**（明るい水彩路線） | **この素材庫**（下の20枚） | 草川（Geminiで生成） |
| 和風・自治会・敬老（`style_washu_calm`） | この素材庫の washi_* | 草川（Geminiで生成） |

市政報告に水彩の桜を貼っても⑤は埋まらず、むしろAI臭が出る。
参照 `references/trifold/tri06〜09` が使っているのは**政策ボックスのアイコン**、`tri05` は**円バブルの図解**であって、装飾イラストではない。
また `references/trifold/tri03`（東大病院 外面）は**イラストを一切使わずに成立する系統**で、素材庫が空でも
円形マスク写真＋円バブル地紋だけで⑤を回避できる。


> 「淡色＋水彩＋キャラ」路線（DESIGN_RULES.md §1（明るいイラストチラシ））をHTML/CSS印刷物で実現するための
> 装飾イラスト置き場。**いらすとや等のフリー素材は政治利用禁止規約があるため使わない**。全て自前生成。

## 運用フロー

1. `prompt_cards.md` のカードを草川がGemini（nano-banana）にコピペして生成
2. 生成PNGをこのフォルダに投入（ファイル名はカードID: `flower_sakura_01.png` 等）
3. Claudeに「イラスト素材庫を台帳化して」→ `catalog.html`（一覧プレビュー）を再生成
4. design-studio Step2 で photo-curator と並ぶ素材源として参照

## 白背景素材の使い方（透過が不完全でも困らない）

nano-banana は真の透過PNGが安定しないため、**白背景で生成**して以下で馴染ませる:

- 淡色背景のチラシ: `mix-blend-mode: multiply;` で白が消えて水彩だけ乗る（最も確実・推奨）
- どうしても透過が必要な場合: Claudeに依頼→PIL で白抜き処理（水彩のにじみは劣化するので multiply 優先）
