スタイルレシピ: インク節約レポート系

用途: 市政報告レポートA4両面・議会報告・文字量多めの情報物（正本テンプレ=templates/report_a4_duplex・原典=木下v22）。自宅/ラクスル大量印刷前提でベタ面積を最小化しつつ、緑2階調＋金の数字で退屈させない。

配色（白面積70%以上を維持）

#ffffff 白（節約の核）
#1f7a3a 主緑・罫
#0e4d27 深緑・帯
#c89211 金・数字
#222222 本文

フォント

見出しヒラギノ角ゴ W6・深緑 #0e4d27。帯見出しは白抜き
本文ヒラギノ角ゴ W3・9.5〜10.5pt・2〜3段組（文字量勝負のレポートは段組が命）
数字W8＋金 #c89211 で大きく（stat_numbersコンポーネント＝2×2数字セル/5連ZEROグリッド）

装飾語彙 / CSSのコツ

  • ベタは帯見出しのみ（深緑）。地紋・背景色は張らない（インク節約）／緑5px左罫の小見出し
  • 数字ブロックで視線の休符を作る（3〜4カ所/面）／photo_text_row（同高flex・float禁止）で写真と本文を並べる
  • QRフッター（components/qr_footer_block）＋「討議資料」表記を忘れない

NG

  • 全面背景色・大面積ベタ（インク大量消費）／段組なしの1段ベタ流し（読まれない）
  • 写真の過小配置（切手サイズ写真の羅列＝素人化。使う写真は絞って大きく）
