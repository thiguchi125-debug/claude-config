スタイルレシピ: 和風・落ち着き系

用途: 自治会総会・敬老行事・伝統行事・式典案内。和紙60% / 薄香＆常磐緑25% / 群青10% / 山吹茶5%。低彩度統一＋「間」が主役。朱赤は使わず藍/金茶/墨で置換。

配色（日本の伝統色から抽出）

フォント

見出しヒラギノ明朝 ProN W6・大きめ＋letter-spacing:.1em。縦書き（writing-mode:vertical-rl）が映える
本文ヒラギノ明朝 ProN W3 / 游明朝 Medium・11〜12pt（年配層配慮でやや大きく）・行送り1.9
禁止丸ゴ・ポップ体は厳禁。角ゴは最小限

装飾語彙

  • 和紙テクスチャ背景（assets/illustrations/washi_texture_01＋background-blend-mode:multiplyで薄く）
  • 山吹茶の1px細罫のみで区切る（太線禁止）／縦組みタイトル＋脇に細縦罫
  • 青海波・七宝など和文様を隅に淡く小さく（washi_pattern_01）／短冊・色紙風カード（薄香地）
  • 落款風の角印は藍or金茶で（朱＝赤は草川NG）／余白（間）を大きく＝それ自体が装飾

構図

  • A型: 右に縦書き大見出し＋縦罫、左に横組み本文
  • B型: 上部に常磐緑or群青の帯（格式）＋和紙地の案内＋右下に角印 — 式典・敬老向け
  • C型: 中央寄せ縦書きタイトル・上下大余白・金茶細罫のみ — 招待状・案内状型

CSSのコツ / NG

  • 字間 letter-spacing:.08〜.12em で「間」を演出／box-shadowはほぼ使わない（フラット・平面が正解）
  • NG: ゴシック主体・高彩度原色・影/グラデ/立体ボタン・朱赤の多用・余白を詰める・絵文字/アイコン多用（文様で代替）
