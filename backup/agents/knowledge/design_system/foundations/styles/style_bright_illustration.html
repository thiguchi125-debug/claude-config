スタイルレシピ: 淡色水彩・明るいイラスト系

選択規則 — この様式を選ぶ判断
向く判型A4チラシ／ポスター／SNS画像
向く相手子育て世帯・子ども・地域イベント参加者。「楽しそう」が最初に伝わるべき紙面
向かない場面議会報告・政策・予算など重い話（軽く見える）／家庭用プリンタ配布（淡色面が広くインクを食う）／文字量の多い紙面
相性の良い参照fly01（リソ2〜3色・昭和レトロ縁日・イラストが主役）、tri05（北里大学・淡色図解型）
外してはいけない1点イラストを1点は必ず入れる。無いなら別の様式を選ぶ
判断の一言: イラストが主役。文字はイラストの邪魔をしない量まで削る。

用途: 子育て支援・親子イベント・地域行事・市民向け告知。「怖くない・優しい」を淡いトーン統一と余白で作る。理想形＝feedback_flyer_bright_illustration_style。

配色（比率: 背景55 / 水彩30 / アクセント10 / 補助5）

フォント

見出しヒラギノ丸ゴ ProN W4〜W6（丸ゴが柔らかさの主軸）。手書き親しみ枠は Klee One
本文ヒラギノ角ゴ ProN W3 / 游ゴシック Medium・10.5〜12pt・行送り1.7〜1.8
日時・数字丸ゴBoldで本文の1.5〜2倍級（最優先可読）

装飾語彙

  • 水彩にじみ円（radial-gradient＋blur(40px)を背景に2〜3枚）／手描き風の波線・ジグザグ罫（直線区切り禁止）
  • 角丸大バッジ（border-radius:24px以上）で「無料」「予約制」／点線・破線フレーム／マスキングテープ風帯
  • 水彩の花・葉・雲イラスト（assets/illustrations/ の自前素材を mix-blend-mode:multiply で合成）
  • 手描き矢印・吹き出し／ドット散らし

構図

  • A型: 上1/4に丸ゴ大見出し＋水彩帯 → 中央イラスト/丸トリミング写真 → 下1/3に日時・場所・申込カード群
  • B型: 左55%テキスト・右45%大水彩イラスト（イラストは矩形で切らず背景に溶かす）

CSSのコツ / NG

  • 全要素 border-radius 16〜28px・直角排除／影は極薄広ぼかし 0 8px 24px rgba(74,64,56,.08)
  • font-weightを上げすぎない（W4〜W6）／下線は波線SVGをbackground敷き
  • NG: 純白背景＋純黒文字・原色ベタ塗り・極太ゴシック詰め込み・濃い立体影・赤系アクセント
