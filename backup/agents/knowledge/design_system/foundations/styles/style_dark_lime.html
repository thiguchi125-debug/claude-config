スタイルレシピ: ダーク×ライム

選択規則 — この様式を選ぶ判断
向く判型SNS画像／イベントチラシ／ポスター／ショート動画の挿入画
向く相手若者・eスポーツ・攻めた告知。既存ブランドの主戦場
向かない場面高齢者向け／全世帯ポスティング（黒ベタで印刷コストと可読性が落ちる）／議会報告・市政報告／子ども・地域向け（暗く硬くなる既知の失敗）
相性の良い参照なし（ブランド由来の様式。参照ではなく templates/flyer_a4 が正本）
外してはいけない1点ライムは差し色。面で使うと安くなる
判断の一言: 攻める紙面専用。迷ったら選ばない。

用途: eスポーツ・若者向けイベント・攻めた告知。既存ブランドの主戦場（正本テンプレ=templates/flyer_a4・原典=eスポーツflyer_a2）。子ども・地域向けにはデフォルトで選ばない（暗く硬くなる既知の失敗＝そちらは淡色イラスト系へ）。

装飾語彙 / CSSのコツ

  • 質感: グレイン／ハーフトーンを地に薄く。文字の下だけは静かに保つ（§1.5-4）
  • 躍動: 斜め色面 ±8deg〜-14deg（斜め緑マッシブ＝templates/leaflet_trifold／ウェッジ＝templates/flyer_a4）。8様式で最も強く角度を使ってよい。ただし1面1角度
  • ライム下線は box-shadow: inset 0 -Npx 0 rgba(199,255,74,.35)（gradient hard-stop禁止＝rules.md確定パターン）
  • ダーク→深緑の対角グラデ地／ライムのソリッドバッジ（文字は深緑）／数字大強調（stat_numbersコンポーネント）
  • ライムは面積を絞る（画面の10%以下）。全面ライムは安っぽくなる
