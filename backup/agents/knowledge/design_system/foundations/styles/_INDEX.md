# 様式の選び方（判断表）

> **design-studio Step 1 で参照を選ぶ前に、まずここで様式を1枚決める。**
> 様式を決めずに作り始めた紙面は、禁止則（紫グラデ・絵文字・浮きカード）を守っていても
> 「無難で弱い」に着地する。禁止は事故を防ぐだけで、造形の強さは作らない。

## 1. 読む相手と目的から引く（第一手）

| 誰に・何のために | 選ぶ様式 | 根拠 |
|---|---|---|
| 全世帯に配る市政報告・議会報告を**読ませたい** | `style_ink_saving_report` | 白70%で情報量が主役。自宅印刷のインクも持つ |
| 初対面の有権者に**顔と名前を覚えてほしい** | `style_photo_bold` | 顔＋一言。後援会・選挙物の正 |
| 自治会総会・敬老会で**格を保ちたい** | `style_washu_calm` | 明朝＋余白。急かさない紙面 |
| 子育て世帯・子どもに**楽しそうと思わせたい** | `style_bright_illustration` | イラストが主役。文字は削る |
| 若者・eスポーツに**攻めた印象を出したい** | `style_dark_lime` | 差し色ライム。迷ったら選ばない |

## 2. 制約から引く（第二手・第一手と衝突したらこちらが勝つ）

| 制約 | 効く判断 |
|---|---|
| **使える実写真が無い** | `style_photo_bold` は不成立 → brand01（Warren 2020）のタイポ路線か `style_ink_saving_report` へ |
| **家庭用プリンタで刷る** | ベタ面の多い `style_dark_lime`・`style_bright_illustration` を外す → `style_ink_saving_report` |
| **文字量が多い（中面・レポート）** | `style_ink_saving_report` 一択。参照は tri04（中面が文字中心の解） |
| **イラスト素材が無い** | tri03（東大病院・公的清潔・単色）が最短。イラスト前提の様式を選ばない |
| **緊急・締切を伝える** | `style_washu_calm` を外す（明朝と余白が緊急度を殺す） |
| **高齢者が主読者** | `style_dark_lime` を外す（可読性） |

## 3. 決めたら次にやること

1. 選んだ様式カード（`style_*.html`）を**自分でRead**する — 配色・フォント・装飾語彙・NGをそのまま実装制約にする
2. カード内「相性の良い参照」の ID を `references/_INDEX.md` で引き、**参照画像を自分でRead**する
3. 参照の `_karte.md` の5軸数値（級数ジャンプ率／色数／図形語彙／写真・図版占有率／イラスト点数）を
   print-layout-architect への指示にそのまま目標値として渡す（Step 4-B でこの5軸が採点される）

## 4. 「該当なし」のとき

無理に既存5枚へ寄せない。次の順で処理する:

1. 制約表（2章）で**外す様式**だけ先に決める
2. 残った中から一番近いものを**ベース**にし、変更点を1〜2点に絞る（配色だけ／書体だけ）
3. 出来が良ければ Step 7-1 で**新しい様式カードとして昇格**させる（`_INDEX.md` の1章にも行を足す）

様式を3点以上いじった時点で、それは既存様式ではなく新様式。カード化して残す。

## 5. 空白（次に埋めるもの）

- **官公庁フォーマル系** — デジタル庁デザインシステム由来。議会・行政向け資料、スライド、デジタル面に効く。現状デジタル判型の様式が1枚も無い
- **新聞体エディトリアル系** — 文字量の多い紙面の第2の解。`style_ink_saving_report` の一択状態を崩す
