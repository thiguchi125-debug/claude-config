判断の一言: 紙は「読ませる」、ここは「止める」。情報量で勝とうとした瞬間に負ける。

用途: SNSの小判型。紙の6様式は全て「読者がすでに紙を手に持っている」前提だが、ここだけは手に取らせる前の勝負。だから設計の主語がレイアウトではなく可読性の床とセーフゾーンになる。数値は short-video-image-designer の可読性フロアと同一（二重管理しない）。

文字サイズの床（1080px幅基準・階層は2つだけ）

主役メッセージ72px以上（推奨88〜120px）・weight 900。1画面に主役は1つ
支え（補足・ラベル）44px以上
出典・注釈26px以上。ここに重要情報を入れてはいけない
紙との違い紙の様式はジャンプ率3〜8倍を作りにいくが、小判は主役と支えの2階層だけ。中間の見出しを作ると主役が埋もれる
SVGの罠読ませたい文字を縮小表示されるSVGの中に置かない。重要な語はHTMLレイヤーの特大テキストとして絵の上／外に置く

装飾語彙 / CSSのコツ

  • 文字の下は必ず静かに。ドット地紋・グレイン・写真のディテールを読みテキストの背後に敷かない（「背景が汚くて読めない」の正体）。質感は絵の領域だけに薄く乗せる
  • 帯を水平矩形で終わらせない（§1.5-3）。小判で最も効くのは傾けた色面（transform:rotate(8deg) のライム面＝4:5スターターの実装）
  • 写真は角版で切らない（§1.5-1）。片側フェード（mask-image:linear-gradient()）か、太いクリーム枠＋濃緑のオフセット影（box-shadow:22px 25px 0 #0f3d27＝スターター実装済み）
  • 数字を図版化する（§1.5-2）。小判は数字1つを特大で置くのが最強。単位と出典は支え・注釈の階層へ落とす
  • 見出し記号に絵文字を使わない。ライムバー・角マーカー・ピルで代替する
  • 実装は1080px実寸のHTMLで作り、Chrome headless でPNG化 → PNGを20%に縮めて自分の目で見る（親指テスト）。等倍で確認して合格にしない

NG

  • 主役文字が72px未満／1画面に主役が2つ以上／情報を1枚に詰め込む（割って複数枚にする）
  • ライム×クリーム・淡色×淡色などの消えるペア／薄い文字で雰囲気を作ること
  • 字幕セーフ帯（y1240〜1460）に主役・高コントラスト要素を置くこと
  • 印刷物への流用（→ style_ink_saving_report / style_photo_bold で作り直す）
  • 絵文字・浮きカード・紫グラデ（DESIGN_RULES §1）
