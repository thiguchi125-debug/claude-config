選択規則 — この様式を選ぶ判断
向く判型議会・委員会の配付資料／政策提案資料／16:9スライド／Notion・PDFで画面で読ませるもの。デジタル判型の第一候補（他の4様式は全て紙前提）
向く相手執行部・所管課・他会派・報道。「この人の資料は数字が読める」という信用が成果物の目的である場面
向かない場面全世帯ポスティングのチラシ／イベント告知／後援会リーフレット（硬すぎて手に取られない）。市の公式広報と誤認されうる対市民配布物には使わない（下の「借りないもの」参照）
相性の良い参照tri03（公的・清潔・単色／ジャンプ率4倍・色数3）、tri05（数値と関係性を図解1点に集約）、rep10（写真0枚で図版60%＝数字を図版化する手本）
外してはいけない1点本文と地のコントラスト比4.5:1以上を全要素で守る。装飾で格を作らず、余白・整列・数字の精度で作る
判断の一言: 権威は装飾ではなく整列から出る。線を1本足す前に、揃っていない要素を1つ直す。

用途: 議会・行政向け資料とデジタル面。デジタル庁デザインシステムの文法（4/8pxの倍数で刻むスペーシング、Noto Sans JP、装飾ゼロ、アクセシブルなコントラスト）を借り、色は草川ブランド（濃緑2階調）に載せ替える。文字量が多くても表と図解で構造を見せて読ませる。

借りるもの / 借りないもの（この様式の要）

借りるグリッドとスペーシング（4/8pxの倍数のみ・半端値を作らない）／Noto Sans JP 1書体で階層を作る／罫は細グレー1種／表・定義リスト・図解を主役にする／アイコンは単色線画のみ
借りない官公庁ブルー系の配色。国・県・市の刊行物と同じ色調にすると、議員個人の資料が公式広報に見える。誤認は品位・公選法いずれの面でも取り返しがつかない。色は必ず #0f3d27 / #1f5a3a に置換する（tri11・tri12 の政党色置換と同じ扱い）

装飾語彙 / CSSのコツ

  • 質感: 乗せない。この様式では質感＝ノイズ。格は余白と整列で作る（§1.5-4）
  • 躍動: 使わない（躍動ゼロが正解）。整列が権威を作る。角度を使いたくなったら様式の選択を間違えている（§1.5-5）
  • 面の分割は罫1本か余白だけ。影・角丸カード・グラデーションは使わない（浮きカード禁止＝DESIGN_RULES §1）
  • 要素の上端3pxだけ濃緑で締める（border-top:3px solid var(--green)）。囲み枠を全周太くしない
  • 数字は図版化する（§1.5-2）。3列グリッドの数字セル＋出典行を、原稿を流す前に確保する
  • 強調はライムのアンダーライン1か所のみ（background:linear-gradient(transparent 62%,#c7ff4a 62%)）。太字の乱発で階層を壊さない
  • スライドは16:9・左右マージンを揃え、1画面1メッセージ。1画面に見出しは1つ

NG

  • 官公庁ブルー・自治体ロゴ調の意匠（公式刊行物との誤認）／市章・市のマークの流用
  • 薄いグレー文字（#999以下）・小さい注記の多用でコントラストを割ること
  • 装飾で埋める（アイコンの飾り置き・意味のない罫・背景の淡色ベタ）。埋めたくなったら余白のまま残す
  • 写真の無理な挿入。この様式は写真0枚で成立する（rep10 が手本）。入れるなら図解の説明として1点
