# 造形カルテ — ブランドシステム（判型をまたぐ統一の作り方）

---

## brand01 — Elizabeth Warren 2020 大統領選 キャンペーンブランド
`brand01_warren2020.jpg` ／ 系統: 選挙キャンペーンのブランドシステム一式
（ポスター／Tシャツ／缶バッジ／ヤードサイン／ロゴ）

- **① 級数ジャンプ率 = 実質∞**（ポスターが**文字だけで構成される**。写真もイラストも無く、
  タイポグラフィそのものが絵。「AMERICA NEEDS TRUTH / WARREN / PERSIST & VOTE DEM」）
- **② 色数 = 3**：ネイビー／レッド／リバティグリーン（淡緑）。この3色だけを全アイテムで反復。
  淡緑が効いていて、赤青2色の「ありがちな政治色」から抜けている
- **③ 図形語彙**：極太コンデンス大文字の全面組み／下線・打ち消し線の記号的使用（`NOT WINNING = NOT AN OPTION.`）／
  縦ストライプ（旗の抽象化）／単純な矩形ロックアップ／ポスターの紙のシワ質感
- **④ 写真占有率 = 約5%**（顔写真は1点、それも**2階調のポスタライズ**に加工して絵にしている）
- **⑤ イラスト = ゼロ**。ロゴマーク（3本線＋アーチ）だけ

**転用ポイント**：**写真もイラストも無いまま強い紙面を作る唯一の解＝タイポグラフィを絵にする**。
草川の「声を、チカラに。」は、現状ライムのバー1本を添えた小さな文字だが、
この参照に倣えば**面の半分を占める特大ロックアップ**になりうる。

**最重要の学び**：ブランドは「色3つ＋書体1つ＋反復」で成立する。
草川の4色（濃緑・ライム・クリーム・墨）は既にこの条件を満たしている。
**足りないのは色でも書体でもなく、反復と大きさの決断**。

**注意**：英字の極太コンデンスは和文にそのまま移植できない。
和文でジャンプ率を稼ぐなら、ゴシック極太＋字間詰め＋縦組み（tri06〜09の姓名の扱い）が対応する。
