T5（斜め片側色面）1600×900のアイキャッチでは、文字が全部左の色面（テキスト幅668px）に入る骨格上、
ラベル行と役職行が「幅に収めるため」38px・24pxまで落ちる。原寸では読めるが、
400px配信面では9.5px・6.0pxになり、200pxでは4.75px・3.0pxで消える。

**Why:** 2026-09-04 周産期通院支援アイキャッチの実測。原寸目視・check_overflow・空きポケット判定は
全部通っていたが、ラベル「健診の費用に、市の助成はある」が400pxで死に、
「ある↔ない」の対比＝この画像の用件そのものが配信面で成立していなかった。
2026-08-31の育休退園サムネ事故（本文20px→7px）と同じ型の再発。

**How to apply:** T5で1600×900を組むときは設計段階で先に割る。
- メイン1行 ≥100px（400px時25px）／副1行 ≥56px（400px時14px）
- 副行は 668px ÷ 56px ＝ **最大11字**。文言を先に11字以内へ削ってから級数を決める
- 役職24pxは400pxでも6px＝装飾。カードは氏名だけにするか、氏名を56px以上へ
- 述語を分割する語（「市の」等・限定を担う語）は200px（原寸96px以上）で残るか必ず確認する。
  落ちると「通院支援は無い」のような過剰主張に読める
