## tri01 — インフルエンザ予防接種 三つ折り
`tri01_influenza_vaccine.png` ／ 系統: 啓発・行動喚起／情報密度・高

- **① 級数ジャンプ率 = 約8倍**（「怖い！」が本文の約8倍。表紙の半分を1語が占める）
- **② 色数 = 5**：クリーム地／赤（最重要見出し）／橙（セクション地・囲み）／黄（強調ハイライト）／黒（本文）＋白抜き文字。**色に役割が割り振ってある**
- **③ 図形語彙**：斜め帯（表紙上部を斜めに切る）／円形の抜き（ウイルス写真を丸マスク）／写真の重ね／**縦組みの背表紙帯**／チェックボックス／吹き出し／表組み（月別カレンダー）
- **④ 写真・図版占有率 = 約35%**
- **⑤ イラスト = 多用**（人物イラスト10点以上、注射器、アイコン）

**転用ポイント**：市政報告の「これから取り組みたいこと」を、赤の特大1語＋橙の囲みで見せる。
本文を読ませず、**色面とイラストで拾い読みさせる**構造。
**注意**：煽り色（赤の全面）は政治広報では強すぎる。赤の位置に濃緑、橙の位置にライムを置き換える。

## tri02 — 隅田稲荷神社 八僧稲荷 三つ折り
`tri02_sumida_inari.png` ／ 系統: 和風・格式／読ませる情報型

- **① 級数ジャンプ率 = 約6倍**（表紙の書道体タイトル）。中面見出しは本文の約1.8倍と控えめ
- **② 色数 = 4**：生成り地／金茶（飾り罫・見出し地）／えんじ（見出し文字）／墨（本文）＋写真
- **③ 図形語彙**：和風の飾り枠罫／ベタ帯見出し／**縦組み本文**／イラストマップ／写真の角版並置
- **④ 写真・図版占有率 = 約40%**（表紙全面写真＋中面の実物写真多数）
- **⑤ イラスト = 境内見取り図の俯瞰イラスト1点（大）＋飾り罫**

**転用ポイント**：中面が文字主体でも保つ作り。**「大きな俯瞰イラスト1点」が紙面を支える**構造は、
地区版レポートで「地区の地図イラスト1点」に置換できる。自治会・敬老向けの和風系統の正。
**注意**：中面のジャンプ率が低いので、これだけ写すと迫力不足になる。表紙の6倍は必ず守る。

## tri03 — 東大病院 皮膚科 三つ折り 外面
`tri03_todai_hospital_omote.jpg` ／ 系統: 公的機関・清潔／単色ブランド

- **① 級数ジャンプ率 = 約4倍**（「ご案内」）
- **② 色数 = 3**：シアン（ブランド）／濃紺（本文）／白 ＋写真
- **③ 図形語彙**：**円形マスク写真（大小3点）**／**円形の淡色バブル地紋**／上下のベタ帯／点線罫
- **④ 写真・図版占有率 = 約45%**（表紙面）
- **⑤ イラスト = なし**（円バブルの地紋のみで軽さを出す）

**転用ポイント**：**イラスト素材が無くても成立する唯一の系統**。円形マスクと円バブル地紋だけで、
帯と罫線しかない紙面から脱出できる。素材庫が空の現状で最短に効く参照はこれ。
表紙は「地図面／ロゴ面／タイトル面」の3面構成で、**ロゴ面をあえて白く空ける**判断が効いている。

## tri04 — 東大病院 皮膚科 三つ折り 中面
`tri04_todai_hospital_naka.jpg` ／ 系統: 同上／中面の作り方の教科書

- **① 級数ジャンプ率 = 約3倍**（「ご挨拶」）
- **② 色数 = 3**＋ベージュの面地
- **③ 図形語彙**：**ピル型タグ6個**（診療メニューを丸タグで一覧）／角丸ベタ帯見出し／表組み（曜日×午前午後）／**写真の下部ブリード**（面の下端を写真で断ち切る）／囲みボックス（予約センター）／装飾線付き見出し（—— ご挨拶 ——）／**面ごとに地色を変える**（白／白／ベージュ）
- **④ 写真・図版占有率 = 約20%**
- **⑤ イラスト = なし**

**転用ポイント**：**草川の三つ折り中面が最も直接的に学ぶべき1枚**。
中面が文字中心でも、ピル・角丸帯・表・下部ブリード・地色替えの5語彙で単調を回避している。
現状の草川版は「ベタ帯＋水平罫線」の2語彙しかない。

## tri05 — 北里大学 医療衛生学部 視覚機能療法学 三つ折り

- **② 色数 = 4**：淡緑／青緑／紺／白 ＋写真
- **③ 図形語彙**：**斜めの色面切り**（表紙を斜めに分割）／**円形バブルの関連図**（中央）／写真の斜めトリミング／淡いグラデーション地紋／アイコン／QR

## tri06〜09 — 議員向け選挙リーフレット見本 4種（制作会社テンプレ・架空候補）
`tri06_giin_leaflet_a.png` `tri07_giin_leaflet_b.png` `tri08_giin_leaflet_c.png` `tri09_giin_leaflet_d.png`
系統: 選挙・後援会リーフレット／**用途が草川に最も近い**

- **① 級数ジャンプ率 = 約8〜10倍**（姓名の縦組みが表紙の半分を占める。本文は極小）
- **② 色数 = 5**：赤（ブランド地）／黄（キャッチの下敷き）／濃紺（政策番号）／白（抜き文字）／黒。**色ごとに役割が固定**
- **③ 図形語彙**：**斜めの赤帯で表紙を切る**／**人物の背景切り抜き**（バスト・全身）／白フチ付き極太縦組み／黄色の帯アクセント／**番号付き政策ボックス＋アイコン**／後援会申込ハガキの一体化（ミシン目）／縦組みと横組みの併用
- **④ 写真・図版占有率 = 約45%**（人物切り抜き＋風景写真）
- **⑤ イラスト = 政策ボックスのアイコンイラスト4〜8点**

**転用ポイント**：後援会リーフレット（`templates/leaflet_trifold/`）の正の参照。
特に **「人物を背景から切り抜いて斜め帯に重ねる」** は、現状の草川版（矩形写真を右に置くだけ）との最大の差。
**注意**：赤×黄の配色は政党色を連想させるため踏襲しない。**構図と切り抜き処理のみ借り、色は草川の4色に置換**。

## 草川の三つ折り 2026-08版 との差分（採点結果）

| 軸 | 参照の水準 | 2026-08版の実測 | 判定 |
|---|---|---|---|
| ① 級数ジャンプ率 | 3〜10倍 | **約1.5倍** | ✗ |
| ② 色数 | 3〜5色（役割分担あり） | **実質2色**（濃緑・ライム＋クリーム地） | ✗ |
| ③ 図形語彙 | 斜め／円／重ね／ピル／地紋／表 | **ベタ帯＋水平罫線の2つのみ** | ✗ |
| ④ 写真・図版占有率 | 20〜45% | **約5%**（写真2枚。素材は8枚あった） | ✗ |
| ⑤ イラスト・アイコン | 数点〜多用 | **ゼロ** | ✗ |

5軸すべて不可。ただし**表紙面（特大の名前＋ライムバー＋顔写真）だけは①が成立しており**、
表紙の作り方は正しい。問題は中面と、外面のプロフィール／QR面に限られる。
