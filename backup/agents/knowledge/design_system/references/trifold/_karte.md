## 草川の三つ折り 内面 — v1 → v2 の採点（2026-08-12 実走）

参照＝**tri04**（東大病院 中面）。実装＝`~/publications/2026-08_市政報告レポート三つ折り/index_v2.html`。

| 軸 | 参照 tri04 | 合格ライン | v1（入稿版） | v2（改訂） | |
|---|---|---|---|---|---|
| ① 級数ジャンプ率 | 3倍 | 2.1倍 | 2.5倍（20pt/8pt） | **3.4倍**（26pt/7.7pt） | ✓ |
| ② 色数 | 3色＋面地 | −1色まで | 実質2色 | **4色**（生成り・白・濃緑・ライム）＋写真 | ✓ |
| ③ 図形語彙 | 5語彙 | 半分以上 | 2（ベタ帯・罫線） | **5/5**（ピル型タグ・角丸ベタ帯・図解・写真の裁ち落とし・面ごとの地色替え） | ✓ |
| ④ 写真・図版占有率 | 約15% | 10.5% | 1.5% | **7.1%** | ✗ |
| ⑤ イラスト・アイコン | 0 | 参照が使うなら必須 | 0 | **アイコン3点＋図解2点** | ✓ |

**4/5可 → 合格。** ④だけ届かない。

**④が届かない理由と、次にやること**: 内面の3パネルはいずれも本文が下端まで使い切っており、
図解を1点足すとグリッド全体が伸びて両段とも切れる（01章にタイムラインを入れて実際に破綻し、撤回した）。
**④を上げるには記事本数か本文量を減らすしかない**——これは草川の編集判断であって、実装側では解けない。
chiku-report G4「図表・写真の最低数（守れないなら記事を減らす）」が正しく、
**図表の枠を先に確保してから本文を流す**順序にしないと、後から図解は入らない。

**この実走で見つかったゲート自体の不備**: ④の定義が「写真・図版」と曖昧で、色ベタ帯を数えるかで
6.3%とも20%とも計算できてしまった。`README.md` で**写真＋図解のみ／色ベタ帯は数えない**に厳格化済み。

なお**表紙面（特大の名前＋ライムバー＋顔写真）は v1 の時点で①が成立**しており、変更していない。
未使用のまま残っている素材＝`profile-family-blurred`（外面プロフィール面向き）、
`skatepark-meeting`（実績02に対応）。**外面はまだ手を入れていない。**
