# thumbnail 造形カルテ（ブログOGP・サムネ）

> 規格：**1600×900（16:9）が既定**（2026-08-31改訂・`feed-visual-reviewer` A-3）。
> 安全域＝中央800×800。**下端12%に文字を置かない。外周40px相当に主要要素・署名を置かない。**
> 5軸の測り方は `../_types.md` のデジタル列。型は `../_types.md`。

## 恒久の下限（`feed-visual-reviewer` A-1／旧 feedback_thumbnail_pro_typography_default を2026-09-05に本節へ吸収）

- メイン1行 **原寸で最低100px**（1600×900では約133px以上を推奨）、副1行 **最低56px**
- 文字ブロックは **4つまで**（ラベル・見出し・副見出し・署名で既に4）
- `font-feature-settings:"palt" 1` 全体付与。ヒラギノW8/W9の実ウェイト。絵文字なし
- 本文級（20px前後）が入った時点でサムネではなく図版 → 本文の図解へ逃がす

### プロ級和文タイポの既定CSS（最初のレンダから入れる。「まず作る→後でプロ級に」の往復禁止＝2026-07-14 給水スポットサムネで草川「最初からそうして」）
テンプレ／AI感の主因は①約物（「」、。×）の間延び ②締まりの緩さ（line-height過大・不要な影）。
- フォント: `font-family:"Hiragino Sans","Hiragino Kaku Gothic ProN","YuGothic","Yu Gothic",sans-serif;` ＋ `-webkit-font-smoothing:antialiased`。Hiragino Sans はW3〜W9の実ウェイトを持つので 800→W8 Heavy／900→W9 Black が合成でなく本物の字面になる
- **約物半角（最重要）**: `.canvas` に `font-feature-settings:"palt" 1;` を全体付与。「」、。× の余分な字間が詰まり「ワンワード」化する
- **カギ括弧の左ぶら下げ**: 見出しに `text-indent:-.5em`（1行目の「だけ版面外へ）。1行目の実字と2行目頭のインク左端が一直線に揃う。レンダ後±0.05em目視調整
- 見出し line-height: 2行大見出しは **1.16〜1.18**（1.28は緩い）。letter-spacing .03em
- 氏名（表札）: `font-weight:900; letter-spacing:.10em;`。役職はW7・サイズ比2:1
- × セパレータは語より格下げ: `font-weight:400; font-size:.78em; opacity:.6; margin:0 .3em; vertical-align:.06em`（paltで詰まった分をmarginで復元）
- 影: ソリッド背景の文字は text-shadow **削除**（濁るだけ）。写真の上に載る文字だけ `0 2px 10px rgba(0,0,0,.55)` 程度
- 写真＋文字の縦型は、文字帯の下地グラデを `.78` 前後まで沈めてライム文字の可読性を確保
- 勝負所は design-director に before→after のCSS値粒度で外科的リファイン指示書を出させてから実装すると速い。制作後は必ずPNGを自分でRead（EYES-FIRST）。正規保存先 `~/outputs/thumbnails/`

## 観察まとめ（2026-08-31・政治/解説サムネ実物12点を採寸して判明したこと）

実物はすべて **1280×720**。既定の1600×900へ移すときは **級数を×1.25** すること。

### 1. 顔写真は「消す」のではなく「端に押し込む」

12点中11点が人物を使っている。**写真なしは thm10（イラスト）だけ**。
そして、人物とテーマが意味的に繋がっている例は thm05 と thm09 の2点しかない。
thm01の玉木、thm02の玉木、thm11の中田はいずれも「ただ喋っている人」で、
GDPにも憲法にも103万円にも繋がっていない。それでも成立しているのは、

- 人物が **画面の右または左 25〜35% に押し込まれている**
- 人物の上に文字を **重ねていない**（文字は必ず空いた側）
- 顔は **胸から上・目線がカメラかやや斜め**。全身は thm09 のみ

→ **「写真がテーマと合わないから写真なしにする」は、実物に照らすと不要な後退。**
合わない写真でも、端30%・文字は反対側、で成立する。これが今回いちばん大きい発見。

### 2. 暗幕を使っている例が1点もない

写真の上に文字を載せる9点は、**全部が極太の縁取り**で処理している
（stroke 相当 8〜14px＠1280幅、白フチまたは黒フチ。二重フチが thm10・thm11）。
`_types.md` の **T2「全面ブリード＋暗幕」は紙の作法であって、サムネの実物には無い。**
サムネで写真を沈めたいときは、暗幕ではなく次の3手が使われている。

- 素材そのものが暗い写真を選ぶ（thm08・thm11・thm12）
- **全面モノクロ化**して地紋に落とす（thm12）
- 人物に**暗い服**を着せて暗い地と同化させ、切り抜き線と体の輪郭を消す（thm11 の黒スーツ）

### 3. 級数ジャンプ率は「制度もの」だけが高い

| ジャンプ率 | 該当 | 性格 |
|---|---|---|
| 8〜10倍 | thm08 / thm12 | 企画名・タイトルを1語で覚えさせる |
| 4〜7倍 | thm06 / thm07 / thm10 | **制度名・金額を主役に立てる** |
| 3倍前後 | thm03 / thm04 / thm11 | 見出し＋ロゴ／補足帯 |
| 2倍前後 | thm02 / thm05 / thm09 | 2ゾーンに割り切る |
| 1.5倍 | thm01 | **弱点**。4ブロックが同大で並び、読む順が決まらない |

→ **制度変更の解説は「4〜7倍」を狙う。** thm01 のような4ブロック同大は真似しない。

### 4. 数字・制度名の立て方は3手しかない

- **単語1個を巨大に**（thm06「相続税」＝画面幅の55%／thm11「103万円の壁」＝画面幅の72%）
- **年号・金額を見出しと同格で並べる**（thm10「年収の壁」＋「2026」を左右に）
- **区分を色違いの矩形バーで並べ、各バーに数字を白抜き**（thm10 の119/136/169/178万、thm11 の103/106/130/150万円）
  → バーは**棒グラフではなく色分けのラベル置き場**。高さは意味を持たせず、右肩上がりに並べるだけ

### 5. 400px に落として残った要素（実測）

400px幅に縮小した接触シートで数えた結果。**2〜3個で止まっている面が強い。**

| 残り2〜3個（合格） | thm02 / thm03 / thm04 / thm05 / thm06 / thm07 / thm08 / thm09 / thm12 |
|---|---|
| 残り4個以上（要注意） | thm10 / thm11（バーの数字まで残ってしまう） |
| 破綻 | thm01（4ブロックが等価に並び、どれから読むか決まらない） |

## 📌 恒久ガードルール（草川の差し戻しから／追記は末尾へ）

### 2026-09-04 顔アップに寄せない・敵を作る言い回しにしない

周産期通院支援のアイキャッチv2が「サムネ画像終わってる。もっとマシな写真と切り取り方ないのか、
顔アップすぎる。文章内容も変に敵を作るような言い回し。支援を！ぐらいでいい」で差し戻された。
再発防止として、着手時に次の2点を必ず満たしてから組む。

**A. 写真の切り取り（顔の大きさ）**
- **顔（頭頂〜顎）が画面高の40%を超えたらやり直し。** 目安は25〜35%。v2は約85%で、額と顎が切れていた
- 人物は **胸から上のバストアップ**。首から上だけに寄せない。縦位置の原本は
  「切り抜く」のではなく **原本の全幅を使って縦に長く取り、人物を小さく収める**（`magick -crop <全幅>x<高さ>+0+<y>`）
- 選抜済みストック `📷写真ストック/10_使える写真/01_人物単独` の**ファイル名の目利きタグを読む**
  （「ヒーロー向き最良」「クロップ必須」等）。ここが第一手で、Photos.app検索より優先
- 背景に看板・車・電柱が入るのは可。**寄って背景を消すより、引いて人物を小さくする方が常に良い**

**B. 短文コピー**
- **「◯◯がない」「◯◯されていない」型の断罪を短文に載せない。** 「◯◯を」の要求型に寄せる
- 事実は事実として1行（例「お産は市外の病院へ」）、要求は要求として1行（例「通院にも／支援を」）に分ける。
  混ぜて「市の支えが ない」にすると、提案が消えて糾弾だけが残る
- 詳細＝`~/.claude/agent-memory/content-fact-checker/feedback_thumbnail_copy_avoid_adversarial_tone.md`

**C. 機械チェックの当て方（16:9アイキャッチ）**
