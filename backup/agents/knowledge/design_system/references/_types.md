# 型カタログ（判型をまたぐ構図の正本）

> 新設 2026-08-31。カルテが「この参照はこういう造形」を記録するのに対し、
> ここは **判型をまたいで再利用できる構図に名前をつける** 台帳。
> **複数案を出すときは型を変えて振る。同一骨格の文字量違いは1案と数える。**

運用ルールと模写採点表は `README.md`、参照の一覧は `_INDEX.md`。

## 5軸の判型別読み替え

| 軸 | 紙（trifold / a4_flyer / a4_report / poster） | デジタル（thumbnail / sns_square / vertical_9x16） |
|---|---|---|
| ① 級数ジャンプ率 | 4〜8倍 | **4〜7倍**（制度・数字もの）／8〜10倍（企画名を1語で立てるとき）<br>※2026-08-31訂正。旧「8〜15倍」は実測に基づかない値だった。実物12点の分布は1.5〜9.6倍で、**2倍を切ると読む順が決まらず破綻する**のが下限 |
| ② 色数と役割分担 | 共通 | 共通 |
| ③ 図形語彙 | 共通（斜め／円・円形抜き／重ね／ピル・角丸／地紋／ベタ帯／罫） | 共通 |
| ④ | 写真・図版**占有率**（%） | 写真の**処理法**。切り抜き／斜めの色面で切る／全面ブリード／トーン統一（モノクロ化）<br>※2026-08-31訂正。**「無加工ベタ置きは不可」は撤回**——実物12点のうち thm09・thm03・thm01 は無加工の実写をそのまま置いて成立している。条件は「人物を端25〜35%に寄せ、文字を反対側に置き、色面か額縁で写真の縁を締める」こと。**暗幕は実物では使われていない**（＝紙の作法） |
| ⑤ | イラスト・アイコン**量** | **縮小時に残る要素数**（400px幅で3つ以下） |

## 型の選び方（デジタル）※2026-08-31 サムネ実物12点に当てて全面改訂

1. **この画像が伝える用件を1文で言えるか。** 言えないなら型を選ぶ前に用件を絞る
2. 用件の核で選ぶ。**制度・金額の説明** → **T6**（本命）／**人の表情** → **T8**／**告知・お願い** → **T5**／**シリーズの1回** → **T9**／**企画名を覚えさせる** → **T10**
3. **写真がテーマと意味的に繋がらなくても、写真は外さない。** → **T5**（斜めの色面で切る）か **T7**（モノクロ化して地に落とす）を選ぶ。
   人物は端25〜35%に押し込み、文字は必ず反対側に置く。実物12点中、人物とテーマが繋がっている面は2点しかなく、残り9点は「ただ喋っている人」で成立している
4. 迷ったら **T5 か T8**。どちらも装飾がほぼゼロで、失敗しても凡庸に留まり破綻しない

> **旧ルール「写真がテーマと繋がらないならT1/T2を選んではいけない」は撤回した。**
> これを「だから写真なしで作る」と読み替えた結果、判型違いの印刷物参照を代用する事故が起きた（2026-08-31）。

### サムネ実物から出た横断則（型選択の前に効く）

1. **顔写真は消すのではなく端に押し込む。** 12点中11点が人物入り。人物とテーマが意味的に繋がっている面は2点だけで、残りは「ただ喋っている人」を端25〜35%に置いて成立させている。**テーマに合う写真が無いことは、写真を外す理由にならない**
2. **文字は人物の上に重ねない。** 人物と文字は必ず左右に分ける
3. **暗幕は使われていない。** 写真の上に文字を置くときは極太の縁取り（8〜14px＠1280）。沈めたいときは「暗い素材を選ぶ／モノクロ化する／暗い服で溶かす」
4. **400pxで残す要素は2〜3個。** 4個以上残る面は読む順が決まらない（`thumbnail/_karte.md` §5の実測）

## 規格の例外（2026-09-01・実測で判明）

**「中央1:1クロップで文字が欠けないこと」（`feed-visual-reviewer` A-3）は、斜め二分型（T5）には適用しない。**
採用した実物 `thm09` 自体がこの試験に落ちる（中央1:1で「緊急」が丸ごと消える）。
文字を全部片側の色面に置く骨格である以上、構造的に両立しない。両立させると色面が72%まで膨らみ別物になる。
**正方形の配信面が必要なら、同じ骨格を上下二分にした別版を起こす。**
