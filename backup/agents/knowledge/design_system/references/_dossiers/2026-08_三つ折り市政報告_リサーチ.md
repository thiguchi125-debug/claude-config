### #4 生成り地＋濃色＋金という和の配色と高密度組版 — 隅田稲荷神社リーフレット
- 出典: https://www.dofdesign.jp/works_all/ryoun-leaflet/ 系列（`leaflet31_img01.png`）

**目視所見**

## 深緑を主役にする配色レシピ

```css
:root{
  /* 地 —— 面積 約55% */
  --paper:      #f3efe4;   /* 生成り。紙全体の地。白は使わない */
  --paper-2:    #ffffff;   /* 表・グラフの抜き地としてのみ 約8% */

  /* 主役 —— 面積 約30% */
  --green:      #1f5a3a;   /* 見出しベタ帯・大数字・パネル見出し地 */
  --green-deep: #0f3d27;   /* 表紙の地・締めの文字。面積 約5% */
  --green-tint: #e4ece5;   /* 深緑5%相当の淡色。表のヘッダー地・囲み地 */

  /* 差し色 —— 面積 3%以下・ベタ面禁止 */
  --lime:       #c7ff4a;

  /* 文字 */
  --ink:        #14231c;   /* 本文。純黒でなく緑寄りの黒 */
  --ink-weak:   #4a5a50;   /* キャプション・注記 */
}
```

**面積比の目標**: 生成り55 / 深緑（濃淡合わせて）30 / 白8 / ライム3 / 墨系4

**ライムを差す場所（ここだけ）**
1. 小見出し左の縦バー（幅3mm × 文字高）
2. 大数字のアンダーライン（太さ2mm・数字幅の80%）
3. 深緑ベタ帯の中の矢印・番号・記号（白抜きの中の1点だけ）
4. グラフの強調系列1本のみ
5. 表紙スローガン帯の下端3mmの細帯
6. QRコード脇の「読み取り」誘導アイコン

**ライムを使ってはいけない場所**
- 生成り地の上の本文文字色（コントラスト比が2:1台まで落ちる。#1f5a3aなら7:1超）
- 20mm角を超えるベタ面（一気に安っぽくなる。#4の金茶が罫と飾りに限定されていたのと同じ理屈）
- 顔写真に接する位置（肌色と補色関係で写真が濁って見える）

**紙色との関係**
- 生成り#f3efe4は印刷では**マットコート or 上質紙**を前提に。光沢コートだと深緑が黒に沈み、ライムだけが浮く
- 生成りを紙自体の色で出す（ファンシーペーパー）か、CMYK地色で刷るかを決める。ネット印刷の標準紙＋地色ベタ刷りなら、**塗り足し3mmを全パネルに必ず設定**し、断裁ズレで白フチが出ないようにする
- 深緑#1f5a3aのCMYK変換目安: C85 M40 Y80 K40 前後。**RGBのまま入稿するとくすむ**ので、入稿前にCMYK変換して色味を再確認する

## 今回案件のNGリスト（AI臭・素人臭を殺す）
