# 様式資料（造形は借りない）

ここにあるものは**判型・様式・記載事項の確認にだけ使う**。
造形（配色・図形語彙・タイポ階層）の参照にしてはいけない。

理由：参照を忠実に写すほど天井が参照の質で決まるため、
素人紙面・スキャン原稿の寄せ集めを造形の参照にすると、模写しても凡庸な紙面にしかならない。
