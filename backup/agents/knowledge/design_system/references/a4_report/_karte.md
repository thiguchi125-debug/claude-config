# 造形カルテ — A4 レポート／広報紙特集（表紙・見開き）

> 数値は画像を目視した目測。精度より、書いてあることが重要。
> 制作時は **1本だけ選ぶ**。混ぜると平均化して凡庸になる。
> 出典・受賞歴は同フォルダ `_sources.txt`。全点が令和7年 全国広報コンクール入選級 ／ 制作会社の実績。
>
> **草川の用途＝A4両面の市政報告レポート**（表面＝掴み／裏面＝実績・数字）。
> 各カルテの1行目に **［表面向き］／［裏面向き］** を明記してある。参照は表裏で別々に1本ずつ選んでよい
> （表裏で系統がずれると別紙に見えるので、**色と図形語彙は表裏で揃える**）。

- **① 級数ジャンプ率 = 約3倍**（「廃業した旅館のお話」が本文の約3倍。ヘッダー内で完結する控えめな設計）
- **② 色数 = 4**：橙（主色・ヘッダー地／見出し文字／縦ラベル帯）／白（抜き文字）／グレー（before-after帯・要点ボックスの見出し地）／黒（本文）＋写真

- **⑤ イラスト・アイコン = 実質なし**（吹き出し1・● ビュレット・QR1のみ。イラストゼロで持たせている）

**転用ポイント**：市政報告の表面で「**誰と誰が対置されているか**」を1秒で見せたいときに選ぶ。

**効いている理由**：ヘッダーの色面を曲線で切ったうえに人物を**はみ出させて**いるので、帯と本文が分離せず1枚の絵になっている。
**注意**：橙の全面は草川の色に無い。橙の位置に濃緑、要点ボックスのグレーの位置にライムを置く。

- **② 色数 = 2**：黒／白 ＋写真のみ。**このライブラリで最も色数が少ない**
