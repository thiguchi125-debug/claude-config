# 参照ライブラリ（造形の借り先）

> 新設 2026-08-12。**印刷物の造形をゼロから発明しないための正本。**
> 制作は必ずここから参照を1本選び、その造形を寸法レベルで模写する。

## なぜ作ったか

2026年8月の市政報告レポート三つ折りで、参照11枚を案件フォルダに集めながら
**一枚も模写せず**、矩形の帯と水平罫線だけの紙面を出した。
`design-studio` SKILL には「ゼロからのHTML発明禁止。参照を最初に自分でReadし、
構図・配色・余白比率・タイポ階層を模写する」と既に書いてあり、実行が守っていない。

根因は2つ。

1. **参照が案件フォルダに置き去りで、次の制作に引き継がれない**（全案件で参照が残っていたのは2件だけだった）
2. **模写できたかどうかを判定する数値基準がない**。natural-design-reviewer は破綻検出役なので、
   帯を積んだだけの平凡な紙面が「破綻ゼロ＝合格」で通ってしまう

このライブラリは1を、下の造形カルテと模写採点表が2を潰す。

## 使い方（制作フロー）

1. 判型フォルダ（`trifold/` `a4_flyer/` `poster/` `a4_report/`）の `_karte.md` を読む
2. 案件に合う参照を **1本** 選ぶ（複数を混ぜない。混ぜると平均化して凡庸になる）
3. **画像を自分で Read する**（カルテを読んだだけで実装に入らない）
4. 実装する
5. 出力PNGと参照画像を並べ、下の**模写採点表**で採点。合格ラインを割ったら差し戻し

## 造形カルテの5軸（この5つを数値で書く）

| 軸 | 測り方 | なぜ効くか |
|---|---|---|
| **① 級数ジャンプ率** | 最大見出しの文字高 ÷ 本文の文字高 | 紙面の迫力はほぼこれで決まる。プロは4〜8倍、素人紙面は1.5〜2倍 |
| **② 色数と役割分担** | 使用色の数と、各色に割り当てた役割 | 「緑濃淡だけ」は情報の階層が色で分けられない |
| **③ 図形語彙** | 斜め／円・円形抜き／重ね／ピル・角丸／地紋／ベタ帯／罫 のどれを使うか | 矩形の帯と罫線しか無い紙面は「Wordで丁寧に作った資料」に見える |
| **④ 写真・図版占有率** | 紙面面積に占める割合（目測%） | プロの広報物は30〜40%。5%を割ると文字の壁になる |
| **⑤ イラスト・アイコン量** | 点数と使い所 | 情報の入口になる。ゼロだと拾い読みできない |

数値は目測でよい。**書かないことが問題であって、精度は問題ではない。**

## 模写採点表（Step4で使う。合格ライン＝5軸中4軸で「可」以上）

| 軸 | 可 | 不可（差し戻し） |
|---|---|---|
| ① 級数ジャンプ率 | 参照の **70%以上** を再現 | 参照6倍に対し出力2倍、など |
| ② 色数 | 参照の色数 **−1色** まで | 参照4色に対し出力2色 |
| ③ 図形語彙 | 参照が使う語彙のうち **半分以上** を使用 | 参照が斜め・円・重ねを使い、出力は帯と罫線だけ |
| ④ 写真・図版占有率 | 参照の **70%以上** | 参照35%に対し出力5% |
| ⑤ イラスト・アイコン | 参照が使っていれば **必ず使う** | 素材庫が空だからゼロ、は不可（先に素材を作る） |

**「破綻ゼロ」は合格条件ではない。** 破綻ゼロは natural-design-reviewer の担当で、
この表を通らない限り紙面は完成していない。

## 参照の質ゲート（採用の可否）

採用してよいもの — デザイン会社・印刷会社の制作実績／広報コンクール受賞紙面／
公的機関・大学・病院の公式広報物／選挙広報会社のテンプレ見本／海外キャンペーンのブランドシステム。

採用してはいけないもの — **議員の自作紙面／Wordっぽい紙面／スキャン原稿の寄せ集め**。
参照を忠実に写すほど天井が参照の質で決まるため、ここを外すと模写しても凡庸になる。
判定は必ず**画像を自分で見てから**行う。落としたものは `_format_only/`（様式の参考にはなるが造形は借りない）へ。

## 追加のしかた

制作のたびに集めた参照は、案件フォルダに置き去りにせず**必ずここへ移す**。
判型フォルダに画像を置き、同フォルダの `_karte.md` にカルテを1本追記し、`_INDEX.md` の表に1行足す。
画像が取得できずテキストのドッシエしか残らない場合も、`.md` として保存する（`a4_flyer/fly01` がその例）。
