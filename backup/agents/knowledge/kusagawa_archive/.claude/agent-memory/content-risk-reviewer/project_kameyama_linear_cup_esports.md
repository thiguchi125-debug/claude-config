亀山市eスポーツ協会主催「かめやまリニア杯 eスポーツ大会」。第1回=2024年12月・亀山公園旧図書館（プレイヤー70名超／体験見学含め400名超）、第4回=2026年8月11日・亀山市関文化交流センター。草川は同協会 **事務局長**（議員本業とは別の団体役職）。

**Why:** 「議員個人SNS」で「参加費無料＋賞品あり」のイベントを「選挙区内」に告知する構図は、公選法199条の2（候補者等の寄附禁止）の外形に毎回必ず当たる。中庄町夏祭り（[[project_nakasho_natsumatsuri_flyer]] 相当）と同じ論点系統で、毎回同じ確認を繰り返す必要がある。

**How to apply:** 本大会の告知物をレビューするときは、以下を毎回確認事項として草川に提示する。
1. **賞品・運営費の原資**（協会予算／協賛／草川個人負担のどれか）— 個人負担なら CRITICAL、協会負担なら文言手当てで可
2. 告知文に「運営費・賞品はすべて協会が負担」と**費用負担まで**明記されているか（「協会から賞品」だけでは主体表示として弱い）
3. 会場が公共施設の場合、**使用料の減免・優先予約に議員の立場が働いていないか**、施設使用許可の名義が協会か
4. 市の補助金・後援名義・委託費が入っていないか（入っていれば利益相反の突かれどころ／地方自治法92条の2の兼業も念のため）
5. **申込フォーム取得情報（保護者名含む）を後援会名簿・選挙目的に転用しない**担保
6. 撮影・肖像権の事前告知（未成年参加者多数のため必須）
7. ゲームタイトルの大会開催ガイドライン許諾（賞品ありは許諾要区分に入りやすい）
8. 告知ポスター等の**9月中旬以降の残置回避**（P2直前期の文書図画規制）

問い合わせ番号 090-1099-2458 は草川個人番号（市政報告レポート発行元と同一・自己開示済のため個人情報事故ではない）。「亀山市eスポーツ協会 事務局（事務局長・草川）」と協会窓口である旨を添えて表記する。
