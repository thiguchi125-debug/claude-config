少年事件（逮捕・補導・触法）を草川の内部ワークシートに記録するときは、報道原文をそのまま写さず次を必ず落とす。

- 発生地・被害地の**町名**（例「関町古厩」「住山町」）→「市内」に丸める
- **被害者の属性**（年齢・性別・職業。例「市内の男性会社員（26歳）」）→ 全削除
- **少年の年齢内訳**（例「15歳・14歳」）→「男子中学生2人」等に丸める。14/15の別が議論上必要なときのみ「14〜15歳」
- 盗品の細目・負傷部位など、議会論点に不要な具体性

残してよいのは「事案が起きた事実・日付・容疑名・議会での問い立て」まで。

**Why:** 少年法61条は「新聞紙その他の出版物」への推知報道を禁じており内部メモは直接の適用外だが、(1) このページは ohayo → spark / content-pipeline へ流れる発信素材の上流にあり混入経路が実在する、(2) Notion は共有設定次第で外部に出る、(3) 被害者側の属性は報道済みでも議員が保持する必要性がない。「持たなければ漏れない」を優先する。

**How to apply:** news-briefing / ohayo / smart-intake いずれの経路でも少年事件を保存する時点で丸める。地の文の括弧書きで「対外発信は不可」と書くだけでは機械が拾えないので、`[SNS]` と同列の grep 可能な `[NO-SNS]` タグを見出し行に付けて、下流スキルが除外できる形にする。関連 [[kusakawa-yoshitsugu-doseibetsujin]]
