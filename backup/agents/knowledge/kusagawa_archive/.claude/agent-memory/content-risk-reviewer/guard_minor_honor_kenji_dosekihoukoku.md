未成年（中高生）の全国大会優勝・受賞など**他人の栄誉**に、草川が議員として同席した／表敬訪問に立ち会ったことを発信する場合、毎回この5点を潰す。初出＝2026-09-04 全中110mH 中学新記録の祝福SNS（X/Instagram/LINE）。

**Why:** この型は「事実は全部正しいのに構図で燃える」。危険は数字ではなく**成果の帰属が個人→地域→議員へスライドして読める配置**にある。加えて選挙が近いほど、慶事同席報告そのものが売名・事前運動の文脈で採点される。報道機関が実名報道済みでも、議員個人アカウント（肩書・ご意見箱・LINE導線つき）は同意の器が違う（[[feedback_consent_scope_org_to_personal_blog]] と同根）。

**How to apply:**
1. **未成年の実名をハッシュタグにしない。** 本文の実名は報道済みなら射程内だが、`#氏名` は検索面に恒久的な紐付けを作り報道の範囲を超える。`#草川たくや` と並置すると「その子の名前で検索した人に議員名が出る」構造になる。同じ理由で**慶事投稿に `#草川たくや` を付けない**。
2. **「同席させていただきました」を書かない。** 読者にとって議員の所在は不要情報で、投稿中で唯一の自己PR要素になる。書くなら主語を消して「市役所で表敬訪問が行われました」まで後退させる。
3. **冒頭は本人主語で始める。** 「〇〇から、日本一が生まれました」型の地域主語を冒頭に置くと、個人の努力が地域（＝議員の地盤）の手柄に読み替えられる。記録・本人名を先に出し、地域は後段に添える。
4. **所属民間クラブ／学校の扱い。** 学校の部活動でなくクラブで出場した場合、市立中学校名を主語級に置くと学校の成果と誤読され、学校からもクラブからも苦情の余地。所属は括弧で1回だけ・評価語なし・リンクや入会案内は絶対に付けない（[[feedback_consent_scope_org_to_personal_blog]] の便益供与ライン）。草川と当該クラブに支援関係があれば利益相反軸で再判定。
5. **選挙をまたぐ残置運用を必ず添える。** 投稿可否ではなく「いつ何を止めるか」で判定する。告示日以降は当該投稿のピン留め・リポスト・ストーリーズ再掲を停止、投票日当日は再掲・拡散行為を全面停止（残置自体は可）。

**あわせて毎回確認する事実（本文からは見えない事故源）:**
- 表敬訪問の場で草川または後援会名義の花束・記念品・金一封を渡していないか（公選法199条の2／199条の5。渡していれば写真にも写る）。
- 本人・保護者から「議員個人のSNSに実名で載せる」ことの同意を取ったか。
- 対戦相手・他県の未成年を実名で書く必然性があるか（無ければ「別組の選手」「北海道の選手」で足りる）。
- 選手と市長・関係者が同姓の場合、同一投稿内の並置が血縁の誤読を生まないか。
