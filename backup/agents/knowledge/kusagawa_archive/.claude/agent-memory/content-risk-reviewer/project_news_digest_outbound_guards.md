`drafts/<日付>_news-digest.md` → Notion固定ページ（ohayoが毎朝読む1ページ・全置換）は**対外発信物ではないが、各itemに「→ 活用: SNS」タグが付いており、そのままSNS/ブログ/演説の素材に流れる**。したがってリスクレビューは「このページを公開してよいか」ではなく「**このタグが立ったitemが対外に出たとき何が起きるか**」で見る。

**Why:** 2026-08-10版のレビューで、内部物としては全項目クリアなのに、`活用: SNS` タグが付いた2件が既存の確立ルールと正面衝突していた。
- 昼生ツアーitemに `国分等会長`（一般市民の実名）が入っていた → [[feedback_ohanami_hanyu_shusai_attribution]]「国分等会長など市民の実名は対外SNSでは原則伏せる」に抵触。
- 熊本地震義援金itemに `活用: SNS` → [[feedback_disaster_rescue_phase_no_local_pivot]] 追記5「熊本地震に触れる媒体は経緯を最後まで書ける長文ブログ1本だけ。切り取られる長さの面（SNS・動画・画像）には入れない」に抵触。
どちらもページ単体では無害で、**下流のspark/content-pipelineが素直にタグへ従った瞬間に事故になる**構造。下流は元記事の文脈を持たないので、ガードはこのページ側に書いておくしかない。

**How to apply:**
- 実名（市民・団体役員）を含むitemは、実名を消さず（内部の追跡精度が落ちる）**インラインで `／⚠️対外発信では氏名を伏せ「協議会の会長」表記` を併記**する。
- 確立ルールで媒体が限定されているテーマ（他地域の災害等）は、`活用: SNS` を立てず `活用: 保留（〜のため草川判断）` にする。
- ページ冒頭に「対外転記時は fact-checker → risk-reviewer を再通過。G枠(iJAMP)と[dedup判定ログ]は転記対象外」の1行を常設する。iJAMPは有料契約情報で転載不可。
- `[dedup判定ログ]` の刑事事件itemの除外理由は「議員活動に使える論点を立てられず」だけにしない。**「被害者・関係者の特定リスク」を必ず併記**する。前者だけだと将来のセッションが「論点さえ立てば使える」と読む。
- 受付期間・開催期間を持つ市の事業itemは、期間が **告示2026-10-18／投票2026-10-25** を跨ぐかを確認する（跨ぐitemは選挙期に自動的に地雷化する）。
