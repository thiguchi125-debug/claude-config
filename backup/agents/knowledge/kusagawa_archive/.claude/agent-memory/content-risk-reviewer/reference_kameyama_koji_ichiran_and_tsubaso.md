道路の荒れ・段差を「◯◯工事のせい」と書く発信をレビューするときの一次資料と既知の落とし穴。

**工事の一次資料**: `~/.claude/agents/knowledge/kusagawa_archive/01_council/R7.3月 予算決算委員会提出資料.txt`
に「工事名／場所／工種」の一覧（管路関係）がある。`R6所管事務事業概要書(産業建設委員会).txt` も同種。
`grep -rho ".\{28\}<地名>.\{28\}" 01_council 05_resources` で場所名から工事を引ける。

**既知の事実（2026-09-02時点で確認）**: 椿世町地内（市道椿世9号線ほか）で挙がっている工事は
**「公共下水道事業に伴う配水管移設工事」＝上水道（配水管φ20〜50mm L=285m）の支障移設**であり、
下水道の管渠布設工事ではない。下水管渠布設として資料に出ているのは布気町など別の町。
→「下水道の管渠を入れる工事」と書くと、発注部局も受注業者も違う相手に施工不良を示唆することになる。

**「新椿世」は自治会名**（住所表記は椿世町。地元は椿世ニュータウンと旧集落を区別している）。
自治会名を地名として使うと、自治会の総意の要望と読まれる／別区域に風評が及ぶ。
発信では路線名（市道椿世◯号線）＋ランドセルになる目印で範囲を閉じる。

**レビュー上の3分離ルール**（工事×道路不良の発信一般）:
①観測事実（段差がある・危ない）②原因（どの工事か・工種・発注者）③評価（施工の出来）を混ぜない。
②が未確認なら②③とも書かない。②③を書くと工事看板から受注業者が特定でき、信用毀損（刑法233条）の射程に入る。
