原稿に実在の第三者の氏名（〇〇会長・〇〇代表など）が出てきたら、「他議員かどうか」の確認だけで通さない。**草川の後援会員DB／選挙地域名簿と同姓同名がいないかも必ず突合**してから判定する。

突合先（ローカルgrepで足りる）:
- `05_resources/notion_archive_*/02_選挙地域150件.md`（地区つき人物リスト）
- `05_resources/notion_archive_*/04_action_plan.md`（後援会員DB登録バッチの地区別名簿）
- 議員名の確認は `grep -rho "伊藤[^。、）)　 ]\{1,6\}議員" 01_council ...` の形で姓＋「議員」を引く

**Why:**
2026-08-11の納涼大会続報レビューで、伊勢新聞から引いた「亀山市納涼大会実行委員会（伊藤峰子会長）」の氏名が、草川の後援会員DB移行リスト（城東地区）に同名で存在していた。亀山市議の伊藤姓は伊藤彦太郎なので「他議員名NG」ルールには触れないが、**投票日（2026-10-25）まで75日の時点で、後援会関係者を実名で顕彰する構図**になりうる。氏名が報道済み＝公開情報だから安全、で止めると、この second-order のリスクを丸ごと見落とす。同一人物かどうかは草川しか判断できないので ASK_USER が正しい出口。

**How to apply:**
- 内部記録（Notion内部ページ・drafts）に留まる限りは LOW。**対外発信（ブログ・SNS・印刷物）へ流す段で HIGH に格上げ**し、①同一人物か ②実名で出す必要があるか ③「実行委員会」など団体名だけに置換できないか、を1問ずつ選択式で聞く。
- 置換案の既定は団体名のみ（例:「主催は亀山市納涼大会実行委員会」）。実名を残すなら「伊勢新聞2026-08-10の報道による」と出典を明示させる。
