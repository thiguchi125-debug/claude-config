亀山市職員（部長・課長・参事等の管理職）の実名の扱いは、内部記録と対外発信で分ける。

- **内部記録（Notion各DB・照会カード・会議メモ）** → LOW。保持してよい。職員録・組織図で公開されている職務上の属性であり、照会先を特定する業務必要性がある。
- **対外発信（ブログ・SNS・印刷物・報告会スライド）** → 原則 HIGH。氏名は落とし「産業環境部の担当参事」「建設部住宅担当」のような職名表記にする。

**Why:** 職員は市長・議員と違い、名指しで論評されても自ら反論する場を持たない。公人性が低いぶん名誉毀損・議員品位の当たりが強く出る。加えて人事異動で肩書が陳腐化し、古い氏名を残すと誤情報になる。

**How to apply:** 📰ニュースDBの `議会活用メモ` は「職名まで・氏名は書かない」で統一する（同DB内で「産業環境部（村田博参事）」と「建設部住宅担当」が混在していた実例あり）。氏名が実務上必要なのは照会・アポ取りの局面なので、それは会議／照会カード側に置く。レビューで氏名を見つけたら、削除ではなく「内部は可・対外転用時に落とす」ラベルの有無を問う。
