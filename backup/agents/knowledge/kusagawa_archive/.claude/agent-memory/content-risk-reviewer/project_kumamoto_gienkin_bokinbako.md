亀山市は令和8年熊本地震（2026-07-28発生）の義援金募金箱を **2026-10-29まで** 設置している。この期間は市議選の告示日 2026-10-18 と投開票日 2026-10-25 を完全に内包する。

**Why:** 公選法199条の2第2項は、公職者が選挙区内で**氏名を表示して寄附をすること**を禁じている。募金箱への寄附は日赤等への義援金であり議員本人の寄附自体は可能だが、草川が募金する様子を写真・動画付きで発信する、あるいは自身の名を冠して募金を呼びかける形にすると、氏名表示寄附・売名と評価されるリスクがある。選挙期間直前〜期間中はこの評価が最も厳しくなる。

**How to apply:** 熊本地震の義援金・募金箱に触れる原稿が来たら、(1)主語が「市の取り組み」として書かれているか（草川個人の寄附行為・呼びかけになっていないか）、(2)草川の氏名・写真と募金行為が同一投稿内で結び付いていないか、を確認する。募金の様子の撮影・投稿は、時期を問わず ASK_USER とする。[[ijamp-internal-only]]
