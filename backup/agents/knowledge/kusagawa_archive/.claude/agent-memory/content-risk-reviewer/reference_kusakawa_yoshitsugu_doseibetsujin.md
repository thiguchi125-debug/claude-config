亀山市議会の過去答弁（H30.12 昼生地区アンダーパス等）に出てくる **草川吉次・教育部長**は、草川たくや議員とは**同姓の別人**（市の幹部職員）。

- 「草川は…と質問済み（当時の草川吉次教育部長が…と答弁）」という並記は、質問者と答弁者の双方が「草川」になり、本人の実績・親族関係と誤認される最悪の形。
- 対外発信では答弁者は役職のみ（「当時の教育部長」）で足り、実名は不要。
- 内部メモで実名を残す場合は「※草川たくや議員とは同姓の別人」を同じ行に置く。

**How to apply:** 議事録引用・ニュースダイジェスト・議会だより・市政報告レポートで「草川」が答弁者側に出たら必ずこの注記を確認する。関連 [[shonen-jiken-naibu-memo-ryudo]]
