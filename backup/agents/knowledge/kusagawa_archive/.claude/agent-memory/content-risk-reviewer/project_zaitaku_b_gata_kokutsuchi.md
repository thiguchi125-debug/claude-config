2026-08-25、草川が「在宅の就労継続支援B型に関する国の通達」を調査。結論＝削減目標・削減指示の通達は存在せず、要件遵守徹底の通知3本（R7.3.31 Q&A VOL.8／R7.11.28 障障発1128第1号ガイドライン／R8.4.13 事務連絡）で審査が厳格化方向。R8.4.13に令和9年度報酬改定での在宅支援見直し検討が明記。

**Why:** 「在宅利用者を減らせという国の指示が出た」という趣旨の話が現場に流れている疑いがあり、その真偽を一次資料で確定させるのが調査の目的。R8.6施行の1000分の984特例は新規指定事業所限定で、既存事業所の減額ではない（誤解の温床）。

**How to apply:**
- 未実施の市照会3点＝(1)亀山市が在宅利用の支給決定基準を文書で定めているか (2)県がR8.4.13をいつ市へ周知し市の運用がいつ変わったか (3)市内の在宅利用者数推移と既利用者の継続可否。
- (3)は**母集団が小さく実数が個人特定に近づく**。市から数字を得た段階で必ず個人情報軸を再レビューし、対外発信では丸めるか非公表とする。
- 本メモに調査の端緒（誰の相談か・どの事業所か）が書かれていない。利益相反軸の判定を確定できないため、端緒は名簿区画（Drive `日常資料アーカイブ/00_名簿・個人情報/`）に分離記録し、政策メモ側には残さない二層分離を適用（[[feedback-naibu-memo-notion-review]]）。
- 国通知の「要件を満たしていない事例や不適切な事例も散見される」は**全国傾向の記述**。市内事業所を指す記述ではないので、転記のたびに引用範囲を明示する。
