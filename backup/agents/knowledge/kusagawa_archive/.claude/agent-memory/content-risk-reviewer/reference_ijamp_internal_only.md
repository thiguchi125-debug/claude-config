iJAMP（時事通信 官庁速報／自治体情報サービス）の記事は有料会員契約に基づく内部閲覧限定で、再配布・転載が禁止されている。news-briefing の「G. iJAMP」枠に入った項目は、Notion内部ページへの保存は可だが、**SNS・ブログ・一般質問・印刷物へそのまま持ち出すと契約違反**になる。

対外展開する場合は、当該自治体（例: 東京都国立市）の公式発表・議会資料・報道発表を一次情報として取り直し、出典をそちらに差し替えること。議事録が公開される一般質問での「iJAMPによると」という引用も同様に不可。

**How to apply:** iJAMP由来項目をレビューするときは、項目行そのものに「🔒iJAMP＝内部閲覧限定・転載禁止／対外発信は一次情報を取り直す」の但し書きがあるかを確認する。セクション見出しだけの明示では、ohayo等が項目単位で抜き出したときに注意書きが落ちるため不十分。
