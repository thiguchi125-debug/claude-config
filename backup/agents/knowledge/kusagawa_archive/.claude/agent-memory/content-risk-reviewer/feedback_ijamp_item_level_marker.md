iJAMP（時事通信社・有料法人契約／無断転載禁止）由来の記事は、**セクション見出しに「🔒内部専用」と書いてあるだけでは不十分**。項目行の先頭に `【iJAMP配信／🔒内部閲覧専用・転載禁止】` を付けるよう REVISE を出す。

**Why:**
📰今朝のニュースダイジェスト固定ページは、nichijo・spark・content-pipeline が**箇条書き1行単位で素材として抜き出す**。見出しに依存したマーカーは、行をコピーした瞬間に剥がれて出所が消える。2026-08-11版はG枠見出しに `（🔒内部専用）` はあったが、赤磐市の項目行は素の1行で、単体で見ると内部限定と判別できない状態だった（同じページ内のdedupログでは「正ページはSNS・ブログ活用対象で内部専用情報を混ぜられない」と正しく判断できているのに、G枠自身が同じページに同居している）。

**How to apply:**
- 転載禁止なのは**表現**であって着想ではない。「首長が動画で政策を語る」のような施策アイデアを草川の言葉で書くのは可。ただし公開時は①赤磐市公式など一次情報で裏を取り直す②出典は「時事通信社の報道によると」程度の短い言及に留める、を条件として添える。
- iJAMP見出しだけで一次情報に到達できない項目は、正ページに追記させない（2026-08-11の人事院勧告1.1兆円増は正しく除外されていた＝この判断は維持させる）。
