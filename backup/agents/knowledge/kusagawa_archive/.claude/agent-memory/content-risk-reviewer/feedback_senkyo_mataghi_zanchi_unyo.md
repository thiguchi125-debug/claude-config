投稿時点が通常期（P1）でも、内容の有効期限が告示日（2026-10-18）・投票日（2026-10-25）をまたぐ発信は、本文のリスク判定だけで終わらせず **期間別の運用表を成果物に添付する**。判定は「投稿してよいか」ではなく「いつ何を止めるか」。

運用表に必ず入れる行為列：新規・再投稿／既存の残置／ピン留め・ハイライト・プロフィール固定／一斉配信（LINE・メール・DM）／保存・シェア誘導／コメント返信／広告出稿。

固定の結論：
- **既存投稿の残置は全期間とおして可**。削除は不要（削除のほうが不自然）
- **ピン留め・ハイライト・プロフィール固定は 9/18 までに外す**。告示後に外すと「選挙運動用文書図画の変更」に見える。事前に外しておく
- **広告出稿・ブーストは全期間で不可**（142条の6）
- **10/18〜10/24 の一斉配信は保守側に倒して停止**。LINEのトーク配信は総務省見解上「ウェブサイト等」寄りだが、142条の4（電子メールによる選挙運動は候補者本人主体のみ）の疑義を自分で作らない
- **10/25 投票日はコメント返信を含めて全面停止**
- **賞味期限のある実用情報（販売期間・申込期限）は期限日に追記か非公開**。期限切れの情報が残ると誤情報になる

**Why:** 2026-09-02 かめやま健康弁当（販売11/29まで）のSNS7媒体レビューで、投稿は P1 だが販売期間が P2〜P4 を丸ごとまたぐ構成だったため。動画台本側には既に同型の運用表があり、SNS版と食い違うと現場で運用が割れる。

**How to apply:** Axis 3-B の判定時、内容に「◯月◯日まで」「期間限定」「今年度中」等の有効期限があるか、または投稿が固定・ピン留めされる想定かを見る。どちらかに該当したら運用表を作る。動画・ブログ・SNSが同一案件なら、3つの運用表の期間区切りと行為列を一致させる。
