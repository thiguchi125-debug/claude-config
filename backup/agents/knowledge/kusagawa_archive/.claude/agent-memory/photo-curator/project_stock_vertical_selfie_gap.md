Drive `📷写真ストック/10_使える写真` の在庫は15枚（2026-07-17時点）で、うち14枚が Pixel の**縦の自撮り**。横位置トリミング前提の紙面・PDF資料に使える「横長・引き・他人が撮った」カットが構造的に存在しない。

**Why:** 2026-07にメイン機が Pixel に移行し、日常の撮影が自撮り中心になったため。ストックの目利き自体は機能しているが、供給される構図に偏りがある。

**How to apply:**
- 横位置・引きが要件のタスク（A4紙面のヒーロー画像、サムネ、資料の表紙）では、ストックに期待せず**最初に「該当なし」の可能性を草川に伝える**。無理に縦自撮りを勧めない。
- 例外：`2025-04-16_スーツ緑タイ_のぼり前.jpg` は 1600×1200 で格納されているが EXIF回転で実表示は縦。**寸法だけ見て横長と判定しない**（[[exif-orientation-trap]] の逆パターン）。
- ランドマーク実写（鈴鹿川・亀山駅・一里塚公園等）も0件。不足は毎回 `_wishlist.md` に追記して次回撮影につなげる。
