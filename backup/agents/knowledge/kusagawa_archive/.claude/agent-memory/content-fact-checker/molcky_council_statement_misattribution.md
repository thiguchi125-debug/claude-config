令和7年12月12日 亀山市議会一般質問の「モルックは子どもから高齢者、障がいのある方まで多様な世代が一緒に楽しめるスポーツで、高齢者の健康維持・介護予防・地域福祉の推進に合致」という発言は、**櫻木善仁議員（2番）**のもの。草川卓也（4番）の発言ではない。

一次情報: `01_council/mydrive_一般質問3令和7年12月12日_IwxiA.txt` L281-293（○２番 櫻木善仁君登壇）。同ファイル全文を `grep 草川` すると0件＝この日のこの文脈に草川は登場しない。出席議員名簿（議案質疑ファイル冒頭）で草川4番・櫻木2番と確定。

亀山市自体はモルックをニュースポーツ体験会に導入済み（令和7年12月現況報告書 L320-322「フィンランド発祥のスポーツであるモルックを取り入れ、本年2回目のニュースポーツ体験会」＝R8.1.7予定）。この市の事実は中立引用可。

**Why:** 昼生キッズの日モルック大会ブログ(drafts/2026-06-14_昼生モルック大会_v1.md)で、櫻木議員の議場発言を「私が議会でお話しした」と草川発言として4PFに展開する誤帰属が発生。CLAUDE.mdの「議事録は草川発言＋市回答ペアのみ／他議員発言の誤帰属防止」に直接抵触。
**How to apply:** モルック関連の草川発信で「議会で私が発言した」型の帰属を見たら即フラグ。草川自身がモルック/ニュースポーツを議場で発言した一次資料は現アーカイブ内で未検出。多世代性は草川の現場実感として書くか、主語なし事実描写にする。関連の主催帰属注意は [[feedback_ohanami_hanyu_shusai_attribution]] と同種。
