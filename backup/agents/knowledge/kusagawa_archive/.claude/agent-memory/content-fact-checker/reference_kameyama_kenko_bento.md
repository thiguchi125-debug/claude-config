# かめやま健康弁当 確定スペック

一次情報：市ページ `https://www.city.kameyama.mie.jp/docs/2026012900020/`／
令和8年8月市長定例記者会見 資料 `260825-2-2.pdf`（`/mayor/2026082100030/file_contents/`配下・要 pdftotext -layout）

## 主体関係（発信で最も事故りやすい）

- 事業主体は **スーパーサンシ株式会社×亀山市**（記者会見資料の表題そのもの）。製造・販売・商品問合せは**スーパーサンシ側**（お客様サービスセンター 0120-34-1134）。
- 市の役割は連携・意識啓発・レシピ提供。**「亀山市がお弁当をつくりました」は主体の誤認を生む**。「市が民間と組んで」「市の調査を設計図にした弁当」等に言い換える。
- メニューは、令和6年度に**食生活改善推進協議会・健都サポーター・一般社団法人セルフケアフード協議会と市**が作成した冊子「**美味しい！かんたん！かめやま健康レシピ**」を参考。冊子には認定NPO法人健康都市活動支援機構も協力（ヘルシーパートナーズ事業の協賛で発行）。冊子の**収載品数は市が明示していない**ので「全20品」等の数字は書かない。

## 第2弾「健やか七彩（なないろ）弁当」

- 販売期間 令和8年8月31日（月）〜11月29日（日）／スーパーサンシ亀山エコー店及び会員向け宅配（**店頭販売は数量限定**）
- 価格 本体680円・税込735円
- **設計基準**（＝条件）：カルシウム200mg以上、**塩分**3g以下で設計
- **栄養成分（概算）**（＝結果）：592kcal／たんぱく質20.9g／脂質20g／炭水化物82.3g／食塩相当量2.8g／カルシウム389mg
  - ⚠️ 設計基準と栄養成分は**別物**。混ぜると「200mg以上入っている弁当」等の誤情報になる。市は栄養成分に「概算」と付しているので「実測」と言い切らない。
- メニュー10品：鮭の塩焼き／きのことパプリカのホワイトソース／小松菜としらすの胡麻和え／切干大根の昆布和え／昆布豆煮／だし巻き玉子焼／れんこんきんぴら／豆腐ナゲット／十六穀ごはん／お魚ふりかけ
  - 記者会見PDFは冒頭2品を中黒で繋いで表記しており9品に見えるが、**市ページは読点区切りで10品**が正。
- けんこうマイレージ：弁当購入1個につき50pt（あいあい7番窓口又は同店サービスカウンターにレシート持参）、発売日イベント参加10pt
- 所管：健康福祉部 健康推進課 健康増進グループ（0595-84-3316）

## 第1弾「かめやま健やか五彩弁当」

令和8年3月2日〜5月31日／本体598円・税込646円／410kcal・たんぱく質16.9g・脂質10.6g・炭水化物61g・食塩2.5g・野菜約129g。テーマは「塩分過多」「野菜不足」。第2弾は塩分過多に加え「カルシウム不足」に対応。
