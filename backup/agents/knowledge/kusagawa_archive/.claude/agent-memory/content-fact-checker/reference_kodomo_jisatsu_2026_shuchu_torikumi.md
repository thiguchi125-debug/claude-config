**集中取組期間**: 正式名称「こども・若者の自殺対策集中取組期間」、8月20日〜9月9日。こども家庭庁プレスリリース「政府全体でこども・若者の自殺防止に向けた取組を強化します」2026-08-07（https://kyodonewsprwire.jp/release/202608053683 ）。原文は「新たに…と位置付け」、教育新聞2026-08-07は「初めて『こども・若者の自殺対策集中取組期間』と設定」→「今回が初めて」は可。連携主体はこども家庭庁・厚労省・文科省・内閣府孤独孤立対策推進室。
傾向の原文は「こどもや若者の自殺が長期休暇明け前後に増加する傾向」。「夏休み明けは増える傾向があるとされています」と出典なしで書かない。

**数字の取り違え注意**: 小中高生の自殺者数は **令和7年(2025年)＝538人・過去最多**／**令和6年(2024年)＝529人**（こちらも当時の過去最多）。529を令和7年に付けると誤り。

**令和9年度概算要求（2026-08時点）**: cfa.go.jp/policies/budget にはまだ未掲載＝報道ベースでしか書けない。NHK 2026-08-25「こども家庭庁 自殺防止やSNS調査研究など7.7兆円余要求へ」（特別会計含む総額7兆7千億円ほど）／朝日 2026-08-20は調整段階で「約7.8兆円」。数字が割れるので媒体名と日付の明記が必須。
中身の正確な表現は「学校や医療機関、警察などでつくる**協議会が使えるような新たな交付金を創設**」＋「**都道府県や政令指定市**で**自殺危機対応チーム**の設置や事案対応の費用にも充てる」。→「協議会の設置を支える」は誤り。設置支援の対象は自殺危機対応チームで、かつ都道府県・政令市レベル（亀山市は直接の対象ではない）。
また国のこの協議会は自殺対策の枠組みで、亀山市いじめ問題対策連絡協議会（いじめ限定）とは別物。「にあたる仕組み」と等値にしない。
