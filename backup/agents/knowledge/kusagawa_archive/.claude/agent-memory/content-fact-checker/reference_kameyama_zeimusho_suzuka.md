# 亀山市と税務署（確定事実）

- **三重県内の税務署は8署のみ**：伊勢・上野・尾鷲・桑名・鈴鹿・津・松阪・四日市。**支署・分室・出張所は一つもない**。
- **亀山市は鈴鹿税務署の管轄**。鈴鹿税務署ページの管轄区域欄は「鈴鹿市　亀山市」の2市のみ。
  - 所在地: 〒513-0801 鈴鹿市神戸九丁目24番45号／近鉄鈴鹿市駅から徒歩7分／代表 059-382-0351
  - 開庁時間: 月〜金 8:30-17:00（土日祝・12/29-1/3は執務なし）
  - 申告書等の郵送先は税務署ではなく **名古屋国税局津業務センター**（〒514-8544 津市桜橋二丁目99番地）
- 一覧の一次情報: https://www.nta.go.jp/about/organization/nagoya/location/mie.htm
- 鈴鹿税務署: https://www.nta.go.jp/about/organization/nagoya/location/mie/suzuka/index.htm

**「亀山市に税務署はない」は断定してよい**（管轄区域の記載だけでなく、県内一覧に亀山所在の署・支署・分室が無いことまで確認済）。

## ただし「だから市外へ出るしかない」は言い過ぎ
確定申告期の申告相談は**亀山市役所本庁舎・関支所・市内10コミュニティ施設**（巡回）で市が実施しており、多くの市民は市内で完結する。亀山会場で扱えない申告のみ鈴鹿税務署の会場（例年イオンモール鈴鹿2階イオンホール）へ案内される。市の申告相談＝市・県民税＋一定範囲の所得税で、**国税の総合窓口業務そのものを市役所が代替するわけではない**点も混同しない。

## 国税庁サイトの読み方（重要・毎回ハマる）
国税庁サイトは **Shift_JIS**。WebFetch すると文字化けして「読めない」と誤判定しがち。必ず：

```
curl -s -L "<URL>" | iconv -f SHIFT_JIS -t UTF-8 | sed -e 's/<[^>]*>//g'
```

PDFの場合は [[../MEMORY]] 記載どおり `pdftotext -layout` へ。
