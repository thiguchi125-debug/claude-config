亀山市の「椿世」まわりの表記と一次情報の所在。発信物で地名を書くたびに再調査しないための恒久メモ。

## 表記の正解
- 公式町名（住居表示・郵便番号 519-0104）＝ **椿世町**（つばいそちょう）。国勢調査町丁字コード 242100240。
- **「新椿世」は公式町名ではない**。椿世町内の住宅団地／自治会区域の通称。
- 市の公文書での正式な言い方は **「新椿世地区」**。令和元年12月定例会本会議で市側答弁が「新椿世地区では、床上浸水９件、床下浸水２件の被害が発生しております」と使用（草川の内水氾濫質問への答弁）。
- 「新椿世自治会」は実在（市の行政財産目的外使用許可一覧に「椿世町518-5／新椿世自治会／土地(災害時における緊急避難通路の確保)」）。
- 施設名としても「新椿世雨水ポンプ場」が実在（土木課 工事一覧）。
- **対外発信では単独の「新椿世」は避け「椿世町（新椿世地区）」と書く**。地図・住所検索に「新椿世」は載らず、地区外の読者が場所を特定できないため。

## 道路
- 当該一帯の路線は **市道椿世7号線／市道椿世9号線** など「市道椿世N号線」系。下水道関連工事の発注名で確認できる。
- 個別区間を「市道」と断定する前に、路線名まで押さえるか「市道」を明示せず書くのが安全。

## 公共下水道の工事（時系列）
- 令和7年度（FY2025）：椿世町で**下水管渠布設工事**。R7.3.21 予算決算委員会で上下水道部長が資料6を説明／R7.9 現況報告「田村町、椿世町、布気町地内等において管渠布設工事の契約を締結」。
- 令和7年度：椿世町地内（**市道椿世9号線ほか**）公共下水道事業に伴う**配水管移設工事** 本設φ20〜50mm L=285m（R7.3月 予算決算委員会提出資料）。
- 令和8年度（FY2026）：椿世町地内（**市道椿世7号線ほか**）公共下水道事業に伴う**配水管移設工事**。入札公告 2026-06-11／開札 7月10日／工期＝契約締結日から178日間。発注＝総務財政部財務課契約管財グループ。
  https://www.city.kameyama.mie.jp/shisei/2026061100013
- **令和8年度の管渠布設の入札公告に椿世町名の案件は無い**（布気処理分区その1／亀山東部処理分区ほかその2／本町南部処理分区ほかその1）。「今、椿世町で下水管渠を入れている」と現在形で書くのは要注意。
- 舗装の**本復旧は別契約**（「布設工事後の舗装復旧工事」として翌年度以降に発注）。仮舗装→本復旧の二段構えは市の標準運用。
