亀山市鳥獣被害防止計画（正式名称＝この通り）の現行期間は **令和8〜10年度（R8-R10）**。

- 市公式ページ（https://www.city.kameyama.mie.jp/docs/2023083100045/）は **2026-03-11 更新**で R8-R10計画を策定済みとして公開。R5-R7計画の記載はすでに差し替え済み。
- R8-R10 は令和8年度＝**2026年4月から施行中**。「これからR8-R10へ移行する時期」「次期計画R8-R10」という旧フレーミングは2026年春以降は**鮮度ズレ＝要修正**。発信物では「今春すでに動き出したR8-R10計画」と書く。

**Why:** 2026-06-23の獣害ブログ事実検証で、原稿が「R5-R7が現行・これからR8-R10へ移行」としていたが、実際は既にR8-R10が施行済みだった。鳥獣計画は議場でも触れる頻出テーマで、自市の最新計画段階の取り違えは議員として精度を欠く印象を与える。

**How to apply:** 獣害・サル・イノシシ・シカ・鳥獣被害の原稿で計画期間を引くときは、計画期間を西暦/令和の現在地で確認してから書く。次回更新（R11-R13策定見込み＝2029年頃）でこのメモも更新する。
