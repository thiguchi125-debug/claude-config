# 減塩・食環境づくり 他自治体事例（2026年9月時点で一次情報照合済み）

## 富津市（千葉県）
https://www.city.futtsu.lg.jp/0000007922.html
令和8年度第3弾：9/23〜10/27・税込537円・野菜約138g・食塩2.4g・525kcal・イオン富津店。基準は「健康ちば協力店」の野菜120g以上／食塩3.0g未満。常設化はしておらず各弾2週間〜1か月強の期間限定。
弁当の一品の元になった減塩レシピを市HP「おいしく！たのしく！ふっつ健活」（https://www.city.futtsu.lg.jp/0000007543.html ）でレシピ集＋**作り方動画**（市公式YouTubeプレイリスト・11本）として公開 ← 事実。
⚠️ コラボ弁当は**イオンリテール系統と株式会社ランドロームジャパン系統の2系統**あり、弾数が別勘定。「第3弾」はイオン系統。系統を書かずに弾数だけ書くと取り違える。

## 駒ヶ根市（長野県）
人口 30,911人（令和7年10月1日現在・市統計）＝「約3.1万人」でよい。
スマートミール弁当4種：さばの味噌煮弁当（食塩2.7g・野菜145g）／ソースチキンかつ丼（2.2g・140g）／甘辛鶏ごぼう弁当（2.3g・140g）／野菜たっぷり中華丼（1.8g・136g）。646〜647円。
チラシPDF https://www.city.komagane.nagano.jp/material/files/group/8/suma-tomi-rubenntoutirasi.pdf に「**ご注文は1週間前までに各店舗へ**」と明記。
⚠️ **落とし穴2つ**：①「常時4種」は誤り＝**1週間前までの予約制**。②「スマートミール認証に乗せて『健康づくり協力店』制度で束ねている」は**因果が逆**。協力店の登録要件は「主食・主菜・副菜のバランスメニュー」「地元産食材」等でスマートミール認証は要件に含まれない。実態は協力店のうちスーパー2店がスマートミール認証弁当を販売。

## 小田原市（神奈川県）
https://www.city.odawara.kanagawa.jp/field/welfare/health/brain/p34135.html
正式表記「野菜たっぷり　ひそかに減塩　弁当」（全角スペース入り）。キッチンのぞみの野菜たっぷり唐揚げ弁当を認定、**令和8年1月13日は「販売開始日」**（認定制度の開始日とは書かれていない）。
⚠️ **落とし穴2つ**：①野菜120g・食塩3.4gは**当該商品のスペック**であって「認定基準（以上／以下）」として市は書いていない。②「認定は1店舗1商品」は市サイト上は正しいが、**別枠でヤオマサ6店舗・小田原百貨店3店舗の期間限定シリーズ実績**あり（令和6年12月〜令和7年3月）。「小田原は1商品だけ」と書くと誤解。神奈川新聞は当該シリーズを「発売2週間で約3千食」と報道している。

## 東京都
https://www.metro.tokyo.lg.jp/information/press/2025/10/2025102908
「ちょっといい選択、お塩の量に注目！減塩応援キャンペーン」令和7年11月1日〜30日。協力3社**249店舗**（いなげや72・東武ストア25・マルエツ152）。
東武ストアは**店製弁当**のうち食塩相当量2.3g以下の商品に「**からだ気くばりメニュー**」シールを貼付＋ポップ広告。2.3gは東武ストア独自の設定で都の基準ではない。

## 効果測定の公表状況
4自治体とも**市／都の公式サイト上では**販売食数・リピート率・認知度を公表していない（各PDF・ページを全文確認）。
⚠️ 「どこも測っていない」「誰も公表していない」と裸で断定すると小田原の3千食報道で反証される。「**公式サイト上では公表していない**」と出典範囲を限定して書く。
