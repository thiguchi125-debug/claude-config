鈴鹿川流域の河川防災ステーションは **既に存在する**。

- 名称: 鈴鹿川防災ステーション（敷地内の建物が「鈴鹿市河川防災センター」）
- 所在: 三重県鈴鹿市庄野町981-1（鈴鹿川右岸堤防に隣接）
- 完成: 2003年
- 機能: 大規模洪水・地震時の現地防災活動拠点。ヘリポート・作業ヤードあり
- 出典: 鈴鹿市公式 https://www.city.suzuka.lg.jp/shisei/shisetsu/1004438/1004440.html ／ 国交省中部地方整備局 三重河川国道事務所 https://www.cbr.mlit.go.jp/mie/river/works/pof_his-suzukagawa.html

**Why:** 2026-08-11のニュースダイジェストで、国交省の河川防災ステーション新規登録（2箇所・全国156箇所）に対し「鈴鹿川流域に同種の拠点はなく」と書かれていた。議会でこの前提を口にすると執行部に即座に否定される。

**How to apply:** 河川防災ステーション／MIZBEステーション／水防資材備蓄拠点を扱うときは「亀山市内にはない」と書く（流域単位で「ない」と書かない）。亀山市は鈴鹿川の**源流域**（坂下・高畑山 標高773m）にあたる。
