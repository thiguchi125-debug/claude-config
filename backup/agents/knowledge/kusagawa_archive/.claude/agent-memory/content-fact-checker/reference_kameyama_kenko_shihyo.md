# 亀山市の健康指標 一次情報

## 特定健診受診率・計画の成果指標

正本＝**「分野別計画実績等報告書」の最新年度版**（計画本体ではない）
`https://www.city.kameyama.mie.jp/docs/2023080700057/` → `R7jisseki.pdf`（14MB超・curl → pdftotext -layout）

特定健診の受診率（％）：R3 37.3 →(実績) R5 29.7 → **R6 42.8** → **R7 42** ／ **目標R8 65**（担当課 市民課・国保被保険者）
- ⚠️ **R6の42.8%は確定した実績値であって「速報」ではない**。R7報告書が出た時点で最新値は42%に更新済み。1年前の値を最新のように書かない。
- 同表の他指標：がん検診 R6 胃25.0・肺26.9・大腸27.2／健都サポーター育成 R7 84人（目標200）／自殺死亡率 R7 12.2（目標9.8以下）。
- **この成果指標一覧に「食塩摂取量」の項目は無い**（＝計画の指標に据える提案は事実として成立する）。

## 平均自立期間（要介護2以上）

正本＝第2期国民健康保険保健事業実施計画（データヘルス計画）中間評価・令和3年3月
`https://www.city.kameyama.mie.jp/docs/2021052800033/file_contents/tyuukan.pdf`

令和元**年度**：亀山 男79.0・女83.5／三重県 男79.8・女83.8／全国 男79.6・女84.0（H28は亀山 男79.3・女84.1）。
市は健康寿命の独自値を公表しておらず、KDBのこの指標を評価指標に据えている旨が同PDFに明記。これ以降の公表値は見つからない。「令和元年時点」ではなく「令和元年度」。

## 亀山市健康まちづくり計画

`https://www.city.kameyama.mie.jp/shisei/2017041800030/` — 令和5年3月策定・**計画期間 令和5年度〜令和8年度**。本文PDF（kenkomachidukuri.pdf・73MB）は画像主体でテキスト抽出がほぼ効かないので、数値は上記の実績等報告書から取る。
⚠️ 「令和8年度＝次期計画の策定年」を明示した市の一次情報は未発見（R8当初予算の主要事業一覧にも策定事業なし）。教育民生委員会R8.1.30が「健康まちづくり計画の改定に合わせて提言内容を反映したい」と述べているのは**委員会側の意向**。断定するなら要照会（健康推進課 0595-84-3316）。
