# スマートミール（「健康な食事・食環境」認証制度） https://smartmeal.jp/

## 基準

- 「**ちゃんと**」＝450〜650kcal未満／野菜等（野菜・きのこ・海藻・いも）**140g以上**／食塩相当量 **3.0g未満**
- 「**しっかり**」＝650〜850kcal／食塩 3.5g未満
- 野菜140g以上は両区分共通。副菜という言い方より「野菜等」が原文。

## 「継続的な提供」要件（期間限定商品が引っかかる論点）

応募要項 https://smartmeal.jp/cn3/pg2177.html の原文：
> 継続的な提供とは，期間を定めた提供ではなく，営業時間には常に提供されていることを示します。

→ **期間限定販売の商品は認証対象外**。制度概要ページにも「継続的に……提供している店舗や事業所を認証する制度」と明記。

⚠️ ただし **第10回認証審査（2026年）から「準認証」が新設**され、提供形態が3区分に整理された：
- 本認証1＝営業日に毎日提供／本認証2＝予約販売での提供／**準認証＝月4回以上提供**（毎週1回等、提供日は自由設定可・事前の顧客周知が必要）

つまり「期間限定では乗らない」は正しいが、「**定期開催なら準認証で乗れる道がある**」という最新の緩和を落とすと、提案が一段浅くなる。

## 認証事業者数の読み違え（頻出）

- **総数（累計現存）と各回の認証数は別物**。総数は失効分を差し引くため第1〜10回の単純合計にならない旨がサイトに注記されている。
- 2026年8月時点の**認証事業者総数 527**（外食105・中食93・給食329）／**第10回単独は34**（外食11・中食10・給食13）。最新回は第10回（2026年6月28日審査）。
- 「第10回認証時点で527事業者」と書くと帰属誤り。「2026年8月時点の認証事業者総数527」が正。
