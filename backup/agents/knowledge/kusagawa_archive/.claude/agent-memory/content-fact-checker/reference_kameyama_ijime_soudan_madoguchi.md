亀山市いじめ防止基本方針（令和5年5月16日改正・PDF実体 .../2017092900017/file_contents/230516.pdf）
- 三重県いじめ防止基本方針の改訂＝令和5年3月／それを受けた市方針の見直し＝令和5年5月（両方とも原文で確認済）
- 「亀山市いじめ問題対策連絡協議会」＝法第14条第1項。構成＝三重県警察の警察官・三重県鈴鹿児童相談所職員・津地方法務局職員・教職員・市職員等
- 「亀山市いじめ問題調査委員会」＝法第14条第3項、教育委員会の附属機関。構成＝弁護士・学識経験者・心理や福祉の専門家等
- 再調査組織は別名称「亀山市いじめ再調査委員会」（市長が設置）

**帰属の分離（発信で混同しやすい）**: 子ども向け相談先＝教育委員会のページ／「こころの健康を保つために（自殺対策）」https://www.city.kameyama.mie.jp/docs/2025070900027/ ＝健康福祉部 健康推進課 健康増進グループ。後者にこども・若者向け窓口の記載は無い。自殺対策計画は「亀山市健康まちづくり計画」に一体化。
