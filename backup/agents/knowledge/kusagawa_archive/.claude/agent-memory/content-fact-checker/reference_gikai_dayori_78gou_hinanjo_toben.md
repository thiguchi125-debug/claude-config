「指定避難所を体育館としている理由（情報連携・物資・トイレ・ベッド・医師保健師の巡回・要配慮者対応・ペット対策を避難所運営組織で行ってもらうため）」および「指定避難所が体育館でないといけない法的な理由はない」という市答弁は、**かめやま市議会だより vol.78 = 令和2年9月定例会号（令和2年11月1日発行・広聴広報委員会編集）** に載っている。

- 一次ファイル: `~/.claude/agents/knowledge/kusagawa_archive/02_publications/leaflets/2026-05-04_shisei_市政報告レホ_ート__78gou.txt` の 1237-1246行付近（PDF原本は Creative Cloud の 市政報告レポート/78gou.pdf）
- **質問者は草川ではなく他議員（会派スクラム）**の一般質問。質問の趣旨は「最初の避難先として公民館やコミュニティセンターを活用できないか」。
- 会期は令和2年8月27日〜9月25日。**コロナ禍の「新しい生活様式」文脈**の質疑。

**Why:** ファイル名が「市政報告レポート78号」なので草川の発信物と誤読しやすいが、中身は議会だより（議会公式）で、しかも他議員の質疑ブロック。ここを草川の実績として引くと誤帰属事故になる（[[feedback-no-other-council-members-names]] 系）。

**How to apply:** この答弁を発信物で使うときは、①他議員名は載せない ②「草川が引き出した」と読める書き方をしない ③**必ず「令和2年9月定例会での答弁」と時点を明記**する。約6年前の答弁であり、その後 地域防災計画へのスフィア基準明記（R6）や、内閣府R8調査での市の記載「要支援者の避難所として自宅から近いコミュニティセンターを指定できるよう市の考えを整理し地域と連携」など方針が動いているため、現在の市の見解として提示すると事実誤認になる。
