亀山市保育所等利用案内の令和7年度版／令和8年度版を草川本人が直接突合済み（2026-08-25時点で確定）。育休退園ネタのファクトチェックはまずこれを基準にする。

## 変更点1: 3歳以上児クラスの扱いが反転
- 令和7年度版 事由9(2)「3歳以上の児童について、当該**地域に容易な受け入れ先がない場合**に、児童福祉の観点から当該施設・事業を引き続き利用することが適当と認められるもの」
- 令和8年度版 事由8 育児休業(利用継続の場合のみ)(2)「(1)に該当するもの以外の既に保育所等を継続利用している3歳以上児クラスの児童の保護者で、育児休業を取得（継続）するもの。ただし、福祉事務所長が保育の必要性がないと認める場合を除く」
- 要約は「容易な受け入れ先がない場合に限る → 原則そのまま継続」。**「容易な」を落として鉤括弧で引用しない**（原文の範囲が狭まる）。

## 変更点2: 期限の「原則」が変わった（新設ではない）
- 令和7年度版 本文⑥「在園児以外の子（第2子等）の産後12か月を超える育児休業中は、原則として保育所等の利用継続はできません」＝実質「下の子が満1歳になるまで」
- 令和8年度版 認定期間表「育児休業＝効力発生日から育児休業対象子どもが1歳になった日の翌日が属する年度の3月末日まで（最長）」
- **「年度末までの期限が新設された」は誤り**。令和7年度版にも3歳未満児クラスの例外としてのみ同じ期限の記載がある。正しい言い方は「原則が変わった」まで。

## 変更点3: 令和8年度版Q35（逐語）
「上の子が3歳以上児クラスの児童であり、下の子が1歳になる月の翌月以降も育児休業を取得することが就労証明書で確認できれば継続利用ができます。なお、この場合における認定期間は、当該年度の3月末日までとなります。」

## 残る課題（発信でセットにする）
1. 3歳未満児クラスは今も条件付き（育休取得の4か月前から在園＋「発達上、環境の変化が好ましくない」と認められる場合のみ）
2. 両親ともに育休は原則翌月から退園（Q34）。令和7年度版にあった「両親で育児を交代する場合」の例外は令和8年度版の原文から削除。**クラス限定か否かはQ34原文未確認**——3歳未満児クラスの話にくっつけて書くと限定に読めるので注意
3. 市外の園（広域利用）は育休で就労要件・送迎困難要件の両方を外れる

## 終期の計算規則と落とし穴
年度＝4/1〜翌3/31。終期＝「1歳になった日の**翌日**が属する年度の3月末日」。
- 5月生まれ: 満1歳の翌年5月 → 終期は**その次の年**の3月末（延長10〜11か月）
- 2月生まれ: 満1歳の翌年2月 → 終期は**その年**の3月末（延長約1.7か月）
- **延びる長さは生まれ月で変わる（1.7か月〜12か月）**。一律「◯か月延びる」と書かせない。
- 簡略表現「1歳になる年度の3月末」は**3月31日生まれのみ条文とズレる**（条文=翌年度末、簡略=当年度末で丸1年差）。短尺では許容だが、長文・チラシでは条文どおりに書く。
