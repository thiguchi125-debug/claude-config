## 新庁舎（✅一次情報で確定）
市公式「新庁舎整備」ページ原文：「『亀山市新庁舎整備基本計画（令和5年7月策定）』において、令和10年度に建設工事に着手し、**令和12年度に新庁舎の開庁を計画**していました。しかしながら、市の財政状況を踏まえ、大規模施設（ごみ処理施設、庁舎、学校等施設、し尿処理施設）の整備について検討した結果、新庁舎の整備スケジュールを**6年程度延伸**することとしました。」
→ **開庁＝令和18年度**。「令和12年度」は旧計画値であり、そのまま書くと誤り。
出典: https://www.city.kameyama.mie.jp/shisei/2014112308730/

## 次期ごみ処理施設（稼働年度✅／事業費⚠️未確認）
基本構想（案）ベース：新焼却施設 **48t/日**、新粗大ごみ破砕処理施設 13.4t/日、必要敷地 16,000㎡。工期 **2030年度〜2033年度**＝**令和15年度稼働**。事業方式は DBO が優位と評価。
概算整備費（**建設費のみ**）：ストーカ式1炉 148億2,000万円／ガス化溶融シャフト式1炉 133億1,000万円／既存建屋活用リニューアル 122億2,600万円、粗大ごみ処理施設 32億4,400万円。
→ 建設費の合計レンジは **約154.7〜180.6億円**。
⚠️ **よく使われる「271〜307億円」は一次情報で未確認**。運営費（DBO 20年程度）込みの総事業費と推定されるが、基本構想（案）本文PDFで内訳を確認するまで「総事業費271〜307億円」と断定して書かない。書くなら「建設費で約155〜181億円（基本構想案の概算整備費）」が安全。
出典: 建設通信新聞 https://www.kensetsunews.com/archives/1254741 ／市パブコメページ https://www.city.kameyama.mie.jp/docs/2026061900026

**How to apply:** 財政・大規模事業を語る原稿（一般質問・演説・市政報告）で年度と金額を書く前にここを見る。金額は建設費か総事業費かを必ず明示する。
