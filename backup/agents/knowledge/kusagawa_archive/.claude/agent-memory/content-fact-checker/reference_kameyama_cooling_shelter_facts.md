「図書館が市内シェルターで唯一21時まで＆週7日」は**誤り**。総合保健福祉センター（月〜日 8:30-21:00）とマックスバリュ（月〜日 7:00-23:00）が同等以上。
正しくは「公共施設で最も遅くまで、週7日開いている施設のひとつ」。
