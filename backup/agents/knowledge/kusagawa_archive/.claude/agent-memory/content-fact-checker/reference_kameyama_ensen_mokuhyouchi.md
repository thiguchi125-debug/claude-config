# 食塩・カルシウム目標値の帰属（亀山市の減塩ネタ共通）

## 目標値（取り違え多発ポイント）

| 主体 | 食塩の目標 | 出典 |
|---|---|---|
| 三重県（ヘルシーピープルみえ・21） | **1日7g** | 広報かめやま令和6年6月1日号 特集1「三重県の摂取目標値（１日）７g」 |
| 国 健康日本21（**第三次**） | **7g**（令和14年度） | 国立健康・栄養研究所 目標一覧 |
| 国 健康日本21（第二次・**旧**） | 8g | 同上 |

- ⚠️ **「国は8g未満」は第二次の旧目標**。第三次で7gに引き下げ済み。県7g／国7gなので「県は厳しく、国は緩い」という対比構図は成立しない。
- 三重県公式サイトの古い健康づくりページ（H25掲載・82603050514.htm）には「成人男性9.0g未満・成人女性7.5g未満」とあるが、これは旧計画。**現行の県目標として引くなら7g**。
- カルシウムの県摂取目標値は **600mg**（同・広報かめやま）。
- ⚠️ **健康日本21（第三次）に「カルシウム」の目標項目は存在しない**（告示 別表第一〜第四 全文検索0件）。カルシウムの目標を引くなら県計画など別出典を必ず明示する。
- 告示原本 https://www.mhlw.go.jp/content/001102474.pdf ／解説 https://www.mhlw.go.jp/content/10900000/001122156.pdf （「食事摂取基準の男7.5g未満・女6.5g未満を踏まえ7.0g未満とした」の原文あり）。第三次の野菜は350g（令和14年度）。
- 別表第三の**食環境イニシアチブ登録都道府県数**＝ベースライン **1都道府県（令和6年度）** → 47（令和14年度）。令和4年度の「0」は現状値であってベースラインではない。
- イニシアチブ参画事業者数は公式表記が「**2024年度は43事業者**」（オープンフォーラム2025レポート）。「令和6年度までに42事業者」は不一致。

## 亀山市食習慣調査（令和5年12月）の確定数値

正本＝広報かめやま令和6年6月1日号 特集1 PDF
`https://www.city.kameyama.mie.jp/kosodate_yuyu/news/2024052800027/file_contents/kouhou20240601_02_03.pdf`
（市の案内ページ＝ `/kosodate_yuyu/news/2024052800027/`。案内ページ本体に数値は無く、**PDFを pdftotext -layout で開かないと取れない**）

- 対象：40歳以上の市民 **545人**（男性172人・女性373人）
- 食塩摂取量平均：男性 **11.8g**／女性 **11.0g**
- 食塩の摂取源：**調味料・香辛料類 63%**（次いで魚介類・練り製品13%、野菜類8%、穀類6%、肉加工品3%、その他7%）
- カルシウム平均：男性575mg／女性638mg。**65歳以上はおおむね目標値600mgを達成、40〜50歳代は75%以上が目標未達**
- 野菜350g・果物200gも多くの年代で未達
- 調査時の担当は健康政策課健康づくりグループ（現在の所管は健康福祉部 健康推進課 健康増進グループ）
