就労継続支援（A型・B型）・就労移行支援の「在宅支援」を扱う原稿の裏取り先。全てPDFなので `curl -sL -o x.pdf <URL>` → `pdftotext -layout x.pdf -` で全文が取れる（WebFetchはバイナリで返る）。

**通知3本（一次情報）**
- 留意事項通知＝平成19年4月2日 障障発第0402001号「就労移行支援事業、就労継続支援事業（Ａ型、Ｂ型）における留意事項について」。在宅支援の算定要件ア〜キの本体。
- 令和7年3月31日 事務連絡「令和6年度障害福祉サービス等報酬改定等に関するQ&A VOL.8」問2。「原則として対面での支援を行うことが求められる」「緊急事態が発生した際には当該事業所の職員が速やかに利用者の元へ駆けつけ」はここが出典。
- 令和7年11月28日 障障発1128第1号「指定就労継続支援事業所の新規指定及び運営状況の把握・指導のためのガイドラインについて」 https://www.mhlw.go.jp/content/12200000/001602338.pdf ／ 別紙3(2)「サ 在宅支援の実態」・2(2)イ(ア)e「在宅支援の適切性」
- 令和8年4月13日 事務連絡「就労移行支援事業、就労継続支援事業（Ａ型、Ｂ型）における在宅支援の要件遵守の徹底について」 https://www.mhlw.go.jp/content/12201000/001694974.pdf ／ 記1〜5＋参考資料に上記3本の該当箇所を全部転載。令和9年度報酬改定での見直し検討を明記。

**取り違えやすい2点（実際に誤りが出た）**
1. 「速やかに駆けつけられる体制」は留意事項通知ウ（＝「緊急時の対応ができること。」だけ）ではなく **Q&A VOL.8** の文言。ア〜キの要件説明に混ぜると出典が崩れる。
2. 令和8年度改定の **所定単位数1000分の984（約1.6%減）は「令和8年6月1日以降に新規指定された事業所」限定**の応急的特例（令和9年度改定までの時限）。既存事業所は従前どおり。B型全体の減額と書くと誤り。出典＝令和8年2月18日 障害福祉サービス等報酬改定検討チーム「令和8年度障害福祉サービス等報酬改定における改定事項について」 https://www.mhlw.go.jp/content/001680064.pdf 2(3)。同PDF 2(2) に平均工賃月額の基本報酬区分基準3千円引上げ（令和8年6月施行）。

**権限の切り分け**: 在宅利用の支給決定＝市町村（亀山市）／事業所の指定・指導＝三重県（亀山市は中核市でないため県。県内で市が指定権者になるのは四日市市のみ）。R8.4.13事務連絡の宛先は都道府県・指定都市・中核市であり、市町村へは県経由の周知。
