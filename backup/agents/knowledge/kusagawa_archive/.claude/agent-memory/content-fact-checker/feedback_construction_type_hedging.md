道路が荒れている・掘り返されている件を発信するとき、**工事の種別（管渠布設／配水管移設／舗装復旧）を断定しない**。「公共下水道の整備に伴う工事」のように事業名で束ねて書く。

**Why:** 一つの下水道整備には〈①配水管（上水）の移設 → ②下水管渠の布設 → ③舗装本復旧〉と別契約・別年度の工程が並ぶ。現地の掘削を見ただけでは今どの工程かは判別できず、年度が変われば発注中の工種も入れ替わる。実例として椿世町は令和7年度＝管渠布設、令和8年度＝配水管移設で、「下水道の管渠を入れる工事が進んでいます」と現在形で書くと所管課に訂正されうる。議員発信での工種の言い間違いは行政データの誤伝達として効く。

**How to apply:** 工事中の道路・現場を扱うブログ/SNSで、工種名を書きたくなったら入札公告か予算決算委員会提出資料で当年度の発注案件名を確認する。確認できないときは「公共下水道の整備に伴う工事」「下水道の工事」まで丸めて書く。逆に路線名（市道〇〇号線）と所管課は具体化してよい——そちらは一次情報で固められる。
