原稿に「市内◯施設のうち〜なのはここだけ」「唯一」「最も長い」等の一意性・最上級表現があったら、**比較対象の全件表を一次情報から取得し、全行を機械的に突合してから**判定する。1件でも同条件があれば ❌ INCORRECT。

**Why:** 2026-07-27 図書館給水ブログで「市内11施設のシェルターのうち21時まで開き週7日開いているのはここだけ」を検証した際、亀山市公式の表を全行読んだところ総合保健福祉センター（月〜日 8:30-21:00）とマックスバリュ亀山みずほ台店（月〜日 7:00-23:00）が同等以上で、主張が誤りだった。しかも同じ主張が本文と提案パートの2か所に出ていた。最上級表現は論の柱になりやすく、崩れると記事全体の説得力を失う＝議員発信では信用問題に直結する。

**How to apply:**
- 数字1個の突合（「◯人」「◯円」）で終わらせず、最上級を含む文は必ず**表全体をスクレイプして全行比較**する。WebFetchの要約は表の一部を落とすので、curl＋HTML→テキスト整形で生の表を取り直す。
- 同じ主張が原稿内で複数箇所に反復していないか grep する（1か所直して残りが生き残る事故を防ぐ）。
- 修正案は「唯一」を消すだけでなく、事実として残せる形（例：「公共施設で最も遅くまで、週7日開いている施設のひとつ」）を提示する。
