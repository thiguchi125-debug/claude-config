鈴鹿川水系流域治水プロジェクト（国交省）の対象自治体に **亀山市は含まれる**。

- 対象3市: 亀山市 / 鈴鹿市 / 四日市市
- 位置図の副題: 「国内有数の産業集積地を守る流域治水対策」
- 亀山市の位置づけ: 液晶関連産業の集積地として明記（中流部=鈴鹿市の自動車関連、下流部=四日市市の石油化学コンビナートと並記）
- 出典: 国交省 流域治水プロジェクト位置図 https://www.mlit.go.jp/river/kasen/ryuiki_pro/pdf/85/85-13.pdf
- 別枠で「鈴鹿圏域二級水系 流域治水プロジェクト」も存在するので混同しない

**How to apply:** 流域治水を扱う発信で「亀山市も対象」と書いてよい。三重県の流域治水パネル展等は「各水系や各圏域毎に作成した流域治水プロジェクト」を紹介する建て付けで、鈴鹿川という河川名を県の告知本文が明示しているとは限らない。
