2026年8月23日、第53回全日本中学校陸上競技選手権大会（8/20-23・山口市 維新百年記念公園陸上競技場＝維新みらいふスタジアム）男子110mH（0.914m/9.14m）決勝で、櫻井楽都選手が13秒26（+0.9）で優勝。日本中学新記録かつ大会新記録。

**事故ポイント2つ**
1. **ふりがな**: 全中公式速報の氏名カナは `ｻｸﾗｲ ｶﾞｸﾄ`（＝さくらい **がくと**）。月刊陸上競技・伊勢新聞ともに本文にふりがなを一切載せていない。「さくらい らくと」はWebFetch要約モデルが妹「咲楽（さくら）」等から推測して作った読みで、一次情報の裏付けがない。ふりがなを書くなら「がくと」か、本人・家族に確認するまで**ふりがなを付けない**。
2. **所属**: 全中の登録所属は**KINGDOM AC（四日市の陸上クラブ）**。全中陸上は2025年から地域クラブでの出場が可能になり、クラブ出場者は学校からは出場できない。在籍校は亀山市立亀山中学校3年。伊勢新聞は「亀山市立亀山中学校3年」＋「四日市の陸上クラブ『KINGDOM AC』に所属」と併記している。発信で「亀山中学校3年の…が優勝」とだけ書くと学校代表と誤読されるので**併記**が正しい。
