北東地区まちづくり協議会（北東地区コミュニティセンター運営主体）の構成字名は **北町・北山町・東台町・渋倉町・椿世町** の5町（WebSearch経由・地区コミュニティセンター公式ページ系から2026-08-09確認）。JR亀山駅は椿世町に立地し、地区の中心的資産。世帯数549（R7.10.1市公式）。

**紛らわしい別概念に注意**: 亀山市資料で頻出する「**市北東部**」は地理的な広域表現で、**井田川地区・川崎地区**（人口増加中のニュータウンエリア）を指すことが多い（例: 都市マスタープラン「市北東部地域（井田川地区、川崎地区）では年少人口比率が高く…」）。行政区としての「北東地区」（北町等5町・亀山駅周辺）とは別物。district-issue-scoutやkameyama-researcherが「北東」でgrepする際は、ヒット文脈が5町側か井田川・川崎側かを都度判定すること。

**Why**: 2026-08-09、2026-09-12開催の北東地区市政報告会（初開催）向けテーマ発掘で、地区名だけでは地区コミュニティセンターの指定管理者(北東地区まちづくり協議会 会長 林明男)の記述からしか確定できなかった。地区の字名を事前に知らないと「北東」grepの大半が「市北東部（井田川・川崎）」の記述を誤って拾ってしまう。

**How to apply**: 北東地区（北町・北山町・東台町・渋倉町・椿世町）関連の調査では、地区名単体でなく5町名＋「亀山駅周辺」「北東地区コミュニティセンター」「北東地区まちづくり協議会」で複合grepするとヒット精度が上がる。上水道系統は新神辺配水池系（布気町・太岡寺町・阿野田町等と共通系統）。
