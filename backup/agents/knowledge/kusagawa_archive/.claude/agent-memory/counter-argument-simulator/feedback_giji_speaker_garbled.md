亀山市議会の自動反訳議事録txtでは、話者名「草川」が「佐川／酒匂／中芸／だから原因」等に化け、部長名・企業名（コストコ→コストFalse／鴻海→本配/本来精密工業）も誤変換される。

**Why:** 2025-12_R071210_一般質問会議録.txt で草川の質問ブロックが「佐川議員」「酒匂議員」表記になっていたが、内容（太陽光条例・AIサーバー・太岡寺コストコ・濁り水アンケート）は草川の既知の立場と完全一致。話者名で機械的に切り出すと本人発言を取りこぼす。

**How to apply:** 議事録から草川発言＋市答弁ペアを抽出する際、話者名のラベルではなく**発言内容のテーマ・立場**で本人を特定する。数字・固有名詞は自動反訳値を信用せず、議案書・現況報告・協定資料等の正規一次資料でクロスチェックしてから議場で使う。
