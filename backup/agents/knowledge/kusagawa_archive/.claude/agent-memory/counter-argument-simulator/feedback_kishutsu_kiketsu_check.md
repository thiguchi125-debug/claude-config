一般質問の想定答弁武装では、各核質問が（A）締結済み協定（B）可決済み議案（C）市の現況報告・施政方針・総合計画（D）過去本会議答弁——で既に決着・着手済みでないかを一次資料で照合してから再質問を設計する。

**Why:** 前任の自己レビューで漏れた観点。重複していると市に「それは○○で済んでいる」と一発で返され、貴重な45分の持ち時間が空転する。特に③-2産業用地は北村組JV官民連携協定（R7.10.22「産業関連施設＝物流を除く商工業等の開発」）と第3次総合計画（「AI・半導体等の次世代産業の集積促進」「新たな産業団地の確保」を既に明文化）で枠組みが先行しており、宣言型単問が「もう計画に書いてある／協定で対応可能」で潰される危険が最大。

**How to apply:** 照合先の定番一次資料パス＝総合計画 `_index/日常資料アーカイブ/01_政策素材/総合計画/`、現況報告・提案理由 `…/01_政策素材/市議会/<期>/`、議事録 `_index/議会資料アーカイブ/`、協定資料は委員会協議会資料。重複検出時は⚠️警告＋「では"その先"の未着手の核心は何か」を再設計（容量の公表有無・期限の明言・困窮減免の制度化など、計画の抽象宣言が触れていない実装レベルへ降ろす）。[[project-taikoji-r712-integou]]
