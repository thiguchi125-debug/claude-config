草川は2026年6月議会③-2で、太岡寺工区を半導体・AIサーバー等の次世代産業に活用する方向を後押しする。ただしR7.12（2025-12-10）一般質問で自ら主張した「商業地域指定は広域集客商業施設の立地という立法事実に支えられる／なし崩しの工場化は都市計画の整合性で問題」と矛盾しないよう、「なし崩しではなく正式な手続（用途地域変更等）を踏むなら」という縫合を必須とする。

**Why:** 自己矛盾は議場で最も突かれやすい。R7.12で草川は「公的投資（右折レーン）との整合がとれるものが来るべき」「次世代産業に限って認める質の担保」とも述べており、半導体=高付加価値次世代産業なら当時の立場と整合する。コストコも「太岡寺に限らず他適地も（菅内交差点・鈴鹿亀山道路IC周辺）」と主張済みで、太岡寺固執を捨てる立場とも一貫。

**How to apply:** ③-2の旗で「正式な手続を踏んだ上で」を必ず明示。市側の既決カウンター（北村組JV協定が産業利用枠組みを既に作った／総合計画に半導体集積を明記）に対しては「協定・計画は方向を書いただけで、太岡寺の用途地域は商業のまま＝正式手続未着手」「容量の把握・公表という実装は計画にない」を突破口にする。市長R7.12答弁「種がまかれた」をその続きの位置づけとして引用可。[[feedback-kishutsu-kiketsu-check]]
