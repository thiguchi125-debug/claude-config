`check_subtitle_band.py`（字幕セーフ帯 y1240-1460 の機械判定）は **帯に本当に要素が無くてもFAILする**ことがある。原因は2つで、どちらも実装側で先に潰せる。

**Why:** 2026-09-02 かめやま健康弁当の挿入画像5枚で、1枚目が 39.93% → 8.05% → 0.00% と3回レンダし直しになった。原因の切り分けに時間を取られた。判定ロジックを知っていれば初回から通る。

**判定ロジック（読まないと誤解する）**
- 背景色 = 画像を108×192に縮小したときの**最頻色**。ページ背景ではなく、面積の大きい**白カード**が最頻色になることがある。
- 帯内の各画素が、その最頻色から L1距離（RGB差の合計）> 60 なら「前景」。1.5%超でFAIL。

**How to apply（新規制作で最初から守る）**
1. **ページ背景をフラットにする**。上下に効く多ストップグラデをページ全体に敷くと、白カードが最頻色に取られた瞬間に帯の背景色が L1>60 に届いてFAILする。実測：ページ背景 #e9efd8 付近 vs カード白 (255,253,246) は L1=63 で**アウト**。
   - 安全策＝ページ背景は単色 `#f4f1e6`。質感（グレイン・グロー）は **y0-1180 と y1462-1920 の2枚のrectに分けて**乗せ、帯は素の単色のままにする。カード白との L1 は約39で余裕を持って通る。
2. **帯直上の要素の box-shadow を勘定に入れる**。`box-shadow:0 14px 30px` は要素下端から**約44px**下まで濃く落ちる。帯の上に置くカードは
   **カード下端 ≤ 1240 −（shadow の y offset + blur）** に収める。これを忘れて y1230 にカード下端を置き、影が y1240-1274 を汚してFAILした。
3. **固定高のカードに `overflow:hidden` を付ける**。中身が伸びると子要素が帯まで滑り落ちてFAILする（a4 で「店頭販売は数量限定」チップが帯に落ちた）。ただし overflow:hidden は**FAILを隠すのではなく見切れに変える**だけなので、行の高さを実測で合わせるのが本筋。見切れは機械判定では捕まらない＝必ず自分でPNGをReadして確認する。
