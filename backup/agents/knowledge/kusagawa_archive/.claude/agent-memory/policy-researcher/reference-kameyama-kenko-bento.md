## 亀山市「かめやま健康弁当」（一次情報＝市公式）
- 市公式ページ: https://www.city.kameyama.mie.jp/docs/2026012900020/（2026-09-02取得）
- 第2弾「健やか七彩（なないろ）弁当」: 販売 令和8年8月31日(月)〜11月29日(日)／スーパーサンシ亀山エコー店＋会員向け宅配／680円(税込735円)／**食塩相当量2.8g・カルシウム389mg**
- 第1弾: 市公式ページに記載なし。伊勢新聞(2026-08-26)が「今年3月に期間限定販売」と報道（新聞のみ＝裏取り未了）
- 献立の作り手: 市食生活改善推進協議会／健都サポーター／一般社団法人セルフケアフード協議会／市 の4者で作成した「かめやま健康レシピ」を参考
- **担当課: 健康推進課 健康増進グループ**
- 論点: 第1弾も第2弾も**期間限定**。常設化・レシピ公開・栄養表示の常設が議会論点になる

## 比較に使える自治体（人口規模が近い順）
- **富津市（千葉・39,414人/令和8年3月住基）**: R6年度から「野菜120g以上・食塩3.0g未満」（健康ちば協力店基準）でランドローム／イオンとコラボ弁当。**各弾15日間×年3回**の反復型。https://www.city.futtsu.lg.jp/0000007922.html
- **駒ヶ根市（長野・約3.1万）**: **スマートミール認証弁当**を健康づくり協力店（市内スーパー）で常設販売。4種・646〜647円税込・食塩1.8〜2.7g・野菜136〜145g（R7.7.1現在）。要1週間前注文。https://www.city.komagane.nagano.jp/soshikiichiran/chiikihokenka/kenkochojukakari/1/2/10532.html
- **小田原市（神奈川）**: 「野菜たっぷり ひそかに減塩 弁当」認定＝野菜120g以上・食塩3.4g以下。R8.1.13販売開始だが**認定は1店舗1商品のみ**（横展開の難しさの実例）
