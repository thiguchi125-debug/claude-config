子どもの居場所・子育て支援テーマの原稿を検証するときの一次情報束（2026-08-25 突合）。

## 亀山子育て支援センター「あいあいっこ」
出典: https://www.city.kameyama.mie.jp/docs/2018031300011/hoiku.html
- 所在「亀山市羽若町545番地 総合保健福祉センター2階」
- 対象の市公式表記は「就学前のお子さんと保護者」（"0歳から" は市の明記ではない）
- 開設「月～土 9時～12時、13時30分~16時」／「日曜日、祝日、年末年始は休館日です。」
- **土曜も開設している**ため「土曜のきょうだい同伴枠」提案は運用上成立する

## 子育て支援センターは市内5か所（同ページ「子育て支援センター(5カ所）」）
あいあいっこ（総合保健福祉センター2階）／あすれっこ（関認定こども園アスレ内）／のんの（野登ルンビニ園内）／コスモス倶楽部（亀山愛児園内）／なぎの木（川崎愛児園内）。
→ **保育所・認定こども園内は4か所**（あすれっこを落として3か所と数える誤りが出やすい）

## 亀山児童センター
出典: https://www.city.kameyama.mie.jp/docs/2022072000021/
- 「0歳から18歳未満の子ども」／「〒519-0124 亀山市東御幸町69番地5（文化会館隣）」
- 「午前10時から午後6時」／休館「月曜日、祝日、年末年始(12月29日から1月3日）」
- 「就学前の乳幼児は保護者の同伴が必要です。」
- 市の子育て・福祉施設一覧で**児童館・児童センターに該当するのは1施設のみ**
  （https://www.city.kameyama.mie.jp/shisetsu/2014121800232/fukushi.html）

## 旧図書館への移転（年度の言い方に注意）
- 令和8年度施政及び予算編成方針: 「移転先となる旧図書館における**令和9年度での施設整備**に向け、機能強化のための検討を進めます」
  https://www.city.kameyama.mie.jp/gikai/katsudo/2026021700109/
- 令和7年9月定例会 現況報告: 「旧図書館への移転の方針を決定している亀山児童センター」
- **令和9年度＝整備の年度。移転完了年度・開館年度としては未公表**（[[feedback-koushinbi-is-not-start-date]] と同型の合成エラーに注意）

## 地域子育て支援拠点事業（所管と類型）
出典: こども家庭庁成育局長通知 こ成環第113号 令和6年3月30日（第一次改正 こ成環第204号 令和6年6月28日）、令和6年4月1日適用
https://www.cfa.go.jp/policies/kosodateshien/shien-kyoten
- **所管はこども家庭庁**。旧「平成26年5月29日付け雇児発0529第18号 雇用均等・児童家庭局長通知」は廃止 → 「厚生労働省の制度」と書くと古い
- 類型は**一般型・連携型の2つだけ**。「児童館型」は現行要綱に存在しない（旧ひろば型／センター型／児童館型の名残）
- 連携型: 実施場所に「児童館・児童センターにおける既設の遊戯室、相談室等」と明記。週3日以上・1日3時間以上、専任1名以上
  → 亀山児童センター（月曜休館・10-18時）は連携型の要件を満たしうる

## 亀山市に「明日」という地区名は存在しない
まちづくり協議会別町名一覧（https://www.suzukakameyama-kouiki.jp/insurance/file/houkatsu_kameyama_town_list.pdf）と
地区コミュニティセンター一覧（https://www.city.kameyama.mie.jp/shisetsu/2014121800270/shiminchiiki.html）のいずれにも無い。
実在するのは 関／井田川（南・北）／加太／坂下／白川／昼生／野登／神辺／川崎 等。

## 放課後子ども教室
令和6年4月時点で**市内全ての小学校区で実施**（亀山市教育委員会 青少年健全育成）。
「地区に居場所が無い」と書くと事実と衝突するので、対象が小学生限定である点で切ること。
