## 📜 スクリプト1: 在宅対面用(30〜45秒)

### 完成原稿(共通版・約200字)

```
【ピンポン後、ドア開く → 一歩下がる → 視線は相手の目元】
【お辞儀30度・明るく落ち着いた声で】

「お忙しいところ、突然お邪魔して申し訳ございません。」

【一拍・間】

「亀山市議会議員の、草川たくやと申します。」

【両手で名刺・チラシを差し出す】

「今日は、市政のご報告と、皆さんが日頃感じておられる
ことを直接お聞きしたくて、地区を回らせていただいて
います。」

【相手の表情を見る・嫌そうなら早めに切り上げる】

「お時間あれば一点だけ──最近、暮らしの中で『ここが
気になる』とか『困っている』ということ、何かござい
ますか?」

【話し始めたら最後まで遮らない・メモ取り】
【話さなければ、すぐ次へ】

「もしよろしければ、後援会のご案内もお持ちしました
ので、後ほど目を通していただけたら嬉しいです。」

【再度お辞儀30度】

「貴重なお時間、本当にありがとうございました。」

【一歩下がってからもう一度軽く会釈・退去】
```

**声のトーン**: 地声より半音低め・語尾を上げない・笑顔は控えめで誠実に
**目線**: 相手の眉間〜口元(じっと見つめない)
**距離**: 玄関ドアから一歩半下がる(相手の安全圏を侵さない)
**滞在時間**: 粘らない。45秒で去る人ほど次回会ってくれる

### 想定問答3パターン

**A: 「忙しい・帰って」**
> 「失礼いたしました。お引き止めしてしまい申し訳ございません。チラシだけ置かせていただきますので、お時間あるときにご覧ください。失礼いたします。」
> → 深くお辞儀して即退去。**絶対に粘らない**

**B: 「政策どう思ってるの／何やってる議員なの」**
> 「ありがとうございます。私は子育て・教育・地域交通を中心に取り組んでおります。最近では小学校の体育着替え環境や、関西本線の利便性向上を議会で取り上げました。詳しくはこのチラシと、よろしければ公式LINEで活動をお伝えしていますので、ご覧いただけたら嬉しいです。」
> → 30秒以内・売り込まない

**C: 「もう支持してる候補がいる」**
> 「そうでしたか、教えていただきありがとうございます。それでもご縁ですので、暮らしの中で気になることがあれば、誰の支持者かに関係なく、私は市民の皆さんの声を議会に届ける立場ですので、いつでもお聞かせください。失礼いたします。」
> → **絶対に張り合わない・否定しない・温かく退く**

```
┌─────────────────────────────────┐
│                                 │
│  本日、ご挨拶にお伺いしました    │

│                                 │
│  お留守のようでしたので、       │

│  ポストに失礼いたします。       │

│  ご意見・ご相談など、           │
│  何かございましたら             │
│  下記までお気軽にお寄せください。│
│                                 │
│  またお伺いさせていただきます。 │
│                                 │
│  ─────────────                 │
│  📱 公式LINE:                   │
│      [QRコード]                 │
│  ✉️ ご意見フォーム(匿名OK):     │
│      forms.gle/VHfPR93VPCSnNorAA│
│  ☎️ 後援会事務所:               │
│      0595-XX-XXXX               │
│                                 │
│  皆さんの声、お聞かせください。 │
│                                 │
│         草川たくや              │
│                                 │
└─────────────────────────────────┘
```

**用紙**: A6(105×148mm)
**用途**: チラシと一緒にクリアファイル等で玄関ノブに挟む or ポスト投函
**両面印刷**: 表=このメモ／裏=政治活動報告(市政の取り組み3点)
**QRコード**: 2cm角以上・LINEとフォーム両方を併記推奨

### 連絡先動線(3チャネル)

| チャネル | 用途 | 設計ポイント |
|---------|------|--------------|
| **公式LINE(QR)** | 継続接点・最重要動線 | QR読み取り→友だち追加→自動応答で「ご相談はこちら」フォーム誘導 |
| **匿名フォーム** | 言いにくい意見・相談 | URL直打ちが負担、QRコード併記推奨 |
| **電話(後援会事務所)** | 高齢層・急ぎの相談 | 留守電必須・営業時間明記(平日9-18時) |

## ✅ 公選法NG表現チェックリスト(訪問者必携・ラミネート推奨)

### 🚫 絶対に口にしてはいけない表現

| NG表現 | 理由 | 代替表現 |
|--------|------|---------|
| 「投票してください」 | 138条戸別訪問禁止に直撃 | 「ご意見をお聞かせください」 |
| 「○月○日の選挙、よろしく」 | 投票依頼明示 | 「市政について伺いに参りました」 |
| 「私に一票を」 | 投票依頼 | 「市政報告にお伺いしました」 |
| 「当選させてください」 | 投票依頼 | 「議会で取り組ませていただいています」 |
| 「票をお願いします」 | 投票依頼 | (言わない・代替なし) |
| 「○○候補に勝ちたい」 | 他候補比較 | (他候補に一切触れない) |
| 「次の選挙では」 | 選挙運動認定リスク | 「これからも」「引き続き」 |
| 「○○党をよろしく」 | 投票依頼 | 「市政の課題に取り組んでいます」 |

### 🚫 配布物のNG

- 選挙運動用ビラ(告示後限定)を告示前に配布
- 投票日が記載されたビラを政治活動期間に配布
- 「必勝」「必ず勝つ」等の表現

### ✅ OK表現リスト(迷ったらこれ)

- 「市政のご報告にお伺いしました」
- 「皆さんのご意見を直接伺いに来ました」
- 「議会で取り組んでいることをお伝えしたくて」
- 「後援会のご案内をお持ちしました」(後援会入会勧誘は政治活動として合法)
- 「お困りごとがあればお聞かせください」

### 🔍 訪問前1分セルフチェック(玄関前で唱える3問)

1. これから話す内容に「投票」「選挙」「票」「当選」が含まれていないか?
2. 配布物は「政治活動用」と明記された後援会パンフ・市政報告チラシのみか?
3. 滞在時間は2分以内、相手が嫌がったら即退去できる準備があるか?

## 🎯 運用Tips

- **天候配慮**: 雨「お足元の悪い中失礼します」を冒頭追加／猛暑日は短縮版(25秒)に切替
- **時間帯**: 平日は18:00-19:30が最も在宅率高い／土日は10:00-11:30 / 14:00-17:00推奨／朝早すぎ/夜遅すぎは厳禁
- **同じ家への再訪**: 1軒2回まで、3回目以降はビラ投函で完了扱い
- **クレーム対応**: 議論しない・即謝罪・退去・後日電話謝罪・記録を残す
- **服装**: スーツ濃紺、白シャツ、緑のネクタイ(草川ブランドカラー)、日傘OK、汗対策必須
- **携行品**: 名刺、チラシ、A6メモ(束)、クリアファイル、ペン、訪問記録ノート、LINE QRシール、水分、塩飴
