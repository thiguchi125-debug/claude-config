2026-08-26に時事通信・毎日新聞が報じた「環境省が太陽光パネル本体（従来型シリコン）の購入費補助を廃止、ペロブスカイトに重点」の検証済み事実。

**検証済みの数値**
- ペロブスカイト太陽電池の社会実装モデルの創出に向けた導入支援事業（環境省・経産省・国交省の連携事業、脱炭素成長型経済構造移行推進対策費補助金）
  - 令和8年度(2026)当初予算 **7,000百万円＝70億円**（前年度5,020百万円）
  - 出典: 環境省エネ特ポータル https://www.env.go.jp/earth/earth/ondanka/enetoku/2026/
  - → 報道の「27年度概算要求280億円＝26年度予算の4倍」は **70億×4=280億で正確に整合**
- ストレージパリティの達成に向けた太陽光発電設備等の価格低減促進事業（民間企業等による再エネの導入及び地域共生加速化事業の一部）令和8年度 3,200百万円＝32億円

**一次情報の所在**
- 資源エネルギー庁「ペロブスカイト太陽電池の導入促進について」(2026年4月) https://www.enecho.meti.go.jp/category/saving_and_new/saiene/community/dl/10_11.pdf
  - 原文「建物の壁面や、耐荷重性の低い屋根など、これまで導入が困難であった場所にも導入可能となる次世代型太陽光電池」／「2040年には約20GW導入を目指す」
  - ※403を返すので `curl -A "Mozilla/5.0"` でDL→`pdftotext -layout` で抽出する
- 環境省報道発表 https://www.env.go.jp/press/index.html ／ 予算ページ https://www.env.go.jp/guide/budget/index.html

**重要な留保（2026-08-27時点）**
- 環境省は8/26に報道発表を出していない（報道発表一覧の最新は8/25）。令和9年度概算要求も予算ページ未掲載。**＝報道（取材）先行で、一次資料は未公表**。発信では「報道によれば」「概算要求段階」を必ず明示する。
- 報道は廃止対象の補助事業の**正式名称を挙げていない**。毎日は「自治体や企業向け」と書くのみで、単一事業ではない可能性が高い。原稿で特定の事業名を断定しないこと。

**Why:** 議員発信で「280億円」「4倍」を裏取りなしに引くと桁・基準年度の誤りが出やすく、また未公表の概算要求を既定路線として書くと誤伝達になるため。
**How to apply:** 太陽光・再エネ・ペロブスカイト関連の発信をチェックするとき、この数値と留保をベースラインに使う。令和9年度概算要求が公表されたら本メモを更新する。
