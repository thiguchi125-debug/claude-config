亀山市の就学前施設の給食・定員は、原稿で最も取り違えが起きる4点がある。発信物にこのテーマが出たら必ず本メモと照合する。

## 1. 公立幼稚園に給食はない（4園すべて）
- 一次情報A: 就学前教育・保育施設の再編方針（中間案）＝令和2年10月19日開催 教育民生委員会協議会資料。亀山・亀山東・井田川・みずほ台の4園すべてに「園庭面積には十分な余裕があるものの、**給食室が無いため**、保育機能を持った増築をするためには課題が多い」
  - ローカル: `~/.claude/agents/knowledge/kusagawa_archive/05_resources/就学前教育・保育施設の再編方針（中間案）.txt` 647-659行
- 一次情報B: 令和5年9月定例会 市答弁「幼稚園の給食につきましては、法律やガイドラインは定められていないことや**現段階で各園に給食設備が備わっていない**ことから、本市の公立幼稚園におきましては園児が家庭から弁当を持参している」
  - ローカル: `~/.claude/agents/knowledge/kusagawa_archive/01_council/2023-09_R0509_本会議議事録_kusagawa.txt` 725行付近
- 読者に効くのは「給食室がない」より「**給食がなく弁当持参**」。

## 2. 公立保育所の「ご飯持参」は一部の園ではなく、ほぼ全園
よくある誤り＝「白米を持参している園があります」。実態は範囲がはるかに広い。
- 令和5年6月定例会 市答弁「現在、市内公立保育所におきまして、**金曜日以外、3歳以上の園児**が各家庭より昼食用の米飯を持参している」（`R0506kaigiroku_kusagawa_only.txt` 483行）
- 令和5年9月定例会 市答弁「関認定こども園アスレ及び同施設から給食を搬入している加太保育園につきましては…園において主食を提供しております。**ほかの市内公立保育所につきましては**、提供食数が少ない等の理由で米飯を購入できる業者が現在のところ見つかっておりません」
- 理由も「給食室が狭い」ではなく、答弁は①盛りつけスペース②米飯用食器の消毒機器の設置スペース③人員 ④購入できる業者が見つからない。
- **最新の一次情報が令和5年（2023年）で止まっている**。現在形で書くなら「令和5年の市の答弁による」と時点を必ず付す。

## 3. 認定こども園化時の給食提供は市が既に答弁済み（未対応として書くと誤り）
令和5年9月定例会 市答弁「今後、就学前教育、保育施設の再編による施設の集約化において**認定こども園化を図る際には、給食の提供も行ってまいりたい**と考えております」。
→ 「給食も一緒に整えるべき」と要求形で書くと既決事項の見落としになる。正しい構図は「答弁済みの約束を工程に落とし込ませる」。

## 4. 幼稚園定員380人は令和4年の値（現在値ではない）
- 令和4年12月定例会 市答弁「12月1日現在、380人定員のところ181名在籍、47.6％」「令和5年度4月の予定人数は380人定員のところ156名、41.1％」
- 令和8年3月見直しの再編方針では、幼稚園の確保の内容（受け入れ枠）は令和8年度245人・令和9年度195人・令和10年度195人・令和11年度130人。
- **時点を書かずに「定員380人」と引くと現在値と誤読される**。

**Why:** 2026-08-26 夕便SNS原稿で、2の範囲過小記述（「園があります」）と3の既決見落としが同時に発生した。どちらも草川自身の過去ブログを孫引きすると再発する。
**How to apply:** 給食・定員の数字は草川ブログや research_summary からでなく、上記の議事録行番号と再編方針PDFから直接引く。
