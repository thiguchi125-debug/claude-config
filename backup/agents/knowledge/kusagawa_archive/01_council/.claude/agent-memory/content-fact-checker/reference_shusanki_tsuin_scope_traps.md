周産期・妊婦の通院支援ネタは、事実そのものより **スコープ（範囲）の欠落** で事故る。頻出4型。

1. **全国データを亀山の話に見せてしまう**
   「産婦人科医は20年で+10.3%増／分娩取扱施設は-39.8%（H17→R5）」は**全国**の数字。
   台本で「医師の数は、増えているんです」とだけ言うと視聴者は亀山・三重の話と読む。必ず「全国では」を頭に置く。
   なお H17→R5 は **18年**。「この20年で」と丸めるなら「20年ほどで」まで緩めるか「2005年からの18年で」と正確に言う。

2. **「16回すべて市外」型の言い過ぎ**
   妊婦健診は国基準14回程度＋産婦健診2回以内＝最大16回。ただし**妊娠中の健診の一部は市内でも受けられる**。
   市内に無いのは**分娩**。「妊婦さんは市外へ通います」は過度一般化 →「お産のときは、市外の病院へ」に限定する。

3. **「自分持ち」型の言い過ぎ**
   確定しているのは「**妊娠中の通院交通費を対象とした市の制度が現時点でない**」ことだけ。
   「交通費は自分持ち」は国・県・保険を含む全支援の不在を含意する →「通う交通費を支える**市の制度**は、ありません」。

4. **「人口がほぼ同じ」**
   つくばみらい市 53,766 / 亀山 48,822 は約10%差、しかも人口動態が逆方向（TX沿線で増／亀山は減）。
   「ほぼ同じ」と言うと比較の妥当性ごと突かれる →「人口5万人規模の、茨城県つくばみらい市」。

**Why:** 2026-09-03 のショート動画台本 v1 で1〜4が同時に出た。いずれも元データは正しく、範囲の書き落としだけで誤情報になる型。

**How to apply:** 周産期・医療・通院支援の原稿では、数値そのものより「その数字はどこの・いつの・何の数字か」を1件ずつ当てる。
分娩施設が無いという一次情報は令和8年度施政及び予算編成方針の「市内に分娩可能な産科医療機関が無い状況」。
引用を短縮するときも「**市内に**」は絶対に落とさない（落とすと全国の話に読める）。
