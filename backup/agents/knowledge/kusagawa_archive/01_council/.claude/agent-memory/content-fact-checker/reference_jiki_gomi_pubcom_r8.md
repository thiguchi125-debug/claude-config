**表記の正本（発信物で誤りやすい）**
- 構想の位置づけの公式表現＝「本構想は、次期施設整備の方向性を示す段階として、**処理システム・事業方式**の成立性評価を中心に整理」（意見32番回答）。「処理方式や事業手法」は文書の用語ではない
- 次段階の計画名は「**施設整備基本計画**」と「**一般廃棄物処理基本計画**」の2本立て
- 「施設整備基本計画において検討します」「一般廃棄物処理基本計画等でお示しします」は**逐語では存在しない**。鉤括弧で引くと合成引用になる（[[feedback-verbatim-check-for-official-answers]]）

**論点の所在（意見番号）**
- 5番＝ごみ有料化。回答は「総合的に検討を進め、市民の皆様に説明してまいります」で、**基本計画への送りではない**
- 12番＝プラ分別（一般廃棄物処理基本計画等でお示し）／14番＝持込の手軽さ（基本計画への言及なし）
- 12・15・24番＝「基本計画に委ねず基本構想の段階で整理すべき」型の指摘（3件）
- 38番＝道野地区・搬入口前交差点。**本旨は他地区への移転要望**で、道路安全はその理由として書かれている。市回答は課題（視認性・通学路の歩道未整備・大型車と一般車の混雑）を「ご意見のとおり」と明記
