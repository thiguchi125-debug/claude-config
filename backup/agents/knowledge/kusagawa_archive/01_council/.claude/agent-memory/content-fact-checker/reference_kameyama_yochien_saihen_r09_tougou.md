## 確定している一次情報（出典の原文どおり）

**就学前教育・保育施設の再編方針**（令和3年2月策定／第1回見直し 令和6年1月／第2回見直し 令和8年3月）
https://www.city.kameyama.mie.jp/docs/2021120600091/ → PDF `file_contents/file_20263301161952_1.pdf`
- 対象施設「公立幼稚園（4園）亀山幼稚園、亀山東幼稚園、井田川幼稚園、みずほ台幼稚園」＝**令和8年3月時点でも4園**
- 「令和6年度において、令和9年度の両園の統合に向け、令和8年度からの園児募集を停止することとした。また、**令和7年度に統合後の園舎は、井田川幼稚園を活用する方向性を決定した**」
- 3号認定（0〜2歳）の確保の内容−必要利用数の見込み＝令和8年度 △54人／令和9年度 △71人／令和10年度 △66人／令和11年度 +70人。「3号認定は必要利用数の見込みに対し、確保の内容が不足する状況」
- **亀山幼稚園も「園児募集停止」が短期的視点に位置づけられているが、年度は書かれていない**（短期／中長期の分類のみで年次表なし）。時期を書くと未確定情報の断定になる。

**令和7年9月18日開催 教育民生委員会資料「井田川幼稚園とみずほ台幼稚園との統合後の園舎について」**
ローカル `~/.claude/agents/knowledge/kusagawa_archive/01_council/R7.9月 教育民生委員会提出資料.txt` 110-160行
- 園児数（各年5月1日時点）亀山 56→22／亀山東 55→36／井田川 70→31／みずほ台 42→10／計 223→99（R2→R7）
- 「全体の園児数を令和2年度と令和7年度で比較すると約55％減少している」
- 募集停止の対象は**みずほ台幼稚園のみ**（井田川ではない）。原文は「みずほ台幼稚園の令和8年度からの園児募集を停止することとした」
- 園舎は「④将来性を重視し…井田川幼稚園を統合後の園舎とする」

## 取り違えポイント
- 「令和8年度から募集停止」は**令和8年度の入園分から**の意。現在形で書くと令和9年度も募集しないことが読者に伝わらない。
- 園舎は議決事項ではない。方針PDFは「方向性を決定した」、委員会は資料提示。「決まった」と書くより「決定され、令和7年9月の教育民生委員会に示された」が正確。
- 令和4年12月の草川提案は**みずほ台に一本化し井田川園舎を保育園に転用**する案で、市の決定（井田川を園舎に）とは方向が逆。並置して「あれから決まった」と書くと自己功績の過大帰属になる。
- 統合検討の根拠は令和3年2月策定の再編方針で、草川の質問（令和4年12月）より前から存在。市答弁自身がこれを引用している。
