## 数値（案内PDF）
- 対象：亀山市に住民登録があり産後1年以内の産婦（流産・死産含む）
- 自己負担額（1回当たり）：宿泊型 5回目まで500円／6回目以降3,000円、通所型 5回目までなし／6回目以降2,000円、訪問型 5回目までなし／6回目以降600円。市民税非課税・生活保護世帯は自己負担なし
- 利用回数：3類型合わせて最大7回以内（多胎は子の数×7回、8回目以降は訪問型のみ）
- 担当：子ども未来部 子ども総合支援課 母子保健グループ 0595-98-5003

## 発信で踏みやすい3つの罠
1. **「預かってもらう」と書かない**。市は「託児サービスを目的とするものではありません」「預かり保育や家事支援を目的としたサービスではありません」と明記。
2. **実施施設は全て市外**（鈴鹿市・四日市市・津市の医療機関・助産所）。亀山市内に実施施設はなく、市内に分娩可能な産科医療機関も無い（施政方針に明記）。「市内で泊まれる」と読ませない。
3. **「5回まで無料」は令和7年6月答弁時点の訪問型の話**。R8は宿泊型が5回目まで500円なので、現在形で「5回まで無料」と書くと誤り。

## 国の補助率
令和7年度から地域子ども・子育て支援事業に位置づけられ、補助率は国1/2・都道府県1/4・市町村1/4（R6以前は国1/2・市町村1/2）。出典＝こども家庭庁「令和7年度母子保健対策関係予算・令和6年度補正予算の概要」（第5回こども家庭審議会成育医療等分科会 資料1-7・2025-03-12）p.7。
**国の補助率は1/2で据え置き**。市負担が半減したのは都道府県負担1/4が新設されたため。「国が補助率を引き上げた」という因果は不正確。
