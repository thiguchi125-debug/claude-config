市側答弁の数字を発信物に引くとき、**答弁に付いている限定句を1語も落とさない**。落とすと統計の母集団が黙って広がり、事実として誤りになる。

実例（2026-08-27 太陽光条例X原稿）:
- **公式会議録の逐語**（R8.6.11 第2日・発言No.132 産業環境部長 佐藤康二君）:
  「亀山市農業委員会に提出される**おおむね５０キロワット程度の太陽光発電を目的とした**農地転用許可手続が、従前は毎月数件程度ございましたものが、１月以降は１件から２件程度に減少いたしたところでございます」
- 原稿: 「農業委員会への農地転用許可手続は、従前の毎月数件から1〜2件程度に減少しました」
- → 「おおむね50kW程度の」と「**太陽光発電を目的とした**」の**2つの限定句**を落としたため、「亀山市の農地転用許可手続**全体**が毎月数件→1〜2件に激減した」と読める。実際は50kW級の太陽光目的案件に限った数字。市の農地転用全体の統計としては明確な誤り（参考: 他議員発言では農地転用は平成28〜令和6年度の9年間で742件）。

あわせて守ること:
1. **出所を文中に残す**: 「市の答弁によれば」を付ける。特に手元資料がAI反訳しかなく公式会議録が未公開の場合は必須。
2. **期間の単位を落とさない**: 「毎月数件→1〜2件程度」の後段が月次なのか累計なのか答弁が曖昧なら、曖昧なまま答弁の言い回しで引く（勝手に「毎月」を補わない）。
3. **答弁の留保を切り捨てない**: 上記答弁は「件数の増減のみで判断できないため、苦情相談の件数・内容の推移、パトロールでの維持管理状況も勘案し効果を検証」と続いていた。この留保を落として「件数だけを物差しにしていいのか」と論評すると、市が取っていない立場を批判することになる。

**Why:** 議員発信で行政データの母集団を広げて伝えると、誤情報の拡散＋執行部との信頼関係の毀損の両方が起きる。答弁を有利に丸めたと受け取られるリスクもある。
**How to apply:** 議事録・AI反訳から数字を引く原稿をチェックするとき、原文と原稿を並べて「限定句・期間・留保」の3点が保存されているか逐語で突合する。
