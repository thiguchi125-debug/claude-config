**正式名称・議案番号**
- 議案第36号「亀山市自然環境と太陽光発電施設との調和に関する条例の制定について」
- 令和8年6月定例会で可決（議決結果PDF上は賛成多数＝欠1のほか全員賛成）
- 出典: 令和8年6月定例会 議案と議決結果 https://www.city.kameyama.mie.jp/_files/00219150/ginhyouketu.pdf
  （`curl -sL` でDL→`pdftotext -layout` で抽出）

**公布・施行日**
- **令和8年6月26日に公布・施行**（市公式ページの記載）。伊勢新聞の事前報道は「6月29日施行予定」だったので、報道値を引かないこと。
- 出典: 亀山市「太陽光発電施設の適正導入について」 https://www.city.kameyama.mie.jp/docs/2018061900038/

**対象**
- 出力10kW以上の太陽光発電施設（同一事業者が近接地に設置し合計10kW以上のものを含む）
- FIT/FIP認定の有無を問わない。営農型も対象。

**対象外（適用除外）— 市公式の原文**
- 「建築基準法第2条第1号に規定する建築物の屋根、屋上または壁面及び事業所の敷地内に設置する太陽光発電施設」
- 「国又は地方公共団体が管理運営する太陽光発電施設」

**他制度との関係（つなぎ措置＝R8.1.1〜R8.6.25で役目終了）**
- 本条例の施行により、三重県太陽光発電ガイドライン及び亀山市環境保全条例の手続は不要になった。ただし「1000㎡以上の土地の区画形質の変更」を伴うものは環境保全条例の届出が引き続き必要。
- **令和8年1月1日から出力50kW以上**の太陽光発電施設の設置が、亀山市環境保全条例**第2条第6号**「市長が特に環境保全上必要と認める行為」に該当するとして開発行為届出書の対象になった（FIT/FIP・非FIT問わず／出力はパネル合計とパワコンの小さい方）。届出先は**建設部 建築住宅課 建築開発グループ**（環境課は問合せ先）。
- 市公式ページは新条例施行に伴い**削除済み（404）**。原文は Internet Archive で回収する: https://web.archive.org/web/20260606134613/https://www.city.kameyama.mie.jp/docs/2025121800146/
- ⚠️ これは**条例改正ではない**。例規本文は今も平成17年条例第105号（平成22年改正が最新）で、令和7・8年の改正はない。既存の第2条第6号を市長が適用した**運用上の取扱い**。「条例を改正して50kW以上を対象にした」と書くと誤り。
- ⚠️ 条文の表記は「環境保全上」であって「環境の保全上」ではない（第1条には「環境の保全」があり混同しやすい）。

**公式会議録（R8.6.11 議案第36号質疑）**
- 会議録検索システム https://www.kensakusystem.jp/kameyama-s/index.html に**令和8年6月定例会 全6日分が掲載済み**（POSTベースで固定URLなし・キーワード検索で辿る）。公開ラグは実測**おおむね2か月以内**（6/24閉会→8/27時点で全日公開）。
- 当日の議案第36号質疑者は 福沢美由紀・**草川卓也**・深水隆司・櫻井清蔵 の4名。採決は6/24。
- 農地転用の数字は**草川自身の質疑（発言No.130）が引き出した**答弁（発言No.132 産業環境部長 佐藤康二君）＝他議員経由ではないので帰属明示の制約なし。逐語と引用上の注意は [[toben-quote-scope-qualifier]] を参照。

**Why:** 草川の発信で条例名・対象範囲・施行日を誤ると議員としての信頼に直結するため。特に「事業所の敷地内」は除外に含まれる（含まれないと誤読しやすい）。
**How to apply:** 太陽光条例に触れる発信のチェック時、この確定事実と突合する。既設（施行前設置分）は対象外である点も併せて確認する。
