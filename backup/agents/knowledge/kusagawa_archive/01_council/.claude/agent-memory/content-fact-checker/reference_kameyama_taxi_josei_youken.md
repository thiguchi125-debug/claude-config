亀山市の制度の正式名称は **「タクシー料金の助成」**（「タクシー助成」「タクシー券」は通称）。
出典: https://www.city.kameyama.mie.jp/docs/2016033100202/taxi.html

対象（原文）:
1. 「75歳以上の人（**心身等の事情により乗合タクシーに乗車することが困難である人**）」→ 助成額 10,000円
2. 「身体障害者手帳1・2級、療育手帳A、精神障害者保健福祉手帳1・2級のいずれかの所持者」→ 15,000円（じん臓機能障害1級は45,000円）

担当課: 健康福祉部 健康推進課 地域包括連携グループ／同 地域福祉課 障がい者支援グループ

**妊婦は対象に含まれない**（対象は高齢者と障がい者（児）のみ）。この一点だけを言うのは正しい。

**Why:** 2026-09-03 の周産期通院支援ショート動画台本で、テロップに「対象＝75歳以上・重度障がい」と平坦に書かれていた。
75歳以上なら誰でも使えると読めてしまい、議員名義で市の制度を誤って広める＝窓口に誤った期待の問い合わせが行く実害がある。
申請は審査制（ケアマネ確認・専門職員の自宅訪問あり）で、年齢だけで交付されるものではない。

**How to apply:** 「妊婦は対象外」とだけ言うのは可。対象者を列挙・図示するときは必ず 75歳以上に要件が付くことを併記するか、
「対象は高齢者と重度障がいのある方」まで丸めて要件に踏み込まない。「対象＝75歳以上」の断定は INCORRECT 判定。
