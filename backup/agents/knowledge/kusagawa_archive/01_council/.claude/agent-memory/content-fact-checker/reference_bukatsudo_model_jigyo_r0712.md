## 確定した数字

モデル事業の指導者数：**軟式野球10名・剣道4名・ハンドボール5名・陸上競技6名**。それぞれ1教室ずつ開催。対象は市内中学1・2年生、令和7年11月〜1月に月1回・計3回。運営団体は現顧問中心に募集。

## 罠1：硬式ではなく軟式

教育長は「硬式野球で１０名」と読み上げた後、同じ答弁の末尾で自ら訂正している：

> ごめんなさい、硬式ではなくて軟式野球でございました。申し訳ございません。

grepで「硬式野球」だけを拾うと訂正行を読み飛ばして誤記が確定してしまう。**この答弁を引くときは必ず答弁ブロック末尾まで読むこと。**

## 罠2：草川の質問ではない

この数字は今岡翔平議員が引き出した答弁。CLAUDE.mdの誤帰属ガードにより、対外発信・内部ダイジェストのいずれでも「他議員・今岡翔平氏が引き出した教育長答弁」と明示が必要。草川の実績・追及として書くと誤帰属事故になる。
