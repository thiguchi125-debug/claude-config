2026年3月議会議事録のローカル保存ファイルで、ファイル名と中身の日付がクロスしている：

- `mydrive_亀山市定例会第2号_令和8年3月4日_tcuP0.txt` の中身 = **議事日程（第3号）令和8年3月5日**（議案質疑日）
- `mydrive_亀山市定例会第3号_令和8年3月5日_HJfY2K.txt` の中身 = **議事日程（第2号）令和8年3月4日**（代表質問日）

**Why**: 2026-05-27（実体は5-28）の子ども医療費18歳まで拡大v3ファクトチェックで、blog/SNS/動画原稿の全9ファイルが「3月4日代表質問で草川が質問」と書いていたが、実際は **3月5日の議案質疑（議案第33号・34号への質疑）** だった。発信物の元になった原稿生成段階で、ファイル名「第2号_令和8年3月4日」を信じて引用したため日付＋議事種別の二重誤認が混入した。

**How to apply**: 議会議事録を引用する発信物（ブログ・SNS・動画台本・市政報告書・スライド）を検証するときは、**ファイル名の日付を信用せず、必ず本文冒頭の「議事日程（第X号）令和X年X月X日」を直接読んで日付確認**。jqでJSON抽出してから冒頭3行をRead/grep。代表質問日と議案質疑日を取り違えると「議員の発言が代表質問だった」と書いてしまい議会用語誤用・致命的。
