news-briefing v4-local の digest / zokuho / dedup_head は対外発信物ではないが、**行単位でSNS・ブログ・一般質問にコピペ流用される**ため、リスクレビューは「その1行が単独で外に出たとき」を基準に判定する。

**Why:** 内部メモという理由でガードを緩めると、マーカーや前提条件が付いていない行がそのまま発信に載る。事故は流用時に起きるので、メモの段階で1行完結にしておくしかない。

**How to apply:** 毎回この4経路を必ず確認する。

1. **iJAMP（時事通信）マーカーの行単位化** — G枠の見出しに「🔒内部専用」があっても、項目行そのものに `【iJAMP／内部閲覧専用・転載禁止・URL共有不可】` が無いと、行コピペでマーカーが落ちる。dedup判定ログ側にもiJAMP見出しが🔒枠外で素書きされがちなので同様に潰す。対外引用は必ず一次情報を取り直す旨も併記。
2. **他自治体比較が「他市を持ち上げ亀山を貶める」構図になっていないか** — 「亀山市は〇〇にとどまる」型の評価語が典型。人口規模・施設ストック等の前提条件を欠いた比較は執行部批判として物議になる。事実列挙＋「未確認」明示に書き換える。
3. **死亡事案・自殺関連の配慮ガードをメモ段階で書き込む** — 豪雨・事故の死者に触れる項目は哀悼の一文と煽り回避、こども自殺対策は相談窓口併記（自殺報道ガイドライン）を、流用時ガードとして項目に添える。
4. **`[SNS]` `[一般質問]` の活用タグが付いた項目の公選法チェック** — タグ付き＝流用前提なので、事前運動・実績の断定・執行部批判の3点を優先的に見る。義援金/募金の期限が投票日近辺にある項目は、寄附禁止（公選法199条の2）と募金呼びかけの切り分けを事前に確定させる。
