対外発信で **「草川が議会で質した → 後日その施策が実現した」** という時系列並置が出てきたら、公選法軸ではなく **Axis 7（品位・自賛）／voice-dna「主役は市民、草川は背中を押す側」** で採点する。因果を明示していなくても、並置しただけで読者は因果を補って読むため「明示していないからセーフ」と判定しない。

**Why:** 2026-08-20 朝便（産後ケア3類型）で、令和7年6月定例会の質疑→令和8年4月の市ページ更新を並べる構成が出た。公選法上は通常期（P1）で投票依頼も寄附もなく適法だが、原稿は市答弁と草川自身の質問に含まれていた構造要因（令和6年 子ども・子育て支援法改正で地域子ども・子育て支援事業に位置づけ／第3期市子ども・子育て支援事業計画で量の見込みを規定／国の補助率引上げで市負担1/2→1/4）を落としていた。落とした結果、残った因果の穴を読者が草川で埋める形になっていた。

**How to apply:**
- **直し方は削除ではなく1文追加**が最短かつ最良。原稿が依拠している議事録・答弁の中から「制度・法改正・計画・国庫補助率」といった構造要因を1文だけ足すと、帰属が自動的に是正され、同時に事実密度（voice-dna の芯）も上がる。議会質疑の記述自体を削らせない。
- 一次資料を必ず自分で開いて、**構造要因が原稿から落ちていないか**を突合する。落ちていれば MEDIUM、因果を明示（「私が求めた結果」「実現させました」）していれば HIGH。
- **選挙フェーズで採点が変わる**：同じ構成でも P2 直前期（2026-09-18〜10-17）に入ったら Axis 3 の1段階格上げ規則で HIGH 扱い＝ASK_USER。P1 のうちに「構造要因1文を必ず添える」型に直しておくと、P2 でもそのまま使える。
- 合格形の実例（2026-07-27 草川指示 feedback_sns_no_action_promise_assertions に適合）：**「ここは引き続き確かめていきたいところです」**は意思・見解形なので通す。「確かめます」「求めます」「取り上げます」だけが不可。この線引きを毎回引き直さない。
