亀山市 次期ごみ処理施設 整備基本構想（案）関連の発信では以下を固定ガードとする。
- **建設地は未定**。市はパブコメ回答で「建設地を特定したものではございません」と明記。立地に関する推測・見込みは書かない・コメントにも書かない。
- **地区間の移転論には触れない**。パブコメ意見38に「建て替えを機に他の地区への移転についても意見をされる方も見える」とあるが、議員が拡散すると地区間の押し付け合いを起こし、立地決定前に草川が一方の側に立つ構図になる。安全性・交通（搬入口前交差点の視認性／歩道のない通学路／大型車と一般車の混雑）だけを扱えば地区中立でいられる。
- **「道野」の地区名は書かない**。提出者9人と少なく地区名＋論点で提出者が推測されうる。草川自身は令和7年6月議場で「道野方面」と述べており地区名自体は公開情報だが、SNSで再導入する必要はない。
- 意見38にある**特定民間事業者（モータープール）の名称も出さない**（危険・混雑の文脈で私企業を名指しする形になる）。

**Why:** 2026-08-31 夕便SNSのリスクレビューで、上記の省略判断はいずれも妥当と確認。落としたことで地区対立・個人特定・私企業名指しの3リスクが同時に消えている。

**How to apply:** このテーマで原稿を作る／コメント返信を書くとき、上の4点が守られているかを先に確認。市の記述の並置については [[no-juxtaposed-policy-shift-implication]]。
