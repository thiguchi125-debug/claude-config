亀山市議会の**消防関係の議事録**（例：令和4年3月定例会 議案第7号 消防団条例の一部改正）で答弁している「豊田」は、**消防部長・豊田達也**（執行部）である。亀山市議会には現職議員の**豊田恵理**がおり、姓が重複する。

一次資料：`~/.claude/agents/knowledge/kusagawa_archive/01_council/2022-03_R0403_本会議議事録_kusagawa.txt` 行107-145・211-217（草川の議案質疑と消防部長答弁のペア。議長は中﨑孝彦）。

**Why:** 議事録をコピペして発信物に流すと「豊田」が混入する。そのとき二重に事故る——(1) 執行部の個人名を対外発信に出す（不要なリスク）、(2) 読み手・レビュー側が現職議員 豊田恵理と取り違え、[[feedback_no_other_council_members_names]] 違反と誤判定する／逆に他議員の成果と誤帰属される。消防テーマは草川の実績素材として繰り返し使われるため再発しやすい。

**How to apply:**
- 消防テーマの原稿で「豊田」を見つけたら、まず**部長か議員か**を一次資料で確定してから判定する。姓だけで議員名と断定しない。
- 対外発信では答弁者名を出さず「消防部長答弁」「市の答弁」に置換する（議員名でなくても執行部の個人名を載せる実益がない）。
- 同じ議事録の「中﨑孝彦」は議長。これも議員名なので対外発信では出さない。
