通常期（P1）に適法に出した政治活動の投稿について、告示日 2026-10-18 以降の扱いの実務ライン。レビュー時に「告示後も残していいか」と聞かれたら以下を返す。

- **残置**: 過去に適法に行った政治活動の投稿をタイムラインに残すこと自体は削除義務なし。遡って選挙運動になるわけではない。
- **再投稿・引用リポスト・固定表示・プロフィール掲出**: 告示後の**新たな発信行為**として評価される。実績言及（過去の自分の議会質問への言及等）を含む版の再掲は選挙運動性を帯びるので避ける。案内情報だけ再掲する必要があるときは、実績段落と `#草川たくや` を外した純案内版を新規に出す。
- **有料ブースト・広告出稿**: 選挙運動用有料インターネット広告は公選法142条の6で禁止。既存投稿への告示後のブーストもかけない。
- **ウェブサイト等を利用する選挙運動**: 電子メールアドレス等の連絡先表示義務（142条の3第3項）。アカウントを選挙運動に使うなら告示後はプロフィール等に表示。
- **電子メールによる選挙運動**は候補者本人が主体のときのみ。後援会等の第三者による一斉メール転送はさせない。

上記は一般的な整理。個別の可否（特にプロフィール表示の要否と、告示期間と重なる行政手続案内の再掲）は**亀山市選管／三重県選管への事前確認**を推奨として必ず添えること。関連: [[project-en-tougou-boshuu-teishi-risk]]
