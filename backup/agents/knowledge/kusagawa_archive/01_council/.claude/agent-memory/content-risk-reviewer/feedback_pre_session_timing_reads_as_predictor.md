議会の開会日・一般質問の通告締切の**直前**に出す政策テーマの投稿は、末尾が推量形（「〜かもしれません」「〜局面かもしれない」）であっても、読み手には**次の議会での取り上げ予告**として読まれる。レビュー時は投稿日と議会日程を必ず突合し、**そのテーマが今回の通告に入っているかを草川に確認**する。入っていなければ、行動を匂わせる末尾は意思の形（「〜を確かめていきたいと考えています」）か、行動主体を出さない論点提示で閉じる案を出す。

**Why:** [[feedback_no_aggressive_pursuit_phrases]]（特定議会×対決動詞の禁止）と [[feedback_sns_no_action_promise_assertions]]（本人が決めていない行動を断定しない）は、いずれも「文言」を対象にしたルールだが、**開会直前というタイミングそのものが文言に予告の意味を足す**。禁止語を1つも使っていない原稿でも、日程の近さだけで同じ事故（言ったのにやらなかった／やる前提で受け取られた）が起きる。2026-08-27 の太陽光条例×国のパネル補助見直しX原稿（末尾「6月のやり取りは、思っていたより早く出番が来るのかもしれません」）で検出。翌8/28が9月定例会開会・9/1が通告締切、かつ当該テーマは通告4本に入っていなかった。

**How to apply:**
- Axis 3（公選法）・Axis 8（政治的物議）のチェック時に、**投稿予定日から前後10日の議会日程**（開会日・通告締切・委員会・閉会日）を確認する。
- 近接していたら、原稿テーマが今回の通告・議案に入っているかを草川に一問で確認する。入っていれば末尾の予告色は許容範囲、入っていなければ 🔴 HIGH として ASK_USER。
- 代替案として「投稿を通告確定後にずらす」運用提案も併せて出す。文言を弱めるより、日付をずらす方が原稿の力を落とさずに済むことが多い。
