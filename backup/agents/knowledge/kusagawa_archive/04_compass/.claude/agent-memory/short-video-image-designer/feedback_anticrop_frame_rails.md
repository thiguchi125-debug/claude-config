「この情報とこの条件は同一PNGに焼き込む（切り取り拡散で片方だけ残ると実害）」という要件が来たとき、
**外枠 `.frame`（border 6px・左右レールが字幕セーフ帯を縦断）で上部ブロックと下部条件帯を1枚のカードに束ねる**。

- 帯内前景率＝6px×2レール ÷ 1080（2px間引きサンプル）= **1.11%**。許容1.5%以内で `check_subtitle_band.py` をPASSする。
- レールを8pxにすると1.48%で限界、10pxで即FAIL。**6pxが上限の実用値**。
- 下部の条件帯は全ブリードにせず**枠の内側にインセット**する（frameの左右レールが帯の外側に残り、「1枚のカード」の見えが成立する）。

**Why:** 2026-07-31の熊本地震支援物資セット（a2 品目リスト＋「新品・未開封のみ／必要物資以外は受け取れません」、
a3 場所＋締切）で、①分割不可の絶対条件 と ②帯y1240-1460を空ける恒久ルール が正面衝突した。
帯を跨ぐ視覚的連結が一切ないとリスト部分だけをトリミングできてしまい、条件が落ちて実害が出る。

**How to apply:** 「〜だけ切り取られると困る」「同一PNGに焼き込み」がカット表・依頼文にあるとき。
逆に分割禁止要件がない画像（a1/a4/a5/th）はレール不要＝帯内前景0.00%にする。
