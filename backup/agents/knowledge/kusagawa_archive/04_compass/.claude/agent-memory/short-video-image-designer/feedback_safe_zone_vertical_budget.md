1080×1920の挿入画像で実際に文字を置けるのは次の2区画だけ。設計前にこの予算で割り付ける。

| 区画 | 範囲 | 実効 |
|---|---|---|
| 上ゾーン | y250〜1236 | **約990px**（主役・見出し・本体） |
| 字幕セーフ帯 | y1240〜1460 | 使用禁止（動画編集で白テロップが焼かれる） |
| 下ゾーン | y1468〜1670 | **約200pxしかない**（1670より下はSNSのキャプション/UIに食われる） |

**下ゾーンに3ブロック（ラベル＋大きい数字＋注記）を積むと必ず1670を突破して注記がUIに隠れる。**
そうなったら注記を下ゾーンで縮めるのではなく、**上ゾーンの末尾（y1180前後）に逃がす**。
併せて、同じ値が2箇所に重複している要素（例：カード2枚それぞれの受付時間）は
**1本の共有ストリップに集約**すると上ゾーンが空き、下ゾーンは主役1本（電話番号など）だけで済む。

**Why:** 2026-07-31 a3（受入場所カード）で、事前連絡TEL＋注記を下ゾーンに積んだら注記がy1740まで落ちた。
受付時間8:00〜19:00を2枚のカードから抜いて共有ストリップ化したことで上ゾーンに余裕が生まれ、
注記をy1182に置けて、TELは下ゾーンを独占して72pxまで大きくできた。

**How to apply:** 「◯◯を1枚に全部焼き込む」系の情報密度が高い依頼を受けた最初の設計時。
`white-space:nowrap` を主要行に付けて折り返し事故（孤立1文字・住所の途中改行）を機械的に殺すのもセットで。
