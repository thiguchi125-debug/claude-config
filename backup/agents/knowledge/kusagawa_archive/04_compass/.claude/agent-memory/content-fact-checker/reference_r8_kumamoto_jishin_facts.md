令和8年熊本地震の確定事実（一次情報で突合済・2026-07-31検証）。

**呼称**: 「令和8年熊本地震」は**気象庁の正式命名**（陸域M7.0以上＋最大震度5強以上の命名基準に該当）。この呼称で言い切ってよい。
- 出典: https://www.jma.go.jp/jma/menu/20260728_kumamoto_jishin.html

**地震諸元**（気象庁・内閣府7/29 06:00現在）
- 発生: 令和8年7月28日 16時27分
- 震源: 熊本県熊本地方／深さ16km（暫定値）／M7.1（暫定値）
- 最大震度7: 熊本県 宇城市・氷川町。震度6強: 熊本市・八代市・宇土市・美里町・益城町
- 津波注意報（有明・八代海）発表7/28 16:29 → 解除7/28 18:10

**被害**（消防庁情報・7/29 07:00現在／内閣府まとめ）
- 熊本県 死者3人・重傷6人・軽傷22人／鹿児島県 軽傷1人
- 避難所506か所・避難者9,186人（内閣府7/29 06:20現在）
- 断水: 5県23自治体で断水等発生、**最大断水戸数 約84,000戸**、3県12自治体で約84,000戸が断水中（国交省7/29 06:00現在）
- 救助事案47件のうち複数が対応中（八代市の煙突崩落・嘉島町の商業施設2階崩落による閉じ込め多数・氷川町の住宅座屈2件）
- 出典PDF: https://www.cao.go.jp/updates/r8kumamoto_jishin_20260729.pdf （※WebFetchはバイナリ返却。`pdftotext -layout` で抽出可）
