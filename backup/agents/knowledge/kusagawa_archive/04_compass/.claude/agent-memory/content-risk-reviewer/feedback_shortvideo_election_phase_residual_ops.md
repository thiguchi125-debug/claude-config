ショート動画（TikTok／YouTube Shorts／Instagram Reels）のリスクレビューでは、**投稿時点のフェーズ判定だけで完結させない**。動画はアルゴリズムで数週間〜数か月後に再浮上し、ピン留め・再投稿・広告出稿・コメント返信で「新たな発信」が発生するため、選挙フェーズをまたいだ運用注記を必ずレビュー結果に添付する。

**Why:** 2026-08-19 の公共交通ショート動画レビューで、セリフ自体は P1 通常期で問題なし（残67日）だったが、同じ動画が P2 直前期（2026-09-18〜10-17）・P3 選挙運動期間（10-18〜10-24）・P4 投票日（10-25）に残置される前提が原稿側で全く手当てされていなかった。公選法上、選挙期日前に掲載したウェブサイト等をそのまま残置することは新たな選挙運動に当たらないが、**当日の新規投稿・シェア・ピン留め変更・コメント返信は選挙運動になり得る**。「コメントで教えてください」型のCTAがある動画は特に危険。

**How to apply:** 動画レビューの出力に「残置・再利用の運用注記」ブロックを必ず立て、以下を書き残す。
- 投稿日と、その日の選挙フェーズ・投票日までの残日数
- P2入り（9/18）以降に**再投稿・ピン留め・広告出稿をしない**（するなら Axis 3 を1段階格上げで再レビュー）
- P3（10/18〜10/24）は**残置のみ可・新規アクション禁止**。ピン留め位置も動かさない
- P4（10/25 投票日）は**シェア・コメント返信・固定変更を含め一切触らない**
- CTAでコメントを募る動画は、P3入り前にコメント欄をクローズするか返信を止める判断を草川に確認
