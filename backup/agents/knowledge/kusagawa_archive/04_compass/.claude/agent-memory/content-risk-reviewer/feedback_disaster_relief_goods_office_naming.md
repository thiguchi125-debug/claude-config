他団体（亀山青年会議所等）が主体の災害支援物資の受入を草川のSNSで告知するとき、**受入場所は団体名で呼び、肩書も団体側の役職のみを名乗る**。議員肩書と個人事務所名は原稿から外す。

- 受入場所の呼称 → ×「草川たくや事務所（中庄町858）」／○「亀山青年会議所 中庄町事務所（中庄町858）」
- 名乗り・テロップ → ×「亀山市議会議員／JC直前理事長」／○「亀山青年会議所 草川たくや」
- 締めの主語 → ×「責任を持って、届けます」（草川が運ぶわけではない）／○「亀山青年会議所が責任を持って届けます」
- 冒頭フック → ×「亀山から、これだけ集まりました」（地元の成果誇示）／○用件先出し「受付は明日の昼までです」。数量は中盤に「皆さんからお預かりしました」の形で置く
- ハッシュタグ → 到達先が亀山市民なので #亀山市 は機能上必要。**人物ブランドタグ #草川たくや は外す**（[[feedback_hashtag_policy_x_instagram]]の災害時例外の運用）
- 全国拡散面（TikTok / YouTube Shorts）は、市内でしか行動できない告知には不適。市内到達面（LINE公式・Facebook・Instagram・X・Threads）に絞る

**Why:**
2026-07-28 令和8年熊本地震の支援物資告知（2026-07-31レビュー）で確立。市議選2026-10-25まで残86日という文脈が原稿の中身では消せず、次の3経路が同時に立つ：
1. 選挙区内の市民が財物を持って草川の事務所に足を運ぶ絵 → 政治団体への物品寄附（政治資金規正法4条3項の「寄附」は物品を含む）と外形上読まれる。団体名で呼べばこの説明コストがゼロになる
2. 他団体の事業を議員肩書で発信＝団体活動の個人実績への転化（利益相反）
3. 肩書が資料間で不一致（新聞=監事／原稿=直前理事長）のまま選挙3か月前に公表すると、公選法235条 虚偽事項公表罪（身分・経歴）の射程に入る。JCは直前理事長が監事を兼ねる例が多く両立しうるが、**確認が取れるまで確定表記で出さない**

告知そのものは[[feedback_disaster_rescue_phase_no_local_pivot]]の例外として成立する。同memoryが禁じるのは「亀山の備え・政策・実績への接続」であり、**締切のある物資受付は「今出さなければ失われる情報」があるため救助フェーズ中でも出してよい**。禁止対象は地元の成果を誇るフックの方。

**How to apply:**
- 受入場所に議員個人事務所を実際に使うこと自体は可。**呼称と名義だけ団体に寄せる**
- 持参者の氏名・連絡先を記録しない。記録した場合も後援会名簿・お礼DMへの転用は絶対NG。持参者を撮影して「◯◯さんが持ってきてくれました」と投稿するのもNG
- 第三者企業（例：株式会社村山ガス）の社名・住所を草川個人アカウントで読み上げ・掲示するのは、団体側が場所を決めていても**別途その企業の明示了解が必要**（その企業が草川支持と読まれるため）
- 締切・時間・拠点数が報道と食い違うときは、団体の公式決定を書面で確認 → キャプションに「新聞では◯日までと掲載されましたが、△まで延長されました（◯◯決定）」と差分を明記 → 動画に時点注記。市民が閉まった場所に物資を持って行く事故が実害
