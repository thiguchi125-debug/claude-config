ショート動画セリフやブログ本体で「この固有名詞は伏せる」「この属性は書かない」と確定させても、**7PF展開の本文では別経路から復活する**。レビューの第一手は、確定した伏せ物リストを持って全PFを横断grepすること。

**Why:** 2026-08-19 の公共交通ショート動画7PFレビューで、本体では病院実名を「鈴鹿市内の病院」に丸め、アンケート回答者の地区名・性別も伏せる確定をしていたのに、PF別本文で次の漏れが起きた。
- Instagram の「アンケート考察の原文引用」ブロックに、本体で落としたのと同じ性質の固有名詞（市内店舗の実名）が原文のまま残った。原文引用は「原文だから」という理由で伏せ判断の適用外になりやすい
- YouTube Shorts の**タイトル**が片面表現のまま残った。本文には併記があってもタイトルは単独で切り取られ拡散する
- Instagram の**ハッシュタグ**に地区名タグが入り、本文で伏せたはずの回答者の所属地区を復元させた
- 自由記述の**逐語引用＋母数明示**（「19歳以下は57人。その中の一つ」）で、形式上は地区名・性別を書いていないのに実質的な特定可能性が上がった

**How to apply:** PF別本文（sns-content-creator出力・7PFバンドル）のレビューでは、8軸に入る前に次の4面を必ず個別に見る。本文だけ読んで通さない。
1. **引用ブロック**（考察・答弁・自由記述の原文）— 原文であることは伏せ判断の免除理由にならない。原文を出すなら伏せ物を丸めた要旨引用に切り替える
2. **タイトル・冒頭1行**（Shortsタイトル／X 1行目／TikTok冒頭）— 単独露出面。片面表現・断定はここで一発で崩れる
3. **ハッシュタグ**— 地区名・施設名・学校名タグは本文の匿名化を無効化する
4. **母数の明示**— 「N人中の一つ」は分母を小さく見せるほど特定を助ける。母数と逐語を同時に出さない
