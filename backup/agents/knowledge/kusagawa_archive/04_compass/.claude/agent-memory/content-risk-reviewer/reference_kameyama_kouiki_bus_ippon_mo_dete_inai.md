亀山市の公共交通ネタで「市外へ一本も出ていません」と言い切ると、**亀山みずほ台線**（三重交通・鈴鹿市と亀山市が事業主体・赤字損失分を行政が負担・1日15便・亀山駅前→イオンモール鈴鹿けやき通り 片道680円 約40分）の存在で一発で反論される。

- 正確には「**コミュニティバス**7路線がすべて市内完結」であって、「市が支える広域路線バスは鈴鹿へ出ている」。
- 特に「亀山→鈴鹿イオンまで往復1,360円」というフックを冒頭に置く原稿では、**そのフックで使っている路線こそが市の広域支援の成果**なので、直後に「市外へ一本も出ていない」と続けると自己矛盾に見える。
- 安全形：「鈴鹿へは市も支える路線バスが1日15便。でもコミュニティバス7路線は、すべて市内完結。」

**How to apply:** 公共交通・コミバス・広域接続テーマの発信物（ショート動画／SNS／ブログ／地区版レポート／報告会スライド）で「市外へ出ていない」系の表現を検知したら、必ずコミュニティバス限定に絞り、既存の広域路線への言及を1文入れる。名誉毀損軸ではなく「市の名指し批判の根拠が片面的で反論一発で崩れる＝信頼失墜」リスクとして扱う。
