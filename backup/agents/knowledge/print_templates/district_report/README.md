地区版プロローグの数字は**必ず一次資料照合**してから記載すること。

### 過去事故（再発防止）
- 「過去12年で827人減」← 出典不明・公式統計と乖離（実際は約−875〜−1,151人）→ **数字削除し総論化推奨**
- 「神辺地区は微増エリア」← 公式では神辺は減少（H26→R7で約−274人）→ **「世帯流入が続く」「住宅地として安定」等の傾向表現に置換**
- 「総事業費4.8億円」← 期間不明 → **「令和◯〜◯年度の◯年間で約◯億円（対象区間）」と期間＋区間明記**
