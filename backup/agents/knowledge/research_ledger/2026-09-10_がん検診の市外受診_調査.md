# がん検診の市外受診 — 一次情報調査（亀山市）

- 調査日: 2026-09-10
- 依頼元: ブログ執筆（テーマ＝亀山市のがん検診が市外の医療機関で受けられない）
- 起点となった市民の声2件（03_themes/_citizen_voice/healthcare_welfare.md）
  - **No.16**（2026/05/07、40代 / S2-196）「亀山市の個別がん検診は市内医療機関でしか受診できない。乳がん検診で度々要精密検査になり四日市の病院に通っているが、四日市・鈴鹿の市民は市のがん検診をその病院で受けられると聞いた。かかりつけの市外病院でも市のがん検診を受けられる柔軟な仕組みを検討してほしい。」
  - **No.18**（2026/09/08、昼生小学校区、20代 / S1-54）「市の子宮がん検診について、個別検診は市内の産婦人科1医院でしか受診できず、集団検診も例年すぐ定員が埋まり空きがないと言われた。市内に産婦人科が1医院しかないのに、なぜ鈴鹿や津の医療機関を選べないのか。女性医師に診てもらいたいという希望も含め、受診先を選ぶ余地がないことを改善してほしい。」

---

## 0. 結論サマリ（3行）

1. **市内限定は事実**。令和8年度「健康づくりのてびき」P18に「個別検診は、市内の実施医療機関で実施期間内に行っている検診です。」と明記。償還払い規定は市公式サイト上に見当たらない。
2. **同じ亀山市が、特定健診は「県内協力医療機関でも」、妊婦健診は「県内医療機関で受診票が使える＋県外は費用助成」としている**。制度間で越境の可否が割れており、これがブログの構造的な核心。
3. **市民の伝聞「四日市・鈴鹿の市民は市外の病院で市のがん検診を受けられる」は裏が取れなかった**。鈴鹿市は「市内指定医療機関で受診する個別検診」と明記し、令和8年度の実施医療機関一覧の郵便番号はすべて鈴鹿市内。**この伝聞はブログに書いてはいけない。**

### 🚫 書いてはいけない（追補分）
- **「亀山市のがん検診受診率は県内で低い」** ← **事実に反する**（胃・大腸・乳は県平均超え）
- **肺がんの受診率・順位** ← 県資料が図表のみで未公表
- **個別検診の自己負担額の具体的な金額** ← テキスト出典なし（OCRのみ）
- **市内の産婦人科の件数・医療機関名** ← 公的出典なし
- **国保ベースの数字（胃25.9/肺26.2/大腸26.8）と今回の数字を並べること** ← 分母が違う
- 「受け皿が細いから受診率が低い」「市内に行き先がないから精検に行けない」の**断定** ← 因果は推測。「〜ではないか」「市に確認したい」の形にする

### 提言の核心（改訂）
**受診率そのものは県平均並み。だから問題は「量」ではなく「質と、選べなさ」に絞られる。**
1. **子宮頸がんだけが県平均を下回っている**。受け皿（市内の産婦人科／集団検診の枠）との関係を市はどう分析しているか。
2. **乳がんの精密検査受診率35.7%は県内下位3番目**。要精検となった人の6割以上が精密検査に到達していない。**総合計画の指標は全がん種平均の80.9%で、この数字は見えなくなっている。がん種別の指標に分解すべき。**
3. **精度管理の外部評価はすべてC。近隣の津・四日市・鈴鹿はB。** 何が未達で、いつまでにBにするのか。
4. そのうえで**受診できる場所を市内に固定している契約の形（亀山医師会との単独契約）を、特定健診・妊婦健診と同じく県内へ広げられないか**。
