## A. 介護保険で使えるサービス（高齢者向けに整理）

一次の根拠：厚労省「介護サービス情報公表システム」の解説ページ（https://www.kaigokensaku.mhlw.go.jp/publish/ ・サービス別の説明 group○.html）、および広域連合「管内の介護保険事業所」PDFの種別一覧（R8.6.1時点）。種別の名前と区分は制度上の確定事項。今回の調査では新しいページは取得しておらず、前回台帳でgroup14.html（特養）とfee.html（費用）を確認済み。

|---|---|---|---|
| 家に来てもらう | 訪問介護（ホームヘルパー） | 入浴・排せつ・食事の介助（身体介護）、掃除・洗濯・調理（生活援助） | 要支援1・2の人は市町の「総合事業」で受ける |
| | 訪問看護 | 看護師が来て、医療的なケア・健康チェック | 主治医の指示が必要 |

| | 訪問リハビリ | 理学療法士などが自宅でリハビリ | |

| | 通所リハビリ（デイケア） | 日帰りでリハビリ中心 | 病院・老健が運営 |
| | 認知症対応型通所介護 | 認知症の人向けの少人数デイ | |
| 泊まる | 短期入所（ショートステイ） | 数日〜泊まる。家族の休息にもなる | 生活介護（特養併設が多い）と療養介護（老健など） |
| 組み合わせ | 小規模多機能型居宅介護 | 「通い」中心に「訪問」「泊まり」を同じ事業所で | 月定額。看護が付く「看護小規模多機能」もある |
| 用具・住まい | 福祉用具の貸与（レンタル） | 車いす・介護ベッドなど | 要介護度で借りられる物が違う |
| | 特定福祉用具の購入 | ポータブルトイレ・入浴用いすなど | 年10万円が上限（その1〜3割負担） |
| | 住宅改修 | 手すり・段差解消など | 1人生涯20万円まで（その1〜3割負担）。工事前の申請が必要 |
| 入る（施設） | 特別養護老人ホーム（特養） | 生活の場として長く暮らす | 原則要介護3以上 |
| | 介護老人保健施設（老健） | 在宅に戻るためのリハビリ施設 | 長期入所の場ではない |
| | 介護医療院 | 医療の必要が高い人が長く暮らす | |
| | 認知症グループホーム | 認知症の人が5〜9人で共同生活 | 要支援2以上 |
| | 有料老人ホーム・サ高住 | 住まいは民間契約 | **家賃・食費は介護保険の外**。介護分だけ保険（外部サービスか、「特定施設」指定なら施設内） |
| 要支援の人 | 総合事業（介護予防・日常生活支援総合事業） | 訪問型・通所型サービス、体操教室など | 市町の事業。チェックリストで利用できる場合もある |
| 相談 | 居宅介護支援（ケアマネジャー） | ケアプラン作成 | **いまは自己負担なし（10割給付）** |

> 家に来てもらう：ヘルパー（家事・入浴の手伝い）、訪問看護、訪問リハビリ
> 通う：デイサービス、デイケア（リハビリ）
> 泊まる：ショートステイ（家族のひと休みにも）

> 道具・家：車いす・ベッドのレンタル、手すり工事（20万円まで）
> 入る：特別養護老人ホーム（原則 要介護3以上）、老人保健施設、グループホーム
> ※有料老人ホームやサ高住の家賃・食費は介護保険の対象外です
> まず相談：地域包括支援センター（ぼたん・もくれん・きずな）

**2枚目：亀山の介護保険料**
> 65歳以上の保険料（基準額・月額）
> 第1期（平成12年〜）2,771円 → 第8期 5,781円 → **今（令和6〜8年度）6,255円**
> 国の試算では、令和12年度 7,242円、令和22年度 8,112円
> 次の保険料（令和9年度〜）は、いま鈴鹿亀山地区広域連合で計画づくりが進んでいます
> 出典：鈴鹿亀山地区広域連合 資料（令和8年6月）

**3枚目：亀山の介護の現場**
> 要介護・要支援の認定を受けている人：2,397人（65歳以上の約18％／令和5年9月）
> 亀山市内のヘルパー事業所：18か所（令和8年6月）
> 鈴鹿・亀山の介護事業所の約4割が「人が確保できていない」（令和8年3月 調査）

> ・ケアプラン作成に自己負担を求めるか
> ・要介護1・2の人の家事援助を市町の事業に移すか（結論は持ち越し）

## E. 問題提起の論点3つ（事実の裏付け付き）

1. **「払う側」も「使う側」も負担が増えている**
   保険料は第8期5,781円→第9期6,255円（+474円）、試算で令和22年度8,112円。利用者負担は2割拡大が検討中、高額療養費はR8.8に上限引上げ済み（前回台帳）。ケアマネ調査でも「介護者の費用負担が重い」が10.6%→18.5%に増加。→ 負担の議論を国任せにせず、広域連合の第10期計画で低所得層の保険料軽減と、補足給付・高額介護サービス費の申請漏れ防止（周知）を求める。
2. **お金があってもサービスが来ない時代になりつつある**
   事業所の約4割が人材を確保できていない（28.3%＋11.5%）、看護師不足は17.0%→30.0%。広域連合自身が計画で「慢性的な人材不足」と記載。全国では訪問介護の倒産が3年連続で最多（TSR）。亀山市内には訪問入浴・定期巡回・看護小規模多機能の事業所がない（R8.6.1時点の一覧）。→ 第10期計画で亀山市内の在宅サービスの空白（夜間・24時間対応）をどう埋めるか、人材確保策（研修費助成は計画上「鈴鹿市では」実施）を亀山市でも行うかを問う。
3. **国の見直しの行方は「決まっていない」。だから地方の声が要る**
   要介護1・2の総合事業移行は「引き続き包括的に検討」、ケアプラン有料化は在宅全体では結論なし、2割拡大は2026年度中に結論予定。総合事業の受け皿は市町が担う。→ 移行が決まった場合に受け皿となる亀山市の総合事業（住民主体サービス等）の現状を確認し、市議会・広域連合議会から国へ意見を上げる余地がある。

## F. 書いてはいけない点
- **特養の待機者数**（亀山市・広域連合とも公表値を確認できていない）。
- **介護職員の有効求人倍率**（未取得）。
- **「訪問介護の報酬が〇%下がった」**（改定資料を開いていない）。
- **TSRの「2025年91件」**（未確認）。85件は「1〜11月」と期間を付ける。
- **「亀山の事業所の4割が人手不足」**→ 正しくは「鈴鹿・亀山の事業所」。広域連合全体の調査。
- **「ヘルパーの高齢化が深刻（亀山）」**→ 計画書の主語は「鈴鹿市では」。
- **「2割負担拡大が決まった」「ケアプランが有料になる」「要介護1・2が保険から外れる」**→ いずれも未決定。
- **「亀山市内にデイケアが無い」**→ テキスト集計の結果で未確認。
- 2026年の認定者数（2,543人）を実績として書かない（推計）。
- ご意見箱の件数は発信に使わない（横断ルール）。懇談会アンケートの件数も、市の公表値ではないので出す場合は「当日のアンケートで」と明記。
- 市・広域連合の職員や特定の事業所名を責める書き方をしない（事業所名はスライドに出さない）。
