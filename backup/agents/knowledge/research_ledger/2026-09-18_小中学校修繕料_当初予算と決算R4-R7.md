# 小中学校「修繕料」当初予算額と決算額 R4〜R7（亀山市一般会計）

調査日: 2026-09-18 / 目的: R8.9月議会 決算総括質疑（本番2026-09-25）の根拠

## 費目の定義（R7と同じ取り方＝これで揃えた）

一般会計 歳出 第10款 教育費
- 第2項 小学校費 → 第1目 学校管理費 → 第10節 需用費 → **修繕料**
- 第3項 中学校費 → 第1目 学校管理費 → 第10節 需用費 → **修繕料**

ただし 事項別明細書の説明欄では 修繕料 が事業別に2本に割れる。
- 事業「学校管理費」（運営系。小学校で数十万〜150万円規模）
- 事業「**施設管理費**」（施設の修繕本体。数千万円規模）

**草川が既に持っているR7の数字（小 当初1,800万円→決算3,747万8,739円／中 当初480万円→決算846万4,245円）は「施設管理費」事業分。**
→ R7決算書 PDF p.233（印刷 p.217）で 中学校費 施設管理費 予算現額47,180,743／支出済47,010,907・修繕料 **8,464,245円** を確認。当初4,800千円も一致。よって本表は施設管理費事業分で統一。

## 注意（議場で使うとき）

1. 「修繕料」は事業が2本（学校管理費／施設管理費）。R7の既存数字は施設管理費分なので、質疑でも施設管理費分で通すこと。節合算にすると小学校の倍率が下がる（R7未算出）。
2. R6小学校は当初を2,332万7千円まで積み増したので倍率1.59倍に下がった＝「積めば倍率は下がる」証拠として使える。逆にR7は当初を1,800万円に戻して2.08倍に戻った。
3. 中学校はR6→R7で当初を571万7千円→480万円に**下げた**。決算は1,145万円→846万円。
4. 4年連続で決算＞当初（小学校1.30→2.15→1.59→2.08倍／中学校1.08→1.93→2.00→1.76倍）。「毎年足りない」は4年分で言える。
