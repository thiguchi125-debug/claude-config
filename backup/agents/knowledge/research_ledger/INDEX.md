## ルール
1. **投げる前に grep する。** `grep -rl "<KW>" ~/.claude/agents/knowledge/research_ledger/`
   ヒットしたら、まずそれを読む。足りない差分だけを Agent に投げる。
2. **投げたら回収する。** 調査系 Agent の最終報告は、その日のうちにここへ
   `<日付>_<テーマ>.md` として落とす。要約しない（要約すると再利用時に足りなくなる）。
3. **草川の過去発言は対象外。** それは `kusagawa_archive/`。ここは外部＝他自治体・国・県。
4. 各節は当時のままで未検証を含む。発信に使う数値は content-fact-checker を通す。
