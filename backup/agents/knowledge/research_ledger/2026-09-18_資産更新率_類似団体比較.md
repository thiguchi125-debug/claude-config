## 【1】この見方は公的に通用するか

### (a) 国の文書に「分析の視点」として書かれているか

**結論：「減価償却費」と「その年の資産形成額（有形固定資産等の増加）」を直接割り算する比較そのものは、国の文書に指標としても分析手法としても明記されていない。**
ただし、**「減価償却が進む一方で必要な投資が行われていないのではないか」という問題の立て方そのものは、総務省のマニュアルに複数箇所、明確に「分析の視点」として書かれている。**

以下、総務省『統一的な基準による地方公会計マニュアル（令和7年3月改訂）』からの**原文引用**。
URL：https://www.soumu.go.jp/main_content/001001118.pdf （総務省、令和7年3月改訂、取得日2026-09-17）
※ページ番号はPDF内に印字された通し頁（「ー339ー」等）。第Ⅳ編「財務書類等活用の手引き」はp.319から。

**引用①（p.339「（６）指標の組み合わせ分析」）** ＝ 最重要
> 「組み合わせ分析については、例えば、横軸に資産の経年化の状況等を表す有形固定資産減価償却率、縦軸に地方公共団体財政健全化法に基づく将来負担比率を組み合わせて分析することが有用です。財政的には、将来負担比率が下がっていても有形固定資産減価償却率が上昇している場合には、老朽化対策が先送りにされている可能性、あるいは、既存施設を活用して財政負担を抑えている可能性が考えられ、公共施設の維持修繕の履歴等と合わせて老朽化対策の進捗状況の分析が可能となります。」

同じ見開き（p.339）の図の注記（散布図「赤線が自団体／青線が類似団体」の右側解説）にも、原文で次のとおり書かれている：
> 「将来負担比率が低下している一方、有形固定資産減価償却率が上昇していることから、
> ア　必要な投資が行われず、老朽化対策が先送りされている可能性
> あるいは
> イ　単純な施設更新を行うのではなく、既存施設を活用して財政負担を抑えている可能性
> が考えられ、他のデータと合わせて老朽化対策の分析を深めることができる。」

→ **「必要な投資が行われず、老朽化対策が先送りされている可能性」という文言が、国のマニュアル本文に明記されている。** 亀山市は「将来負担比率は比率としては生じておらず（＝ゼロ）」かつ「有形固定資産減価償却率は類似団体平均を大きく上回る」ため、この総務省の記述が指す典型パターンに該当する（【3】参照）。

**引用②（p.326「２　指標による分析」冒頭）**
> 「さらに、決算統計や地方公共団体財政健全化法に基づく健全化判断比率等も組み合わせることによって、例えば、将来負担比率が低くても有形固定資産減価償却率（後述）が高ければ、老朽化対策の先送りという将来負担が潜在している可能性があるなど、より多面的な分析を行うことができます。」

**引用③（p.329「有形固定資産の行政目的別割合」の解説）** ＝ 「投資額」という語が出る唯一の箇所
> 「なお、割合が減少している分野については、金額を取得価額等と減価償却累計額に分けて経年比較することにより、投資額が少ないため割合が減少しているのか、施設の老朽化が加速しているのかを把握することができます。」

**引用④（p.327〜328「住民一人当たり資産額」の解説）**
> 「経年比較においては、資産の増減の要因や資産形成の傾向を分析することが重要です。例えば、住民一人当たり資産額の大きな減少は、資産圧縮に取り組んだ結果である場合と、老朽化により有形固定資産の金額が減少している場合などが考えられますが、金額を取得価額等と減価償却累計額とに分けて経年比較することにより、いずれの理由によるものかを把握することが重要です。」

**引用⑤（p.342「Ⅱ―２ 行政内部での活用（マネジメント）／１ マクロ的な視点からの活用／（１）適切な資産管理」）**
> 「近年、我が国では公共施設等の老朽化対策が大きな課題となっていますが、決算統計上の財政指標や地方公共団体財政健全化法に基づく健全化判断比率では、資産の老朽化度合いを把握することはできませんでした。しかしながら、貸借対照表を作成することで、有形固定資産のうち償却資産の取得価額等に対する減価償却累計額の割合を算出し、有形固定資産減価償却率として把握することができるようになります。」

### (b) 国が定めた正式な指標名があるか

**結論：当該比率（減価償却費に対する有形固定資産等の増加の割合）にズバリ対応する公式指標名は「存在しない」。**

総務省『統一的な基準による地方公会計マニュアル（令和7年3月改訂）』第Ⅳ編「財務書類等活用の手引き」が挙げる分析指標を、原文の見出しから網羅すると以下のとおり（同PDF p.326〜p.338）：

| 分類 | 指標名（原文見出し） |
|---|---|
| （１）資産の状況 | 住民一人当たり資産額 |
| 〃 | 有形固定資産の行政目的別割合 |
| 〃 | 歳入額対資産比率 |
| 〃 | **有形固定資産減価償却率** |
| （２）資産と負債の比率 | 純資産比率 |
| 〃 | **社会資本等形成の世代間負担比率（将来世代負担比率）**＝地方債残高（臨財債等除く）÷有形・無形固定資産合計 |
| （３）負債の状況 | 住民一人当たり負債額 |
| 〃 | 業務・投資活動収支 |
| 〃 | 債務償還可能年数 |
| （４）行政コストの状況 | 住民一人当たり行政コスト 等 |
| （５）受益者負担の状況 | 受益者負担比率 |
| （６） | 指標の組み合わせ分析 |

**この一覧のどこにも「減価償却費に対する投資額（資産形成額）の比率」に相当する指標はない。**
また、依頼で例示された「資産形成度」「世代間公平性」という語は、**このマニュアルでは正式な指標名としては使われていない**（「資産形成度」の語はp.331に「資産形成度を示す住民一人当たり資産額と同様、…」という文脈で1度だけ現れるのみ。「世代間公平性」という語は正式指標名としては存在せず、対応するのは「社会資本等形成の世代間負担比率（将来世代負担比率）」）。

→ **議場では「国が定めた指標名はありません」と先に自分から言い切ったほうが強い。** 指標名を作らず、「国のマニュアルが言う"必要な投資が行われず老朽化対策が先送りされている可能性"を、決算書の数字で確かめただけです」と説明するのが最も反論されにくい。

### (c) 「そのような指標は国が定めていない」と反論された場合に示せる公的文言

執行部の反論は正しい（指標名は無い）。だから**指標名の争いに乗らず、以下3点で切り返す**。

**①「指標名の話ではなく、国が名指しした"視点"の話です」**
→ 引用①（マニュアルp.339）を読み上げる。「必要な投資が行われず、老朽化対策が先送りされている可能性」は総務省の原文。

**②「国が組み合わせろと言った2つの指標が、亀山では最悪の組み合わせになっています」**
→ 亀山市の令和6年度 財政状況資料集には、**市自身が書いた分析欄**に次の記述がある（原文引用）：
> 「将来負担比率については、比率としては生じておらず、地方債残高の減少等により改善しています。有形固定資産減価償却率は減少したものの、公共施設の老朽化が進んでいます。今後、中長期的な視点で施設の更新や統廃合、長寿命化等を検討しなければならないため、各種指標を精査した上で計画を策定、実施していかなければなりません。」
出典：三重県「令和6年度 財政状況資料集（亀山市）」シート「公会計指標分析・財政指標組合せ分析表」セルAN43
https://www.pref.mie.lg.jp/common/content/001217512.xlsx （三重県、取得日2026-09-17）
※この文章は**亀山市が作成し県・総務省を通じて公表しているもの**。市自身が「老朽化が進んでいる」と認めている一次情報であり、反論封じに使える。
※なお同欄の「有形固定資産減価償却率は減少したものの」という記述は、R5→R6で73.9%→75.6%と**上昇**している公表値と整合しない。この点は議場で確認する価値がある（後述「確認できなかったこと」参照）。

**③「単年度で判断していない、複数年度で見ています」（先回りの防御）**
→ 同マニュアルp.326の原文：
> 「なお、これらの指標については、全体の大まかな傾向を把握するためには有用ですが、単年度に発生した取引の影響で大きく数値が変動する場合があることなどから、複数年度の傾向を踏まえた分析を行うことなどに留意が必要です。」
→ 依頼元は9年平均44.7%を持っているので、この国の注意書きを**逆に自分の側の根拠として使える**。「国が複数年で見ろと言うから9年見ました。1年も100%を超えていません」という運び。

## 【3】類似団体平均との比較

### 結論：R6の財政状況資料集には、有形固定資産減価償却率以外の「資産の更新・老朽化に関わる公会計指標」の類似団体内平均は**掲載されていない**

令和6年度 財政状況資料集のシート「公会計指標分析・財政指標組合せ分析表」を、亀山市・名張市・鳥羽市・いなべ市・志摩市・伊賀市の6市すべてについてセル単位で走査した結果、**シート上部（1〜40行）は全市とも完全に空白**であり、記載されているのは下記2つの「組合せ分析」のみだった。

## この調査で確認できなかったこと（正直な記載）

1. **亀山市の令和7年度 財務書類4表は、市の公式サイトで未公表。** 依頼元の提示値（減価償却費3,204,258千円等）は本調査では一次情報で裏が取れていない。決算審査資料等が出所と思われるが、**議場で使う前に出所を1行明示できるようにしておくこと**を強く推奨する。R6値（本調査で実測・公表済）であれば一次情報で完全に裏が取れている。
2. **亀山市のH29末〜R2末の有形固定資産合計・減価償却費・有形固定資産等の増加**は本調査では取得していない（依頼元が9年分を保有しているため重複を避けた）。市サイトの各年度PDFから取得可能。
3. **亀山市の財政状況資料集 分析欄の「有形固定資産減価償却率は減少したものの」という記述と、同資料内の公表値（R5 73.9%→R6 75.6%＝上昇）が整合しない。** 誤記か、別の切り口（施設類型別など）を指しているのか、本調査では判断できなかった。**議場で「資料集の分析欄には減少したと書いてあるが、同じ資料の数値は上昇している。どちらが正しいのか」と問う価値がある**。
4. **減価償却費と資産形成額の比較を「指標」として明示的に扱った国の文書は、本調査の範囲（地方公会計マニュアル令和7年3月改訂版の全文＝21,179行をpdftotextで全文抽出のうえ横断検索）では発見できなかった。** 「更新投資」という語はマニュアル全文に1件も出現しない。
5. **令和6年度の財政状況資料集には、公会計指標（歳入額対資産比率・純資産比率・将来世代負担比率等）の当該団体値および類似団体内平均値が一切記載されていない**（6市とも該当行が空白）。過去年度（R3以前）の様式には掲載されていた可能性があるが、本調査では過年度様式を確認していない。**遡って比較したい場合は、令和3年度以前の財政状況資料集を確認する必要がある。**
6. **施設類型別ストック情報分析表（シートとしては存在する）は本調査で中身を確認していない。** 学校・公営住宅・道路等、施設類型別の有形固定資産減価償却率と類似団体平均が入っている可能性が高く、**「どの施設が特に古いか」を類似団体平均と比べて言うなら、ここが次の一手**。
