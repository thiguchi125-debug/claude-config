- JR西日本「輸送密度2,000人/日未満の線区別経営状況」毎年10月末ごろ公表（2025-10-29版：亀山〜加茂 収支率11.3%・978人/日）。PDFは pdftotext -layout で表が読める。
- 三重県「関西本線活性化利用促進三重県会議」ページ pref.mie.lg.jp/KOTSU/HP/m0009200213.htm に毎年の当日資料・議事概要・合意事項PDF。今後の取組の議題は非公開。
- 落とし穴：観光列車「はなあかり」(京都〜関)は奈良線経由とみられ草津線直通ではない。「急行平安」は議場発言のみで一次未確認。
- 草川はR8.6.15一般質問で草津線直通を質問済（市長「具現化できるよう考えたい」）。詳細は research_ledger/2026-09-28_独自政策_草津線直通_災害関連死_通院交通.md
