# jimuin-irai — 事務員（櫻井さん）への日ごとのお願い

## 何をするか
草川が言った「その日の段取り」を JSON 1枚に書き、`render.py` で公選法チェック → スマホ用ページを作り直し → 同じURLに更新する。
共通ルール（投稿の進め方・毎日の流れ・選挙のきまり）は `render.py` の定数で固定。日ごとのJSONからは消せない。

- ページURL（固定）: https://claude.ai/artifact/4tcKHuhrkqmh3dcZdJ8cPL （非公開。櫻井さんへの共有は草川が済み前提）
- データ: `~/outputs/sakurai_irai/days/<YYYY-MM-DD>.json`
- 出力: `~/outputs/sakurai_irai/index.html`（最新日が先頭、過去日は折りたたみ）
- 遊説コース原本: Drive `遊説コース2026/10/17.pdf`（id `13tZc3-lo5tn_F3s370ZO_zqqNOuopNm1`）。OCRが崩れているので時刻は**草川の言葉が正**。PDFは草川が「コースどおり」と言ったときだけ、その日の行だけ拾って時刻を草川に確認する

## 手順
1. **入力を集める**: 草川は思いつくまま話すだけでよい（音声入力の誤変換は地名をmemory/前日JSONとgrep突合）。毎回聞かずに埋めるもの＝勤務時間（下表）・遊説コース（PDF）・前日に撮って未編集の動画（前日JSONから引き継ぎ）。それでも空く必須3点＝①撮影する場所と時刻 ②事務所での作業と優先順 ③翌日の演説場所と時刻 → 足りないものだけ AskUserQuestion で1回に束ねて聞く。
1.5 **公開前に草川の確認を1回取る**: JSONを書いたら render.py --check を通し、チャットに「時刻つきの段取り5〜8行＋公選法チェック結果＋新しい種類の作業の有無」だけ出してOKをもらう。直しはその場で反映して再チェック。OK後に手順3へ。
2. **JSON を書く**（前日のファイルを `cp` して書き換えると早い）:
   ```json
   {"date":"2026-10-19","hours":"8:00〜17:00",
    "blocks":[{"title":"午前","sub":"櫻井さんの車で移動して撮影","items":[["8:00","みずきが丘ファミマ前で演説を撮影"]],"note":"任意"}],
    "todo_title":"夕方","todo_sub":"16:00〜17:00 事務所で作業",
    "todos":[{"text":"〇〇の演説動画を仕上げて投稿の準備","first":true},{"text":"20日の演説の場所と時間を知らせる画像を作る"}],
    "spots":{"label":"10月20日（火）の演説","items":[["8:00","亀山駅"]]},
    "extra":["任意の一言"]}
   ```
3. **生成とチェック**: `python3 ~/.claude/skills/jimuin-irai/render.py`
   - ERROR が出たら HTML は書かれない。**言い回しを「撮影する」「編集する」「画像を作る」「投稿の準備」「整える」に直す**。作業そのものが選挙運動（配る・呼びかける・頼む・訪問する等）なら書き換えで逃げず、草川に「事務員には頼めない」と返して止める。
   - 新しい種類の作業（これまでに無い動詞）が入った日は、公開前に `content-risk-reviewer` に「事務員の範囲か」だけ聞く（1回）。いつもの撮影・編集・告知画像・投稿準備だけなら render.py のチェックで足りる。
4. **公開**: Artifact publish `file_path=~/outputs/sakurai_irai/index.html`、`url=上の固定URL`。別セッションでは先に `action: read` でURLを読んでから publish（読まないと拒否される）。
5. **報告**: 「何日分を更新・チェックOK・リンク」の3行。LINE用の短文が要ると言われたら、ページの中身を文字で渡す。

## 公選法の固定ルール（render.py が止めるもの）
- 事務員がしない: 演説・あいさつ／マイク・呼びかけ／チラシ等の配布／投票・支持・拡散の依頼／電話作戦／握手・手振り／タスキ・のぼり等の着用／戸別訪問／署名・アンケート集め／飲食物の提供／演説の場での誘導・受付・動員・送迎／本人SNSでのシェア・応援／コメント返信／告知画像の印刷・掲示・個別送信／SMS／生配信で話す／情勢・人気投票
- 演説の場では撮影だけ。報酬は日額のみ（成果連動は不可）
- 投稿は24日23時までに終える（23時以降の時刻はWARN）
- 投稿文は草川が作る。事務員は「整える」（誤字・改行・ハッシュタグ）まで。AIは誤字・改行の点検だけ（10/17草川決定）。訴える中身・順番を変えさせない
- 自家用車に看板・ポスター・スピーカーを付けない（選挙運動に使える車は遊説車1台）
- 有料のネット広告は使わない／メールでの選挙運動は候補者・政党だけ
- 告示前（〜10/17）と投票日（10/25）以降は投稿・告知の作業を入れない。24日分には翌日（投票日）の演説告知を作らない
- 子どもを含む一般の方の顔はぼかすか使わない
- NGの正規表現は `render.py` の `NG`。漏れを見つけたらその場で1行足して、悪い例で止まるか確かめる
