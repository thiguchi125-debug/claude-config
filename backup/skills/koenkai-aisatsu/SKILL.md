# 後援会あいさつ管理

正本ファイル＝Drive `00_名簿・個人情報/後援会名簿_統合版_※個人情報注意_2026-10-27.xlsx`（154名・番号A01〜G26）。
操作はすべて `python3 ~/.claude/scripts/koenkai/aisatsu.py` 経由。xlsxを手で書き換えない（保存前のハッシュ確認を飛ばすことになる）。

| やりたいこと | コマンド |
|---|---|
| 挨拶漏れを見る | `aisatsu.py status` |
| 会った記録 | `aisatsu.py log <番号or氏名> <YYYY-MM-DD> <訪問/電話/会合/行事/LINE/その他> <内容1行>` |
| 印を付ける | `aisatsu.py mark ◎ A01,B03` ／ `mark ○ 町:中庄` ／ `mark △ G:E` ／ `mark - C05`（空欄に戻す） |

## 手順
1. 「昨日」「先週土曜」などは今日の日付から YYYY-MM-DD に直す。日付がなければ今日。
2. 名前は姓だけだと複数件に当たる（草川は35名）。スクリプトが「中止: 該当n件」を返したら候補を見せて1問で確認（AskUserQuestion）。推測で選ばない。
3. 1回の発言に複数人いれば、1人ずつ log を続けて実行する。
4. 最後に `status` の要点だけを返す。返す内容は、漏れの多い町の上位3つと、記録した人の新しい状態。
5. 「中止: Drive側でファイルが変わった」が出たら、そのまま再実行する（毎回最新版を読み直すので草川の手修正は消えない）。

## 判定のしくみ
- ◎は60日、○は120日、△は365日あいたら「漏れ」（赤）。期限まで14日以内は「もうすぐ」（黄）、それより先はOK（緑）。×は対象外、空欄は未判定（灰）。
- xlsx先頭の「挨拶漏れ」シートは、町ごとの漏れ件数を多い順に並べたボード。名簿シートの印・氏名・状態の欄も同じ色で塗られる。
- 間隔を変えたいと言われたら、スクリプト冒頭の `INTERVAL` を直して `refresh` する。

## 注意
- 個人情報。氏名をSNS・Notion・Todoistへ転記しない。
- 当選・落選後のお礼の戸別訪問は公選法178条で禁止。記録内容が「当選のお礼に回った」になっていたら、記録する前に一言注意する。
