## 🔴 大原則（他のすべてに優先）

1. **タスク・プロジェクトはTodoistが唯一のソース**。`python3 ~/.claude/scripts/todoist/td.py` のみ使用。Notionの旧✅タスクDB(292cf503系)・旧🗂️プロジェクトDBは廃止済み（🗄️旧アーカイブ収容）— **クエリ禁止**。
2. **チャット出力が主成果物**。Notionダッシュボードへの書込は3セクションのみ（§F）。ニュース・iJAMP・過去発言連動・Drive資料をダッシュボードに書くことは**ない**。
3. **リトライ規律**: Notion書込がtimeoutしても即リトライ禁止（適用済みの可能性大）。fetch確認→未適用の場合のみ1回だけ再試行。
4. ルーティンページ（`34acf503-`「📅毎日のルーティン（改訂版）」）には**一切書き込まない**（リセット処理は2026-05-08廃止済み）。
5. 日付・曜日は `date '+%Y-%m-%d (%a)'` で実確認してから使う（7/3を木曜と誤記した事故対策・全セクションで同一値を使う）。
6. **`notion-query-data-sources`（SQLモード）は使用禁止**。Businessプラン限定機能でブロックされる（2026-07-03実測）。使ってよいのは notion-fetch / notion-search / notion-query-database-view（view URL必須）のみ。ブロックに遭ったら「プラン制約」と騒がず、このルール違反を疑うこと。

### 🗓 【作業】枠 × Todoist期限の突合（2026-08-11新設・必須）

`task-add` は登録時に【作業】枠を作るが、**その後の期限変更・新規登録を追わない**。放置するとカレンダーが「枠を作った日のスナップショット」に化ける。2026-08-11に翌日分を実測したところ、幽霊枠4本・枠なし6件・時間衝突1件が同時に出ていた。

§3で取得済みの**本日のカレンダー**と、§5-1の `td.py morning`（本日期限ブロック）を突き合わせ、**ズレだけ**を出す。ゼロなら `✅ 枠と期限は一致` の1行で終える（一致リストを並べない）。

- **👻 幽霊枠** — 本日に【作業】枠があるのに、対応するTodoistタスクの期限が今日でない（枠のdescriptionの「Todoist期限」は作成時の値なので信用しない。**必ずTodoist側を正として引き直す**）。→「枠を消す／期限を今日へ戻す」を1件ずつ選択式で聞く。
- **🕳 枠なし** — 本日期限なのに、【作業】枠にも**束ね枠の中身リストにも**出てこない。→ 新規枠を作る前に、必ず**既存枠への相乗り**を先に提案する。
- **⚔️ 衝突** — 【作業】枠が実アポ（会議・来客・現地・議会公務）と時間で重なっている。→ 動かすのは常に【作業】側。

**判定はタイトルだけで済ませない。**「結果待ち催促A／B」「役所連絡タイム」「夜の連絡タイム」「現地ルート」のような束ね枠は、中身がdescriptionにしか書かれていない。descriptionを開かずに突合すると、束ねられている件を全部「枠なし」と誤検出し、逆に束ねから漏れた件を見逃す。

置き場所を決めるときの制約:
- @役所 → **市役所は17:00終業・12:00-13:00は昼休み**。この外に置いた枠は電話が繋がらない。
- @夜電話 → 18時以降。店舗・事業者への「出向く」用件を夜枠に入れない。
- @机上 → 早朝5:00-6:30が唯一安定して空く帯（[[feedback_early_morning_desk_band]]）。ただし**机上作業限定**で、電話・役所・現地は不可。
- 15:00-18:30は挨拶回り優先枠（[[feedback_greeting_rounds_time_reserve]]）。作業ブロックで埋めない。

束ね枠に相乗りさせたら、**枠のタイトルの件数（N件）も更新する**。中身だけ増やすと、翌朝の突合で「4件」と書かれた枠に7件入っている状態になり、容量超過が見えなくなる。想定所要の合計が枠の長さを超えるときは、descriptionの末尾に `※⚠️ 合計N件／M分。押したら〇〇へ送る` と逃がし先を明記する。
