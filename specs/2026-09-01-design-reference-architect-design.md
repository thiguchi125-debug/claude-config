`design-director` は据え置き、役割を分ける。
**design-director＝原則と理論で格上げ（勝負所）／design-reference-architect＝実物の参照から借りる（毎回）。**

## 3. ライブラリの構造

正本を `design_system/references/` に一本化。**旧 `design_references/` は 2026-09-01 廃止**（§6）。

```
design_system/references/
  _INDEX.md      全判型の索引
  _types.md      型カタログ（判型をまたぐ構図の台帳）＋5軸の判型別読み替え
  README.md      運用ルール・造形カルテ5軸・模写採点表・参照の質ゲート
  thumbnail/     サムネ・OGP 16:9      ← 2026-08-31 新設・実物12点
  trifold/ a4_flyer/ a4_report/ poster/ brand_system/
  _format_only/  様式の参考のみ。造形は借りない
  _dossiers/     テキストだけの調査記録。参照ではない
  （第3段で追加）sns_square/ vertical_9x16/ slide/ infographic/
```

### 3-1. 型カタログ `_types.md` が新概念

カルテが「この参照はこういう造形」を記録するのに対し、型カタログは
**判型をまたいで再利用できる構図に名前をつける**。サムネで効いた型が縦9:16でも効く、という横流用がここで起きる。

**複数案を出すときは型を変えて振る。同一骨格の文字量違いは1案と数える。**
（発端の3案が実質1案だったのは、これが無く「文字量」でしか振れなかったため）

### 3-2. 5軸は共通、測り方だけ判型で読み替える

| 軸 | 紙 | デジタル |
|---|---|---|
| ① 級数ジャンプ率 | 4〜8倍 | **実測1.5〜9.6倍。制度・数字ものは4〜7倍**（§7-3で訂正） |
| ② 色数と役割分担 | 共通 | 共通 |
| ③ 図形語彙 | 共通 | 共通 |
| ④ | 写真・図版の**占有率** | 写真の**処理法**。**「無加工ベタ置きは不可」は撤回**（§7-3） |
| ⑤ | イラスト・アイコン量 | **縮小時に残る要素数**（400pxで3つ以下） |

## 4. エージェントの動作

**必ずサブエージェントとして動かす。**参照画像も採点用スクショも親に残さないため。
（ただし §7-4 の制約あり）

| | やること |
|---|---|
| 0 | **受信箱の吸収** — 未処理を質ゲート→判型振り分け→カルテ→`_INDEX`→型カタログ。1回のデザイン仕事につき最大5件 |
| 1 | 判型を判定 |
| 2 | 型カタログから型を1本選ぶ。複数案なら型を変えて振る |
| 3 | **参照画像を自分でReadする**（1案1枚。カルテだけで済ませない） |
| 4 | **模写ブリーフを出力** → 実装者へ |
| 5 | 実装後のPNGを模写採点表で採点 → 5軸中4軸「可」未満は差し戻し |

**模写ブリーフの中身**：型名／参照ID／5軸の目標数値／使う図形語彙／**やらないこと**。

**実装者には「参照画像と自分の出力を並べて採寸比較し、差を数値で報告する」ことまで指示する。**
「参照から借りた」の自己申告だけでは部品貼りを検出できない（§7-1）。

## 5. Drive投函口（第2段）

草川の操作は**「撮ってマイドライブ直下に置く」だけ**。フォルダ分けもリネームもなし。

`_root_intake.py` の `classify_by_rule()` は
```python
if ext in PHOTO_EXT:
    return PHOTO_INBOX, "拡張子=写真"   # ← 中身を見る前に確定してしまう
```
で写真拡張子を**即決**し、`ask_llm()` に届かない。**今のままでは紙面写真は100%写真ストックに落ちる。**

- 写真拡張子を即決せず、**紙面らしさのVision判定を1バッチ**追加（現行 `ask_llm()` はテキストのみ・`--allowedTools ""`）
- 「印刷物・紙面を正面から撮ったもの」→ `🎨デザイン参照/00_受信箱/`、「人物・現場」→ 従来通り
- **confidence low は従来動作へ。捨てない・迷ったら現状維持**

**保存場所は分ける** — 参照画像の実体は Drive `🎨デザイン参照/`（claude-config が既に103M、references だけで7.7M。
6判型に広げると設定バックアップが太る）。カルテ・型カタログ・_INDEX は `~/.claude` 側（gitで版を追う）。
Drive Desktop 経由でローカルからReadできるので「画像を自分でReadする」鉄則は保てる。

**自動化しないもの**：判型の確定と質ゲート。目が要るので、次にデザイン仕事が走ったときに Step0 でまとめて処理する。

## 7. 実作業で判明したこと（本書の核心）

検討の途中で育休退園サムネを実際に作り直し、以下が実測で判明した。

### 7-1. 模写採点表は、参照が間違っていれば質を担保しない

サムネの参照が1枚も無い状態で、印刷物の参照（`brand01`＝Warren 2020 の**Tシャツ・缶バッジ・ヤードサインのムードボード**、
`rep10`＝A4縦の企業インフォグラフィック）を代用して実装した。結果、円・縦ストライプ・斜め面という
**「部品」だけを抜き出して16:9に貼った**面が出て、草川に「クズデザイン」と却下された。

**このとき模写採点表は5軸中5軸「可」で通っている。**
採点表は「間違ったものへの忠実度」を測るだけで、参照の適切さは測らない。

→ **判型フォルダが空なら、代用せずに先に集める。**恒久ルールとして
`feedback_reference_must_match_format.md` に記録済み。

### 7-2. 机上で作った「型の選び方」ルールが事故を起こした

参照が無いまま書いたルール「**写真がテーマと意味的に繋がらないなら T1/T2 を選んではいけない**」が誤りだった。
これが「だから写真なしで作る」と読み替えられ、幾何図形だけの面を生んだ。

政治サムネの実物12点を収集して調べると、**人物とテーマが繋がっている面は2点のみ。
残り9点は「ただ喋っている人」を端25〜35%に置いて成立**していた。ルールは撤回し
「繋がらなくても写真は外さない。T5 か T7 を選ぶ」に差し替えた。

→ **参照が無いまま型の選び方ルールを机上で作らない。実物を見てから書く。**

### 7-3. 借り先の変更と、5軸の実測訂正

草川の指定で借り先を「報道・出版のプロ面」→「他の政治家のサムネ」に変更。実物12点を採寸した結果：

- ①ジャンプ率「8〜15倍」→ **実分布1.5〜9.6倍**。制度・数字ものは4〜7倍が実態
- ④「無加工ベタ置きは不可」→ **撤回**。12点中3点が無加工の実写をそのまま置いて成立
- 「全面ブリード＋暗幕」は**紙の作法**。収集12点に暗幕は1点も無く、写真上の文字は全部が極太の縁取り

**質ゲートは判型ごとに違う。**「議員の自作紙面は採用不可」は紙のチラシの規則で、
サムネには適用しない（サムネは政治発信で最も競争が激しく、実際に強い運用がある）。

### 7-4. `image_budget_guard.py` はサブエージェントでも同じカウンタを共有する

セッションIDで画像枚数を数えており、**サブエージェントは親と同じセッションIDを使う**。
親のカウンタが上限に達すると委譲先も弾かれる。deny メッセージ自身が「サブエージェントに委譲しろ」と
案内するのに、その委譲先が同じ理由で止まる（自己矛盾）。

**本設計の「画像ループはサブエージェントに隔離する」という前提は、後半のセッションでは成立しない。**
長いセッションでデザイン作業に入る場合は、先に `/clear` するか
`~/.claude/hooks/state/<session_id>.imgcount` を消す必要がある。**要修理。**

### 7-5. 「中央1:1クロップで文字が欠けない」規則は斜め二分型と両立しない

`feed-visual-reviewer` A-3 の規則だが、採用した実物 `thm09` 自体がこの試験に落ちる
（中央1:1で「緊急」が丸ごと消える）。**文字を全部片側の色面に置く骨格である以上、構造的に無理。**
両立させると色面が72%まで膨らんで別物になる。

→ 型カタログに「斜め二分型は1:1クロップ規則の対象外。正方形が必要なら上下二分の別版を起こす」と記載する。

### 7-6. 安全ゲート2本は「文字の色の重み付け」を見ない

案Aで主見出しを `育休`＝緑／`退園`＝桃に振ったところ、**画面でいちばん強い文字が「退園」**になった。
`content-risk-reviewer` は「読者は情報が欠けると悪いほうに寄せて読む」を MEDIUM 指摘としていたのに、
色がその不安を増幅していた。**文言だけを見る2つのゲートは、どちらもこれを捕まえない。**

→ 模写採点に「**強調（色・級数）が、承認済み文言の意味と逆を向いていないか**」を軸として追加する。
