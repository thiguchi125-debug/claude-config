`design_system/references/_types.md` の5軸の数値は、**その判型の実物を採寸して初めて正本になる**。
実物に当たっていない欄は推定値として扱い、実測したら**訂正して注記を残す**。

**Why:** 2026-08-31にサムネ実物12点を採寸したところ、デジタル欄の既存値が2つとも誤りだった。
- ①級数ジャンプ率「8〜15倍」→ 実分布は 1.5〜9.6倍。制度・数字ものは **4〜7倍**、企画名を1語で立てるときだけ8〜10倍
- ④「無加工ベタ置きは不可」→ **撤回**。12点中3点が無加工の実写をそのまま置いて成立していた
  （条件＝人物を端25〜35%に寄せ、文字を反対側に置き、色面か額縁で写真の縁を締める）
- ついでに「全面ブリード＋暗幕」は**紙の作法**で、サムネの実物には1点も無かった（写真上の文字は全部が極太の縁取り）

いずれも印刷物から推定した値を判型をまたいで流用したもので、
これが「写真がテーマと合わないなら写真を外す」という誤った判断規則を生み、制作事故につながった。

**How to apply:** 新しい判型（`sns_square` / `vertical_9x16` / `slide` / `infographic` など）の
参照を初めて集めるときは、既存の型カタログの数値を出発点にしてよいが、**実測で必ず上書きする**。
訂正時は旧値を消さず「※印刷物由来・実物での裏付けなし」「※20XX-XX-XX訂正」を残し、
どの判断規則が誤りだったかまで書く（規則が生きたまま残ると事故が再発する）。
