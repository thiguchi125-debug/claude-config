`~/.claude/scripts/feed_preview.py still` が 1600×900 に対して出す2つの矩形は別物。混同すると指摘のpx値が間違う。

- **実際の1:1中央クロップ**（Yahoo・LINEダイジェスト・Google検索モバイルのパネル）＝ **x350〜1250**（900×900をセンターで抜く）。ここから外れた文字は配信面で実際に切れる。
- **レポート表示の「安全域」**＝ さらに `SAFE_SHRINK = 0.89` を掛けた **x400〜1200 / y50〜850**。実クロップに4%ずつの余裕を見た推奨枠であって、切れる境界ではない。

**How to apply:** 「切れている」と断定してよいのは x350 未満／x1250 超に文字がかかっているときだけ。x350〜400 や x1200〜1250 にかかる要素は「切れる」ではなく「余裕2px級の脆さ」として指摘する。CSS の left/right とフォントサイズから文字ブロックの右端を自分で計算し、コンタクトシートの1:1パネルの見た目と突き合わせて確認する。

`CROPS` は 1:1 / 1.91:1 / 4:3 の3種。下端ノーテキスト帯は y792〜900（下端12%）。
